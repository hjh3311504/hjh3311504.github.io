## 재생

0.3·1·2배속 모두 같은 파일을 원래 속도와 음정으로 재생한다. 재생 제한과 화면 범위 처리는 게임 코드에서 관리한다. 선택된 파일과 원본 해시는 정적 음원 폴더의 JSON에서 확인한다.
