# REQ-WEB-024 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 오늘 기록이 없을 때 | 오늘 기록 지우기 버튼을 숨김 |
| 오늘 기록 지우기 실행 | 대상 경기 수와 "기록 보기에는 그대로 남습니다."를 확인 dialog로 알림 |
| 확인 뒤 | 오늘 목록만 비우고 경기 수를 0경기로 바꿈 |
| 지운 뒤 통계 영역 | 카드와 기록 보기 버튼을 계속 보여 주어 전체 기록에 갈 수 있음 |
| 지운 뒤 기록 보기 | 지운 기록이 날짜별 목록에 그대로 남아 있음 |
| 지운 뒤 새 경기 기록 | 지우기 시각보다 나중이라 오늘 목록에 다시 나타남 |
| 지운 뒤 참가자 통계 | 지운 기록도 승패·당첨 집계에 그대로 들어감 |
