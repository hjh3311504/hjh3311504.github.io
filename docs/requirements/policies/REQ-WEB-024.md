# REQ-WEB-024 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 오늘 기록이 없을 때 | 초기화 버튼을 숨김 |
| 오늘 기록 초기화 실행 | 대상 경기 수와 "전체 기록에는 그대로 남습니다."를 확인 dialog로 알림 |
| 확인 뒤 | 오늘 목록만 비우고 경기 수를 0경기로 바꿈 |
| 지운 뒤 오늘의 기록 영역 | 카드와 전체 기록 버튼을 계속 보여 주어 저장된 기록에 갈 수 있음 |
| 지운 뒤 전체 기록 | 지운 기록이 날짜별 목록에 그대로 남아 있음 |
| 지운 뒤 새 경기 기록 | 지우기 시각보다 나중이라 오늘 목록에 다시 나타남 |
| 지운 뒤 참가자 통계 | 화면에 보이는 오늘 기록만 세므로 초기화한 기록은 집계하지 않음 |
