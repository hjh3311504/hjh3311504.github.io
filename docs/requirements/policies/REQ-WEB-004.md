# REQ-WEB-004 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 참가자 4명, 팀 수 2 | 2명, 2명으로 배정 |
| 참가자 5명, 팀 수 2 | 3명, 2명으로 배정 |
| 참가자 8명, 팀 수 3 | 3명, 3명, 2명으로 배정 |
| 같은 팀 규칙이 있는 참가자 2명 | 두 참가자를 같은 팀에 배정 |
| 다른 팀 규칙이 있는 참가자 3명, 팀 3개 | 세 참가자를 서로 다른 팀에 배정 |
| 같은 팀 규칙과 다른 팀 규칙이 충돌 | 결과를 만들지 않고 충돌 이유 표시 |
| 규칙을 만족하는 배정을 찾을 수 없음 | 결과를 만들지 않고 규칙이나 팀 수를 고치라는 안내 표시 |
