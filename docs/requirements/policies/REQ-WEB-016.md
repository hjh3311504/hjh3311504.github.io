# REQ-WEB-016 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 2팀 결과에서 1팀 승리 선택 | 1팀은 승, 2팀은 패로 표시하고 시각·순위·팀 전체 명단과 함께 기록 |
| 3팀 이상 결과에서 순위 버튼 선택 | 고른 팀에 다음 등수를 부여하고 남은 팀 버튼을 그다음 등수 버튼으로 바꿈 |
| 순위를 부여한 팀 | 순위 버튼 대신 뽑기 버튼을 보여 줌 |
| 순위 취소 | 마지막으로 부여한 등수를 한 단계 되돌리고 그 팀의 당첨자를 지움 |
| 남은 순위가 없을 때 취소 | 방금 만든 승패 기록을 통째로 지우고 결과 카드를 기록 전 상태로 복구 |
| 오늘 기록 보기 | 결과 아래 `4. 오늘의 기록`에서 오늘 기록을 먼저 보여 줌 |
| 전체 기록 열기 | `경기 기록` 탭에서 저장된 기록을 날짜별로 묶어 표시하고 `전체 통계` 탭으로 이동할 수 있음 |
| 기록 한 건 삭제 | 확인 dialog를 거친 뒤 해당 기록만 삭제 |
