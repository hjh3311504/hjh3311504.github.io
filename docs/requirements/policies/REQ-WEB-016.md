# REQ-WEB-016 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 결과에서 1팀 승리 선택 | 1팀은 승, 나머지 팀은 패로 표시하고 시각·팀 전체 명단과 함께 기록 |
| 승리를 기록한 직후 승리 취소 | 방금 추가한 승패 기록을 지우고 결과 카드를 기록 전 상태로 복구 |
| 오늘 기록 열기 | 오늘 기록을 먼저 보여주고 전체 기록 dialog에서 날짜별로 묶어 표시 |
| 기록 한 건 삭제 | 확인 dialog를 거친 뒤 해당 기록만 삭제 |
| 이미 승리를 기록한 결과 | 다른 팀의 승리 버튼을 숨겨 같은 결과의 중복 승리 기록 방지 |
