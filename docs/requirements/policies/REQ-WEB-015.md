# REQ-WEB-015 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 처음 방문하고 저장값 없음 | 팀 수 방식, 팀 수 2개, 팀당 인원 2명을 기본값으로 사용 |
| 참가자 10명, 팀 수 3 | 3개 팀 생성, 팀별 인원 차이 최대 1명 |
| 참가자 10명, 팀당 4명 | `ceil(10 / 4)`에 따라 3개 팀 생성 |
| 참가자 5명, 팀당 4명 | `ceil(5 / 4)`에 따라 2개 팀 생성 |
| 참가자 3명, 팀 수 4 | 팀 만들기 비활성화와 참가자보다 팀 수가 많다는 안내 |
| 참가자 3명, 팀당 4명 | 팀 만들기 비활성화와 참가자보다 팀당 인원이 많다는 안내 |
