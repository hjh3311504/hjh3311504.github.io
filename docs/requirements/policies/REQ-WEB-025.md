# REQ-WEB-025 정책 예제

참가자 통계 dialog는 오늘 기록만 셉니다. 전체 기록은 기록 보기 위쪽의 전체 통계에서 봅니다.

| 입력 | 기대 결과 |
|---|---|
| 오늘 기록이 없을 때 | 빈 안내만 보여 주고 순위·표를 숨기며 전체 통계는 기록 보기에 있다고 알림 |
| 어제 경기가 있고 오늘 경기도 있을 때 | 참가자 통계는 오늘 것만 세고, 기록 보기 전체 통계는 두 날을 모두 셈 |
| 오늘 기록을 화면에서 지운 뒤 | 참가자 통계도 비고, 기록 보기 전체 통계는 그대로 남음 |
| 최다 승리 | 1등 팀에 있었던 횟수가 가장 많은 사람과 횟수를 보여 줌 |
| 최다 당첨 | 돌림판에 뽑힌 횟수가 가장 많은 사람과 횟수를 보여 줌 |
| 최다 패배 | 마지막 등수 팀에 있었던 횟수가 가장 많은 사람을 보여 주고 3팀 이상은 마지막 순위를 패로 센다고 알림 |
| 순위가 아직 다 안 정해진 경기 | 마지막 등수가 없으므로 패로 세지 않음 |
| 같은 팀 궁합 | 같은 팀이 2번 이상이었던 조합만 승률 높은 순으로 보여 줌 |
| 한 팀에 같은 이름이 두 번 | 한 명으로 세고 자기 자신과의 궁합은 만들지 않음 |
| 횟수가 같을 때 | 이름 오름차순으로 정렬하고 공동 순위면 인원 수를 함께 적음 |

## 기록 보기의 전체 통계

| 입력 | 기대 결과 |
|---|---|
| 기록이 하나도 없을 때 | 전체 통계 영역을 통째로 숨김 |
| 기록이 있을 때 | 전체 경기 수, 기록한 날 수, 참가자 수를 먼저 보여 줌 |
| 승률 순위 | 많이 이긴 순으로 최대 8명까지 이름·승률 막대·`3승 0패 · 100%`를 함께 보여 줌 |
| 막대만으로 읽기 어려운 경우 | 막대 옆에 승·패와 백분율을 글로 적어 색과 길이 없이도 읽을 수 있음 |
