# REQ-WEB-025 정책 예제

참가자 통계 dialog는 오늘 기록만 셉니다. 저장된 모든 기록은 전체 기록 dialog의 전체 통계 탭에서 봅니다.

| 입력 | 기대 결과 |
|---|---|
| 오늘 기록이 없을 때 | `오늘의 기록이 없습니다.`만 보여 주고 순위·표를 숨김 |
| 어제 경기가 있고 오늘 경기도 있을 때 | 참가자 통계는 오늘 것만 세고, 전체 기록의 전체 통계는 두 날을 모두 셈 |
| 오늘 기록을 화면에서 지운 뒤 | 참가자 통계도 비고, 전체 기록의 전체 통계는 그대로 남음 |
| 최다 승리 | 1등 팀에 있었던 횟수가 가장 많은 사람과 횟수를 보여 줌 |
| 최다 당첨 | 돌림판에 뽑힌 횟수가 가장 많은 사람과 횟수를 보여 줌 |
| 최다 패배 | 1등이 아닌 팀에 있었던 횟수가 가장 많은 사람을 보여 주고 3팀 이상은 2등부터 모두 패로 센다고 알림 |
| 3팀 이상에서 1등만 정해진 경기 | 1등 팀은 승, 나머지 팀은 아직 세부 등수가 정해지지 않았어도 모두 패로 셈 |
| 유효한 1등이 없는 기록 | 어느 팀도 승이나 패로 세지 않음 |
| 이전 형식의 3팀 이상 기록 | 유효한 승리 팀을 1등으로 보고 나머지 팀을 모두 패로 다시 계산 |
| 베스트 팀 조합 | 같은 팀이 2번 이상이었던 조합만 1등 확률 높은 순으로 보여 주되 `승리` 문구는 유지 |
| 한 팀에 같은 이름이 두 번 | 한 명으로 세고 자기 자신과의 궁합은 만들지 않음 |
| 횟수가 같을 때 | 이름 오름차순으로 정렬하고 공동 순위면 인원 수를 함께 적음 |

## 전체 기록의 전체 통계

| 입력 | 기대 결과 |
|---|---|
| 기록이 하나도 없을 때 | 전체 통계 영역을 통째로 숨김 |
| 기록이 있을 때 | 전체 경기 수, 기록한 날 수, 참가자 수를 먼저 보여 줌 |
| 1등 횟수 순 | 많이 이긴 순으로 최대 8명까지 이름·1등 확률 막대·`3승 0패 · 100.0%`를 함께 보여 줌 |
| 1등 확률순 | 참가 경기 중 1등을 한 비율이 높은 참가자부터 보여 줌 |
| 당첨순 | 누적 당첨 횟수가 많은 참가자부터 보여 줌 |
| 참가자 검색 | 이름에 검색어가 들어간 참가자만 보여 줌 |
| 같은 값일 때 | 1등 횟수, 참가 경기 수, 이름 오름차순을 차례로 적용 |
| 막대만으로 읽기 어려운 경우 | 막대 옆에 승·패와 백분율을 글로 적어 색과 길이 없이도 읽을 수 있음 |
| 백분율 계산 | `1등 횟수 ÷ 참가 경기 수 × 100`을 소수점 첫째 자리까지 반올림해 표시 |
| 전체 통계 안내 | `막대와 백분율은 1등 확률입니다. 3팀 이상 경기에서는 2등부터 모두 패로 셉니다.`를 표시 |
