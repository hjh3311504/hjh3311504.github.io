# REQ-WEB-014 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 선택된 참가자 1명 | 규칙 추가 비활성화와 “두 명 이상 골라 주세요” 안내 |
| 가, 나, 다를 같은 팀으로 지정 | 세 참가자를 하나의 묶음으로 배정 |
| 가, 나, 다를 다른 팀으로 지정 | 세 참가자를 서로 다른 팀으로 배정 |
| 같은 참가자 조합에 같은 팀과 다른 팀 규칙을 함께 지정 | 팀 생성 실패와 규칙 충돌 안내 |
| 같은 팀 묶음의 인원이 한 팀 정원보다 큼 | 팀 생성 실패와 정원 초과 안내 |
| 참가자를 제외하거나 삭제 | 해당 참가자는 새 규칙 선택 목록에서 빠지고 삭제한 참가자가 든 기존 규칙은 정리됨 |
