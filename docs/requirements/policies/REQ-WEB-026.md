# REQ-WEB-026 사용 안내와 FAQ

## 표시 순서

1. `3단계로 팀 나누기`
2. `이럴 때 사용하세요`
3. `팀 메이커의 주요 기능`
4. `자주 묻는 질문`
5. 만든 사람과 브라우저 저장 안내

모든 내용은 도구와 오늘 기록 뒤에 정적 HTML로 표시한다. 접힌 내용도 페이지 HTML에 그대로 있어야 한다.

## 문구

문구와 질문·답변은 `docs/design/screens/SCR-WEB-001.md`의 `고정 안내 문구`를 그대로 사용한다.

## 구조

- 페이지 전체의 `h1`은 하나다.
- 안내 묶음 제목은 `h2`를 사용한다.
- FAQ 질문 6개는 각각 `h3`를 사용한다.
- 사용법은 순서가 있는 목록을 사용한다.
- 활용 상황과 주요 기능은 넓은 화면에서 2열, 좁은 화면에서 1열로 표시한다.
- 4개 안내 섹션은 각각 기본 펼침 상태로 표시한다.
- 각 섹션 제목을 누르면 해당 섹션만 접거나 다시 펼칠 수 있어야 한다.
- 브라우저가 제공하는 접근 가능한 접기·펼치기 동작을 사용한다.
- `FAQPage` 구조화 데이터는 추가하지 않는다.
- Team Maker 전용 CSS의 `px` 글자 크기는 모두 짝수로 사용한다.
