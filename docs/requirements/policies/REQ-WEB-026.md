# REQ-WEB-026 사용 안내와 FAQ

## 표시 순서

1. `3단계로 팀 나누기`
2. `이럴 때 사용하세요`
3. `팀 메이커의 주요 기능`
4. `자주 묻는 질문`
5. 만든 사람과 브라우저 저장 안내

모든 내용은 도구와 오늘 기록 뒤에 정적 HTML로 표시한다. JavaScript를 끄거나 FAQ를 누르지 않아도 전체 내용을 읽을 수 있어야 한다.

## 문구

문구와 질문·답변은 `docs/design/screens/SCR-WEB-001.md`의 `고정 안내 문구`를 그대로 사용한다.

## 구조

- 페이지 전체의 `h1`은 하나다.
- 안내 묶음 제목은 `h2`를 사용한다.
- FAQ 질문 6개는 각각 `h3`를 사용한다.
- 사용법은 순서가 있는 목록을 사용한다.
- 활용 상황과 주요 기능은 넓은 화면에서 2열, 좁은 화면에서 1열로 표시한다.
- 별도 열기·닫기 버튼과 `FAQPage` 구조화 데이터는 추가하지 않는다.
