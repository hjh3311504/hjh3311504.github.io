# REQ-WEB-002 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 한 명 추가에 ` 민수 ` 입력 | `민수` 1명 추가 |
| 일괄 추가에 `민수\n영희` 입력 | 민수, 영희 2명 추가 |
| 일괄 추가에 `민수, 영희` 입력 | 민수, 영희 2명 추가 |
| 일괄 추가에 ` 민수 \n\n 영희 ` 입력 | 빈 이름과 공백을 버리고 민수, 영희 2명 추가 |
| 일괄 추가에 `민수\n민수` 입력 | 같은 이름을 별도 참가자 2명으로 추가하고 중복 안내 표시 |
| 전체 4명 중 1명 제외 | 전체 4명과 참가 3명을 함께 표시 |
