# REQ-WEB-023 정책 예제

| 입력 | 기대 결과 |
|---|---|
| 2팀에서 1팀 승리 | `1팀승`·`2팀패`로 적고 등수 표기는 쓰지 않음 |
| 3팀에서 2팀을 1등으로 선택 | 2팀 카드 칩을 `1등`으로 적고 나머지 두 팀 버튼을 `2등`으로 바꿈 |
| 3팀에서 3팀을 2등으로 선택 | 3팀 카드 칩을 `2등`으로 적고 남은 1팀을 자동으로 `3등`으로 확정 |
| 같은 결과를 오늘 기록에서 볼 때 | 팀 이름이 따로 없으므로 `1팀 3등`처럼 팀 이름과 등수를 함께 적음 |
| 4팀에서 1등과 2등만 선택 | 남은 두 팀은 `순위 미정`으로 두고 3등 버튼을 계속 보여 줌 |
| 순위가 정해진 팀 색 | 1등은 파랑, 마지막 등수는 빨강, 중간 등수는 주황에서 빨강 쪽으로 단계를 줌 |
| 색을 못 보는 경우 | 칩에 `2등`처럼 등수 숫자가 글로 적혀 있어 순위를 알 수 있음 |
