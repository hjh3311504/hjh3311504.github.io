# REQ-WEB-017 정책 예제

당첨자 목록은 팀 카드 안이 아니라 결과 격자 아래 별도 영역에 팀별로 모아 둡니다.

| 입력 | 기대 결과 |
|---|---|
| 순위를 받기 전 결과 | 팀별 추첨 버튼을 표시하지 않음 |
| 순위를 받은 팀의 추첨 실행 | 아직 안 뽑힌 사람 중 한 명을 같은 확률로 선택해 당첨자 목록에 추가 |
| 한 번 더 뽑기 | 이미 당첨된 사람을 뺀 나머지로만 돌림판을 다시 그리고 뽑음 |
| 팀원을 모두 뽑음 | 뽑기 버튼을 비활성화하고 더 뽑을 수 없다고 알림 |
| 당첨자 한 명 취소 | 그 당첨자만 목록에서 지우고 돌림판 후보로 되돌림 |
| 당첨자 지우기 | 그 팀의 당첨자를 모두 지우고 돌림판을 팀 전체 명단으로 되돌림 |
| 돌림판 회전 중 | 아무 소리도 내지 않음 |
| 판이 멈춘 직후 | 당첨 팡파르만 울림 |
| 효과음 끄기 | 추첨 애니메이션은 유지하고 효과음만 재생하지 않으며 설정을 브라우저에 저장 |
