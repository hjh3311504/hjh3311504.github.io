# REQ-WEB-027 개인정보처리방침과 광고 상태

- 2026-10-15부터 공개 위치는 `/privacy` route다. 이전 모달은 제거한다. 모든 공개 페이지 footer에 `소개·문의`(`/about`)와 `개인정보처리방침`(`/privacy`) 링크를 두고 그다음에 `© 2026 Lake's develog`를 표시한다. 좁은 화면도 같은 순서로 줄바꿈한다. 화면 구성은 `SCR-WEB-007`을 따른다.
- 운영자는 Lake로 표시한다. 최초 적용일은 2026년 9월 11일이며 처리 방식이 바뀌면 내용과 적용일을 함께 갱신한다. 현재 적용일은 2026년 10월 15일이다.
- 참가자·참가 여부·규칙·저장 명단·경기 기록·설정과 테마·메뉴 고정은 브라우저 localStorage에 저장한다. 운영자 서버로 전송하지 않는다.
- 사용자가 삭제하거나 브라우저가 저장 공간을 정리할 때까지 보관한다. 다른 기기 동기화와 운영자의 조회·복구를 제공하지 않는다.
- 현재 참가자 삭제와 저장 명단·경기 기록 삭제를 구분한다. 전체 삭제는 브라우저 설정의 사이트 데이터 삭제로 안내한다.
- 사이트와 글꼴은 GitHub Pages에서 직접 제공한다. 외부 글꼴 CDN을 사용하지 않는다. GitHub Pages 접속에 따른 정보 전달을 안내하고 GitHub 개인정보처리방침을 연결한다. 문의는 이메일(`src/lib/data/meta.js`의 `contactEmail`)과 공개 GitHub 제보 창구를 함께 안내한다. GitHub에 공개될 수 있는 정보와 문의 이용 목적을 안내한다.
- 2026-10-15부터 홈·도구3개·블로그 목록·공개 글·소개의 production HTML `<head>`에 AdSense 코드(`adsbygoogle.js?client=`)를 1회 넣는다. 게시자 ID는 `static/ads.txt`와 같아야 한다. `/privacy`, 404·동적 오류 화면, 초안·예약 글과 개발 서버에는 넣지 않는다. `/privacy`는 Google CMP 동의 메시지에 연결하므로 동의가 필요한 광고 코드를 두지 않는다. 대상 경로는 방문 통계의 공개 경로 목록을 재사용한다.
- 승인 전에는 수동 광고 칸을 만들지 않는다. 방침에는 Google·제3자 광고 공급업체의 쿠키 사용, 맞춤 광고 해제(Google 광고 설정·aboutads.info)와 Google 파트너 사이트 데이터 이용 안내를 적는다. 유럽 등 동의가 필요한 지역의 동의 창은 AdSense 계정의 Google CMP 설정으로 제공한다. 방문 통계는 아래 Cloudflare 수집 규칙을 따른다.
- 개인정보처리방침은 키보드로 접근할 수 있고 밝은·어두운 테마와 모바일에서 읽을 수 있어야 한다.

## 구슬 레이스 추가

- 적용일: 2026-09-16. 구슬 레이스 footer에도 같은 방침을 연결한다.
- 경기 시작 시 명단과 맵·당첨 방식·소리 설정을 localStorage에 저장한다. 경기 결과는 저장하지 않는다.
- 브라우저의 사이트 데이터 삭제로 지우며 참가자 정보와 효과음은 외부 서버로 전송하지 않는다.

## Cloudflare 방문 통계 수집

- 적용일: 2026-10-09. 사용자 승인에 따라 GA4를 Cloudflare Web Analytics로 교체한다. 이전 결정은 ADR로 보존한다.
- 공개 사이트 토큰과 HTTPS 운영 주소가 설정된 production build에서만 활성화한다. 홈·도구3개·블로그 목록·공개 글을 포함한다. 공개 글 목록은 build 시 확정한다. 초안·예약 글·개발·preview·직접 진입 오류 화면은 제외한다.
- 공식 beacon을 문서마다1회 연결하고 SPA 자동 측정을 사용한다. 직접 조회 요청을 만들거나 Google 태그를 함께 실행하지 않는다. query·hash 이동의 집계 기준은 공식 태그를 따른다.
- 공개 경로와 수집 제외 경로 사이의 이동은 양방향 모두 새 문서를 연다. 제외 화면에서 공개 페이지로 진입한 뒤 뒤로 가도 제외 주소가 자동 측정되지 않아야 한다. 태그가 시작된 뒤 오류 화면에 도달하면 문서를 새로 열어 태그를 제거한다.
- 허용·거부 버튼과 별도의 상단 통계 안내는 표시하지 않는다. 수집 설명과 현재 수집 상태는 `/privacy`에 둔다. 홈페이지에 통계 숫자와 관리자 화면을 추가하지 않는다.
- 기존 localStorage의 거부 선택은 유지하며 Cloudflare 태그도 요청하지 않는다. 기존 허용 방문도 쿠키 없이 측정한다. 이전 GA 쿠키만 삭제하고 도구 데이터는 보존한다. 다른 탭에서 기존 선택이 바뀌면 새로고침으로 반영한다.
- 페이지·유입 주소와 기기·브라우저·성능 정보를 처리한다. 공식 태그가 주소의 query·hash를 제외한다. 외부 유입 경로를 도메인으로만 한정한다고 안내하지 않는다. 참가자·QR 입력·팀 구성·저장 데이터를 전송하지 않는다.
- 방문 횟수와 페이지 조회수를 구분하며 고유 사람 수를 보장하지 않는다. Cloudflare에서 최근6개월의 데이터를 조회할 수 있다고 안내한다. 과거 GA4 집계는 이전하거나 자동 삭제하지 않는다.
- 토큰 미설정과 스크립트 차단이 도구를 방해하지 않아야 한다. 자동 검사는 외부 요청을 차단하며 운영 집계 완료와 구분한다.
- 설치·보고서 확인·수집 중단·검증 절차는 README를 따른다.
