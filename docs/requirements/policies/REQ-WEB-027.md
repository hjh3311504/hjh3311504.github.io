# REQ-WEB-027 개인정보처리방침과 광고 상태

- 공개 위치는 새 route가 아닌 모달이다. 홈 footer와 Team Maker 안내 마지막의 버튼에서 연다.
- 운영자는 Lake로 표시한다. 최초 적용일은 2026년 9월 11일이며 처리 방식이 바뀌면 내용과 적용일을 함께 갱신한다.
- 참가자·참가 여부·규칙·저장 명단·경기 기록·설정과 테마·메뉴 고정은 브라우저 localStorage에 저장한다. 운영자 서버로 전송하지 않는다.
- 사용자가 삭제하거나 브라우저가 저장 공간을 정리할 때까지 보관한다. 다른 기기 동기화와 운영자의 조회·복구를 제공하지 않는다.
- 현재 참가자 삭제와 저장 명단·경기 기록 삭제를 구분한다. 전체 삭제는 브라우저 설정의 사이트 데이터 삭제로 안내한다.
- GitHub Pages와 jsDelivr 접속에 따른 정보 전달을 안내하고 각 개인정보처리방침을 연결한다. 문의는 기존 공개 GitHub 제보 창구를 사용하며 공개될 수 있는 정보와 문의 이용 목적을 안내한다.
- 현재 Google 광고와 별도 방문자 분석 코드는 실행하지 않는다. 광고 도입 전 방침을 갱신하고 필요한 동의 절차를 마련한다. 미래의 광고 처리를 현재 수집처럼 표현하지 않는다.
- 홈, Team Maker, 404와 동적 오류 화면에서 광고 코드를 실행하지 않는다. 소유권 확인에는 기존 ads.txt를 사용하며 실제 계정의 게시자 ID와 일치하는지는 재심사 전에 확인한다.
- 개인정보처리방침은 키보드로 접근할 수 있고 밝은·어두운 테마와 모바일에서 읽을 수 있어야 한다. 닫기 버튼, Escape와 모달 바깥 영역 클릭으로 닫고, 닫으면 연 버튼에 초점을 돌린다.
