# REQ-WEB-027 개인정보처리방침과 광고 상태

- 공개 위치는 새 route가 아닌 모달이다. 홈·QR 코드·Team Maker·구슬 레이스·블로그 footer의 버튼에서 연다. 도구3개는 같은 공용 footer를 사용한다. 모든 페이지에서 개인정보처리방침 버튼 다음에 `© 2026 Lake's develog`를 표시하며 좁은 화면도 같은 순서로 줄바꿈한다.
- 운영자는 Lake로 표시한다. 최초 적용일은 2026년 9월 11일이며 처리 방식이 바뀌면 내용과 적용일을 함께 갱신한다.
- 참가자·참가 여부·규칙·저장 명단·경기 기록·설정과 테마·메뉴 고정은 브라우저 localStorage에 저장한다. 운영자 서버로 전송하지 않는다.
- 사용자가 삭제하거나 브라우저가 저장 공간을 정리할 때까지 보관한다. 다른 기기 동기화와 운영자의 조회·복구를 제공하지 않는다.
- 현재 참가자 삭제와 저장 명단·경기 기록 삭제를 구분한다. 전체 삭제는 브라우저 설정의 사이트 데이터 삭제로 안내한다.
- 사이트와 글꼴은 GitHub Pages에서 직접 제공한다. 외부 글꼴 CDN을 사용하지 않는다. GitHub Pages 접속에 따른 정보 전달을 안내하고 GitHub 개인정보처리방침을 연결한다. 문의는 기존 공개 GitHub 제보 창구를 사용하며 공개될 수 있는 정보와 문의 이용 목적을 안내한다.
- 현재 Google 광고는 실행하지 않는다. 방문 통계는 아래 GA4 수집 규칙을 따른다. 광고 도입 전 방침을 갱신하고 필요한 동의 절차를 마련한다. 미래의 광고 처리를 현재 수집처럼 표현하지 않는다.
- 홈, Team Maker, QR 코드, 404와 동적 오류 화면에서 광고 코드를 실행하지 않는다. 소유권 확인에는 기존 ads.txt를 사용하며 실제 계정의 게시자 ID와 일치하는지는 재심사 전에 확인한다.
- 개인정보처리방침은 키보드로 접근할 수 있고 밝은·어두운 테마와 모바일에서 읽을 수 있어야 한다. 닫기 버튼, Escape와 모달 바깥 영역 클릭으로 닫고, 닫으면 연 버튼에 초점을 돌린다.

## 확인 근거

- [Google 개인정보 공개 정책](https://support.google.com/publisherpolicies/answer/10437794?hl=en)
- [Google 사이트 연결 안내](https://support.google.com/adsense/answer/7584263?hl=ko)
- [GitHub 개인정보처리방침](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

- QR 북마크의 주소·텍스트·제목은 브라우저에만 저장한다. 저장하지 않은 입력은 남기지 않는다. 북마크 삭제 기능을 제공한다.

## 구슬 레이스 추가

- 적용일: 2026-09-16. 구슬 레이스 footer에도 같은 방침 모달을 연결한다.
- 경기 시작 시 명단과 맵·당첨 방식·소리 설정을 localStorage에 저장한다. 경기 결과는 저장하지 않는다.
- 브라우저의 사이트 데이터 삭제로 지우며 참가자 정보와 효과음은 외부 서버로 전송하지 않는다.

## GA4 방문 통계 수집

- 적용일: 2026-09-29. 사용자가 승인한 구현 프롬프트에 따라 홈페이지의 통계 공개 없이 GA4로 수집한다.
- 측정 ID와 HTTPS 운영 주소가 설정된 production build에서만 활성화한다. 개발·preview·오류 화면과 공개 route 외의 경로는 수집하지 않는다.
- 페이지 상단의 일반 문서 흐름에 쿠키 없는 수집 안내만 표시한다. 허용·거부 버튼과 쿠키 기반 측정 전환은 제공하지 않는다. 홈페이지의 통계 숫자와 관리자 화면은 추가하지 않는다.
- Google 태그 실행 전에 분석 저장 동의를 항상 `denied`로 설정한다. 기존 허용 기록이 있어도 쿠키 없이 측정하고 현재 호스트의 기존 분석 쿠키를 삭제한다.
- 기존 localStorage의 거부 선택은 유지하며 이 경우 Google 태그와 통계를 요청하지 않는다. 다른 탭의 기존 설정 변경도 반영하고 거부 시 대기 중인 조회와 이후 전송을 차단한다. 과거 집계가 자동 삭제된다고 안내하지 않는다.
- 페이지 조회는 공통 layout의 페이지 이동 완료 지점에서1회 전송한다. 새로고침은 새 조회이며 같은 경로의 query·hash 변경은 제외한다. 관리 화면의 향상된 측정은 전체 끈다.
- 페이지 주소는 공개 route만, 제목은 고정 문구만 사용한다. query·hash와 사용자 입력을 제외한다. 외부 유입은 도메인까지만 사용한다. 참가자·QR 입력·팀 구성·저장 데이터를 전송하지 않는다.
- 광고 관련 동의는 항상 거부하며 Google 신호와 광고 개인 최적화를 끈다. 관리 설정에서도 광고 연동과 불필요한 공유를 끈다.
- 총 사용자와 조회수를 구분한다. 쿠키 없는 측정의 고유 방문자 식별 한계와 행동 모델링의 자격 요건을 안내한다. 날짜별 사용자 수를 더해 월간 고유 방문자 수로 표현하지 않는다. 상세 데이터 보관2개월과 표준 집계 보고서 보관을 구분한다.
- 측정 ID가 없거나 스크립트가 차단돼도 기존 도구가 작동한다. 자동 테스트는 Google 요청을 차단하며 실제 운영 집계 확인과 구분한다.
- 연동 전 기록은 복원할 수 없다. 계정 설정·보고서 확인·수동 내보내기·수집 중단 절차는 README를 따른다.
