- 공개 페이지: `https://hjh3311504.github.io/team-maker`

- 목표 검색어: `팀짜기`, `조짜기`, `팀 나누기`, `랜덤 팀 배정`

광고, 새 도메인, 유료 SEO 도구는 사용하지 않는다. Google Analytics 같은 방문자 추적 script도 추가하지 않는다. 검색 성과는 Google Search Console과 네이버 서치어드바이저에서만 확인한다.

- [ ] 네이버 웹 페이지 수집에서 `/team-maker` 수집을 한 번 요청한다.

같은 URL의 수집 요청을 매일 반복하지 않는다. 새 페이지나 큰 변경 사항이 배포됐을 때만 다시 요청한다.

## 월1회 운영 원칙

1. Search Console과 서치어드바이저에서 색인 오류와 실제 유입 검색어를 확인한다.
2. 목표 검색어별 노출, 클릭, CTR과 평균 순위를 기록한다.
3. 검색 사용자가 원하는 내용과 페이지 설명이 다른지 확인한다.
4. 근거가 있을 때만 제목이나 본문을 고친다.
5. 날짜만 바꾸거나 같은 검색어를 반복해서 넣지 않는다.
6. 변경 후 다음 월 기록에서 이전 값과 결과를 비교한다.

외부 공유는 README와 GitHub 저장소의 설명·homepage·topic까지만 사용한다. 6개월 뒤 목표에 못 미치면 별도 정보 페이지나 GitHub 밖의 자연스러운 소개 링크를 다음 단계로 검토한다.
