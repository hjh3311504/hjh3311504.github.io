# 음원 공개 자료와 로컬 제작 기록 분리

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자는 음원 파일은 공개하되 제작 방법에 관한 자료는 GitHub에 올리지 않도록 요청했다.

음원 파일·파일명·게임 재생 동작은 유지한다. 공개 문서와 JSON에는 원음 출처·제작자·라이선스·사용 파일·해시를 남긴다. 제작 도구와 상세 작업 기록·검토 자료는 Git에서 제외되는 로컬 폴더에 보관한다. 이전 ADR 원문도 로컬 사본으로 보존하며 공개본에는 음원 선택과 게임 적용 결정을 남긴다.

공개 테스트는 음원 파일의 해시·길이·파형과 재생 동작을 검사한다. 로컬 제작 환경이나 제작 과정의 상세 값에는 의존하지 않는다.
