# 아수라장 모루작 빌드 2티어 신발 아이콘

- 날짜: 2026-11-02
- 상태: 채택
- 근거: 사용자가 2026-11-02 장갑 충격 모루작 빌드의 2티어 신발 이미지를 탐욕의 군화 이미지로 바꾸라고 정했다.
- 이전 결정: [아수라장 장갑 충격 모루작 빌드와 추천 모루](2026-11-02-아수라장-장갑-충격-모루작-빌드와-추천-모루.md)(2티어 신발에 기본 장화 아이콘 사용)

## 결정

모루작 빌드의 `2티어 신발`은 이름을 그대로 두고 아이콘만 탐욕의 군화(3008) 아이콘을 쓴다. 생성 script가 `2티어 신발`을 탐욕의 군화 아이템 번호로 찾아 같은 아이콘 파일을 가리킨다. 기본 장화(1001) 아이콘은 더 쓰지 않아 지운다.

## 이유

기본 장화는 1단계 신발이라 2티어 신발과 맞지 않는다. 탐욕의 군화는 아수라장 가이드의 기본 신발이라 처음 보는 사람도 신발 자리로 바로 알아본다.

## 결과

- 증강 공략과 챔피언 빌드 탭의 모루작 빌드가 같은 탐욕의 군화 아이콘을 보여 준다.
- 단위 테스트가 2티어 신발과 탐욕의 군화 아이콘이 같은지 확인한다.
