# 일반 블록 소리 제한 통일

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 기본 블록의 소리 제한을 도각 키보드처럼 풀도록 요청했다.

현재 활성 일반11종은 전체 동시12개·최소 시작 간격28ms를 사용한다. 청축·타자기의3개·60ms, 불씨의3개·120ms, 개구리·오리의3개·100ms 추가 제한을 제거한다. 나머지 활성 일반 블록은 이미 같은 기준이다.

재생 중인 소리를 새 충돌로 끊지 않는다. 기존 음원 파일과 음량, 실제 오디오 시간 기준, 화면 범위, 일시정지·음소거 정리는 유지한다. 버터·젤리 연못·분산 장치·결승·팡파레와 비활성 재질의 제한은 바꾸지 않는다.

활성11종마다12개 재생·28ms 이내 생략·13번째 동시 재생 생략·종료된 소리 자리 재사용·정지 후 초기화를 검사한다. 특수 장치와 비활성 질감의 기존 제한 검사도 유지한다.
