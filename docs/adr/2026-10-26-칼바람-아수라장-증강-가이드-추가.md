# 칼바람 아수라장 증강 가이드 추가

- 날짜: 2026-10-26
- 상태: 채택
- 근거: 사용자가 2026-10-24 칼바람 아수라장 초보자용 가이드 제작을 요청했다. 2026-10-25~26 독립 HTML 시안을 v86까지 고쳤고, 2026-10-26 마지막 시안을 실제 페이지로 구현하라고 요청했다.

## 결정

공개 route에 `/aram-mayhem`을 추가한다. 마지막 슬래시 없이 `build/aram-mayhem.html`로 배포하고 홈·소개·공통 내비게이션·sitemap·방문 통계 경로에 넣는다. 한 페이지에서 챔피언을 고르고 주소 끝의 `#챔피언id`로 공유한다. 챔피언별 개별 주소는 만들지 않는다.

가이드 원본은 `docs/research/aram-mayhem/`의 조사 JSON으로 저장소에 둔다. 저장소 밖에서 만들던 조사 파일은 이 시점부터 저장소 사본을 기준으로 고친다. `scripts/generate_aram_mayhem.js`가 원본으로 화면 데이터 JSON과 아이콘 webp를 만들고, 결과를 Git에 함께 올린다. 페이지는 build 때 이 JSON을 가져와 첫 챔피언 내용을 정적 HTML로 만든다. 데이터는 gzip 기준 약 24KB라 별도 요청으로 나누지 않는다.

아이콘은 Riot Data Dragon 16.21.1과 CommunityDragon에서 받아 `static/images/aram-mayhem/`에 배포한다. 화면에서 외부 이미지 주소를 부르지 않는다. 모루 아이콘은 출처가 분명한 Data Dragon의 모루 교환권 그림을 쓴다. Riot Games의 Legal Jibber Jabber 정책 문구를 페이지에 표시한다.

조합 출처는 실제로 내용을 가져온 디시인사이드 칼바람 나락 갤러리 글과 유튜브 영상만 보여 준다. 통계 사이트는 조사 근거로 남기되 화면에 출처로 표시하지 않는다. 2026-10-25에는 저장소에 디시 흔적을 남기지 않기로 했지만 2026-10-26 사용자가 디시 출처를 보여 주도록 바꿨다.

## 검토한 대안

- 챔피언별 개별 주소: 검색 노출에는 유리하지만 시안이 한 페이지 선택 방식으로 승인됐고 31개 페이지의 정적 검사와 sitemap 관리가 늘어난다. 이번에는 미룬다.
- 외부 CDN 이미지 직접 사용: 파일을 관리할 필요가 없지만 외부 서비스 장애와 버전 경로 변경에 화면이 영향을 받는다. 아이콘 268개, 약 560KB를 함께 배포한다.
- 조사 자료를 저장소 밖에 두기: 저장소를 가볍게 유지하지만 다른 작업자가 데이터를 다시 만들 수 없다.

## 영향과 검증

- 저장 데이터와 로그인은 없다. 개인정보처리방침의 저장 항목은 바뀌지 않는다.
- 단위 테스트가 생성 데이터의 참조 연결, 아이템 규칙, 문장 나누기·조사 보정, 거르기·빌드 비교를 확인한다.
- build 검증이 정적 안내·canonical·sitemap·홈 링크와 이미지 경로를 확인한다.
- 브라우저 검사가 챔피언 고르기·주소 반영·검색·빌드 탭·증강 효과·접은 카드·좁은 화면을 확인한다.
- 패치가 바뀌면 조사 JSON을 고치고 `npm run generate:aram-mayhem`을 다시 실행한다.
