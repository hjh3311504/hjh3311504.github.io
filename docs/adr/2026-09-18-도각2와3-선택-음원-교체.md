# 도각2·3 선택 음원 교체

- 상태: 승인됨
- 결정일: 2026-09-18
- 근거: 사용자가 L1과 R1·P1을 선택했다.

## 결정

도각2는 L1의 서로 다른 두 구간을 `thock2-v2-1.wav`·`thock2-v2-2.wav`로 연결한다. 도각3은 R1의 두 구간을 `thock3-v3-1.wav`·`thock3-v3-2.wav`로 연결한다. 한 구간을 앞뒤로 나눠 두 파일로 쓰지 않는다. 도감과 경기는 같은 파일을 A→B 순서로 교대한다.

도각4용 P1은 선택됐지만 다운로드가 차단되어 적용을 보류한다. 파일을 확보할 때까지 현재 도각4를 유지한다. 도각1·찰칵·맵·물리와 도각2·3·4의 재질별 동시6개 제한은 유지한다. 이전 음원과 ADR은 보존한다.

## 검증

새 파일의 파형 잘림·끝점·음량 차이, 두 파일 교대, 생략된 충돌의 순서 유지, 도감과 경기의 공통 제한을 검사한다. R1은 연속 타건 녹음이므로 각 발췌가 한 번의 눌림·복귀인지 실제 청음으로 확인할 필요가 있다. 파형 검사만으로 청음 품질을 확정하지 않는다.

오디오 단위 테스트33개와 관련 Chromium 검사3개가 통과했다. lint·Svelte Check·build·정적 페이지 검증·문서 연결 검사도 통과했다. 도각2는 약303ms·315ms, 도각3은130ms·175ms이며 재질별 두 파일의 평균 음량 차이는 각각0.01dB 미만·0.68dB다. 도감의 A→B 재생과 경기 준비·일시정지·재시작·캐시 재사용을 브라우저에서 확인했다. 실제 청음 평가는 별도로 남는다.
