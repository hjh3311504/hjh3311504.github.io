# 사이트 이름을 Seta Lab으로 바꾸고 θ 로고를 쓴다

- 상태: 결정
- 근거: 2026-11-04 사용자 요청. 운영자 닉네임을 Seta로 바꾸고 사이트 이름 후보 중 ‘Seta Lab’과 θ 기호 로고를 골랐다.
- 관련 요구사항: `REQ-WEB-027`
- 관련 화면: `SCR-WEB-001`, `SCR-WEB-002`

## 배경

이전 이름 Lake's develog의 ‘develog’는 개발 기록이라는 뜻이다. 실제 사이트는 모임·수업 도구와 파일·이미지·데이터 가이드를 다룬다. 운영자 닉네임도 Lake에서 Seta로 바뀌었다. [2026-10-25 결정](2026-10-25-AdSense-재심사-다른-서비스명과-블로그-주제-분류.md)의 ‘이름 유지’는 이 결정으로 대체한다. 두 축의 사이트 주제는 그대로다.

## 결정

- 사이트 이름은 `Seta Lab`(세타랩), 운영자 표시는 `Seta`다. 저작권자 표기도 `Seta (hjh3311504)`로 바꾼다. Lake는 같은 운영자의 이전 닉네임이다.
- 로고는 파란색(`#0075de`) 둥근 사각형 안의 흰색 θ 기호다. ‘세타’가 그리스 문자 θ의 이름이라는 점을 이용한다. θ는 모서리 두 곳을 깎고 세로획을 굵게 해 굵기 차이를 주며, 가로획이 몸체 밖으로 뻗는다. Codex가 만든 4차 시안(원본 v3-10)에서 사용자가 골랐다. `static/favicon.svg`가 원본이고 내비게이션과 공유 이미지가 같은 모양을 쓴다.
- 주소, route, sitemap, `localStorage` 키(`juno.develog.*`)는 바꾸지 않는다. 키를 바꾸면 방문자의 테마·동의 설정이 사라진다.
- 모든 페이지의 `WebSite` 구조화 데이터는 `src/lib/data/meta.js`의 `websiteNode`를 쓴다. 구조화 데이터의 `alternateName` 속성에 `세타랩`과 이전 이름을 넣어(값은 `meta.js`의 `alternateNames` 배열) 검색 결과의 이름이 바뀌는 동안 같은 사이트로 알린다. 홈에도 같은 데이터를 넣는다.
- 홈은 남색 소개 영역(부제목 “필요한 도구를 한곳에”, 한 문장 소개, GitHub 링크, θ 타일과 도구 화면 카드 3장을 겹친 그림)을 맨 위에 두고, 그 아래 흰 카드에 도구 격자(화살표 카드)를 둔다. 2026-11-05에는 하단 시안 A를 골라 최신 블로그 글(첫 글 강조 + 2열 카드), 도구 선택 안내(용도별 카드 4칸), 만든 사람과 문의(θ 프로필 카드), footer를 카드 밖 영역으로 옮겼다. 같은 날 홈 본문 최대 너비를 880px에서 1120px로 넓혔다. 소개 영역 왼쪽이 비어 보여 도구 이름이나 특징 목록 대신 만든 이유를 담은 두 번째 문단을 더했다. 도구 안내는 바로 아래 둘러보기 카드가 맡는다. 도구 선택 안내의 마지막 예시 상자는 사용자 요청으로 뺐다. 그 밖의 안내 글과 필수 링크는 애드센스 심사 중이라 그대로 둔다. 홈 공유 이미지도 같은 바탕과 그림을 쓴다.

## 검증과 한계

과거 ADR과 `docs/design/handoff/`·`docs/design/packages/`의 전달본은 당시 기록이라 고치지 않는다. 블로그 예제 PDF의 작성자 정보도 공개된 예제 파일이라 다시 만들지 않는다. 생성 script(`scripts/generate_blog_pdf_examples.py`)의 문구는 새 이름으로 바꿔 다음 생성부터 반영한다. 공개 글 `file-size-mb-mib`의 `C:\Users\Lake\…` 예시 경로는 실제 측정 기록이라 그대로 둔다. 검색 결과의 사이트 이름과 아이콘은 검색엔진이 다시 수집해야 바뀐다. Google·네이버 검색 결과에 Seta Lab이 표시되면 `alternateNames`에서 `Lake's develog`를 뺀다. 공유 이미지는 같은 파일 이름을 쓰므로 배포 뒤 카카오·Facebook 공유 디버거로 미리보기를 다시 수집한다.
