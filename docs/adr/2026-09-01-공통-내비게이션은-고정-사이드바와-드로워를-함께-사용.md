# 의사결정 기록 2026-09-01: 공통 내비게이션은 고정 사이드바와 드로워를 함께 사용

상태: 결정
일자: 2026-09-01

## 결정

- `1201px` 이상에서는 공통 내비게이션을 화면 왼쪽에 고정한다.
- 데스크톱에서 고정을 풀면 상단 메뉴 버튼으로 여는 왼쪽 drawer로 전환한다.
- `1200px` 이하에서는 상단 bar의 햄버거 버튼으로 같은 drawer를 연다.
- 홈과 프로젝트를 세로로 배치하고 새 프로젝트는 프로젝트 묶음에 추가한다.

## 핵심 근거

- 메뉴가 늘어나도 본문 너비와 상단 레이아웃이 깨지지 않는다.
- 데스크톱에서는 주요 이동을 항상 볼 수 있고 좁은 화면에서는 본문 공간을 확보할 수 있다.
- 고정 해제와 모바일이 같은 drawer 동작을 공유해 접근성과 상태 처리를 한 번만 구현할 수 있다.

## 검토한 대안

- 모든 화면에서 drawer만 사용: 데스크톱에서도 주요 이동이 숨고 매번 한 번 더 눌러야 해 기각한다.
- 상단 메뉴를 여러 줄로 표시: 항목이 늘 때 헤더 높이와 본문 시작 위치가 계속 달라져 기각한다.
- 데스크톱 사이드바를 항상 고정: 사용자가 넓은 본문을 선택할 수 없어 기각한다.
