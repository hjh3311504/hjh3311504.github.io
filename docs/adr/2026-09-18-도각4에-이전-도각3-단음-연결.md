# 도각4에 이전 도각3 단음 연결

- 상태: 적용됨
- 결정일: 2026-09-18
- 근거: 사용자가 도각4에는 예전 도각3의 소리를 넣으려던 것이라고 정정했다.

## 결정

도각4를 `thock3-v2.wav`로 연결한다. 직전 작업에서 도각4 자신의 이전 파일을 연결한 해석을 바로잡는다. 예전 도각3 단음을 재편집 없이 사용하며 도감과 경기에서 같은 파일을 반복한다.

도각2의 복구된 단음, 현재 도각3의 두 소리, 동시6개 제한과 맵·물리는 유지한다. 기존 음원과 ADR은 보존한다.

## 검증

기존 도각3 단음의 파일 내용과 현재 연결을 검사하고 도감·경기 로딩 및 반복 재생을 확인한다.

오디오 단위 검사35개, 관련 Chromium 검사3개, lint·정적 검사·build·정적 페이지 검증·문서 연결 검사가 통과했다. 도각4가 이전 도각3 파일을 선행 로딩하고 반복 재생하는 것을 확인했다.
