# 공통 UI와 수정 직후 검사

사용자는2026-09-20 현재 디자인을 보완하면서 공통 컴포넌트를 정리하고 작업 중 에이전트에 직접 경고하는 계획을 승인했다. PR 때만 확인하는 방식은 피드백이 늦다는 이유로 보조 검사로 정했다.

기존 공통 컴포넌트가 마크업만 공유하고 기본 간격·제목 크기는 페이지가 별도로 지정해 차이가 생겼다. Team Maker의 홀수 글자 검사는 build 때 일부 CSS만 검사했다.

공통 모달·섹션·입력 항목이 기본 여백을 제공한다. 글자와 여백은 CSS 토큰으로 관리한다. 기존 테마·게임의 색상은 공통 팔레트로 옮긴다. QR과 구슬 레이스는 기능별 화면으로 분리하되 상태·핵심 동작은 부모에 남긴다. Team Maker의 요소 계층·ID·수명 관리는 보존한다.

Svelte와 CSS 파서를 사용하는 검사기를 Codex·Claude Code의 수정 후 hook에 연결한다. 도구 명령을 추측하지 않고 파일 해시를 비교한다. 새 파일, shell 수정, 정책 변경을 포함한다. 검사 실패는 경고로 전달하고 사용자 작업을 자동으로 덮어쓰지 않는다. 에이전트별 설정·신뢰 등록은 실제 전달까지 확인한 경우에만 활성화됐다고 보고한다.

정적 검사는 기본 규칙과 명확한 재사용 누락을 확인한다. 의미가 같은 새로운 화면의 중복, JavaScript로 생성한 요소, 시각적 균형 전체를 판정한다고 주장하지 않는다. 실제 브라우저에서 간격·글자·모달·기능을 검사한다.

다른 프로젝트용 패키지는 아직 만들지 않는다. 검사기·정책·피드백 연결을 분리해 이 프로젝트에서 검증한 뒤 재사용한다. 기존 설계 handoff와 과거 ADR은 보존한다.
