# 스킬음 제한 해제와 화면 범위

## 결정

사용자가2026-09-22 스킬 소리 제한을 없애고 화면에 보이는 스킬만 소리를 내도록 요청했다. 번개·바람 스킬 추가 결정의 동시1개·최소200ms 음향 정책을 대체한다.

스킬음은 같은 종류가 같은 순간에 발동해도 각각 재생한다. 일반 음향의 동시6개·최소28ms 제한과 프레임당 선택에서도 제외한다. 스킬 때문에 일반음의 자리를 빼앗거나 일반음 때문에 스킬을 생략하지 않는다.

화면 판정은 실제 경기 카메라의 좌우·상하 범위를 사용한다. 파동의 원·번개의 세로 줄기·바람의 상승 범위 중 일부가 보이면 재생한다. 일반 충돌음의 높이800 제한과 경계 밖52 감쇠는 적용하지 않는다. 카메라 이동으로 효과 범위가 화면 밖으로 벗어나면 재생 중인 소리도 짧게 줄여 끈다. 지난 발동을 나중에 다시 재생하지 않는다.

도감 미리듣기는 카메라 범위와 무관하게 재생하며 개수·간격 제한을 두지 않는다. 기존 음원·음량·전체 압축기·음소거·정지 정리를 유지한다. 일반 충돌음·장치음·축하음 정책은 유지한다.
