# GA4는 쿠키 없는 측정만 사용한다

- 상태: 결정
- 근거: 2026-09-29 사용자 요청 “허용 없이 데이터를 수집하고 싶어”, “GA4 유지” 및 허용·거부 버튼 제거와 기존 거부 유지 동의
- 관련 요구사항: `REQ-WEB-027`
- 대체 결정: [GA4 방문 통계는 동의 후 수집한다](./2026-09-29-GA4-방문-통계-수집.md)의 허용 전 수집 차단

## 결정

방문 시 Google 태그를 실행하기 전에 분석 저장 동의를 항상 `denied`로 설정한다. 쿠키 없는 측정만 사용하고, 허용·거부 버튼과 쿠키 측정으로 전환하는 API를 제거한다. 상단에 수집 안내만 남기고 개인정보처리방침에도 실제 처리와 현재 상태를 설명한다.

기존 localStorage 키와 거부 선택을 유지한다. 거부가 저장된 방문에서는 태그도 요청하지 않는다. 기존 허용 방문도 쿠키 없이 측정하며 이전 분석 쿠키를 삭제한다. 이전 버전의 다른 탭에서 거부 설정이 바뀌면 대기열과 이후 전송을 중단한다.

기존4개 경로만 수집하며 query·hash·사용자 입력을 제외한다. 광고 관련 동의는 계속 거부한다. Umami, 새 서버, 추가 추적 항목은 도입하지 않는다.

## 검증과 한계

쿠키 저장 거부 명령 순서, 기존 허용 방문의 쿠키 삭제, 저장된 거부, 로딩 중 거부 반영, 다른 탭의 설정 변경과 페이지 이동을 검사한다. 안내와 개인정보 모달에서 허용·거부 버튼이 없는지도 확인한다. 자동 브라우저 검사는 가짜 측정 ID를 사용하고 Google 전송을 차단한다.

쿠키 없는 측정으로 정확한 고유 방문자 수를 보장하지 않는다. 행동 모델링에는 트래픽 등 자격 요건이 있으며 일반 보고서 반영은 별도 확인 대상이다. 고급 동의 모드 자체가 법적 동의 면제를 의미하지 않는다.
