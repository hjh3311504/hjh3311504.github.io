# AdSense 재심사를 위해 다른 서비스명을 빼고 블로그를 주제로 나눈다

- 상태: 결정
- 근거: 2026-10-25 AdSense 4번째 거절(복제된 콘텐츠·가치가 별로 없는 콘텐츠) 대응 계획 사용자 승인. 사이트 주제는 사용자가 ‘두 축 유지’를 선택했다.
- 관련 요구사항: `REQ-MARBLE-005`, `REQ-BLOG-001`
- 관련 화면: `SCR-WEB-002`, `SCR-WEB-004`, `SCR-WEB-005`

## 배경

10월 15일 보강 뒤에도 같은 두 사유로 거절됐다. 문제 URL은 제시되지 않았다. 공개 사이트를 다시 확인해 다음 약점을 찾았다([점검 기록](../adsense-content-review.md)).

- 구슬 레이스의 검색 제목·설명·본문·홈에 다른 서비스 이름인 ‘마블룰렛’과 ‘마블레이스’를 검색어로 반복했다. 다른 서비스를 베낀 페이지로 보일 수 있다.
- Team Maker 이미지 10개는 제작자와 사용 조건 기록이 없었다.
- 홈의 블로그 카드가 “개발하며 얻은 경험과 생각, 일상의 이야기”라고 소개했다. 실제 글은 파일·데이터 가이드라서 사이트 주제가 섞여 보였다.
- 블로그 분류가 ‘사용 가이드’ 1개에 19개 글이 몰려 있었다. 관련 글도 주제와 관계없이 최신 글로 연결됐다.

## 결정

- 사이트는 ‘모임·수업 도구’와 ‘파일·이미지·데이터 가이드’ 두 축을 유지한다. 이름 Lake's develog는 그대로 두고 홈 소개·블로그 카드·사이트 설명·공유 이미지 문구를 두 축에 맞춘다.
- 구슬 레이스 검색 제목은 `ASMR 구슬 레이스 | 이름 적힌 구슬로 뽑는 무료 추첨 도구`로 바꾼다. 다른 서비스 이름을 검색어로 쓰지 않는다. 2026-09-28 검색 문구 결정을 대체한다.
- 블로그 `category`를 글 종류에서 주제로 바꾼다. `introduction`(도구 소개), `tool`(도구 활용), `image`(이미지·사진), `data`(데이터·텍스트), `file`(파일·링크)를 사용한다. `guide`·`update`·`note`는 없앤다. 프로그램이 없는 글의 관련 글은 같은 주제에서 고른다.
- Team Maker 이미지 10개를 저장소에서 직접 작성한 SVG로 바꾸고 기존 PNG를 지운다.

## 검증과 한계

`npm run verify:team-maker`는 홈과 구슬 레이스 HTML에 다른 서비스 이름이 없는지 확인한다. 블로그 단위 테스트는 새 주제 값과 관련 글 연결을 확인한다.

기존 `?category=guide` 주소는 전체 글 목록으로 열린다. 이 변경도 승인을 보장하지 않는다. 글 운영 방식 변경과 재심사 시점은 [점검 기록](../adsense-content-review.md)을 따른다.
