# GA4 방문 통계는 동의 후 수집한다

- 상태: 결정
- 근거: 2026-09-29 사용자의 GA4 통계 수집 프롬프트 구현 요청
- 관련 요구사항: `REQ-WEB-027`

## 목적과 결정

방문 추이를 기록하되 홈페이지에는 방문자 수를 표시하지 않는다. 무료 GA4의 관리 화면을 사용한다. 서버·데이터베이스·로그인·공개 통계 API는 추가하지 않는다. 유료 기능과 광고 연동도 사용하지 않는다.

공통 layout에서 페이지 이동 완료를 관찰하고 수동으로 페이지 조회를 전송한다. 자동 페이지 조회와 향상된 측정은 끈다. 개발 서버, 다른 도메인과 오류 화면은 제외한다. 환경 변수가 없으면 수집은 비활성 상태다.

방문자가 허용하기 전에는 Google 태그를 로드하지 않는다. 선택은 기존 브라우저 저장 방식으로 유지하고 공통 개인정보처리방침에서 바꾼다. 동의 안내는 기존 Section·Button으로 구성하며 별도 공통 UI 요소는 만들지 않는다. 광고 관련 동의는 거부 상태로 고정한다.

페이지 경로와 제목은 허용 목록에서 만들고 query·hash·사용자 입력을 제외한다. 외부 유입 경로는 도메인만 남긴다. Google의 자동 기본 이벤트는 있을 수 있으므로 모든 수집 항목이 페이지 조회뿐이라고 안내하지 않는다.

## 운영과 검증 경계

운영 build는 GitHub repository variables를 사용한다. PR build에는 예약 도메인과 가짜 ID를 사용한다. 브라우저 검사는 Google 요청을 가로채고 코드가 구성한 요청과 페이지 이동을 확인한다. Google 서비스의 실제 처리와 보고서 반영은 계정 설정·배포 이후 별도로 확인해야 한다.

총 사용자와 페이지 조회수를 구분한다. 상세 데이터는2개월 보관으로 설정하고 장기 추이는 표준 집계 보고서에서 확인한다. 일별 고유 사용자를 합산해 월간·평생 고유 인원으로 표현하지 않는다. 동의 거부와 광고 차단에 따른 누락을 인정한다. 영구 보관을 보장하지 않으며 수동 내보내기를 안내한다.
