# 특수 장치 앞 분산 핀과 연못3분할

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 특수 구역의 장치와 분산 핀 순서를 바꾸고 젤리 연못을 좌·중앙·우로 나누도록 요청했다.

구역 사이3곳의 높이1220을 유지한다. 앞쪽260에 기존13개 핀을 두고, 뒤쪽960에 유도벽과 특수 장치를 둔다. 핀을 먼저 지나 버터·연못으로 진입한다. 유도벽도 장치와 함께 옮겨 핀과 겹치지 않게 한다. 첫 분산 통로도 같은 순서로 바꾼다. 마지막 재질층과 결승 사이의 핀13개는 유지한다.

젤리 연못은 가로 중심88·360·632에 폭152·깊이140으로 배치한다. 세 연못은 같은 높이이며 사이의 틈은 각각120이다. 연못과 우회로의 위치는 고정한다. 각 연못은 별도 장치 ID로 진입음을 한 번씩 내며, 기존 감속과 음향 제한을 유지한다. 구역 높이·일반 블록 수·결승 위치는 바꾸지 않는다.

기존 ADR의 장치 뒤 핀 배치와 한쪽 연못 우회로 결정을 이 배치로 대체한다.

검증 결과: 구슬 레이스 단위 검사88개 중86개가 통과했다. 핀·장치 순서, 연못3개의 개별 진입음·감속·탈출, 우회로 통과와 Worker 계산 동일성을 확인했다. 기본3개 맵×2/30/60명×난수10개의90경기는 모두120경기초 안에 완주했으며 최대82.68초였다. 기존 결승15초 목표는58경기에서 초과했고 최대 체류는56.86초였다. 결승 밀집 검사도 시작 각도0에서30초 동안40/60명만 도착해 실패했다. 이 두 시간 제한 검사는 기존에도 실패하던 항목이며 기준을 변경하지 않았다.
