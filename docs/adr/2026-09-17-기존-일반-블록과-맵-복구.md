# 기존 일반 블록과 맵 복구

- 상태: 적용
- 근거: 사용자가 이번에 작업하지 않은 도각 키보드음 등 기존 소리의 복구를 요청했다.

## 변경

도각 키보드·타자기·슬라임·키네틱 샌드·비누·팝잇을 다시 활성화한다. 파일과 음향 정책을 수정하지 않는다. 청축의 Computer Keyboard 52 (SFX)와 왁뿌볼의 Crack-A.wav는 유지한다.

기존 맵3개와 도감8종을 복구한다. 각 맵은 중복 없는 재질4층·총960개 블록이다. 임시2종 맵을 제거하고 보존한 맵 정의를 다시 사용한다. 분산 장치·원통·복구3초·저장 명단을 유지한다. 이전 맵 ID는 원래 대응 맵으로 연결한다.

## 검증

복구한8종·3개 맵·960개 배치와 이전 맵 ID 연결을 검사한다. 음원 파일은 변경하지 않으며 승인 크랙 A 파일 해시와 청축 경로 검사를 유지한다. 화면에서는 도감8종·도각 미리듣기·선택 맵 로딩과 명단 보존을 검사한다.

- 복구 음원·물리 단위 검사64개 중63개 통과. 기존 시간 목표1개는 실패 상태다.90경기 모두 완주했으며 최대60.90초, 마지막 체류 최대48.05초다. 좌우102 이상 이동은88.6%로 기존75% 기준을 통과했다.
- 도감8종·선택 맵 로딩·일시정지·초기화·모바일·이전 맵 ID와 명단 보존 관련 Playwright3개 통과. Chromium 정적 미리보기에서3개 맵 첫 충돌·재시작·미리듣기 후 시작·재개·음소거 해제 출력 검사3개도 통과했다.
- lint·Svelte Check·build·정적 결과·문서 연결·git diff --check 통과.
