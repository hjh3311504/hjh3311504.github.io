# 100개 블록 상한과 종료 뒤 준비 복귀·마지막 골인

- 상태: 적용
- 날짜: 2026-09-24
- 연결 요구사항: REQ-MARBLE-001, REQ-MARBLE-002, REQ-MARBLE-004
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

## 요청과 결정

사용자는 구슬이 많을 때 블록 수가 계속 늘어 경기가 길어지는 문제, 종료 뒤 참가자·맵·당첨 방식을 바꿔도 결과가 남는 문제, 마지막 구슬이 회전바에 반복해서 걸리는 문제를 요청했다. 블록 증가 상한은 사용자 답변에 따라100개로 정했다.

### 일반 블록 상한

구역당 행 수는 `max(4, round(12 × sqrt(min(구슬 수, 100) / 30)))`다.100개 이상은4구역·20열·22줄로 일반 블록1,760개를 만든다.1000개는 기존5,520개보다약68.1% 줄어든다. 참가자 수를 줄이지 않으며 출발 공간은 실제 인원에 맞게 확보한다. 특수 구간과 크랙 왁스의 내구도 규칙은 유지한다.

일반층 높이·블록 난수 소비가 바뀌므로100개를 넘는 경기의 궤적·도착 순서는 이전 구현과 달라질 수 있다. 준비 미리보기·실제 경기·카메라·미니맵은 같은 배치를 사용한다.1000개 상태 해시3개는 새 배치를 기준으로 갱신했다. 겹침·벽 통과·배속 재현성 검사를 별도로 유지해 해시 갱신만으로 동작을 검증하지 않는다.

### 종료 뒤 설정 수정

참가자 명단, 선택한 맵 내용, 당첨 방식, 순위 범위, 순번을 한 묶음으로 비교한다. 경기 종료와 실제 설정 변경을 구분한다. 종료 상태에서 이 값이 바뀌면 기존 `reset()`으로 Worker·결과·축하 효과·카메라·배속을 정리하고 시작 준비로 돌아간다. 수정한 값과 나머지 설정은 보존한다.

입력이 잠시 잘못되어도 이전 결과를 지운다. 유효한 값으로 고치기 전에는 시작할 수 없다. 종료 자체나 소리·음량 변경으로는 결과를 지우지 않는다. 기본·커스텀 맵의 기존 초기화 경로도 유지한다.

### 마지막 구슬의 통로 열기

기존 단일 구슬의 위치·속도·회전각3,456조합에서는 무한 정체를 재현하지 못했다. 작은 경기의 최대 통과 시간은약14.50경기초,200개 경기 중1개만 남긴 같은 조합은약14.46경기초였다. 기존1000개·105경기초 저장 상태도492.94경기초에1개가 남고499.25경기초에 전원 도착했다. 사용자가 본 정확한 무한 정체 조건을 확인했다고 주장하지 않는다.

반복 반동을 끝내는 동작을 추가한다. 미도착 구슬이1개이고 결승에 진입하면 회전바 길이를2경기초 동안440에서260으로 줄인다. 다른 구슬이 남았거나 마지막 구슬이 결승 전이면 줄이지 않는다. 회전축·회전 속도·반발·중력·골인 기준은 유지한다. 별도 힘·순간이동·자동 도착을 추가하지 않는다. 구슬은 실제 중앙 통로를 거쳐 판정선을 넘어야 한다.

길이260의 반길이130에 구슬 반지름13을 더한143은 축에서 가까운 경사벽까지의 거리약152보다 작다. 따라서 접힌 바는 정상적인 깔때기와 중앙 통로 안의 구슬을 다시 막지 않는다. 회전은 계속하고, 새 경기에서는 원래440으로 시작한다. 마지막 순위 경쟁이 끝난 뒤에만 적용하므로 두 구슬 이상의 경합에는 적용하지 않는다.

경기 시간으로 길이를 계산한다. Worker 전달 항목에 너비 `w`를 추가해 충돌·그림·미니맵이 같은 모양을 사용한다. 길이가 줄어드는 동안 블록 탐색의 기존 넓은 범위는 안전하게 재사용하며 충돌 모양은 너비 변경을 반영한다. 고정 구슬을 바 길이 변경으로 이동시키지 않는다.

이 변경은 앞선 성능 개선과 달리 사용자의 마지막 골인 문제를 해결하기 위한 경기 동작 변경이다. 과거 ADR의 회전바 고정 길이 결정은 보존하고 새 동작을 이 문서에 기록한다.

## 검증

- 블록 경계2/10/20/30/60/99/100/101/200/300/1000개와 기본3개 맵, 백만 명 배치 미리보기 확인.
- 기존 단일 구슬3,456조합을 그대로 실행해 최대14.50→4.96경기초, 미완주0개 확인.
- 2개·1000개 경기의 마지막 구슬 각각80조합: 최대약5.017경기초에 중앙 통로를 거쳐 완주. 벽 반대편 이탈 없음.
- 회전바 축소의 실제 충돌·Worker 너비 전달·배속0.25/1/2 재현성·얼음 고정·새 경기 초기화 확인.
- 개발 서버에서1440px·390px 종료 후 참가자·방식·범위·순번·잘못된 입력 수정2개 브라우저 검사 통과.
- 최종 관련 단위 검사110개 통과. 새 배치1000개 밀집의 최대 실제 겹침0.499987·표시 겹침0.499926 미만. 회전각4가지·35경기초 벽 통과 방지와 중앙 골인 검사 통과.60개 밀집은46.475~53.075경기초에 전원 도착했다.
- 별도 과거 회전바 길이 비교3개 중1개 통과·2개 실패. 이전부터 실패하던 검사2개이며 이번 마지막 구슬 바 축소가 추가되어 평균 되튕김 높이 수치도 달라졌다. 역사적180/290/320길이 비교 기준을 완화하지 않았다. 최종110개 통과 집계에는 이 실패2개를 포함하지 않는다.
- Svelte 정적 검사 오류0개·경고0개, 변경 코드 ESLint·Prettier·UI 검사, REQ-MARBLE-001/002·전체 화면 연결 검사 통과.
- 최종 build1회와 정적 산출물 검사 통과. 전체 lint와 다른 도구의 전체 단위 검사는 실행하지 않았다.
- 최종 build의 관련 Playwright20개를 확인했다. 최초19개 통과·미니맵1개 실패였다. 줄어든 경기장보다 큰 옛 높이10,000을 기대하던 검사를 실제 경기장 끝까지의 탐색 확인으로 수정했고, 해당1개 재검사가 통과했다. 제품 코드는 build 뒤 바꾸지 않았으며 재build하지 않았다.
- 실제2개 경기에서 마지막 구슬의 당첨·팡파레1회·실제 골인·줄어든 바 너비 수신을 확인했다.1000개 미리보기 전체 생성·새 명단 반영·정지/재개/초기화, 종료 뒤 기본/커스텀 맵·참가자·방식·순번·범위 초기화도 통과했다.

## 남은 한계

일반 블록 감소가 모든 경기의 전체 완료 시간을 같은 비율로 줄인다는 뜻은 아니다. 큰 경기의 결승에는 여전히 통로 처리량과 스킬의 영향이 있다. 마지막 구슬 변경은 검증한 배치에서 반복 반동을 해소했으며 모든 비정상 위치를 복구하는 장치는 아니다.
