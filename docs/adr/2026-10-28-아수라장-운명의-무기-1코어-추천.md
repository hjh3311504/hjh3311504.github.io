# 아수라장 운명의 무기 1코어 추천

- 날짜: 2026-10-28
- 상태: 채택
- 근거: 사용자가 2026-10-28 운명의 무기 증강 공략을 요청했다. 디시 칼바람 갤러리 조사 결과, 챔피언 후보(카이사·오공·진·블리츠크랭크)는 모두 추천 0~1개의 단일 후기였다. 사용자는 챔피언별 공략 없이 1코어 추천만 짧게 쓰고 별명 `운무`를 넣으라고 정했다. 처음 만든 역할군 4개(마법사·암살자·원거리 딜러·전사) 안을 본 뒤 AD는 무조건 도미닉 경의 인사, AP는 무덤꽃으로 카드 2개만 두고 이 페이지의 출처를 모두 없애라고 정했다.
- 이어지는 결정: [아수라장 증강별 공략 페이지](2026-10-27-아수라장-증강별-공략-페이지.md)

## 결정

`/aram-mayhem/augments/weapon-of-destiny`를 증강 공략 페이지로 더한다. 어울리는 챔피언 대신 1코어 추천 카드 2개와 알아 둘 점을 보여 준다.

| 카드      | 1코어            | 이유                                         |
| --------- | ---------------- | -------------------------------------------- |
| AD 챔피언 | 도미닉 경의 인사 | 방어구 관통력이 늘어나 100%까지 오를 수 있음 |
| AP 챔피언 | 무덤꽃           | 마법 관통력(100%까지)과 스킬 가속이 늘어남   |

카드 위에는 `중첩을 쌓으면 방어구 관통력과 마법 관통력이 100%까지 올라 적의 방어력을 모두 무시할 수 있어요.`를 굵게 보여 주고, 검색 설명에도 `중첩을 쌓으면 관통력이 100%까지 오릅니다.`를 붙인다. 사용자가 관통력 100%를 강조하라고 정했다. 방어구 관통력·마법 관통력은 스킬 가속처럼 아이콘 타일로 보여 준다. 아이콘은 CommunityDragon의 게임 글자 아이콘(`scaleapen`·`scalempen`)이다.

이 페이지는 출처 링크를 보여 주지 않는다. 다른 조합 카드의 디시·유튜브 출처 표시는 그대로다. 근거 글 번호는 `docs/research/aram-mayhem/augment-guides.json`의 `evidencePostIds`에 기록만 한다.

생성 script가 원본을 증강 데이터의 `guide`로 넣는다. 검색 설명은 `증바람 운명의 무기(운무) 1코어 추천은 AD 챔피언 도미닉 경의 인사, AP 챔피언 무덤꽃입니다.`로 시작한다. 챔피언이 없으므로 챔피언 목록 구조화 데이터는 넣지 않는다.

## 검토한 대안

- 챔피언 후보 4명 조합 추가: 근거가 짧은 후기 1개씩이고 신발·2·3코어를 확인하지 못했다. 장갑 충격 때처럼 넣지 않는다.
- 역할군 4개 카드(독사의 송곳니·원칙의 원형낫 포함)와 출처 표시: 사용자가 AD·AP 2개로 줄이고 출처를 빼라고 정했다.

## 영향과 검증

- 단위 테스트가 제목, 빈 챔피언 목록, 1코어 검색 설명, AD·AP 아이템과 아이콘, 출처 없음을 확인한다.
- build 검증이 이 페이지에서 범례·챔피언 링크 대신 추천 아이템을 확인한다.
- 브라우저 검사가 카드 2개와 출처 없음을 확인한다.
