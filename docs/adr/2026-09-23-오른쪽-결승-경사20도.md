# 오른쪽 결승 경사를20°로 복원

- 상태: 적용
- 날짜: 2026-09-23

## 결정

사용자 요청에 따라 오른쪽 결승 경사만 수평 기준20°로 되돌린다. 왼쪽은30°를 유지한다. 오른쪽 바깥 시작 높이는 `결승 시작점+400−328×tan(20°)`로 정하고 기존 폭40 통로에 연결한다. 벽 두께12와 회전바 위치·길이440·회전 주기13.2경기초는 유지한다. 경기 그림·미니맵·충돌은 같은 블록 배치를 사용한다.

## 검증

60개 밀집 상태에서 회전바 시작 각도4가지를 검사했다. 모두 약48.7~58.6경기초에 완주했다. 현재 지형의 접전32가지도 모두 완주했다. 난수가 같은200개 경기의0.25·1·2배속 상태와 Worker 초기화 검사를 통과했다.

기존 겹침1 이하 검사와 위아래2개 구슬의10초 완주 검사는 실패한다. 이번 각도 변경에서 보정 횟수나 충돌 처리를 바꾸지 않는다.
