# 템플릿을 정리하고 GPLv3를 유지한다

- 상태: 결정
- 날짜: 2026-09-11
- 사용자 승인: 템플릿 전체 정리 계획의 구현을 요청했다. 홈·Team Maker 디자인 유지, 현재 디자인을 사용한 오류 화면, Lake 문자 favicon, 두 공유 이미지 갱신을 승인했다. MIT는 전환 근거가 확보되는 경우에만 적용하도록 했다.

## 확인한 내용

첫 commit `c0100a6`의 README는 Matheus Fantinel의 SvelteKit Static Blog Template을 가리킨다. LICENSE는 GPLv3이며, 정리 전 현재 LICENSE와 같다. 최초 도입 이후의 파일 이동도 `git log --follow`로 확인했다.

| 분류                      | 확인 근거                                                                                                      | 처리                                                         |
| ------------------------- | -------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------ |
| 템플릿 화면·장식·유틸리티 | 첫 commit에 atoms, molecules, About, Features, Header, Footer, Waves, icons, utils가 존재                      | 사용하지 않는 기능과 오류 화면 연결을 제거한 뒤 삭제         |
| 공통 스타일과 테마        | reset·animations·breakpoints는 원본과 동일하고 다른 SCSS와 테마 처리는 수정 이력이 있음                        | 현재 요구사항에 필요한 기본 CSS와 테마 저장 처리로 교체      |
| route와 문서 외곽         | waves 그룹·오류 화면·app.html이 원본에서 이어짐                                                                | 홈을 루트 route로 이동하고 공통 오류 화면과 문서 외곽을 작성 |
| 원본 이미지               | 기존 favicon PNG·ICO·SVG와 sample-image, features, site-preview, site-screenshot의 Git blob이 첫 commit과 동일 | 제거하고 Lake favicon과 새 공유 이미지로 교체                |
| 현재 홈·공통 UI           | 홈·내비게이션은 `0357d54`, 공통 UI는 `3219d64` 이후 이력에서 확인                                              | 현재 기능과 디자인을 유지하고 옛 공통 스타일 의존을 제거     |
| Team Maker                | `8216eb3` 도입 후 `8ebdc78`에서 SvelteKit에 통합된 별도 기능                                                   | 기능·데이터 형식을 유지하고 글꼴 선언만 공통으로 이동        |
| SUIT·SUITE                | 글꼴 파일에 SUNN 저작권과 OFL 원문이 있음                                                                      | 원문 유지 및 build에 포함                                    |
| 설계 전달본·업로드        | 외부 디자인 체계와 이미지가 포함된 기존 자료                                                                   | 보존하고 새로운 라이선스를 선언하지 않음                     |

정리 뒤 source의 4개 연속 비어 있지 않은 줄 중 140자가 넘는 구간을 최초 source와 비교했을 때 완전히 같은 구간은 발견하지 못했다. 이 검사는 흔적을 찾는 보조 수단이며, 파생 저작물 여부나 재라이선스 권한을 판정하지 않는다.

## 결정

실행 화면에서 템플릿의 화면·이미지·스타일·외부 글꼴 의존을 제거한다. 홈과 Team Maker의 공개 URL 및 정적 출력 이름은 유지한다. 정적 404와 동적 오류 화면은 같은 한국어 안내 component를 사용한다. 별도 블로그 기능은 추가하지 않는다.

글꼴은 GitHub Pages에서 직접 제공한다. 개인정보처리방침에서 jsDelivr 안내를 제거한다. 같은 날짜에 적용하므로 적용일은 2026년 9월 11일로 유지한다.

GPLv3는 유지한다. 현재 공통 UI는 기존 component를 통합한 작업에서 도입되었다. Git에 새 파일로 추가되었다는 사실만으로 원본과 독립적으로 작성됐다고 확정할 수 없다. 공통 UI와 홈을 포함한 파생 관계, 설계 전달본의 외부 자료에 대한 MIT 적용 권한은 이번 조사로 확정하지 못했다. 이는 MIT 전환이 불가능하다는 판정은 아니다.

MIT 전환을 다시 검토할 때는 남길 코드의 독립 작성 근거 또는 해당 권리자의 별도 허락을 확보한다. 설계 자료와 외부 자산의 적용 범위도 파일별로 정한다. 단순한 이름 변경·문법 변경·텍스트 일치율은 허락을 대신하지 않는다. 과거 이력은 재작성하지 않는다.

## 검증

기존 검사 전체와 외부 자원 요청·테마 복원·JavaScript 없는 정적 404 검사를 실행한다. build 검사는 원본 문구·이미지·외부 글꼴 요청의 재유입, OG 크기와 연결, 글꼴 라이선스 배포를 확인한다. 브라우저에서는 홈의 기존 배치, 테마·내비게이션·모달과 오류 안내를 확인한다.
