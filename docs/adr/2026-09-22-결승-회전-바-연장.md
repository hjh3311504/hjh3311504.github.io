# 결승 회전 바를 늘려 더 멀리 밀어낸다

## 결정

사용자가2026-09-22 결승 회전 바를 길게 만들어 구슬을 더 멀리 밀어내도록 요청했다. 기존 입구 판의 길이290을320으로 늘린다. 회전축은 x220에서 x210으로10만큼 왼쪽으로 옮긴다. 높이·두께·회전 주기·탄성·마찰은 유지한다.

길이만 늘리면 결승 통로를 오래 막으며 구슬이 반복해서 튕길 수 있다. 수평 판의 오른쪽 끝을 x370으로 맞춰 더 넓은 범위를 밀면서 통과할 틈을 유지한다. 경기장 그림·충돌·미니맵은 같은 배치를 사용한다.

양쪽 진입·시작 각도32조합에서 평균 되튕김 높이는97.16에서125.78로 약29% 늘었다. 해당 표본의 역전은10회로 같고 모두20경기초 안에 완주했다. 이 값은 고정 표본의 비교이며 모든 경기의 결과를 보장하지 않는다. 결승 밀집60개·시작 각도4가지의60초 내 배출 조건과 배출 정체 검사는 유지한다.
