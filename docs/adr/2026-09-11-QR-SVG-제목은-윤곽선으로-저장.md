# QR SVG 제목은 윤곽선으로 저장

- 날짜: 2026-09-11
- 상태: 채택
- 사용자 승인: 공용 UI 정리와 제목 윤곽선을 포함한 SVG 저장 계획의 구현 요청

## 결정

SVG는 QR과 제목을 별도 벡터 그룹으로 저장한다. 제목은 로컬 SUIT 700의 윤곽선을 사용하며 PNG에도 같은 경로와 배치를 그린다. text·글꼴 참조·삽입된 래스터 이미지를 사용하지 않는다. 제목은 Illustrator 등에서 도형으로 편집하고 문구 변경은 페이지에서 다시 생성한다.

지원하지 않는 제목 글자는 SVG만 제한하고 PNG를 제공한다. 글꼴 로딩·변환 실패는 재시도할 수 있다. 제목이 없으면 글꼴 코드를 로딩하지 않는다. 입력·북마크·route는 유지한다.

## WOFF2 호환 문제와 처리

fontkit 2.0.4에서 현재 SUIT WOFF2의 getVariation은 cmap 오류를 내며 WOFF2 변형 경로에서도 복합 글리프 오류를 확인했다. 라이브러리 내부 객체를 수정하지 않는다. 개발·build 단계에서 wawoff2로 기존 원본의 압축만 풀어 TTF를 생성하고 fontkit의 공개 getVariation API로 700을 선택한다.

생성 파일은 `.svelte-kit/qr-font/`에 두며 Vite가 이름에 해시를 붙여 자산으로 배포한다. fontkit과 이 글꼴은 제목이 필요할 때만 불러온다. 원본 글꼴과 OFL 고지는 유지한다.

## 공용 UI

QR은 기존 Section·SectionHeader·EmptyState·Button·Dialog를 활용한다. QR 안내 2개와 Team Maker 하단 안내 4개는 같은 DisclosureSection 스타일을 공유한다. 주요 작업 영역의 접기 기능은 추가하지 않는다.

## 검증

실제 로컬 글꼴을 사용하는 윤곽선 테스트와 SVG의 독립 렌더링·QR 해독 테스트를 실행한다. 브라우저에서 두 형식 비교, 미지원 글자·로딩 실패·재시도와 두 페이지의 접기·키보드·테마·모바일을 검사한다.

2026-09-11 검증 결과:

- 단위 테스트 55개와 Team Maker 브라우저 테스트 48개 통과.
- 한글·영문·숫자·기호·긴 제목·빈 제목의 PNG와 SVG를 실제 다운로드해 비교했다. QR 영역 픽셀은 같고 두 형식 모두 입력 원문으로 해독했다. 이모지·줄바꿈·앞뒤 공백과 최대 1,800바이트 입력을 포함한다.
- 빈 Fontconfig 설정의 별도 렌더링에서도 SVG 제목과 줄바꿈이 유지됐다. SVG에 text·글꼴 참조·래스터 이미지가 없음을 검사했다.
- 미지원 제목 글자, 글꼴 요청 실패, PNG 유지와 SVG 재시도 복구를 확인했다. 제목이 없을 때 글꼴 엔진·TTF 요청은 없었고 제목을 수정해도 읽은 글꼴을 재사용했다.
- QR 안내 2개와 Team Maker 안내 4개의 독립 접기, Enter·Space 조작, 초점 표시, 페이지 이동과 밝은·어두운 테마를 확인했다. 390px 화면에서도 가로 넘침이 없다.
- 이 Mac에는 Illustrator가 없어 실제 가져오기는 검증하지 못했다.
