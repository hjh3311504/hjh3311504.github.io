# 결승 배속과 타건음 동시 재생 조정

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 결승 배속을0.25배로 낮추고 별도 슬로모션 알림을 삭제하도록 요청했다. 찰칵 키보드와 옛날 타자기의 겹침도 줄인다.

결승 연출은0.25배속을 사용한다. 물리 계산 간격은 유지하고 같은 실제 시간에 진행하는 계산 횟수만 줄인다. 배속 버튼은 현재 배속을 표시하며, 당첨 확정 전 배속 잠금과 일시정지는 유지한다. 별도의 슬로모션 안내 문구는 표시하지 않는다.

청축 키보드의 표시 이름을 찰칵 키보드로 바꾼다. 내부 ID와 물리 값은 유지한다. 찰칵 키보드와 옛날 타자기는 재질마다 동시에3개까지만 재생한다. 최소 시작 간격28ms와 전체 동시12개 제한은 유지하며, 재생 중인 소리를 끊지 않고 초과한 새 소리를 생략한다. 다른 일반 블록의 제한은 변경하지 않는다.

키보드 음원은 후보 비교 후 별도로 선택한다. 이번 변경에서는 현재 음원 파일을 유지한다. 후보 검토 파일은 공개 자산에 추가하지 않는다.
