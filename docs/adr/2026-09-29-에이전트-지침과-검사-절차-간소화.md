# 에이전트 지침과 검사 절차 간소화

- 상태: 적용
- 근거: 사용자가 GPT-6-Astra용 지침 정리 프롬프트와 검토 보완 내용을 적용해 구현하도록 요청했다.

## 확인한 문제

AGENTS.md와 README·UI 안내에 같은 절차가 반복됐다. 모든 UI 작업 전 문서 읽기, 사소한 가정의 사전 보고, 새 공통 요소를 만들 때 별도 이유 기록은 작업 규모와 무관하게 적용됐다. UI 경고를 반드시 다음 수정에서 해결하도록 한 문구는 관련 변경을 함께 마치는 순서도 제한했다.

hook은 도구 실행 뒤 파일 해시를 비교하지만 내용이 같으면 검사를 반복하지 않는다. 정책·토큰·공통 제목 class 변경은 영향을 받는 다른 파일까지 재검사한다. 호출 빈도만으로 hook 전체를 제거할 근거는 없다. 다만 실행 실패 안내는 원인과 무관하게 `npm ci`를 요구하고 있었다.

## 결정

- AGENTS.md와 CLAUDE.md에는 프로젝트 정보·권한 경계·작업별 참조·검증 선택 기준을 남긴다. 중복된 구조 설명과 일반 작업 요령은 삭제한다.
- 이미 요청받은 로컬 구현·수정·검증은 완료까지 진행한다. 일상적인 구현 선택에 반복 승인을 요구하지 않는다. 질문은 결과나 권한 범위를 크게 바꿀 때 한다.
- Team Maker의 DOM 선택자·초기 렌더링·공유 상태 객체·종료 시 자원 해제는 현재 코드가 의존하는 조건으로 설명한다. HTML 계층이나 CSS import 순서 전체를 일괄 고정하지 않고 관련 의존성을 함께 수정하도록 한다.
- 공통 컴포넌트·토큰·접근성 기준은 유지한다. 매번 문서를 처음부터 읽거나 새 컴포넌트마다 별도 정당화 문서를 만들지는 않는다.
- UI 경고는 작업 완료 전 해결한다. 다음 수정의 순서는 강제하지 않는다. hook 검사와 같은 내용의 수동 검사를 반복하지 않는다.
- hook 실행 실패는 원인을 먼저 확인한다. 패키지 설치는 의존성 누락이 확인된 경우에만 안내한다.
- hook 등록 조건·캐시·검사 정책과 PR 검사는 유지한다. 과거 ADR과 제품 요구사항은 변경하지 않는다.

이 결정은 [공통 UI와 수정 직후 검사](2026-09-20-공통-UI와-수정-직후-검사.md)의 피드백 제공을 유지하면서 경고 처리 시점과 작업 절차를 보완한다.

## 적용 범위와 확인 한계

저장소 안에서 추가 AGENTS.md·CLAUDE.md나 SKILL.md는 발견되지 않았다. 상위 디렉터리에도 별도 AGENTS.md·CLAUDE.md가 없었다. 사용자 전역 Codex·Claude 지침에는 한국어 출력 규칙이 있으며 수정하지 않았다. 설치된 skill의 승인 규칙과 실행 환경에서 전달하는 지침은 이 저장소 변경 대상이 아니다.

파일 수정이 현재 대화에 이미 전달된 지침까지 즉시 교체하지는 않는다. 실제 hook 활성화와 모델의 작업 시간·비용·정확도 개선은 이번 코드·문서 검사로 입증하지 않는다.
