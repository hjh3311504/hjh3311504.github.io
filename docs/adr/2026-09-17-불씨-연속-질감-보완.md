# 불씨의 연속 질감 보완

- 날짜: 2026-09-17
- 상태: 적용
- 근거: 사용자가 불씨 느낌을 더 살려 달라고 요청했다.

## 변경

사용자가 선택한 Fire Sounds 원음과 기존 파일을 보존한다. 적용 파일과 원음 출처는 [음원 출처](../marble-audio-sources.md)를 따른다.

## 검증

두 파일의 평균 음량은−27.4dB 수준이며 차이는0.1dB 미만이다. 최대 파형은0.64 미만이고 시작·끝은0이다.250~800ms 구간에도0.039 이상의 RMS가 남아 첫 타격 뒤 소리가 이어짐을 확인했다. 기존 WAV 전체의 해시가 그대로임을 검사했다. 이는 파형 검사이며 실제 청감 만족도는 사용자가 확인해야 한다.

오디오 단위 테스트28개와 lint·Svelte Check·build·정적 build·UI 문서 연결 검사를 통과했다. 브라우저의 맵별 음원 로딩 검사는 통과했다. 첫 미리듣기 연계 검사는 불씨를 불러오기 전 키보드 맵의 소리 준비 단계에서 실패했다. 이전에도 나타난 준비 지연과 같은 증상이며 이번 불씨 편집으로 해결했다고 판단하지 않는다. 첫 실패 기록은 `.context/ember-v2/browser-first/`에 보존한다.

같은 코드로 미리듣기 연계 검사를 새 브라우저에서 다시 실행해1.7초에 통과했다. 불씨를 포함한 도감의 실제 재생 명령을 확인했다. 첫 준비 지연의 원인은 미확인으로 남긴다.
