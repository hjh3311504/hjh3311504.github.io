# 도각1 외 일반 블록의 동시 재생6개 제한

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 도각 키보드1을 제외한 소리의 동시 재생을6개로 제한하도록 요청했다.

도각 키보드1은12개를 유지한다. 도각2·3·4, 찰칵, 팝잇 등 나머지 활성 일반 블록은 재질마다6개로 제한한다. 전체 소리 합계12개·최소 시작 간격28ms와 특수 장치의 제한은 유지한다. 제한을 넘는 새 소리를 생략하며 이미 재생 중인 소리는 끊지 않는다. 도감 미리듣기와 경기 충돌음은 같은 제한을 사용한다.

음향 단위 검사로 모든 활성 일반 재질의 상한,28ms 간격, 재생 완료 후 자리 재사용과 정지 후 초기화를 확인했다. 기존 음원 파일과 음량은 변경하지 않는다.
