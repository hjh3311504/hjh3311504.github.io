# 얼음 경사판의 선택 동결음 연결

## 결정

사용자가 연속으로 얼어붙는 느낌의 새 음원을 선택했다. 얼음 경사판의 무음 대기 상태를 끝내고 `frost-freeze-v1.wav`를 연결한다.

- 약1.61초의 균열과 잔향을 하나의 효과음으로 사용한다.
- 동결이 시작되는 접촉에서 한 번 재생하며 같은 판에 붙어 있는 동안에는 반복하지 않는다.
- 일반3개 맵과 커스텀 맵에서 선행 로딩한다. 특수 구간 안내의 미리듣기도 같은 파일을 쓴다.
- 장치 그룹 동시1개·전체 동시3개와 기존 재생 간격을 유지한다. 재생 중인 동결음을 새 충돌 때문에 끊지 않는다.
- 경기 배속과 별개로 원래 음정·속도로 재생한다.1초 동결과 해제 뒤 경사 이동은 바꾸지 않는다.

## 검증

음향·얼음판 단위 테스트44개에서 정적 파일·선행 로딩·캐시 재사용·미리듣기·충돌 재생·중복 제한·음소거·정리를 확인했다. 선택 음원의 앞 균열과 뒤 잔향도 파일 검사로 확인했다.

lint·Svelte Check·build·정적 페이지·문서 연결 검증을 통과했다. 관련 Playwright는 새 동결음 파일을 허용 목록에 추가한 뒤 맵 음원 준비·일시정지·초기화·캐시 검사1개를 통과했다. 브라우저에서 얼음 경사판 미리듣기 버튼 활성화와 선택 파일 로딩, 오류 로그 없음을 확인했다.
