# QR 캡션은 일반 텍스트로 표시

- 상태: 승인됨
- 날짜: 2026-09-11
- 근거: 사용자의 「QR 미리보기와 두 열의 배치 정리」 계획 구현 요청

## 결정

미리보기 캡션은 제목 문자열을 받는 HTML 문단으로 표시한다. 선택·복사를 제공하고 제목 입력을 즉시 반영한다. SUIT 700과 데스크톱 22px·모바일 20px를 사용한다. 저장용 제목 윤곽선 계산은 PNG·SVG에 유지한다.

일반 미리보기의 QR은 최대 280px다. 빈 상태에도 QR과 60자 캡션 공간을 확보한다. 데스크톱에서는 입력·북마크 열과 미리보기의 전체 높이를 맞추고 북마크 목록을 내부 스크롤로 표시한다. 모바일에서는 각 카드가 독립된 높이를 갖는다.

출력은 너비 1,024px, QR 영역 768px, 위쪽 여백 32px를 사용한다. 제목은 QR 아래 32px부터 64px 크기·88px 줄 간격·896px 최대 너비로 배치한다. 빈 제목의 출력 높이는 832px다. 제목이 있으면 실제 줄 수와 아래 여백 32px를 추가한다. 출력 크기와 좌표는 image-layout.js에서 관리한다.

입력 하단 안내·입력 지우기·상시 상태 문구·북마크 저장 위치 배지를 제거한다. 오류와 SVG 재시도는 기존 오류 영역을 사용한다. 출력 중 버튼은 aria-busy를 제공하고 중복 실행을 막는다.

## 영향

미리보기는 화면 너비에 따라 자연스럽게 줄바꿈한다. PNG·SVG의 줄바꿈은 고정 출력 너비를 기준으로 서로 공유한다. SVG는 글꼴 참조 없이 제목 경로를 저장한다. 주소 변경 시 QR 계산, 제목 변경 시 제목 처리, 버튼 클릭 시 최종 이미지 생성 원칙과 북마크 형식은 유지한다.
