# 결승 추가 보정을1회로 줄인다

- 상태: 결정·겹침 허용 폭과 완주 지연은 미해결
- 날짜: 2026-09-23
- 연결 요구사항: REQ-MARBLE-002, REQ-MARBLE-004
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

사용자는 결승의 추가 겹침 보정을1회로 줄이도록 요청했다. 기본 구슬 충돌은 유지하고 `settleFinaleContacts`의 반복 횟수만 최대32회에서1회로 바꾼다. 회전바 길이440·주기8.8·회전 방향·위치는 유지한다.

물리 계산의 기본 간격은1/120경기초다. 각 단계는 이동 속도에 따라 다시 나뉜다. 기본 속도 상한430에서는2개로 나뉘므로 추가 보정은 보통1/240경기초마다 호출된다. 빠른 구슬이나 바람 스킬이 있으면 더 자주 호출된다. 이번 변경은 호출 간격이 아니라 호출당 순회 횟수를 바꾼다. 결승에 미도착 구슬이 없으면 바로 종료한다.

아래쪽 구슬부터 한 차례 처리하고 남은 겹침은 다음 세분 계산에서 다시 검사한다. 구슬 한 개가 여러 이웃과 닿으면 한 순회에서도 여러 번 위치가 바뀔 수 있다. 기본 반발 속도 계산·벽 충돌·고정 및 도착 구슬 제외·효과음 중복 방지는 유지한다.32회 보정 당시 상태와 완전히 같은 위치·순위를 보장하지 않는다. 이전 상태의 해시 비교는 현재200개 경기의0.25·1·2배속 동일 결과 검사로 바꾼다.

로컬 Node.js에서 같은200개 시작 배치·난수47·스킬ON으로12경기초를 계산했다. 각 방식의 준비 실행1회 후3회 측정 중앙값은32회 보정5.452초,1회 보정1.728초였다. 계산 시간이 약68% 줄었다. 두 방식의 진행 경로는 달라질 수 있으며, 이 결과는 브라우저fps나 휴대폰 성능 측정이 아니다.

기존 겹침1 이하 기준은 충족하지 못한다.60개 밀집 시험은 약1.675경기초에서 겹침1.107을 관찰했다.1열 배치에서도 기준을 넘었다. 기존 짧은 시간 내 전원 완주 조건도 통과하지 못한다. 실패한 기존 검사를 삭제하거나 허용 오차를 임의로 늘리지 않는다. 한 차례만 보정하는 새 검사, 고정 구슬 보호, 배속별 동일 상태와 Worker 동일성은 별도로 확인한다.

이 결정은 [당첨 후 결승 계산 분할](2026-09-22-당첨-후-결승-계산-분할.md)의 최대32회 보정과 물리 결과 보존 조건을 대체한다. Worker의 계산 분할·잔여 시간 전달과 기존 계산 재사용은 유지한다.
