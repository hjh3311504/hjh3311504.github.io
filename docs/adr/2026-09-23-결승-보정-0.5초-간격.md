# 결승 추가 보정을0.5경기초마다 실행한다

- 상태: 결정
- 날짜: 2026-09-23
- 연결 요구사항: REQ-MARBLE-002, REQ-MARBLE-004
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

사용자는 추가 보정을0.5초마다1회 실행하도록 요청했다. 기존 경기 시간 기준을 유지해0.5·1.0·1.5경기초 경계에 실행한다. 벽시계나 별도 타이머는 사용하지 않는다. 각 경계를 처음 지난 세분 계산에서 한 차례만 순회한다. 기본 구슬 충돌과 벽 충돌은 모든 세분 계산에서 계속 처리한다.

새 경기는 첫 보정 시각을0.5로 초기화한다. 다음 예약은 경기 시간의0.5초 배수로 정해 누적 오차를 막는다. 결승에 대상이 없어도 다음 시각으로 예약을 옮긴다. 일시정지 중 경기 시간이 흐르지 않으면 보정도 실행하지 않는다.0.25배속에서는 실제 약2초,1배속에서는0.5초,2배속에서는0.25초마다 실행된다. 기기가 계산 속도를 따라가지 못하면 실제 간격은 더 길어질 수 있다.

실행 사이에는 추가 보정으로 풀지 못한 겹침이 더 오래 남을 수 있다. 기존 겹침1 이하·완주 시간 기준을 충족한다고 주장하지 않는다. 회전바 길이440·주기8.8·위치·방향은 유지한다.

0.5초 직전·경계·직후와 다음1.0초 경계에서 실제 구슬 위치를 비교한다. 추가 보정1회, 새 경기 예약 초기화, 고정 및 도착 구슬 제외,200개 경기의 배속별 동일 결과와 Worker의 직접 계산 일치를 검사한다.

이 결정은 [결승 추가 보정1회](2026-09-23-결승-추가보정-1회.md)의 실행 간격만 대체한다. 이전 성능 수치는 매 세분 계산에서1회 보정한 결과이므로 현재 설정의 측정값으로 사용하지 않는다.
