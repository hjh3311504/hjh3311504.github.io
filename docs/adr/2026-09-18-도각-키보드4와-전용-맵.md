# 도각 키보드4와 전용 맵

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 도각 블록을 하나 더 추가하고 도각4종으로 맵을 구성하도록 요청했다.

도각 키보드4(`thock4`)를 살구색 키캡과 숫자4로 표시한다. 도감과 커스텀 맵에서 선택할 수 있다. 도각1과 같은 반발계수0.61·마찰0.25, 첫 충돌 파괴·3초 복구를 적용한다. 도감과 경기는 `thock4-v1.wav`를 공유하며 전체 동시12개·최소28ms 제한을 유지한다. 활성 일반 블록은13종이다.

기존3개 맵을 유지하고 도각 키보드 모음(`thock-collection`)을 추가한다. 재질 순서는 도각 → 도각2 → 도각3 → 도각4다. 일반4구역·960개 블록과 특수 구간·결승 구조는 재사용한다. 마지막 선택 맵은 기존 설정 저장 방식으로 복구한다. 기존 도각1·2·3의 음원과 저장된 커스텀 맵은 유지한다.

검증: 음향·설정 관련 단위 검사42개와 재질·물리 검사3개를 통과했다. 브라우저 검사3개로 도감13종의 서로 다른 이미지, 도각4 미리듣기, 모든 맵의 음원 선행 로딩과 재시작을 확인했다. 새 맵에서2/30/60명·난수10개의30경기가 모두120경기초 안에 완주했다. 최대 완주 시간은83.97초다. 결승 체류15초 목표는20경기에서 넘었으며 최대50.88초다. 기존 결승 대기 문제와 구분해 기록하며 이번 블록 추가에서 판정이나 충돌을 바꾸지 않았다. lint·정적 검사·build·정적 산출물·문서 연결 검사도 통과했다.
