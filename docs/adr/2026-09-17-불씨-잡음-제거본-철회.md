# 불씨 잡음 제거본 철회

- 날짜: 2026-09-17
- 상태: 적용

사용자가 잡음 제거본 v3를 듣고 소리가 이상해졌다고 평가했다. 잡음을 줄인 수치만으로 불씨 질감의 보존을 판단할 수 없었다.

불씨 음원을 기존900ms v2 파일로 복구한다. 새로 편집하지 않고 기존 파일과 출처 기록을 그대로 사용한다. 재생 제한3개·120ms·음량 배율0.85는 유지한다. 다시 생성하는 스크립트에서도 v3 잡음 제거와 지연 보정을 제거한다.

배경 잡음 제거 요청은 아직 해결하지 못했다. v3 음원과 이전 ADR은 철회한 시도의 기록으로 보존한다. 활성 음원의 길이·첫 타격·끝부분·음량 차이·파일 해시는 기존 음향 테스트로 확인한다.

검증 결과: 음향 단위 테스트28개, build, 정적 build 검증과 `git diff --check`가 통과했다. 복구 파일2개의 해시가 v2 기록과 일치하며 다른 자연음의 출처 기록은 그대로다. 실제 청감 만족도는 이번 검사로 판단하지 않는다.
