# 결승 후보 즉시 전환

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 선두 변경 시 카메라와1등 표식을 즉시 옮기도록 요청했다.

기존 후보 확정 대기0.3경기초는0.3배속에서 실제 약1초가 걸렸다. 후보를 매 물리 계산 단계의 현재 순위로 즉시 갱신하도록 바꾼다. 첫 번째·여러 명은 선두, 마지막은 꼴등, n번째는 현재 n등 후보라는 규칙은 유지한다.

결승 후보가 바뀌면 카메라는 다음 화면 갱신에서 새 후보의 좌우·상하 위치로 바로 이동한다. 확대 비율은 유지하며 같은 후보가 계속 움직일 때만 기존의 부드러운 추적을 사용한다. 카메라·강조 표식은 같은 경기 상태의 후보 번호를 사용한다. 순위 목록도 후보 변경 시 즉시 갱신해 기존150ms 주기 갱신을 기다리지 않는다.

경기 시간·0.3배속·당첨 확정·축하 중복 방지는 바꾸지 않는다. 수신 전의 물리 상태를 예측하지 않고 Worker가 전달한 최신 경기 상태를 기준으로 표시한다.

현재 경기 시각을 그대로 둔 여러 번의 추월과4개 당첨 방식, 카메라 보간 시간이0인 후보 변경, Worker 계산 일치 및 결승 연출을 검사한다.
