# 파동음 Pixabay A 선택

## 결정

사용자가 후보 A를 선택했다. 원형 파동의 음원을 ksjsbwuil의 Whoosh Deep Short로 교체한다. 출처와 이용 조건은 [음원 기록](../marble-audio-sources.md)에 남긴다.

새 파일 `pulse-whoosh-deep-v2.wav`를 사용해 이전 음원의 캐시와 구분한다. 도감 미리듣기와 경기 발동에서 같은 파일을 쓴다. 앞뒤 무음을 정리한1.75초 길이로 연결하며 원음의 음색·음정·재생 속도를 유지한다.

기존 파동 동시1개·최소200ms, 전체6개·최소28ms, 우선 재생·음소거·볼륨·정지 처리는 변경하지 않는다. 기존 자체 파동음은 공개 정적 자산에서 제외한다.

## 검증

음향 단위 테스트44개를 통과했다. 파일의 WAV 형식·유효 파형, 도감과 경기 파일 공유, 동시 재생·간격·정지 처리를 확인했다. 파형의 시작·끝 무음과 최대 음량도 확인했다. 직접 청음한 평가는 포함하지 않는다.

Chromium에서 도감 미리듣기와 실제 파동 발동이 새 파일을 재생하는 검사1개를 통과했다. build·변경 코드 lint·문서 연결 검사도 통과했다. 전체 경기 검사는 음원 교체 범위에 포함하지 않았다.
