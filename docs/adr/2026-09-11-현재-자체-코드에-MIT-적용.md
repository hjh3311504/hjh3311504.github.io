## 추가로 확인한 내용

앞선 보류는 GPL 코드가 남았다는 확정에 따른 결정이 아니었다. 홈·공통 UI의 출처 검증이 부족했기 때문이다. 이번에는 새 파일 여부만 보지 않고 원본 component의 동작·마크업·스타일과 실제 작성 이력을 함께 대조했다.

## 결정과 적용 범위

구조와 작성 이력을 함께 검토한 결과 현재 실행 코드에서 템플릿의 고유 구현을 찾지 못했다. 사용자에게서 확인한 자체 작성·생성 경위와 MIT 적용 요청을 근거로, 현재 자체 소스·script·테스트·설정·일반 문서와 이번에 생성한 사이트 자산에 MIT를 적용한다. 과거에 GPL 아래 공개됐다는 이유만으로 권리자가 자신의 독립 코드에 다른 라이선스를 적용하지 못하는 것은 아니다.

`LICENSE`에는 표준 MIT 원문과 `Copyright (c) 2026 Lake (hjh3311504)`를 기록한다. `package.json`과 lock 파일의 프로젝트 license도 MIT로 맞춘다. 영어 라이선스 원문은 번역하거나 조건을 고쳐 쓰지 않는다.

정확한 포함·제외 경로는 루트 `THIRD_PARTY_NOTICES.md`를 기준으로 한다. SUIT·SUITE는 OFL, Bootstrap 아이콘은 원저작권자가 부여한 MIT, npm 의존성은 각 라이선스를 유지한다. `static/images/team-maker/`, `docs/design/handoff/`, 마지막 Claude Design 요청문은 이번 MIT 적용에서 제외한다. 제외된 자료를 GPL이나 MIT로 새로 허가한다고 표시하지 않는다.

원본 템플릿과 과거 commit의 조건은 유지한다. 기존 ADR 본문도 보존하고 목록에서 새 결정으로 연결한다. 원저작자에게 연락하거나 별도의 허락을 받았다고 주장하지 않는다.

## 배포와 검증

`scripts/licenses.js`의 목록에 따라 자체 MIT, 출처 목록, 글꼴·Bootstrap Icons·브라우저 실행 의존성의 라이선스 원문을 `build/licenses/`에 포함한다. 설치된 패키지 원문을 복사하므로 패키지 업데이트 때도 저작권 고지가 함께 갱신된다. 의존성이 바뀌면 복사 목록도 함께 검토한다.

build 검사는 package의 MIT 표시와 자체 LICENSE를 확인하고, 배포한 모든 원문을 원본 파일과 비교한다. 기존 lint·정적 검사·단위 테스트·build·브라우저 테스트도 실행한다. GitHub 링크의 크기와 이름은 유지하며 새 아이콘의 표시를 브라우저에서 확인한다.
