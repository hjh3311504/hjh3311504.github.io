# 번개 구슬의 회전바 접촉과 오른쪽 이동

- 상태: 결정
- 날짜: 2026-09-23
- 연결 요구사항: REQ-MARBLE-002, REQ-MARBLE-003
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

사용자는 번개에 맞은 구슬도 회전바에 밀려나도록 요청했다. 회전축은 조금 오른쪽으로 이동한다.

번개 정지 중에는 결승 회전바와의 접촉을 매 세분 계산에서 확인한다. 닿으면 기존 바·벽 충돌 처리로 고정 위치를 옮긴다. 이동 뒤 속도는0으로 두며 번개의 종료 시각을 바꾸지 않는다. 바가 떨어지면 그 위치에서 정지하고, 종료 시각에 도달하면 새 위치에서 중력으로 떨어진다. 흰 전기 효과는 계속 표시한다. 얼음판 고정은 기존대로 유지한다.

번개 구슬의 실제 회전바 접촉도0.5경기초 보정 기록에 넣어 주변 이웃을 검사한다. 이때 번개 구슬 자체는 옮겨진 고정 위치를 유지하고 겹친 이웃을 민다. 같은 번개 상태가 이어지는 표시 프레임 사이에서는 이동을 보간한다. 번개 시작·해제·골인 전환은 이전처럼 즉시 표시한다.

회전축은 `(140, 결승 시작점+460)`에서 `(160, 결승 시작점+460)`으로 오른쪽20 이동한다. 길이440·회전 주기8.8경기초·방향·충돌 세기는 유지한다. 기존 중앙 경로 표본 검사에서 바와 겹칠 수 있는 시간은 한 바퀴당1.79초에서2.52초로 늘어난다. 더 이전 위치 `(200, 시작점+500)`의4.11초보다는 짧다. 실제 구슬의 체류 시간을 뜻하지 않는다.

번개 상태·종료 시각·이동 후 낙하·얼음 고정 유지·상태 전달·표시 보간과 모바일·데스크톱의 실제 계산 장면을 검사한다. 이번 변경은 기존 밀집 겹침·완주 지연을 해결한 것으로 표시하지 않는다.

이 결정은 [회전바 주변 보정과 왼쪽 위 이동](2026-09-23-회전바-주변보정과-왼쪽위-이동.md)의 회전축 위치와 번개 구슬 제외 조건을 대체한다.
