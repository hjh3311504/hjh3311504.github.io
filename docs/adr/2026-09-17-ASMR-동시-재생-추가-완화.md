# ASMR 동시 재생 추가 완화

- 상태: 사용자 요청에 따라 적용
- 날짜: 2026-09-17

사용자가 동시 소리 제한을 더 풀어 달라고 요청했다. 긴 질감 소리의 재질별 한도를2개에서3개로, 질감 합계 한도를4개에서6개로 늘린다.

시작 간격은 키네틱 샌드·비누80ms→60ms, 슬라임110ms→80ms, 왁뿌볼140ms→100ms로 줄인다. 전체12개·28ms 제한과 키보드·타자기·팝잇·장치 설정은 유지한다. 승인 음원과 전체 음량은 바꾸지 않는다.

음원 단위 테스트18개가 통과했다. 질감3개 겹침과 합계6개 제한, 기존 소리 유지, 재생 간격과 정지 후 초기화를 확인했다. 실제 청음 만족도는 자동 검사로 확정하지 않는다.
