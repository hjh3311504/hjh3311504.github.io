# ASMR 구슬 레이스 검색 정보와 사용 가이드

- 날짜: 2026-09-18
- 상태: 사용자 요청에 따라 구현
- 연결: REQ-MARBLE-005, SCR-WEB-004

## 결정

이름을 ASMR 구슬 레이스로 정하고 검색 제목에 무료 구슬 추첨기·랜덤 뽑기를 함께 쓴다. [참조 사이트](https://lazygyu.github.io/roulette/)는 마블 룰렛·랜덤 추첨기라는 용도를 제목에 드러낸다. 우리 페이지는 블록 충돌음과 직접 고르는 맵을 중심으로 설명한다. 경쟁사 이름을 자사 이름이나 검색 키워드로 사용하지 않는다.

검색 설명·canonical·공유 카드·전용 이미지·WebPage와 WebApplication 정보를 제공한다. 공용 DisclosureSection에 사용법·당첨 방식·수업/방송 활용·FAQ를 정적 본문으로 넣는다. 공개 경로와 기존 sitemap·robots 허용 설정은 유지한다. 확인되지 않은 평점·리뷰와 같은 당첨 확률은 추가하지 않는다.

[Google의 AI 검색 안내](https://developers.google.com/search/docs/appearance/ai-features)에 따라 검색 가능한 HTML 본문, 내부 링크, 본문과 일치하는 구조화 데이터에 집중한다. AI 검색 전용 파일이나 특수 마크업이 필수라는 주장은 하지 않는다. [앱 구조화 데이터 안내](https://developers.google.com/search/docs/appearance/structured-data/software-app)도 참고하되 실제 평점이 없으므로 앱 리치 결과 요건 충족을 주장하지 않는다. 검색·AI 답변의 노출 순위나 반영 시점은 보장할 수 없으며 배포 뒤 수집이 필요하다.

## 접근성 수정

일시정지 버튼·경기 상태·창 제목의 표현을 통일한다. 경기 시작·당첨·종료 안내는 시각 정보를 보지 못하는 사용자에게 필요하므로 유지한다. 기존 안내가 숨김 스타일의 적용 영역인 `.marble-page` 밖에 있어 화면에 보일 수 있었다. 이를 경기장 안으로 옮기고 전체 문장을 알리도록 설정한다. 화면의 여백에는 영향을 주지 않으며 전체화면에서도 사용할 수 있다.

## 검증

정적 build 검사에서 검색·공유 정보, 구조화 데이터, FAQ 본문과 이미지 크기를 확인한다. 브라우저에서는 가이드 접기·펼치기, 모바일 배치, 일시정지 표시와 화면 읽기 안내가 숨겨지는지 확인한다. 검색 순위나 실제 AI 답변 인용 여부는 로컬 검사의 범위가 아니다.

검증 결과: lint·Svelte Check·build·정적 build 검사·UI 문서 연결 검사를 통과했다. 관련 Playwright8개에서 검색 정보·가이드 접기/펼치기·숨김 안내·320px 화면·일시정지·기존 경기 조작을 확인했다. 전용 공유 이미지와 가이드의 데스크톱·모바일 화면도 확인했다.
