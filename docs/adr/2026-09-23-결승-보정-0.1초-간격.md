# 결승 추가 보정을0.1경기초마다 실행한다

- 상태: 적용·밀집 겹침은 일부 남음
- 날짜: 2026-09-23
- 연결 요구사항: REQ-MARBLE-002, REQ-MARBLE-004
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

사용자는 결승에서 구슬 겹침 검사를 더 자주 실행하도록 요청했다. 추가 위치 보정의 간격을0.5경기초에서0.1경기초로 줄인다. 실행 빈도는5배로 늘어난다. 회전바에 닿은 구슬과 그 구슬에 연결된 겹친 이웃을 한 차례씩 처리한다.

## 적용 규칙

- 최근0.1경기초의 회전바 접촉을 다음 보정의 시작점으로 사용한다. 처리한 기록은 비운다. 대상이 없으면 주변 탐색을 건너뛴다.
- 경기 시간의0.1초 경계를 처음 지난 세분 계산에서 한 차례 보정한다. 새 경기의 첫 예약은0.1초다. 일시정지 중에는 경기 시간과 보정이 함께 멈춘다.
- 실제 시간으로는1배속에서 약0.1초,2배속에서 약0.05초,0.25배속에서 약0.4초 간격이다. 기기가 계산을 따라가지 못하면 실제 간격이 더 길어진다.
- 기본 구슬·벽 충돌은 계속 매 세분 계산에서 처리한다. 추가 보정은 반발력·효과음·스킬을 중복 적용하지 않는다. 결승 벽 통과 방지와 중앙 통로 진입 판정을 유지한다.

## 검증 범위와 한계

0.1초 직전·경계·직후와0.2초 경계의 실제 위치, 새 경기 초기화, 접촉 기록의 범위, 연결된 이웃, 고정·도착 구슬 보호를 검사한다. 같은 경기 시각에서0.25·1·2배속의 위치·순위·스킬 상태가 일치해야 한다.1000개 밀집의 벽 통과 방지도 다시 검사한다.

간격을 줄여도 한 차례의 보정으로 모든 겹침을 없애지는 못한다. 기존의 실제 위치·표시 위치에서 겹침1 이하를 요구하는 검사2개는 계속 실패하며 기준을 낮춰 통과시키지 않는다. 과도하게 밀집한1000개 상황에서는 완전히 겹친 쌍이 남을 수 있다.

1000개를 결승 앞에20열로 배치하고 난수47·스킬ON·시작 각도0과3π/2에서 각각35경기초를 비교했다. Node.js에서 물리 단계1회의 평균 시간은 각도별로6.81→6.72ms,6.34→6.38ms였다. 단일 로컬 측정이므로 브라우저의 실제 배속이나 기기별 성능으로 해석하지 않는다.

같은 시험에서 겹친 쌍의 침투 깊이 합을 표본마다 구한 평균은2124→1712,1932→2300이었다. 각도에 따라 개선과 악화가 함께 나타났고 최대 겹침은 구슬 지름에 가까운26이었다. 이 변경은 검사 주기를 줄이는 조정이며 밀집 겹침의 완전한 해결은 아니다.

관련 단위 테스트31개 중29개를 통과했다. 실패2개는 변경 전0.5초 간격에서도 같은 조건으로 실패하는 것을 확인했다.1000개·시작 각도4가지의 각35경기초 벽 통과 검사와60개·각도4가지의 완주 검사는 통과했다. 정적 검사·변경 파일 lint·포맷·요구사항·화면 문서 연결 검사도 통과했다. 이번 변경에서는 build와 브라우저 검사를 실행하지 않았다.

이 결정은 [결승 보정0.5초 간격](2026-09-23-결승-보정-0.5초-간격.md)의 간격과 [회전바 주변 보정](2026-09-23-회전바-주변보정과-왼쪽위-이동.md)의 접촉 기록 시간을 대체한다. 각 보정의 순회 횟수와 범위는 유지한다.
