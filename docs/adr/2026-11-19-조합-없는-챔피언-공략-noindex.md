# 검증된 조합이 없는 챔피언 공략을 noindex로 둔다

- 상태: 결정
- 근거: 2026-11-19 사용자 결정. AdSense가 `setalab.kr`을 6번째로 거절했다. 사유는 ‘가치가 별로 없는 콘텐츠’였다.
- 관련 요구사항: `REQ-ARAM-003`, `REQ-WEB-027`, `REQ-SEO-001`
- 관련 기록: [AdSense 콘텐츠 점검](../adsense-content-review.md)

## 배경

2026-11-19에 공개 sitemap 214개 주소의 본문을 쟀다. 공백을 빼고 `<main>` 안의 글자만 셌다. Riot Games 고지와 footer도 포함한 값이다.

| 묶음           | 수    | 본문 글자 수(중간값) |
| -------------- | ----- | -------------------- |
| 챔피언 공략    | 173개 | 537자                |
| 증강 공략      | 4개   | 692자                |
| 블로그 글      | 28개  | 2,706자              |
| 그 밖의 페이지 | 9개   | 1,581자              |

sitemap의 83%가 아수라장 상세 페이지였다. 챔피언 공략 173개 중 96개는 증강 조합 없이 `아직 검증된 조합이 없어요` 안내와 아이템 목록만 있었다. 이 페이지들은 같은 틀에 챔피언 이름과 아이템만 바뀐다. Google의 [가치가 낮거나 미완성인 화면](https://support.google.com/publisherpolicies/answer/11112688?hl=ko) 설명과 가장 가깝다고 판단했다. Google이 문제 URL을 알려 주지 않았으므로 원인으로 확정하지는 않는다.

## 결정

- 조합(`combos`)이 하나도 없는 챔피언 공략에 `<meta name="robots" content="noindex">`를 넣는다. 링크는 따라가게 둔다.
- 이 주소는 sitemap과 허브의 챔피언 목록 구조화 데이터에서 뺀다.
- 이 주소에는 AdSense 코드를 넣지 않는다. 광고가 있는 페이지에서 이동하면 새 문서로 불러와 이미 실행된 광고 코드를 남기지 않는다.
- 페이지 자체와 허브 타일, 검색, 방문 통계는 유지한다. 게임 중에 빌드를 찾는 사용자는 계속 쓸 수 있다.
- 기준은 `src/lib/aram-mayhem/seo.js`의 `isIndexedChampion` 하나다. 조합을 더하면 다음 배포부터 자동으로 sitemap·광고 대상에 다시 들어간다.

검토한 다른 방법:

- 상세 페이지 177개를 모두 제외: 심사에는 더 유리하다. 하지만 검색 유입이 늘고 있는 조합 있는 공략과 증강 공략까지 잃는다. 이번에는 고르지 않았다.
- 페이지를 그대로 두고 설명만 보강: 근거 없는 조합이나 설명을 지어낼 수 없다. 96개를 채울 자료가 지금은 없다.

## 영향과 남은 문제

- sitemap 주소는 214개에서 118개로 준다. 그중 아수라장 상세 페이지는 81개(69%)다.
- 조합이 있는 챔피언 공략 77개도 본문이 짧다. 이번 조치 뒤에도 거절되면 이 페이지들의 보강이나 제외를 다시 검토한다.
- `noindex`는 검색 결과에서 빼 달라는 지시다. AdSense 심사 크롤러가 이 페이지를 보지 않는다는 보장은 없다. 심사 직후 되돌리지 않고 조합이 생길 때만 다시 포함한다.
- 이미 색인된 주소는 Google·네이버가 다시 방문해야 검색 결과에서 빠진다.
