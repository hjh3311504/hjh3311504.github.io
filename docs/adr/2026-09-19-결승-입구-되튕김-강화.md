# 윗 회전판을 제거하고 입구 판의 되튕김을 강화한다

## 배경과 사용자 선택

사용자가 추가 회전판의 효과가 없다고 지적했다. 기본10개 구슬·난수3가지에서는 윗 판에 닿은 구슬이 각각1·2·2개뿐이었다. 윗 판이 있는 경우와 없는 경우의 우승자·첫 골인 시각도 같았다. 기존의 완주·정체 검증만으로 재미를 확인했다고 볼 수 없었다.

2026-09-19 사용자는 윗 회전판을 없애고 기존 입구 판의 위치·길이를 조정해 골인 직전 되튕김과 역전 기회를 만드는 방향을 선택했다. 이 결정은 앞선 엇갈린 회전판 결정 중 결승 배치만 대체한다. 이름표·모바일 버튼·footer 수정은 유지한다.

## 결정

- 회전판은 입구에1개만 둔다. 회전축은 기존 x290·결승 시작점400아래에서 x220·410아래로 옮긴다. 길이는180에서290으로 늘리고 두께16·모서리 반경8은 유지한다.
- 수평 상태의 오른쪽 끝은 기존 x380에서 x365로 옮긴다. 판의 더 바깥쪽 면으로 구슬을 걷어 올리면서 출구 오른쪽을 덜 가려 뒤 구슬이 통과할 기회를 준다.
- 반시계 방향·4.4경기초 회전 주기·탄성0.35·마찰0.05를 유지한다. 별도의 밀어내는 힘이나 순간이동 없이 실제 회전 표면의 속도로 충돌한다.
- 깔때기·폭40통로·판정선은 유지한다. 슬로모션 시작점은 움직인 회전축 대신 골인 입구100위로 계산해 기존 결승 시작점300아래를 유지한다. 확대·음향·당첨·배속 복귀도 유지한다.
- 경기 그림과 미니맵은 같은 판을 사용한다. 화면 가장자리에 판 끝만 보이는 경우도 늘어난 회전 반경에 맞춰 그린다.

## 비교 방법과 검증 기준

기존 배치는 추가 판을 제외한 x290·높이400·길이180이다. 변경 배치와 같은 진입 상태·시작 각도로 비교한다. 스킬은 꺼서 회전판 효과만 측정한다.

접전은 두 구슬을 입구45위와75위에서 하강 속도150으로 출발시킨다. 좌우를 바꾼2가지 배치와 시작 각도16개를 조합한다. 판에 닿은 선두가 위로 움직이기 시작한 위치부터 하강으로 바뀔 때까지의 높이를 측정한다. 접전32개에서 평균 상승 높이가20% 이상 커지고 역전 횟수는 줄지 않아야 한다. 고정 접전에서는 기존에 이기던 선두가 튕기는 사이 뒤 구슬이 실제 판정선을 먼저 통과하는지도 검사한다.

기본3개 맵×2/30/60개×난수10개의120경기초 완주와 밀집60개×시작 각도4가지의60경기초 완주를 유지한다.8.8경기초 배출 정체·벽 관통·동일 난수 재현도 검사한다.1,000개 장시간 완주 검사는 추가하지 않는다.

## 사전 비교

- 접전32개에서 선두의 평균 상승 높이는58.89에서97.16으로 약65% 커졌다. 역전은 두 배치 모두10개였으며 전체 역전 비율이 늘었다고 주장하지 않는다.
- 오른쪽 선두·왼쪽 추격·시작 각도π/8의 접전은 기존 선두 우승에서 추격 구슬 우승으로 바뀌었다. 선두가 상승하는 동안 추격 구슬이 아래로 앞서 나가는 것을 확인했다.
- 기본3개 맵·10개 구슬·난수5가지의15경기는 결승 진입 시 상태를 복사해 비교했다. 평균 상승 높이는58.22에서83.01로 커졌고 평균 첫 골인은40.62에서39.68경기초로 변했다. 역전은10경기에서8경기로 줄었다. 이 표본에서도 역전 비율 개선으로 해석하지 않는다.

## 구현 후 검증

- 구슬 레이스 단위 테스트153개를 통과했다. 기본90경기의 최대 완주 시간은77.78경기초다. 결승15초 목표를 넘긴 경기는57개이며 최대 결승 체류는42.52경기초다.
- 밀집60개·시작 각도4가지는38.30~42.70경기초에 전원 완주했다. 최대 배출 간격은2.53경기초이며 벽 관통과 배출 정체는 없었다.
- 관련 브라우저12개를 통과했다. 실제 계산한 되튕김 장면·회전판1개와 미니맵 위치·이름표·모바일 버튼·후보 추적·마지막 당첨·여러명 당첨을 확인했다. 화면용 고정 장면은 물리 계산 결과를 전달 경계에서 주입하며 실제 경기를 대체한 측정으로 표현하지 않는다.
