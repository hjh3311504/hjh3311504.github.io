# 확률형 구슬 파동 스킬

## 결정

사용자 요청으로 출발 준비 중 선택하는 스킬 사용 토글과 원형 파동을 추가한다. 기본은 OFF다. 후속 요청에 따라 경기 중·일시정지·로딩 중에는 토글을 잠그고 Worker 준비 시 선택을 확정한다. 초기화 후에는 페이지 안의 선택을 유지하고 새 페이지에서는 OFF다. 저장 형식은 바꾸지 않는다.

ON일 때 경기2초 이후 미도착·비동결 구슬마다 초당 약1% 확률을 적용한다. 고정 계산 간격마다 `1 - exp(-0.01 × dt)` 확률로 검사하고, 구슬별8경기초의 대기 시간을 둔다. 배치 난수와 별도 난수를 사용해 OFF일 때 기존 경기 난수를 바꾸지 않는다. 순위·이름은 발동 확률과 힘에 관여하지 않는다.

파동 반경은120이다. 범위 안의 다른 구슬에 거리별 `340 × (1 - 0.65 × 거리 / 120)`만큼 바깥 방향 속도를 더한다. 위치를 옮기거나 충돌을 끄지 않으며 힘을 준 뒤 이동 세분화 계산으로 벽·블록 충돌을 유지한다. 동결·도착 구슬은 제외한다. 중심이 완전히 겹쳤을 때만 고유 번호로 재현 가능한 분리 방향을 구한다.

파동은 발사 위치에0.45경기초 동안 확대되는 이중 원으로 표시한다. 동작 줄이기에서는 확대 없이 옅은 원만 표시한다. 일시정지 시 파동 시간도 멈춘다. 새 경기에는 이전 파동·대기 기록을 넘기지 않는다. 새 음원은 추가하지 않는다.

## 검증

거리·방향·제외 대상·연속 발동 제한·난수 재현·벽 충돌과 Worker 전송을 검사한다.0.25·1·2배속에서 스킬 ON/OFF 각각 Worker와 직접 계산 결과를 비교한다. 경기 진행 메시지에 다른 스킬 설정이 들어와도 시작 설정을 유지하는지 검사한다. 브라우저에서 기본 OFF·키보드 선택·진행 및 정지 중 잠금·설정 화면 복귀·모바일 배치를 확인한다.

관련 단위 테스트11개와 Chromium 검사2개를 통과했다. 스킬 ON으로 기본3개 맵을2/30/60명·난수47에서 실행한9경기는 모두120경기초 이내 전원 완주했다. 완주 시간은42.17~~86.19경기초, 경기별 발동은2~~38회였으며 중복 도착은 없었다. 이는 한 난수의 동작 확인이며 모든 경기의 시간이나 우승 분포를 보장하지 않는다.

정적 검사·변경 파일 lint·포맷·build·정적 결과·문서 연결 검사를 실행했다. 전체 테스트와 장시간1,000개 경기는 실행하지 않았다.
