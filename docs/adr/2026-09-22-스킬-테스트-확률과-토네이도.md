# 스킬 테스트 확률과 토네이도 효과

## 결정

사용자가 스킬을 자주 확인할 수 있도록 발동 확률을 높이고 도감 아이콘과 바람 효과를 변경하도록 요청했다.

스킬 발동률 상수는0.005에서0.1로20배 높인다. 초당 약10%의 테스트용 임시값이며 구슬별8초 대기와3종의 같은 선택 확률은 유지한다. 테스트가 끝난 뒤 원래 발동률로 복원할 때는 별도 요청에 따라 변경한다.

도감의 번개·바람은 구슬을 포함한 작은 경기 그림 대신 번개 모양과 바람 모양 아이콘을 사용한다. 경기의 바람은 아래에서 자라 위로 올라가는 어두운 토네이도로 표현한다. 회오리 층과 먼지가 상승하며 동작 줄이기에서는 고정된 모양으로 표시한다. 바람의 범위·지속 시간·피격·효과음은 기존 결정을 유지한다.
