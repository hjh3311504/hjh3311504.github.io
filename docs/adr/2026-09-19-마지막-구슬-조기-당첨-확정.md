# 마지막 미도착 구슬의 당첨 확정

- 상태: 승인됨
- 날짜: 2026-09-19
- 관련 요구사항: REQ-MARBLE-001
- 근거: 사용자가 마지막 방식에서 골인하지 않은 구슬이1개 남는 순간 당첨과 팡파레를 실행하도록 요청했다.

## 결정

마지막 방식은 다른 구슬이 모두 도착한 순간 남은 구슬을 당첨자로 정한다. 공통 winners 함수에서 판정하므로 Worker의 축하 이벤트와 화면의 확정 당첨 목록이 같은 규칙을 사용한다.

당첨 이벤트는 기존 고유 번호별 중복 방지를 사용한다. 당첨 확정 즉시 슬로모션을 해제하고 사용자가 선택한 배속으로 복귀한다. 구슬을 골인 처리하거나 이동시키지 않으며 마지막 구슬의 실제 골인까지 물리 계산과 도착 순위 기록을 계속한다. 나중의 골인에서는 팡파레를 반복하지 않는다.

같은 계산 단계에서 마지막 구슬들이 모두 도착하면 실제 교차 시각으로 정렬된 최종 도착자를 당첨자로 선택한다. 첫번째·여러명·n번째 방식과 저장 형식은 유지한다. 가이드와 경기 방식 설명도 마지막 남은 구슬 기준으로 바꾼다.

## 검증

2·3·30개 구슬에서 미도착1개가 되는 시점, 중복 이름의 고유 번호, 슬로모션 해제·중복 축하 방지·새 경기 초기화와 같은 계산 단계의 도착 순서를 검사한다. 실제 Worker로 진행하는 브라우저 경기에서 마지막 구슬 골인 전 팡파레·당첨 목록·축하 효과와 골인 뒤 중복 방지를 확인한다.

- 관련 단위 검사25개 통과. 다른3가지 당첨 방식과 Worker의2배속 복귀 검사도 포함한다.
- Chromium의 실제2개 경기에서 골인 전 팡파레 재생·축하 표시·2배속 복귀·골인 뒤 중복 방지 검사1개 통과.
- 변경 파일 lint·포맷, Svelte 정적 검사, build1회, 정적 결과 검증·문서 연결 검사·diff 검사 통과.
- 전체 경기 테스트는 로컬에서 반복하지 않았다. 실제 청음의 질감 평가는 이번 변경 범위에 포함하지 않는다.
