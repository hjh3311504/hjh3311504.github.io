# 아수라장 장갑 충격 모루작 빌드와 추천 모루

- 날짜: 2026-11-02
- 상태: 채택
- 근거: 사용자가 2026-11-02 장갑 충격의 다른 템트리(쇠사슬 조끼 6개 → 해신 작쇼 → 모루)를 `모루작 빌드`로 바꾸라고 정했다. 아이템은 쇠사슬 조끼 + 2티어 신발 → 해신 작쇼 → 모루로 바꾸고, 기본 빌드보다 모루 등급에 기대 저점이 낮다는 안내를 붙이라고 했다. 프리즘 모루에서는 방어구 관통력으로 피해를, 모든 피해 흡혈로 유지력을 챙기라고 정했고, 등급별로 유효한 모루 선택지를 정리해 두라고 요청했다.
- 이전 결정: [아수라장 운명의 무기 1코어 추천](2026-10-28-아수라장-운명의-무기-1코어-추천.md)(쇠사슬 조끼 6개 템트리를 처음 넣은 결정)

## 결정

`docs/research/aram-mayhem/augment-guides.json`의 장갑 충격 `builds`를 모루작 빌드로 바꾼다. 증강 공략과 장갑 충격 빌드가 있는 챔피언의 `장갑 충격 · 모루작 빌드` 탭이 같은 내용을 보여 준다.

- 아이템: 쇠사슬 조끼 + 2티어 신발 → 해신 작쇼 → 모루(반복 구매). 함께 사는 아이템은 `withPrevious`로 적고 화면에서 `+`로 잇는다. 2티어 신발은 특정 신발이 아니어서 기본 장화(1001) 아이콘을 쓴다.
- 추가 안내(`cautionKo`): 기본 빌드보다 모루 등급에 크게 기대는 빌드라 저점이 낮다.
- 추천 모루(`anvils`): 등급 묶음마다 1순위·2순위 능력치 이름만 보여 준다. 수치와 이유 설명은 넣지 않는다. 화면은 사용자가 시안 중 고른 표(줄은 등급, 칸은 1순위·2순위)로 보여 주고 1순위 타일을 강조한다.

| 등급      | 1순위                         | 2순위                                                            |
| --------- | ----------------------------- | ---------------------------------------------------------------- |
| 프리즘    | 방어구 관통력, 모든 피해 흡혈 | 이동 속도, 강인함, 체력과 크기                                   |
| 골드·실버 | 방어력, 방어력 + 마법 저항력  | 물리 관통력, 체력, 스킬 가속, 스킬 가속 + 공격 속도, 마법 저항력 |

추천은 모두 사용자가 정했다. 처음에는 수치와 이유 문장, 주 담당이 고른 골드·실버 추천을 넣었지만 사용자가 설명과 수치를 빼고 두 단계 우선순위로 바꾸라고 정했다. 빠진 선택지를 확인한 뒤 2순위에 체력과 크기(프리즘)와 마법 저항력(골드·실버)을 더했다. 능력치 이름은 [League of Legends Wiki의 Stat Bonus (ARAM: Mayhem)](<https://wiki.leagueoflegends.com/en-us/Stat_Bonus_(ARAM:_Mayhem)>) 표(2026-11-02 확인)의 선택지를 따른다. 사이트 등급 표기는 기존 증강 등급과 같은 `프리즘`이다. 능력치 아이콘은 CommunityDragon 게임 글자 아이콘(스킬 가속은 룬 능력치 조각)에 어두운 바탕을 씌운다.

## 검토한 대안

- 쇠사슬 조끼 6개 유지: 사용자가 쇠사슬 조끼 + 2티어 신발로 바꾸라고 정했다.
- 등급별 수치·이유 문장 표시: 페이지가 길어져 사용자가 빼라고 정했다.

## 영향과 검증

- 검색 설명은 `쇠사슬 조끼와 2티어 신발, 해신 작쇼를 갖춘 뒤 모루로 능력치를 올리는 모루작 빌드도 있습니다.`를 붙인다.
- 단위 테스트가 모루작 빌드의 아이템·`+` 연결·저점 안내·등급 묶음·1·2순위 능력치·아이콘, 수치와 설명이 없는지, 챔피언 탭의 같은 내용을 확인한다.
- 브라우저 검사가 증강 공략과 람머스 빌드 탭에서 아이템, 저점 안내, 등급 배지, 1·2순위를 확인한다.
