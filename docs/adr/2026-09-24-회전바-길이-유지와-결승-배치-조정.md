# 회전바 길이 유지와 결승 경사·회전축 조정

- 상태: 적용
- 날짜: 2026-09-24
- 연결 요구사항: REQ-MARBLE-002, REQ-MARBLE-004
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

## 사용자 교정과 결정

사용자는 마지막 구슬을 위해 회전바를 줄이는 방식에 동의하지 않았다. 바 길이를 유지하고 위치와 결승 경사를 조정하도록 요청했다. 앞선 [100개 블록 상한과 종료 뒤 준비 복귀](2026-09-24-100개-블록-상한과-종료-뒤-준비-복귀.md)의 바 축소 결정을 이 문서로 대체한다. 과거 ADR 본문은 보존한다.100개부터 일반 블록1,760개로 고정하는 정책과 종료 뒤 설정 수정 시 준비 화면으로 돌아가는 동작은 유지한다.

| 항목        | 이전 배치            | 새 배치         |
| ----------- | -------------------- | --------------- |
| 왼쪽 경사   | 30°                  | 40°             |
| 오른쪽 경사 | 20°                  | 30°             |
| 회전축 x    | 160                  | 145             |
| 회전축 높이 | 결승 시작점+460      | 결승 시작점+440 |
| 바 길이     | 마지막1개에서440→260 | 경기 내내440    |

회전축은 왼쪽15·위쪽20으로 이동한다. 바 두께16·회전 주기13.2경기초·반시계 방향·탄성0.35·마찰0.05는 유지한다. 양쪽 경사는 같은 입구 높이인 결승 시작점+400에 연결한다. 통로 폭40·판정선+710·전체 높이740도 유지한다. 별도 힘이나 자동 도착을 추가하지 않는다. 마지막 구슬도 실제 중앙 통로와 판정선을 지나야 한다.

마지막 구슬 수를 세어 바를 줄이던 호출과 `finale-release.js`를 제거했다. 이 기능을 위해 추가했던 Worker의 동적 너비 전달 항목도 제거했다. 충돌·그림·미니맵은 동일한 고정 길이와 새 배치를 사용한다.

## 후보 비교

경사·회전축16개 후보를 비교했다. 축을 x115~130으로 더 옮기면 마지막 통과가 빨라졌지만 접전32조합에서 역전이0개였다. 선택한 x145·높이+440·경사40°/30°는 반복 반동을 줄이면서 표본의 역전6개를 유지했다.

아래 비교의 이전 배치는 바 축소를 적용하지 않은 길이440·x160·높이+460·경사30°/20°다. 축소 방식과 성능을 혼동하지 않는다.

| 검사                              | 이전 배치           | 새 배치             |
| --------------------------------- | ------------------- | ------------------- |
| 마지막1개3,456조합 최대 통과 시간 | 약14.50경기초       | 8.633경기초         |
| 후보 비교용336조합 평균/최대      | 6.914/14.125경기초  | 3.666/8.633경기초   |
| 60개 밀집·회전각4가지 전원 도착   | 48.775~55.375경기초 | 29.475~35.858경기초 |
| 접전32조합의 추격 구슬 선착       | 16개                | 6개                 |

역전 빈도는 표본에서 줄었다. 모든 경기에서 같은 비율로 줄어든다는 뜻은 아니다. 전체 경기 난수·경사 접촉·스킬이 결과에 영향을 준다. 이전 배치에서도 정확한 무한 정체는 재현하지 못했다. 이번 결정은 확인한 반복 반동과 통과 시간을 개선한다.

## 검증

- 마지막1개3,456조합과1000개 중 마지막1개80조합은 모두1회전 이내 완주했다. 후자의 최대 시간은6.975경기초였다. 매 단계에서 길이440·축 위치 고정·벽 반대편 이탈 방지·중앙 통로 진입을 확인했다.
- 1000개·스킬ON·각도2가지·12경기초의 최대 실제 겹침은0.499997 미만, 표시 겹침은0.499453 미만이었다.60개 밀집의 최대 실제 겹침은0.621536 미만이었다. 모두 기준1 이하다.
- 1000개·회전각4가지·35경기초 벽 통과 방지와 중앙 골인 검사가 통과했다. 과거30°벽에서 발견한 좌표 회귀 검사는 테스트 안에 해당 벽을 복원해 그대로 보존했다. 새40°벽의 검사를 대신하지 않는다.
- 번개 고정 구슬의 회전바 밀림·얼음 고정·0.25/1/2배속 상태와 이벤트 재현성·효과음 이벤트 검사가 통과했다.
- 관련 단위 검사에서 기존 과거 길이 비교2개는 계속 실패한다.180/290/320길이의 역사적 접전 비교이며 새 배치를 사용하지 않는다. 역전 수10→8과 평균 반동 높이99.35→114.53의20% 증가 기준을 만족하지 못했다. 실패 기준을 완화하지 않았다.

- 정적 검사 오류0개·경고0개, 변경 코드 ESLint·Prettier·REQ-MARBLE-002와 전체 화면 연결·정적 build 검사 통과. REQ-MARBLE-004는 비UI 요구사항이므로 UI 연결 검사 대상이 아니다. 해당 동작은 단위 검사와 브라우저 계산 주기 검사로 확인했다.
- 최종 화면 build는1회 수행했다. 같은 build로 Playwright9개가 통과했다. 마지막 당첨·팡파레1회·실제 골인·길이440, 데스크톱/모바일의 번개 밀림 표시, 종료 뒤 설정 편집, 일시정지·재개·초기화를 포함한다. 과거 길이 비교2개 실패와 구분한다. 전체 lint와 다른 도구의 전체 테스트는 실행하지 않았다.

- 접근성 snapshot을 먼저 확인한 뒤1440×1000·390×844 준비 화면과 실제 결승 화면을 확인했다. 버튼·시작 창의 잘림과 가로 넘침은 없었다. 경사·고정 길이 회전바·중앙 통로와 실제 골인을 확인했다. 화면 자료는 `output/playwright/finale-layout/`에 남겼다.

## 최종 build의 실제 진행 속도

1440×1000 데스크톱 브라우저에서1000개·도각도각 키보드·난수47·마지막 방식·스킬/소리ON·2배속으로 출발부터 실행했다. 일반 블록은100개 상한을 적용한1,760개이며 새 결승 배치를 사용한다. 다른 계산 검사와 동시에 측정하지 않았다.

| 경기 시간 구간      | 실제 진행 속도 | 최대 결승 구슬 수 | 상태 수신  | Canvas 그리기 |
| ------------------- | -------------- | ----------------- | ---------- | ------------- |
| 85.11~105.09경기초  | 1.9983배속     | 312개             | 52.30회/초 | 60.00fps      |
| 105.09~125.10경기초 | 2.0004배속     | 313개             | 51.99회/초 | 59.99fps      |
| 125.10~145.14경기초 | 2.0032배속     | 314개             | 52.27회/초 | 59.97fps      |

각 구간은 실제10초다. 출발 구간은1.9958배속이었다. 밀집 구간의 처리하지 못한 시간은 최대4.10ms, 각 구간 끝은0.53~0.97ms였다. 미뤄 둔 시간이 계속 늘어나는 현상은 없었다. 경기 시간을 버리는 코드를 추가하지 않았다. 사용자 최초 측정1.41배속에 비해 현재 설정은약2배속이지만, 블록 수와 결승 지형도 변경됐으므로 같은 물리 상태의 순수 계산 비용 비교로 해석하지 않는다. 바 배치를 바꾸기 전 심한 밀집358개에서의2배속 측정은 [계산 여유와 그리기 주기 ADR](2026-09-24-1000개-경기-계산-여유와-그리기-주기.md)에 따로 남아 있다.

이 결과는 지정한 기기·브라우저·난수와 측정 구간에 한정된다. 다른 환경이나 모든 가능한 밀집 상태에서2배속을 보장하지 않는다. 모바일 검증은 데스크톱 브라우저의 좁은 화면으로 수행하며 모바일 실기 성능 측정은 아니다.

## 재현 자료

`.context/finale-layout/`의 `compare.mjs`, `compare-more.mjs`, `single-grid.mjs`와 각각의 로그에 후보·최대 통과 시간을 기록했다. `candidate-tests.log`, `boundary-history.log`, `layout-tests.log`, `final-unit.log`에 검사 결과를 남겼다. `built-speed.log`에 실제 진행 속도와 별도로 집계한 Canvas 그리기 횟수, `e2e.log`에 최종 브라우저 검사 결과를 남겼다. 채택하지 않은 바 축소 파일은 같은 폴더의 `rejected-release*`로 보관하며 제품에서 사용하지 않는다.
