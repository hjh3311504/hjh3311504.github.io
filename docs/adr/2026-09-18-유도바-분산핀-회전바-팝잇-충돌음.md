# 유도 바·분산 핀·회전 바의 팝잇 충돌음

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 세 장치의 충돌음을 다시 켜고 팝잇 소리를 사용하도록 요청했다.

유도 바와 분산 핀의 무음을 해제하고 결승 회전 바와 함께 기존 팝잇 파일2개를 교대로 사용한다. 장치 재생 경로 rubber는 유지하며 파일만 팝잇과 공유해 중복 다운로드를 피한다. 골인 통로 수직 벽은 무음을 유지한다.

장치 합계1개·최소100ms, 전체6개·최소28ms, 화면 밖 감쇠와 충돌 세기에 따른 음량을 유지한다. 일반 팝잇의 물리·파괴·재생 제한은 바꾸지 않는다.

소리·장치 단위 테스트48개에서 연결·파일 재사용·교대 재생·동시 제한·최소 간격과 기존 충돌 동작을 확인했다. 실제 청음 만족도는 별도 확인이 필요하다.
