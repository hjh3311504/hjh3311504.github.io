# 도각4 두 타격 교대 재생

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 도각1처럼 타격2개를 사용하는 방안을 검토한 뒤 진행하도록 요청했다.

도각4에 서로 다른 두 타격 파일 `thock4-v3-1.wav`·`thock4-v3-2.wav`를 연결한다. 기존 재생 순환 기능으로 A→B→A→B 순서로 재생하며 도감과 경기에서 같은 파일을 사용한다. 두 파일의 합계에 재질 동시6개 제한을 적용하고 전체12개·최소28ms 제한을 유지한다. 제한으로 생략한 충돌은 재생 차례를 소비하지 않는다. 음원 길이는 각각70ms이며 평균 음량 차이는0.02dB 미만이다.

도각2·3은 청음 후보만 준비하며 현재 게임 파일을 유지한다. 도각1과 찰칵 키보드의 기존 두 음원, 맵 순서와 물리 값도 유지한다. 파일명을 바꿔 이전 캐시와 구분한다.

음향 단위 검사31개에서 두 파일의 교대, 도감·충돌의 공통 제한, 제한으로 생략한 뒤의 차례와 재생 완료 후 자리를 다시 사용하는 동작을 확인했다. 브라우저 검사3개로 두 파일의 선행 로딩과 미리듣기 교대를 확인했고 lint·정적 검사·build·문서 연결 검사도 통과했다. 음원의 취향 적합성은 비교 청음을 통해 확인한다.
