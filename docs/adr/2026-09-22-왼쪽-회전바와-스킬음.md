# 왼쪽 회전바와 스킬음

- 상태: 결정
- 날짜: 2026-09-22
- 연결 요구사항: REQ-MARBLE-001, REQ-MARBLE-002, REQ-MARBLE-003, REQ-MARBLE-004
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

사용자는 스킬 효과음 축소와 회전바의 왼쪽 이동을 요청했다. 첨부한 순위 카드의 새 레이아웃은 별도 로컬 시안3개로 비교하며 현재 서비스의 카드 배치는 유지한다.

파동·번개·바람의 음량 계수를0.8에서0.4로 낮춘다. 미리듣기와 경기 재생에 같이 적용한다. 전체 볼륨, 화면 안의 스킬만 재생하는 규칙, 동시 재생 수 제한 해제와 음소거·정리는 유지한다. 파일을 다시 편집하지 않는다.

회전축은 `(200, 결승 시작점+500)`에 둔다. 오른쪽 아래 배치에서 같은 높이로 왼쪽에만 옮기면 구슬이 걸려 남아20만큼 위로 조정했다.20° 벽·폭40 통로·바 길이320·두께16·회전 방향·속도·충돌 세기는 유지한다.

기본3개 맵×2·30·60개×난수10개의90경기가 배출 정체 없이 모두 완주했다. 최대 완주 시간은68.53경기초였다. 기존 결승 체류15초 목표는34경기가 초과했으며 최대32.80경기초였다. 두 종류의60개 밀집 배치와 시작 각도4가지는 모두37경기초 안에 완주했다. 최대 구슬 겹침은0.622였다.

현재 지형의 고정 접전32조합은 모두 완주했으며 역전은0회였다. 왼쪽 바는 좁은 통로에서 구슬을 위로 밀어 순서가 바뀌는 빈도가 이전 오른쪽 배치보다 줄었다. 이 차이를 숨기지 않고 기록한다. 위아래 구슬의 되튕김·겹침 방지·실제 경기 시각별 결과와 과거 회전바 비교 검사는 유지한다.

이 결정은 [스킬 그림 비용과 완만한 결승](2026-09-22-스킬-그림-비용과-완만한-결승.md)의 회전축 위치와 기존 스킬음 음량을 대체한다. 나머지 그림 최적화와 순위6열은 유지한다.
