# 결승 카메라의 부드러운 전환

- 날짜: 2026-09-18
- 상태: 적용
- 이전 결정: 결승 후보 즉시 전환
- 근거: 사용자가1등 표식은 즉시 갱신하되 카메라 이동은 부드럽게 전환하도록 요청했다.

후보 판정과 강조 표식·순위 목록은 대기 없이 최신 선두로 바꾼다. 카메라의 순간 위치 변경을 제거하고 새 목표로 이동을 즉시 시작한다. 실제 시간 약0.3초에 남은 거리의95%를 이동하는 방식으로 좌우·상하를 부드럽게 따라간다. 다시 추월하면 별도 대기 없이 새 방향으로 전환한다.

경기 배속은 화면 이동 속도에 영향을 주지 않는다. 확대 비율과 결승 아래 여백·일시정지·동작 줄이기는 유지한다. 직전 ADR의 후보 판정 규칙은 유지하고 카메라의 즉시 위치 변경 결정만 대체한다.
