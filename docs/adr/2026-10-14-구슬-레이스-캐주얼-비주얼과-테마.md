# 구슬 레이스 경기장을 캐주얼 비주얼로 바꾸고 사이트 테마를 따른다

- 상태: 결정
- 근거: 2026-10-14 사용자 요청 “옛날 게임 느낌이 나서 별로다. 캐주얼하고 깔끔한 비주얼”과 GPT 시안 A안 선택
- 관련 요구사항: `REQ-MARBLE-003`
- 관련 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md#캐주얼-경기장-비주얼-2026-10-14)

## 배경

경기장은 짙은 남색 배경과 점 격자, 흰색에서 남색으로 넘어가는 강한 구슬 광택을 사용했다. 블록 타일의 얇은 흰 선·어두운 선, 네온 청록 결승 회전판, 체크무늬 도착선도 옛날 게임처럼 보였다. 경기장은 사이트 테마와 관계없이 항상 어두웠다.

## 결정

경기장 Canvas와 상단 버튼줄·시작/일시정지/결과 창·하단 바·미니맵·당첨 표시를 사이트 테마에 맞춘다. 밝은 테마는 옅은 하늘빛 흰색, 어두운 테마는 채도가 낮은 회청색 배경이다. 사이트 테마가 `auto`면 운영체제 설정을 따른다.

- Canvas 색은 `src/lib/marble-race/arena-theme.js` 한 곳에서 관리한다. Worker에는 테마 이름만 보내고 그리는 쪽에서 색을 찾는다.
- CSS 색은 `tokens.css`의 `--color-arena-*` 토큰을 사용한다. 경기장 안에서는 공용 `--ui-*` 변수를 경기장 색으로 덮어써 공용 버튼과 결과 창이 같은 색을 따른다.
- 블록 종류별 색은 유지한다. 블록 색이 종류를 구분하는 정보이기 때문이다.
- 구슬은 단색·작은 흰 광택·옅은 아래 음영으로 그린다. 테마와 관계없이 같은 그림이라 기존 구슬 그림 캐시를 그대로 쓴다.
- 이름표 그림은 배경색을 포함하므로 테마가 바뀔 때만 다시 만든다.
- 번개 정지 효과는 밝은 배경에서도 보이도록 흰색 대신 파란 전기선을 사용한다.
- 미니맵의 흰 현재 위치 테두리는 유지하고 어두운 바깥선을 더한다.
- 벽·결승 회전판·도착선·얼음 표식은 경기장과 미니맵 배경에 대해 3:1, 이름표 글자는 4.5:1 이상의 대비를 유지한다. `tests/marble-race/arena-theme.test.js`가 두 테마의 색을 검사한다.

## 성능

프레임마다 구슬 그림을 복사하는 횟수와 캐시 구조는 유지한다. 구슬 그림을 처음 만들 때의 채우기는 1번에서 3번으로 늘지만 캐시에 한 번만 만든다. 구슬 그림에는 그림자 흐림 효과를 쓰지 않고 결승 회전판의 흐림 빛도 제거했다. 전체 성능 변화는 측정하지 않았다.
