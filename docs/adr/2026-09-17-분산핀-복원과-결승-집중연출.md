# 분산 핀 복원과 결승 집중 연출

- 날짜: 2026-09-17
- 상태: 적용
- 연결: [요구사항](../requirements/marble-race.yaml), [화면](../design/screens/SCR-WEB-004.md)

## 배치

사용자는 기존 특수 장치를 없애지 않고 공간을 늘려 분산 핀을 복원해 달라고 요청했다. 기존960높이 구간3곳의 입구 유도벽·버터5개·젤리 연못을 유지한다. 각 구간 뒤쪽에260높이를 추가하고 원형 핀13개를 배치한다. 마지막 재질과 깔때기 사이에는320높이와 핀13개를 추가한다. 총52개이며 일반 블록960개와 맵 구성은 유지한다.

핀은 기존3줄 좌표를 재사용한다. 첫째·셋째 줄은 가로192·304·416·528, 둘째 줄은136·248·360·472·584다. 세로 위치는 핀 자리 시작점에서58·150·212다. 반지름16·반발계수0.45·마찰0.02와 고무 범퍼 음원을 사용한다. 구슬의 이름이나 순위로 힘을 다르게 주지 않는다.

젤리는 폭452·깊이140으로 두고 한쪽에 폭244의 우회로를 남긴다. 좌우는 경기 난수로 정한다. 실제로 연못에 진입한 구슬에만 저항과 진입음을 적용한다. 우회로 안내와 실제 블록 모양을 경기장에 표시한다.

## 버터

경기 시작 시 전체 구슬 수 N으로 `max(1, round(5 × sqrt(N / 30)))`회를 정한다.2/30/60/1000개는 각각1/5/7/29회다. 소수 경기에서는 쉽게 부서지고, 대규모 경기에서도 파괴 횟수가 인원에 비례해 지나치게 늘어나지 않도록 제곱근을 사용한다.

독립 충돌만 세고 같은 접촉의 중복 손상은 막는다. 최대 내구도에 대한 남은 비율로 그림과 충돌 높이를 함께 줄인다.3초 후 복구할 때 원래 크기와 해당 경기의 최대 내구도를 복원하며, 구슬과 겹치면 기다린다. 경기장과 안내에 현재 횟수를 표시한다. 대규모 명단의 준비 화면도 전체 입력 수를 기준으로 표시한다.

## 결승과 카메라

기존 회전판의 위치·크기·반시계4초 회전은 유지한다. 판 아래 중앙 폭40통로를240연장해 결승 전체 높이를740으로 늘린다. 입구는 결승 시작점400아래, 판정선은710아래다.

당첨 후보 연출은0.3배속·최대2.4배 확대다. 확대 중에는 후보의 좌우·상하 위치를 부드럽게 추적한다. 위로 걷어 올려진 구슬도 따라간다. 화면 그리기와 미니맵의 흰 테두리, 음향 범위에 같은 카메라 좌표를 사용한다. 일반 따라가기의 아래 방향 이동과 동작 줄이기 설정은 유지한다. 동작 줄이기에서는 크게 확대하지 않는다.

물리는1/120초 간격을 유지하고 진행 횟수만 바꾼다. Worker와 표시 문구는 같은0.3배속 값을 사용한다. 음원 파일·음정·재생 속도는 그대로다. 당첨 인원을 채우면1배속으로 돌아간다.

## 검증

- 핀52개와 기존 장치 보존, 구간 안의 배치, 구슬 지름보다 넓은 핀 간격과 실제 옆 방향 반동을 확인했다.
- 젤리 양쪽 우회 배치, 우회 구슬의 무감속·무음 통과와 연못 구슬의 감속·진입음1회를 확인했다.
- 2/30/60/1000개의 버터 내구도·독립 충돌·재생 시 내구도 복원을 확인했다.
- 0.3배속의 실제1초당36회 물리 계산과 Worker의0.3/1/2배속 상태 일치를 확인했다.
- 확대2.4배에서 후보의 좌우·상하 추적, 결승 위로 반동한 후보의 연출 유지, 동작 줄이기를 확인했다.
- 기본3개 맵×2/30/60개×난수10개,90경기가 모두120경기초 안에 완주했다. 최대108.27초다. 결승 진입 차이가1초 이하인73경기 중41경기에서 선두가 바뀌었다(56.2%).
- 단위 검사88개 중86개 통과. 기존 시간 검사2개는 실패로 유지했다. 결승15초 목표는60/90경기에서 초과했으며 최대77.32초다. 결승 입구에60개를 몰아넣는 별도30초 검사는35개만 도착했다. 시간 한도를 늘리거나 충돌을 생략하지 않았다.

- 초기 폭156우회로는 구슬30개·난수47경기에서 사용되지 않았다. 폭244로 넓힌 뒤 같은 조건에서 연못 진입과 우회가 모두 발생했다. 이 실제 경기 검사를 추가한 핀·특수 구간 검사5개가 통과했다.
- 키보드 맵·구슬1000개·난수47경기는384.69경기초에 전원 완주했다. 연못 진입776개·우회224개이며, 버터 내구도는29회였다. Node.js 계산에 실제298.78초가 걸렸다. 결승 최대 체류는359.82경기초로, 대규모 단일 출구의 대기가 남아 있다. 이 계산 시간은 브라우저 화면 성능이나 슬로모션을 포함한 실제 경기 시간이 아니다.
- 오디오 검사31개가 통과했다. 가로 확대에서도 화면 밖 소리를 거르고 실제 화면 중심에 맞춰 좌우 음향을 배치한다. 음원과 동시 재생 제한은 바꾸지 않았다.
- Playwright 관련4개 검사가 통과했다. 핀52개·참가 수별 버터 안내·0.3배속·2.4배 확대·일시정지와 재개·미니맵·첫 충돌과 결승 소리·화면 크기 변경·전체화면을 확인했다. 데스크톱과 모바일 화면도 확인했다.
- lint·Svelte 정적 검사·build·공개 정적 페이지 검증·요구사항과 화면 연결 검증·`git diff --check`가 통과했다.
