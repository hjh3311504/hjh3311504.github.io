# 1,000개 장시간 완주 테스트 삭제

- 상태: 승인됨
- 날짜: 2026-09-19
- 근거: 사용자가 실행 시간이 긴1,000개 경기 테스트 삭제를 요청했다.
- 관련 요구사항: REQ-MARBLE-004

## 결정

1,000개 전원 완주를 기다리는 단위 테스트1개와 Playwright 테스트1개를 삭제한다. 해당 검사에만 쓰던 배출 기록·270초 중간 측정 코드도 제거한다. 실행을 건너뛰는 표시나 시간 제한 확대는 사용하지 않는다.

1,000개 입력·Worker 전송량 검사와5초간의 브라우저 화면 응답·순위 목록 부분 렌더링 검사는 유지한다. 기본90경기와 결승60개 밀집 검사도 유지한다. 수동 측정 스크립트는 필요할 때만 실행하며 기본 검사에는 포함하지 않는다.

게임의 참가자 지원 범위·물리 계산·결승 모양은 바꾸지 않는다. 이전 측정 결과와 ADR은 보존한다.

## 실행 시간과 검증

삭제한 검사의 이전 실행 시간은 단독 물리 계산 약176초, 브라우저 약410초였다. 전체 검사와 함께 실행한 물리 검사는 약229초였다. 실행 환경에 따라 차이가 나므로 고정된 절감 시간을 보장하지 않는다.

- 단위 테스트187개 통과. 구슬 레이스127개는 약90초에 완료했다.
- 변경한 도우미를 사용하는 첫 충돌음·결승 충돌음·카메라 검사와5초 성능 검사, 총4개 Playwright 검사 통과.
- 브라우저 검사 목록은90개에서89개로 줄었다. 이번 변경에서는 전체 Playwright를 다시 실행하지 않았다.
- lint·정적 검사·build·정적 결과 검증·문서 연결 검사·diff 검사를 통과했다.
- 5초 성능 검사는 약111fps, 버튼 응답4.4ms를 기록했다. 기존과 같은 Chromium151·10코어 환경이다.
