# 회전바 길이448로 연장

- 상태: 적용
- 날짜: 2026-09-25
- 연결 요구사항: REQ-MARBLE-002
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

## 요청과 결정

사용자는 회전바 길이를 조금 더 늘리도록 요청했다. 길이를440에서448로 늘린다. 회전축을 기준으로 양 끝이4씩 늘어나며, 수평 범위는 x-64~384다. 회전축 x160·결승 시작점+480, 두께16, 모서리8, 주기13.2경기초, 방향, 반발계수, 경사와 스킬 규칙은 기존 설정을 사용한다. 마지막1개에서도 같은 길이를 쓴다. 결승0.25배속 강제와 소리 설정은 유지한다.

제품 변경은 `physics.js`의 바 너비1곳이다. 물리·Canvas·미니맵은 이 값을 공유한다. 과거 ADR 본문은 보존한다.

## 길이 선택

처음에는480을 시도했지만 마지막 구슬과 밀집 완주 검사가 실패했다.460에서도 같은7개 검사가 실패했다. 두 길이 모두60개 밀집 시험에서60경기초에59개만 도착했다.450은 밀집 시험을 통과했지만 마지막 구슬3,456조합 중1회전 이내 완주 기준을 충족하지 못한 표본이 있었다.

448은 기존 완주 시간과 겹침 기준을 그대로 통과했다. 검증한 후보 중 모든 관련 완주 검사를 통과한448을 선택했다. 실패한 후보의 시간 상한을 늘리거나 회전축·경사를 추가로 바꾸지 않았다. 실패는 해당 시간 안에 완주하지 못했다는 뜻이며 영구 미완주를 증명한 것은 아니다.

## 물리 검증

| 검사                                  | 결과                                                    |
| ------------------------------------- | ------------------------------------------------------- |
| 마지막1개3,456조합                    | 전원 중앙 골인, 최대11.459경기초                        |

길이가 늘어60개 밀집의 최대 완주 시간은 직전 표본42.13경기초보다 길어졌다. 기존60경기초 기준 안에 완주했다. 이 결과는 검증한 표본의 결과이며 모든 난수의 완주 시간을 보장하지 않는다. 이번 길이 변경에서 실제 진행 배속과 화면 fps를 다시 측정하지 않았으며 성능 개선 수치를 주장하지 않는다.

바 크기도 상태 해시에 포함되므로 기록한 해시3개가 바뀌었다. 별도 재현에서 길이만440으로 설정했을 때 기존 해시3개가 모두 일치함을 확인했다. 길이448의 겹침·벽·완주 검사를 통과한 뒤 새 해시를 기록했다.

## 검사 범위

관련 단위 테스트84개가 통과했다. 최초 실행에서 길이 변경으로 해시3개가 달랐으며 위 확인과 기준 갱신 후 해당 파일7개를 다시 실행해 통과했다. Svelte 정적 검사 오류0개·경고0개다. 전체 테스트·전체 lint와 과거 별도 배치의 반동 비교 검사는 실행하지 않았다.

최종 build는1회 수행했다. 관련 Playwright5개가 통과했다. 접근성 snapshot 확인 후1440px·390px 화면에서 회전바·구슬 반동·번개 밀림 표시를 확인했다. 마지막 당첨·팡파레1회·실제 골인도 통과했다. 변경 코드 ESLint·Prettier, REQ-MARBLE-002·전체 화면 연결, 정적 build 검사와 `git diff --check`도 통과했다.

재현 로그는 `.context/rotor-480/`에 있다. 디렉터리 이름은 최초 후보480에서 따왔으며 최종 적용 값은448이다. `first-tests.log`, `460-tests.log`, `450-tests.log`에 미채택 후보 실패를 보존하고 `448-tests.log`, `related-tests.log`, `hash-before.log`, `hash-after.log`에 최종 검증을 남겼다.
