# 블로그 주제 확장과 RSS 위치

- 상태: 결정
- 근거:2026-09-29 사용자 후속 요청. 일반적인 블로그 이름·설명, 프로그램에 한정하지 않는 구성, RSS의 개인정보처리방침 옆 이동, 본문 홈 링크 삭제, 팀 메이커 글1개 작성을 요청했다.

## 결정

- 목록 제목은 ‘블로그’, 설명은 ‘경험과 생각, 일상의 이야기를 기록합니다.’로 표시한다. 검색·공유·RSS에도 같은 정보를 사용한다.
- `program`을 선택 항목으로 바꾸고 일반 글을 위한 `note`(기록) 분류를 추가한다. 프로그램이 있는 글만 사용 버튼과 프로그램 이름을 표시한다. 일반 글은 같은 종류의 일반 글을 관련 글로 연결한다.
- 목록 본문의 홈 링크와 빈 상태의 프로그램 둘러보기 버튼을 제거한다. 공통 내비게이션의 홈 이동은 유지한다.
- 목록·상세의 RSS 구독은 공통 footer의 `showRss` 옵션으로 개인정보처리방침 옆에 표시한다. 기존 도구 footer의 기본 구성은 유지한다.
- 팀 메이커 소개 초안을 실제 화면의 사용법·규칙·저장·기능 제한을 설명하는 글로 작성하고 공개 상태로 변경한다. 외부 배포는 수행하지 않는다.

이 결정은 같은 날의 Markdown 블로그 결정 중 프로그램 연결 필수와 예시 글 초안 유지 조건을 대체한다. 글 검증·정적 게시·초안 제외와 기존 통계 범위는 유지한다.
