# 불씨 블록 비활성화

- 상태: 적용됨
- 결정일: 2026-09-18
- 근거: 사용자가 불씨 블록을 비활성화하도록 요청했다.

불씨를 활성 목록·도감·커스텀 맵 선택에서 제외한다. 활성 일반 블록은12종이다. 나무공방은 나무 → 코르크 → 찰칵 키보드 → 뽁뽁이로 구성한다.

저장된 커스텀 맵의 불씨 자리만 찰칵 키보드로 연결한다. 맵 ID·이름·선택·참가자와 나머지 구역은 보존한다. 불씨 정의와 음원 파일·출처는 보존하되 현재 맵 음원 로딩에서는 제외한다. 전체 동시3개 제한은 유지한다.

활성 목록·기본 맵·저장 맵 연결·음원 로딩과 도감에서 불씨가 제외되는지 검사한다.

검증 결과: 음향·설정 단위 테스트48개, 활성 목록과 재질 충돌 검사2개, Chromium 도감·음원 로딩 검사3개를 통과했다. lint·정적 검사·build·정적 페이지 검증·UI 문서 연결 검사와 `git diff --check`도 통과했다. 전체 경기 시뮬레이션은 이번 변경에서 다시 실행하지 않았다.
