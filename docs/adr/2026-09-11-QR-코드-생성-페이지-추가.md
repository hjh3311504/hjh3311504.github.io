# QR 코드 생성 페이지 추가

- 날짜: 2026-09-11
- 상태: 채택
- 근거: 사용자가 TeacherCan QR 생성 페이지를 참고한 새 페이지 구현을 요청했다.

## 결정

공개 route에 `/qr-code`를 추가한다. 마지막 슬래시 없이 `build/qr-code.html`로 배포한다. 기존 도구의 주소와 build 형태는 유지한다. 홈·공통 내비게이션·sitemap에 진입점을 추가한다.

QR 생성은 MIT 라이선스의 `qrcode`를 사용한다. 외부 생성 API나 서버는 추가하지 않는다. 북마크는 별도 localStorage 키 `lake.qr-code.bookmarks.v1`에 최대 30개 저장한다. 일반 입력은 저장하지 않는다.

참고 페이지의 주요 작업을 제공하며 스타일은 현재 사이트의 공통 디자인을 따른다. 원본 코드와 이미지 자산을 복제하지 않는다. 입력 내용을 담은 정적 QR을 제공하며 단축 URL·접속 추적·연결 주소의 사후 변경은 제공하지 않는다.

## 영향과 검증

REQ·IA·화면 문서·README·개인정보 안내·AGENTS.md·CLAUDE.md·배포 검증에 새 route를 반영한다. 브라우저에 포함되는 qrcode와 dijkstrajs의 MIT 원문을 배포한다. QR 해독과 브라우저 작업을 확인하고 기존 Team Maker 검사도 실행한다.

사용자 승인은 참고 페이지를 바탕으로 한 구현 요청에 해당한다. 별도 시안 검토 승인을 받았다는 뜻은 아니다.
