# 크랙 왁스 이름과 충돌음 변경

- 상태: 적용됨
- 결정일: 2026-09-18
- 근거: 사용자가 버터의 음원2개 교체와 소재에 맞는 이름, 파괴 전에도 부딪힐 때마다 소리를 요청했다.

표시 이름은 크랙 왁스로 바꾼다. 내부 ID `butter`와 배치·참가자 수에 따른 내구도·눌림·3초 복구는 유지한다. 음원은 `wax-crack-v1-1.wav`와 `wax-crack-v1-2.wav`를 교대한다. 미리듣기와 경기는 같은 파일을 사용한다.

기존 코드도 손상 때 소리 이벤트를 보냈지만 장치 그룹 동시1개 제한을 공유했다. 크랙 왁스를 이 제한에서 분리하고 전체 동시3개·최소28ms를 적용한다. 한도에 걸린 소리는 나중에 몰아서 재생하지 않으며 교대 순서도 소비하지 않는다.

독립 접촉마다 파괴 전부터 소리 이벤트를 보낸다. 약한 충돌도 소리 나지만 손상 기준은 유지한다. 지속 접촉·위치 겹침 보정에서는 중복 소리와 손상을 만들지 않는다. 마지막 파괴 때도 한 번만 재생한다. 음향 범위는 실제 충돌면 위치를 사용한다.

음원 교대·장치음과 동시 재생·전체 제한, 파괴 전 충돌·지속 접촉·약한 재접촉·복구를 검사한다.

검증 결과: 음향·설정·접촉 단위 테스트50개와 참가자별 내구도 검사1개를 통과했다. Chromium 검사3개에서 모바일·데스크톱 안내와 맵별 음원 로딩·일시정지·캐시를 확인했다. 로컬 미리보기에서도 크랙 왁스 미리듣기와 두 파일 요청을 확인했다. lint·정적 검사·build·정적 페이지 검증·UI 문서 연결 검사를 통과했다. 전체 경기 시뮬레이션은 다시 실행하지 않았다. 음색의 주관적인 만족도는 사용자의 청음으로 확인한다.
