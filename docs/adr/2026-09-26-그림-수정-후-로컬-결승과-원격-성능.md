## 원격 PR 결과

[실행36235260133](https://github.com/hjh3311504/hjh3311504.github.io/actions/runs/36235260133)은 실패했다. lint·UI 규칙·정적 검사·전체 단위 테스트·build는 통과했다. 우선7개 중3개 통과,4개 실패였다. 모바일1배속 fps, 데스크톱과 모바일2배속,500ms 멈춤 뒤 따라잡기 검사가 실패했다. 나머지146개 브라우저 검사와 마지막 정적 결과 검증은 실행되지 않았다. 계측 검사4개는1개 통과,3개 실패다.

## 남은 결정

그림 수정은 첫 그림 비용을 줄였지만 원격2배속 목표는 해결하지 못했다. 성능 기준을 낮추거나 실패 검사를 생략하지 않는다. 추가 이동 분할 실험은 계산 비용을 약34% 줄이지만 기존 난수의 경로·당첨 결과가 달라질 수 있다. 안전 검사와 배속별 재현성은 통과했어도 과거 상태 일치 검사는 실패했다. 이 변경의 허용 여부를 사용자에게 물었고 답을 받기 전에는 적용하지 않는다.

기존 결과를 유지하는 별도 실험도 수행했다. 블록의 번호 조회 단순화는 유의미한 개선이 없었고, 블록 탐색 격자를68에서34로 줄이는 실험은 반복 표본에서 약3~4%에 그쳤다. 두 실험 모두 제품에 반영하지 않았다. 현재 제품의 물리 결과와 기존 안전 기준은 그대로다.
