# 블록 재생성 비활성화

## 결정

사용자 요청에 따라 일반 블록과 크랙 왁스의 재생성을 비활성화한다. 파괴 시 복구를 예약하지 않으며, 경기 중 복구 처리도 실행하지 않는다. 기존 복구 로직은 내부 상수로 꺼 두어 이후 비교할 수 있게 보존한다. 사용자 설정이나 저장 형식에는 항목을 추가하지 않는다.

파괴된 자리는 경기 종료까지 비어 있다. 복구 예정 시각이 없으므로 예고 윤곽도 나타나지 않는다. 새 경기를 시작하면 모든 블록을 다시 채운다. 충돌음·파괴 효과·왁스의 다회 충돌 내구도는 유지한다.

## 영향과 검증

후발 구슬은 먼저 열린 통로를 계속 이용할 수 있다. 경기 시간이나 우승 편향이 개선됐다고 단정하지 않는다.

일반 재질별 중복 파괴·효과음 방지,3초 이후와30초 이후 빈자리 통과, 크랙 왁스 파괴와 새 경기 초기화를 검사한다. 기존90경기 완주 검사와 Worker 전송 검사를 유지한다.

검증 결과: 관련 단위 테스트59개와 Chromium 검사1개가 통과했다. 브라우저에서3초 이후와 일시정지 재개 후에도 파괴 상태가 유지됐다. build·정적 결과·변경 파일 lint·포맷·문서 연결 검사도 통과했다. 전체 테스트는 반복 실행하지 않았다.

기본3개 맵의90경기는 모두120경기초 이내에 완주했고 최대93.22경기초였다. 기존 결승 체류15초 목표는60경기에서 초과했으며 최대56.34초였다. 결승 밀집60개 검사는4개 시작 각도에서 모두 통과했다. 이는 재생성 비활성화 확인이며 기존 결승 대기 문제의 해결을 뜻하지 않는다.
