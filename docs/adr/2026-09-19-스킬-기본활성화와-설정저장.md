# 스킬 기본 활성화와 설정 저장

사용자 요청에 따라 스킬 사용의 기본값을 ON으로 변경한다. 기존 localStorage 설정에 skillsEnabled를 추가하며200ms 묶음 저장과 페이지 종료 시 저장을 재사용한다.

저장된 true·false만 복원한다. 항목이 없는 이전 설정·첫 방문·잘못된 값은 ON으로 시작한다. 사용자가 저장한 OFF와 나머지 명단·맵·음량 설정은 유지한다. 경기·일시정지·준비 로딩 중 변경 제한은 유지한다.

설정 복원 단위 검사와 브라우저의 ON/OFF 저장·새로고침·경기 중 잠금 검사를 수행한다.

관련 단위 테스트20개와 브라우저 검사4개를 통과했다. 새로고침 후 ON/OFF 복원·경기 중 잠금·스킬 음원 선행 로딩·미리듣기와 발동 재생을 확인했다. 정적 검사·build·정적 결과·변경 파일 lint·포맷·문서 연결 검사도 통과했다.
