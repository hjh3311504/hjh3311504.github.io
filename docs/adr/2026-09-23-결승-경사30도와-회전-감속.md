# 결승 경사30°와 회전 감속

- 상태: 결정·밀집 겹침은 미해결
- 날짜: 2026-09-23
- 연결 요구사항: REQ-MARBLE-002
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

사용자는 회전바의 속도를 더 낮추고 결승 경사를 더 가파르게 만들도록 요청했다.

양쪽 직선 경사를 수평 기준20°에서30°로 높인다. 폭40 통로의 입구 높이는 결승 시작점+400으로 유지한다. 바깥 시작 높이는 `결승 시작점+400−328×tan(30°)`다. 벽 두께12와 통로 연결 방식은 유지한다. 경기 그림·미니맵·충돌은 같은 벽 정보를 사용한다.

회전 주기는8.8경기초에서13.2경기초로 늘린다. 각속도는 기존의2/3이며 약33% 느려진다. 바 길이440·회전축 `(160, 결승 시작점+460)`·반시계 방향·탄성·마찰은 유지한다. 회전바 주변의0.5경기초 간격1회 보정과 번개 구슬을 미는 예외도 유지한다. 정체를 감지해 바를 줄이는 동작은 추가하지 않는다.

난수47·스킬OFF·60개 밀집·시작 각도4가지에서 모두 완주했다. 완주 시각은61.925·58.625·61.925·58.625경기초였다. 이전20°·8.8경기초 설정의 같은 위치 시험에서는120경기초에55~56개만 도착했다. 이 결과는 해당 재현 조건의 개선이며 모든 경기의 완주를 보장하지 않는다.

추가 보정을 줄인 현재 정책에서는 밀집 겹침이 남는다. 이번 재현의 최대 구슬 겹침은 약12.028이었다. 기존 겹침1 이하 기준과 일부60경기초 완주 기준은 여전히 충족하지 못한다. 기존 검사의 허용 오차나 시간을 늘려 실패를 감추지 않는다. 별도120경기초 완주 검사를 추가해 이번 개선을 재현한다.

대칭 벽·통로 연결·회전 주기·배속별 동일 상태·Worker 전달·번개 구슬 이동을 검사한다. 접근성 상태를 먼저 확인하고 모바일·데스크톱에서 변경 지형과 실제 충돌 장면을 확인한다.

이 결정은 이전 결승20° 경사와 [긴 결승 회전바와 감속](2026-09-23-긴-결승-회전바와-감속.md)의 회전 주기를 대체한다. [번개 구슬의 회전바 접촉](2026-09-23-번개-구슬의-회전바-접촉.md)의 위치와 번개 동작은 유지한다.
