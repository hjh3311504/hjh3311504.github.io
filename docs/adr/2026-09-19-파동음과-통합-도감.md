# 파동음과 통합 도감

## 결정

사용자 요청에 따라 블록 도감의 제목을 도감으로 바꾸고 기본 블록·특수 블록 아래에 스킬 영역을 추가한다. 원형 파동은 기존 카드 템플릿과 그리드를 사용하며 그림도 경기장의 원형 효과 그리기 함수를 공유한다. 스킬 선택법·초당 약0.5% 확률·8초 대기와 소리 미리듣기를 제공한다.

사용자가 고른 낮은 훙 느낌의 짧은 효과음 pulse-whoom-v1.wav를 연결한다. 스킬 ON 경기에서만 선행 로딩하며 도감에서 같은 파일을 미리 듣는다. 스킬의 발동 이벤트를 물리 계산에서 한 번 만들어 Worker로 전달하고, 파동 그림의 지속 시간 동안 반복하지 않는다.

보이는 파동은 일반 충돌음보다 먼저 고른다. 파동 동시1개·최소200ms와 전체6개·최소28ms 제한을 적용한다. 한도가 가득 차면 팡파레를 제외한 기존 소리 하나를 짧게 줄여 교체하고 종료 시점 이후에 재생한다. 화면 밖 감쇠·음소거·볼륨·일시정지·초기화·페이지 종료 정리는 기존과 같다. 배속별 음원이나 음정 변경은 하지 않는다.

## 검증

파동별 이벤트 한 번, 음원 파일 유효성·무음·파형 여유, 도감과 경기의 동일 파일, 일반음과 파동음 동시 한도·재생 간격·교체·정리를 검사한다. 브라우저에서는 실제 발동 이벤트와 재생 기록의 연결, 도감 제목과 스킬 카드의 모바일·데스크톱 배치를 확인한다. 음색 만족도는 사용자의 청음으로 확인한다.

관련 단위 테스트54개와 Chromium 검사3개를 통과했다. 마지막 재생 간격 보정 뒤에는 음향 검사44개와 실제 파동음 브라우저 검사를 다시 통과했다. 정적 검사·변경 파일 lint·포맷·build·정적 결과·문서 연결 검사도 통과했다. 전체 테스트는 반복 실행하지 않았다.
