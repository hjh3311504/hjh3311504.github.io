# ASMR 승인 후보 v5 적용

- 상태: 사용자 승인 후 적용
- 날짜: 2026-09-17

## 결정

사용자가 선택한 청축 키보드 B·옛날 타자기 A·키네틱 샌드 A·왁뿌볼 B를 경기와 도감에 함께 적용한다. 소재마다 승인한2개 파일을 추가 가공 없이 복사한다. 슬라임·비누·도각 키보드·팝잇과 장치 소리는 유지한다.

새 파일은48kHz이며 v5 이름을 사용한다. 원음 출처와 사용자 선택, 파일 해시는 정적 음원 편집 기록에 남긴다. 키네틱 샌드는 소금 분쇄, 왁뿌볼은 달걀 껍데기 파쇄 녹음을 활용한 대체 소리다.

## 검증 기준

승인한8개 파일의 SHA256 해시를 검사해 재가공 여부를 확인한다. WAV 검사는 파일에 기록된 표본 주파수로 시간을 계산한다. 승인한 청축 B의 길이는205ms다.

이전 v3 질감 음원의 연속 소리 비율75% 기준은 새 후보의 간헐적인 파쇄음에 적용하지 않는다. 승인한 소리를 이 기준에 맞추려고 변경하지 않는다. 시작 무음·파형 잘림·변형 간 음량 차이 검사는 유지한다. 기존 슬라임의 연속 질감 검사도 유지한다.

음원 단위 테스트18개가 통과했다. 출발 무음은 사용자가 헤드셋 문제로 확인했으므로 이번 변경에서 경기 시작이나 오디오 준비 절차는 수정하지 않는다.

## 적용 검증 결과

- 승인 파일8개의 해시가 일치하고 유지 대상10개 파일도 변경되지 않았다.
- 음원 단위 테스트18개, 관련 Chromium 검사3개가 통과했다. 음원 로딩·일시정지·초기화·캐시·실패 후 재시도·중복 시작 방지를 확인했다.
- lint·Svelte Check·build·정적 산출물 검사·UI 문서 연결 검사가 통과했다.
- 첫 브라우저 검사는 정적 검사와 build를 동시에 실행해 생성된 초기화 식별자가 달라 실패했다. 단독 build 후 식별자 일치를 확인하고 같은3개 검사를 다시 실행해 통과했다. 검사 실패를 숨기기 위한 앱 코드 변경은 하지 않았다.
- 물리 계산을 바꾸지 않아 전체 경기 시간 측정은 다시 실행하지 않았다. 기존 경기 시간 목표 실패는 이번 음원 적용으로 해결됐다고 간주하지 않는다.
