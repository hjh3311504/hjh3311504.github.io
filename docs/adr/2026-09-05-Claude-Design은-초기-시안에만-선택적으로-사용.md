# 의사결정 기록 2026-09-05: Claude Design은 초기 시안에만 선택적으로 사용

상태: 결정
일자: 2026-09-05

## 결정

- Claude Design을 모든 M·L UI 작업의 필수 단계로 사용하지 않는다.
- 새 화면 묶음의 초기 시안, 복수 디자인 방향 비교, 새 Design System 탐색이 필요할 때만 선택적으로 사용한다.
- 시안을 선택하면 한 번 export해 구현 참조로 쓴다.
- 구현을 시작한 뒤에는 Git revision과 실제 브라우저 결과를 최종 원본으로 삼는다.
- 구현 결과를 Claude Design으로 다시 보내는 역동기화는 하지 않는다.

## 핵심 근거

- DSN-010 시각 결과 승인 뒤 PR 요청 전까지 추가 요청 119개가 실제 코드와 브라우저에서 처리됐다.
- 구현이 최종 원본이 된 뒤 Claude Design을 맞추려면 별도 bundle 생성과 수동 업로드가 필요했다.
- DSN-009는 통계 화면과 모달의 초기 시각 방향을 잡는 데 도움이 됐으므로 초기 탐색 용도는 유지한다.

## 검토한 대안

- 모든 M·L UI 작업에서 필수 사용: 반복 수정과 양방향 동기화 비용이 크며 실제 작업 흐름과 맞지 않아 기각한다.
- Claude Design 전면 폐기: 새 화면의 시각 방향을 빠르게 탐색하고 비교할 수 있는 장점까지 사라져 기각한다.

## 영향 참조

- 영향 REQ: 없음. 제품 동작이 아닌 UI 설계·승인 절차에 대한 결정이다.
- 영향 절차: `ui-design-freeze`, `docs/design/`, Claude Design handoff 생성·반입 흐름
- 기존 DSN과 승인된 handoff는 변경하지 않는다.

## 되돌리기 비용

중간 정도이다. `ui-design-freeze` 절차와 manifest 검증을 개정해야 하지만, 기존 DSN 형식을 계속 읽게 하면 과거 기록을 migration할 필요는 없다.
