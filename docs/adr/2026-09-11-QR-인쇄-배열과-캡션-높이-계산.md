# QR 인쇄 배열과 캡션 높이 계산

- 상태: 승인됨
- 날짜: 2026-09-11
- 근거: 사용자의 QR 여백 축소와 인쇄 배열 선택 계획 구현 요청

## 결정

캡션의 192px·168px 고정 높이를 제거한다. CSS grid의 같은 칸에 실제 제목과 보이지 않는 한글 60자 측정 문단을 배치한다. 측정 문단은 접근성 트리와 선택 대상에서 제외한다. 브라우저가 현재 너비와 SUIT 글꼴로 실제 높이를 계산하므로 화면 크기·글꼴 로딩 변화에 자동 대응한다. 빈 제목도 확보 높이를 유지하고 실제 제목이 더 높으면 확장한다.

qr-feedback의 고정 공간을 제거한다. 오류와 SVG 재시도는 필요한 경우에만 작업 버튼 아래에 표시한다. 오류가 나타날 때 카드 높이가 바뀌는 것은 허용한다.

인쇄 버튼은 공용 Dialog를 연다. A4 세로 1장에 같은 QR과 제목을 1열×1행·3열×4행·5열×6행으로 배치한다. 기본은 1개이며 선택은 페이지를 떠나기 전까지 유지한다. 용지 여백은 10mm, 칸 간격은 4mm, 출력 영역은 190mm×276mm다. 1개 출력의 최대 이미지 너비는 140mm다.

설정 창의 인쇄하기 버튼을 누를 때 QR·제목·배열을 고정하고 PNG를 한 번 생성해 반복 사용한다. 이미지가 준비되면 선택 창을 닫고 브라우저 인쇄를 요청한다. 실패는 선택 창에서 알린다. 준비 중 취소하거나 페이지를 떠난 작업은 뒤늦게 인쇄하지 않는다.

## 영향

다운로드의 PNG·SVG 규격과 SVG 제목 윤곽선, 주소별 QR 계산, 북마크 형식은 유지한다. 인쇄 배열은 서버나 localStorage에 저장하지 않는다. 검증 기준은 A4·배율 100%·머리글/바닥글 없음이며 실제 프린터 설정은 사용자가 브라우저에서 조정한다.
