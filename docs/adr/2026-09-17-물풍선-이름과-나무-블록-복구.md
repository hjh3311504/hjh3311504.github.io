# 물풍선 이름과 나무 블록 복구

- 상태: 적용
- 사용자 요청: ASMR 캡슐을 물풍선으로 바꾸고 기존 나무 블록을 되살린다.
- 범위: 도감·재질·그림·나무 음원을 변경하며 기존3개 맵은 유지한다.

## 결정

ASMR 캡슐의 표시 이름을 물풍선으로 변경한다. 그림은 하늘색 풍선과 아래 매듭, 파괴 시 둥근 물방울 모양으로 표현한다. 내부 ID `asmr`, 기존 음원 파일과 반발계수·마찰·소리 제한은 유지한다. 선택한 음원이 실제 물풍선 녹음이라는 뜻은 아니다.

나무를 활성 일반 블록과 도감에 다시 포함한다. 반발계수0.59·마찰0.35와 기존 나뭇결 그림을 재사용한다. 일반 블록처럼 첫 충돌에 깨지고3초 후 복구하며 구슬과 겹친 위치에서는 기다린다. 소리는 전체12개·28ms 제한을 적용한다. 도감은8종이다.

예전 나무 개별 WAV는 남아 있지 않지만 같은 Tapping on Desk 원음은 작업 폴더에 보존돼 있다. 원음0.340초와1.044초에서0.18초 타격을 다시 편집한다. 기존 파일과 바이트가 동일하다고 설명하지 않는다. 원음과 편집 해시는 edits.json, 출처와 라이선스는 음원 출처 문서에 기록한다. 다른 음원은 수정하지 않는다.

## 검증

변경한 도감과 관련 음원·충돌·3초 복구 검사를 실행한다. 맵과 장치 물리는 변경하지 않아 기존90경기 시간 목표 검사는 이번에 다시 실행하지 않는다. 이전 시간 목표 실패와 WebKit 첫 충돌 음량 미해결 기록은 이전 ADR에 보존한다.

음향 단위25개와 관련 물리 검사4개를 통과했다. 브라우저3개 검사에서 도감8종·물풍선 이름·나무 실제 재생 명령·맵 음원 선행 로딩·320px 화면을 확인했다. lint·Svelte Check·build·정적 페이지·UI 문서 연결·git diff --check를 통과했다. 물풍선 음원의 SHA-256은 변경 전후 동일하다.
