# 유도 바와 분산 핀 무음

- 상태: 적용됨
- 결정일: 2026-09-18
- 근거: 사용자가 유도 바와 분산 핀의 충돌음 제거를 요청했다.

특수 구간의 유도 바6개, 분산 핀52개와 결승의 고정 유도벽4개를 무음으로 처리한다. 위치·충돌·반동과 화면 효과는 유지한다. 충돌 이벤트에 무음 여부를 전달하며, 오디오에서는 후보 선정 전에 제외한다. 따라서 무음 장치가 일반 블록이나 특수 블록의 재생 자리를 차지하지 않는다.

결승 회전 바는 소리를 유지한다. 사용자가 새 음원 후보를 듣고 선택하기로 했으므로 아직 기존 음원을 바꾸지 않는다. 첫 번째 특수 구간도 새 블록 제안 후 선택을 기다리며 기존 유도 바와 핀을 보존한다.

음향 단위 테스트38개와 관련 배치·반동 검사2개를 통과했다.

lint·정적 검사·build·정적 페이지 검증·UI 문서 연결 검사와 Chromium의 음원 준비·일시정지·초기화 검사1개도 통과했다.
