# 단일 출발 바·좌우 반동·클릭 배속과 짧은 경기

- 날짜: 2026-09-16
- 상태: 사용자 계획 구현 요청에 따라 적용
- 관련 요구사항: REQ-MARBLE-001, REQ-MARBLE-002, REQ-MARBLE-003, REQ-MARBLE-004

## 문제와 선택

수직으로 정렬된 평평한 윗면은 같은 통로를 반복하게 했다. 재질6층과 회전통은 경기를 길게 만들었다. 사용자는 반발계수0.55~0.65, 엇갈린 둥근 블록, 출발 바 한 개, 클릭마다 전환하는2배속, 재질4구역과 좌우 왕복 장애물을 선택했다. 26명을 넘으면 출발 바 위에 자연스럽게 쌓이며, 마지막 중앙 통로 한 개는 유지한다.

## 결정

블록을 줄마다 좌우8씩 옮기고 모서리 반지름6을 그림과 충돌에 함께 적용한다. 기존 마찰과2초 복구를 유지하며 임의의 옆 방향 힘은 더하지 않는다. 좌우 공기 저항은 초당 감쇠계수2로 조정한다. 충돌 뒤 옆 방향 속도가 오래 유지되어 벽으로 쏠리던 현상을 줄이며 재질별 접촉 마찰은 유지한다. 원래 반발계수로 복원하는 중간 요청은 최종0.55~0.65 선택으로 대체됐다.

수평 바 위 여러 높이에서 구슬이 내려앉고2초 뒤 바를 제거한다.26명 이하는 가로 간격을 확보해 한 줄로 내려앉으며 인원이 많으면 위에 쌓인다. 참가자와 위치는 경기 난수로 연결한다. 추가 발사 힘은 없다.

재질은4개·총960개로 줄이고 가운데 빈 통로·젤 구간1곳을 둔다. 왕복 캡슐은 폭160·높이20이며 좌우180 범위를4초 주기로 이동한다. 표면 속도를 충돌에 반영하며 고무 범퍼 음원을 사용한다. 마지막 구간 높이는500이다. 유도벽의 안쪽 면을 맞추고 출구에서 수직에 가까워지는 곡선으로 만들어 좁은 목에서 구슬끼리 버티는 현상을 줄인다. 장애물 반발계수는0.55다. 중앙 내부 폭40과 실제 아래 방향 교차 판정은 유지한다. 마지막 구간에 바람·순위별 힘·출구 잠금은 없다.

배속은 Canvas 클릭·모바일 탭·키보드·별도 버튼으로 전환한다. clock.js는 고정1/120초 계산의 횟수만 늘린다. 같은 경기 시각의 물리 상태와 도착 순서는 배속과 무관하다. 출발·복구·왕복 이동은 경기 시간을 따르고 음원의 음정은 그대로다. 다른 조작은 배속을 바꾸지 않으며 일시정지 후 유지하고 새 경기와 초기화는1배속이다.

## 호환성과 검증

공개 route, localStorage 저장 형식, 도감23종과 Pixabay 녹음46개는 유지한다. 선택 맵의 재질·젤·고무 범퍼 음원만 먼저 준비한다. 예전 ADR은 당시 결정을 보존한다.

180경기의60초 완주와 마지막 구간15초 이내 통과, 가로68 이상 이동하는 구슬75% 이상, 출발 정렬, 배속별 상태·순위 일치, 클릭·키보드·모바일 탭·일시정지·초기화를 검사한다. 곡선 유도벽을 적용하기 전에는60명 밀집 조건에서 장시간 정체가 발생해 해당 조건을 유지한 채 다시 검사한다.

## 측정 결과

동일한 난수10개(5,47,999,1,2,3,17,29,81,2026)와 맵6개, 인원2·30·60명의180경기를 검사했다. 모든 경기는1배속 경기 시간24.72~54.41초에 완주했다. 마지막 구간의 구슬별 최대 체류 시간은9.77초였다. 충돌과 블록 복구를 계속 켠 상태의 결과다.

30명·60명 경기의5,400개 구슬 중4,978개(92.2%)가 재질 구간에서 가로68 이상 이동했다. 중간 통로 다음 재질층의 좌·중·우 최초 진입은36.5%·26.7%·36.8%였다. 두 번째 구슬이1초 안에 마지막 구간에 진입한152경기 중94경기(61.8%)에서 진입 선두가 우승을 놓쳤다. 이는 해당 시작 조건의 관찰값이며 모든 난수에 대한 보장은 아니다.

브라우저의30명 경기에서는2배속 선택 후 실제20.958초 동안 경기 시각41초까지 진행해 모두 도착했다. 로딩 완료 뒤 측정했으며 일시정지는 없었다.

단위 검사106개, lint, Svelte 정적 검사, build, 정적 페이지·sitemap 검증과 문서 연결 검증이 통과했다. Playwright 전체57개는 순차 실행에서 통과했다. 구슬 레이스9개는 병렬 실행에서도 통과했다. 기존 Team Maker의 밝은 테마 추첨 버튼 hover 색상 검사는 병렬 실행에서2회 실패했으며 단독 반복6회와 전체 순차 실행에서는 통과했다. 해당 Team Maker 코드와 검사는 이번 변경에서 수정하지 않았다.

데스크톱·모바일390px·전체화면에서 출발과 경기장을 확인했다.60명 출발처럼 구슬이 밀집한 순간에는 기존 이름표가 일부 겹친다. 구슬 번호·따라가기와 아래 명단에서 참가자를 확인할 수 있다.
