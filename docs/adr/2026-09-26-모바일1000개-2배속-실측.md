# 모바일1000개 경기의2배속 실측

- 날짜:2026-09-26
- 상태: 측정 기록. 전체 구간의2배속 유지는 확인하지 못함

## 조건과 측정 방법

사용자의 모바일2배속 확인 요청에 따라 최신 로컬 build를 재사용했다. 이번 측정에서는 제품 코드를 추가로 수정하지 않았다.

- Chromium headless shell, 화면390×844, CPU4배 감속, reducedMotion reduce
- 도각도각 키보드,1000개, 난수47, 스킬ON, 소리OFF, 선택 배속2배
- 실제 배속은 Worker가 전달한 경기 시간 증가량을 실제 경과 시간으로 나눠 계산했다.
- fps는 Canvas 그리기 횟수로 측정했다. 상태 수신 횟수와 구분했다.
- 결승의 필수0.25배속 규칙은 유지했다. 아래 모든 표본에서는 해당 감속이 발동하지 않았다.

## 첫 번째 당첨 방식: 초반3회 반복

기존 성능 검사와 같은 방식으로 출발부터 실제5초씩 연속2구간을 측정했다.

| 반복 | 출발 fps | 출발 실제 배속 | 다음 구간 fps | 다음 구간 실제 배속 | 전체10초 실제 배속 | 일시정지 응답 |
| ---- | -------- | -------------- | ------------- | ------------------- | ------------------ | ------------- |
| 1    | 49.14    | 1.713배        | 59.95         | 2.296배             | 2.005배            | 10.0ms        |
| 2    | 47.43    | 1.553배        | 60.18         | 2.033배             | 1.792배            | 12.4ms        |
| 3    | 47.93    | 1.627배        | 59.87         | 2.215배             | 1.921배            | 13.1ms        |

출발 직후에는 화면이47fps 이상이어도 실제 경기 진행은2배속에 못 미쳤다. 이후 구간의2배 초과 진행은 밀린 계산을 따라잡는 동작으로 해석한다. 전체10초 평균도 반복마다 차이가 있으므로 항상2배속을 유지한다고 판단하지 않는다.

## 마지막 당첨 방식: 실제 경기의 결승 진입

별도 경기에서 실제10초씩3구간을 측정했다. 일반 블록 제거, 구슬 강제 고정, 저장 상태 주입은 하지 않았다.

| 경기 시간     | 실제 배속 | Canvas fps | 상태 수신/초 | 결승 내 미도착 구슬 | 누적 도착 |
| ------------- | --------- | ---------- | ------------ | ------------------- | --------- |
| 0.61→20.77초  | 2.014배   | 59.25      | 41.37회      | 0→0개               | 0개       |
| 20.84→40.85초 | 2.000배   | 58.47      | 43.18회      | 0→266개             | 22개      |
| 40.92→60.98초 | 2.007배   | 57.60      | 42.70회      | 268→314개           | 77개      |

마지막 구간은 실제10.0006초 동안20.0667경기초 진행했다. 남은 계산 시간은0.01837초에서0.00023초로 줄었다. 이 표본에서는 계산 지연이 누적되지 않았다.

## 해석과 한계

- 결승 내 구슬 수는 결승 시작선에 닿거나 들어간 미도착 구슬 수다. 모든 구슬이 하나의 접촉 무리로 밀집했다는 뜻은 아니다.
- 마지막 방식의 카메라는 뒤쪽 구슬을 추적했다. 결승을 확대해서 그린 화면의 fps는 아니다. 당첨 방식에 따른 카메라 차이로 두 측정의 화면 부담도 다르다.
- 약61경기초까지 확인했다. 과거105경기초의 심한 밀집 저장 상태와 동일한 조건을 재검사한 결과는 아니다.
- CPU 감속을 적용한 로컬 브라우저 측정이다. 실제 휴대폰과 GitHub 검사 환경의 성능을 보장하지 않는다.
- 이번 요청에서는 성능을 측정했다. 겹침·벽 통과 등 물리 회귀 검사는 다시 실행하지 않았다.
