# 순위 티켓 카드와 이름 생략

- 상태: 결정
- 날짜: 2026-09-22
- 연결 요구사항: REQ-MARBLE-003
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

사용자가 로컬 시안의 A안 레이스 티켓을 선택했다. 구슬과 이름을 세로 중앙에 놓고 이름이8자를 넘으면 `...`으로 표시하도록 구현을 요청했다.

기존 Button과 MarbleIcon을 사용한다. 카드 위28px 띠에는 등수와 진행률 또는 도착 상태를 둔다. 본문은36px 번호 구슬과 이름을8px 간격으로 묶고 가로·세로 중앙에 배치한다. 이름이 한 줄인지 두 줄인지에 따라 실제 묶음 높이를 기준으로 정렬한다. 아래4px에는 구슬 색의 진행 막대를 두고 추적 중인 카드는 테두리와 추적 표시로 구분한다. 사이트의 밝은·어두운 테마를 따른다.

이름은 `Intl.Segmenter`로 눈에 보이는 글자를 나눈다.8자까지는 그대로 표시하고9자부터는 앞8자 뒤에 점3개를 붙인다. 이모지의 결합 문자도 중간에서 끊지 않는다. 원본 이름은 바꾸지 않으며 전체 이름을 title과 접근성 이름에 제공한다. 전체 이름 검색과 결과 복사는 유지한다.

2·4·6열과 보이는 행만 그리는 구조를 유지한다. 카드 높이는152px, 행 간격은164px로 같이 바꾼다. 이전128px 카드보다 한 화면에 보이는 세로 행 수는 줄지만, 구슬과 이름을 중앙에 놓을 공간을 확보한다. 전체 순위 접근·검색·선택 기능은 유지한다.
