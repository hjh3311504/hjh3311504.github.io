# 불씨·물방울·개구리·오리 블록 추가

- 날짜: 2026-09-17
- 상태: 적용
- 근거: 사용자가 불씨·물방울 진행을 승인하고 개구리·오리 원음을 추가 선택했다. 도미노는 보류했다.

## 구성

활성 도감은11종이다. 물풍선과 기존 긴 질감4종의 비활성 상태를 유지한다. 도미노는 제작하지 않는다. 공개 route·맵 ID·설정 저장 형식·기존 음원을 유지한다.

- 키보드: 도각 키보드 → 청축 키보드 → 옛날 타자기 → 팝잇.
- 나무공방: 나무 → 코르크 → 불씨 → 뽁뽁이.
- 물놀이: 물방울 → 개구리 → 오리 → 팝잇.

맵당4구역·960개와3초 복구를 유지한다. 새4종은 기존 일반 블록 충돌을 공유한다. 불씨는 반발계수0.59·마찰0.35, 물방울은0.59·0.25, 개구리·오리는0.61·0.25다. 게임과 도감의 그림은 같은 타일 함수를 사용한다. 불씨에는 작은 파편, 나머지는 둥근 파편을 사용한다.

## 음원

선택한 Pixabay 원음에서 불씨와 개구리는2개, 물방울과 오리는1개 타격·울음을 추출했다. 불씨240ms, 물방울320ms, 개구리320/350ms, 오리200ms다. 전체6개 파일은48kHz mono WAV다.

음정과 속도는 유지하며 다른 소재나 긴 배경음을 추가하지 않았다. 재생 시 불씨·물방울은 전체12개·28ms 제한을 따른다. 울음의 겹침을 줄이기 위해 개구리·오리는 각각3개·100ms·음량 배율0.85로 시작한다. 기존 소리를 중간에 끊지 않는다.

원음에 Pixabay Content License를 적용하고 MIT와 구분한다. 자세한 링크는 [음원 출처](../marble-audio-sources.md)에 기록한다.
