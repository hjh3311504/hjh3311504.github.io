# 도각도각 키보드 맵 통합

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 현재 음원을 유지한 채 도각 키보드만으로 맵을 구성하도록 요청했다.

도각도각 키보드(`keyboard`)의 일반4구역을 도각 키보드1 → 2 → 3 → 4로 바꾼다. 별도 도각 키보드 모음(`thock-collection`)과 구성이 같아지므로 목록에서는 하나로 합친다. 저장된 `thock-collection` 선택은 `keyboard`로 복구한다. 나무공방·물놀이 맵과 참가자·당첨 방식·볼륨 설정은 유지한다.

새 후보 음원은 적용하지 않는다. 현재 도각1·2·3·4 파일을 사용하며 특수 구간과 결승 구조도 유지한다. 찰칵 키보드는 도감과 커스텀 맵에서 계속 선택할 수 있다. 기본 맵은3개, 활성 일반 블록은13종이다.

검증: 음향·설정 검사42개와 맵 구성 검사1개를 통과했다. 기존 맵과 도각 전용 맵의 저장 복구, 도각4종 선행 로딩, 일시정지·초기화·캐시와 도감 이미지를 브라우저 검사3개로 확인했다. lint·정적 검사·build·문서 연결 검사도 통과했다. 배치와 물리 값은 기존 도각 전용 맵과 같으며 이전 ADR의 경기 시간 측정과 결승 대기 한계를 유지한다.
