# 도각4 P1 음원 적용

- 상태: 승인됨
- 결정일: 2026-09-18
- 근거: 사용자가 P1을 선택하고 다운로드한 파일을 제공했다.

## 결정

다운로드 문제로 보류했던 도각4 교체를 적용한다. `thock4-v4-1.wav`·`thock4-v4-2.wav`를 도감과 경기에서 A→B 순서로 번갈아 재생한다. 두 파일은 원음의 서로 떨어진 구간을 사용하며 한 타건의 앞뒤를 나눠 쓰지 않는다.

동시6개·전체12개·최소28ms 제한과 도각1·2·3·찰칵·맵 구성·물리는 유지한다. 기존 도각4 파일과 이전 ADR도 보존한다. 새 파일명으로 이전 캐시와 구분한다. 출처는 음원 출처 문서와 제3자 고지에 기록한다.

## 검증

파형 잘림·끝점·음량 차이, 교대 재생과 동시6개 제한, 도감·경기 파일 공유를 확인한다. 실제 청음 품질은 자동 검사 결과로 단정하지 않는다.

두 파일은280ms·250ms이며 평균 음량 차이는 약0.04dB다. 오디오 단위 테스트33개, 관련 Chromium 검사3개, lint·정적 검사·build·정적 페이지 검증·문서 연결 검사가 통과했다.

첫 브라우저 검사는 페이지 초기화 오류로 실패했다. 정적 검사와 build를 동시에 실행한 결과 HTML과 클라이언트 코드의 생성 식별자가 달랐다. build를 단독으로 다시 실행해 식별자가 일치하는지 확인한 뒤 같은 브라우저 검사3개가 통과했다. 두 명령은 같은 생성 디렉터리를 사용하므로 순서대로 실행한다.
