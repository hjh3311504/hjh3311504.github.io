# 첫 특수 구간의 얼음 경사판

## 결정

사용자가 포장지 대신 접촉하면 잠깐 얼어붙고 대각선으로 굴러 떨어지는 얼음 블록을 요청했다. 첫 연결 구간에만 전용 `frost` 장치를 추가한다. 비활성 일반 얼음의 파괴 규칙과 구분한다.

- 유도 바와 핀52개, 크랙 왁스·젤리 연못, 일반960개 블록의 배치와 경기장 높이를 유지한다.
- 첫 구간의 핀 아래에160×28 크기의 판5개를 두 줄로 배치한다. 모두 좌우30도 경사이며 끝 반지름은8이다.
- 구슬을 표면 바깥으로 보정한 뒤 경기 시간1초 동안 고정한다. 다른 고정 구슬과 겹치는 자리에서는 먼저 구슬 충돌로 분리한다.
- 풀리면 반발계수0·마찰0.01로 표면을 유지하며 중력으로 내려간다. 강제 발사와 블록 관통은 없다.
- 판의 접촉 범위를 벗어나기 전에는 다시 얼리지 않는다.12의 여유 범위를 두어 모서리의 작은 떨림 때문에 재동결되지 않게 한다.
- 동결 상태를 Worker에서 화면으로 전달하고 구슬에 반투명 육각 얼음 테두리를 그린다. 일시정지·배속은 경기 시간을 따른다.
- 기존 얼음 파괴음은 사용하지 않는다. 새 동결음은 사용자 선택 대기 중이며 현재 무음이다. 후보 선택 전까지 안내의 미리듣기 버튼을 비활성으로 표시한다.

## 검증

- 동결1초·좌우 경사 해제·표면 관통 방지·지속 접촉 중복 방지·재진입·새 경기 초기화 검사 통과.
  -2/30/60개 구슬과3가지 시작 조건의9개 구간 시험에서 전원 통과했다. 구간 통과 시간은10.275~16.258경기초다. 초기 폭200에서는60개 밀집 통과가20초를 넘겨 폭160으로 줄였다.
- 관련 음향·특수 장치·설정·Worker 단위 테스트62개 통과. Worker는12경기초까지 직접 계산과 비교하여0.25/1/2배속의 동결 상태와 좌표 일치, 일시정지 보존을 확인했다.
  -3개 맵×2/30/60개×10개 난수의90경기 전원 완주를 확인했다. 완주 시간은62.48~88.35경기초다.
- 전체 물리 검사에서는 결승15초 체류 목표와 결승 밀집 검사가 미통과다.55/90경기가 결승 체류 목표를 넘었으며 최대48.81초다. 별도 시작 각도0의 결승 밀집 시험에서는60개 중40개만 관측 한도 안에 도착했다. 결승 구조는 이번 변경 범위에 포함하지 않는다.
- 첫 연결 구간 출구 분포는 좌34.9%·중앙8.1%·우57.0%다. 분포가 고르거나 사이드 편향이 해결됐다고 판단하지 않는다.
- 관련 Playwright2개, lint·Svelte Check·build·정적 페이지 검증·문서 연결 검증 통과.
- 브라우저에서 첫 동결 프레임의 Worker 상태와 얼음판5개를 확인했다. 데스크톱·390px 모바일에서 경사판, 동결 테두리, 미니맵과 일시정지 화면을 확인했다.
