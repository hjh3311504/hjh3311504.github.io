# 구슬 레이스와 블록 효과음 추가

- 상태: 채택
- 근거: 2026-09-16 사용자가 승인한 14종 블록과 공통 구슬 경기장 구현 요청

## 결정

`/marble-race`를 SvelteKit 정적 페이지로 추가한다. 마지막 슬래시는 사용하지 않으며 `build/marble-race.html`로 배포한다. 홈·메뉴·sitemap·build 검증·배포 주소 검사에 포함한다.

구슬과 회전 직사각형의 충돌을 별도 JavaScript 모듈에서 1/120초 간격으로 계산한다. Canvas 표현과 오디오는 결과 이벤트를 소비하며 경기 난수나 순위를 변경하지 않는다. 외부 물리·음원 의존성을 추가하지 않는다.

나무·유리·모래·비눗방울·얼음과 9종 유지 장치를 4개 맵에 배치한다. 합성 효과음은 브라우저에서 준비하고 재생 개수·간격·압축·음량을 제한한다. 소리의 실제 만족도는 사용자 청취로 추가 조정할 수 있다.

구슬이 오래 갇히는 경우를 위해 8초 정체 시 임시 통과, 75초 전체 통과를 적용한다. 이 규칙은 화면에서 안내하며 실제 도착 순서에 반영한다. 마지막 모드는 전원이 도착해야 결과를 공개한다.

명단과 설정은 현재 브라우저에만 보관한다. 별도 서버, 로그인, 녹음 음원, 외부 요청과 경기 결과 저장은 추가하지 않는다.
