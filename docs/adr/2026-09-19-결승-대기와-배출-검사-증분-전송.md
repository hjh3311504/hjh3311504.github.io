# 결승 대기와 배출 검사·Worker 증분 전송

- 상태: 사용자 계획 승인 후 적용
- 결정일: 2026-09-19
- 관련 요구사항: REQ-MARBLE-004
- 화면: `docs/design/screens/SCR-WEB-004.md`

## 결정

결승 모양·회전 바 크기·위치·속도와 물리 계산은 그대로 유지한다. 좁은 출구의 정상 대기를 영구적인 끼임과 구분한다. 기존 제한을 바꾸는 결정은 사용자가 명시적으로 선택했다. 기준 변경 자체를 속도 개선으로 표현하지 않는다.

기본90경기는120경기초 내 전원 완주해야 한다. 결승15초 목표의 초과 횟수와 최대 체류는 계속 보고한다. 결승 입구에60개를 모으는 검사는 시작 각도4가지에서60경기초 내 전원 완주·중복 도착·실제 판정선을 검사하며, 기존30초 초과 인원도 기록한다. 출구 앞(회전축 높이100위부터30아래)에 대기 구슬이 있는데2회전인8.8경기초 동안 추가 도착이 없으면 별도 배출 정체로 실패한다.

1,000개는600경기초 내 전원 완주를 직접 계산과 브라우저에서 각각 검사한다. 브라우저는900실제초에서 안전하게 종료하며270실제초의 도착 수·경기 시각을 기록한다. 화면30fps·버튼200ms 기준은 유지한다. 실패 시 미도착 위치·속도·접촉 장치·최근 도착 기록을 첨부한다.

준비 시 전체 블록·이름·색·맵 정보를 한 번 보낸다. 진행 중에는 구슬 동적 상태와 변경된 블록 속성만 전송하고 클라이언트에서 기존 객체에 반영한다. 재시작 시 인코더와 복원기를 새로 만들고 종료된 Worker의 늦은 응답을 무시한다. 같은 난수·동일 경기 시각에서 원래 직접 계산과 위치·속도·도착 순서를 비교한다.

음원 검사는 선택 맵의 실제 파일 집합과 요청 목록을 비교한다. 결승 진입을 삭제된 안내 문구로 감지하지 않고 실제 충돌 이벤트와 재생 기록을 연결한다. 첫 충돌·결승 충돌·카메라 검사를 분리한다.

## 변경 전 측정

- 기본90경기는 전원120초 이내 완주했다. 결승15초 목표는59경기가 초과했고 최대 체류52.56초, 최대 완주99.63초였다.
- 결승 밀집60개·시작 각도0은30초에40개 도착,52.59초에 전원 도착했다.
- 브라우저1,000개는270실제초에 아직 경기 중이었다. 실패 화면에는636개 도착·경기3분22초가 표시됐다. 이 결과는 원래 난수가 고정되지 않은 관측이라 새 고정 난수 경기와 직접 속도 비교하지 않는다.

## 변경 후 측정

- 동일한 결승 밀집 시작 각도0·π/2·π·3π/2는52.59·51.49·54.79·53.69경기초에 전원 완주했다. 기존30초 초과 인원은20·21·23·21개다. 최대 배출 간격은2.29·3.69·2.39·2.35초였다. 물리는 변경하지 않았다.
- 1,000개 정지 프레임의 JSON 크기는 전체1,441,071바이트에서 변경 프레임136,382바이트로 감소했다. 이는 전송량 측정이며 경기 시간 단축을 뜻하지 않는다.
- 고정 난수47의1,000개 직접 계산은378.79경기초에 전원 완주했다. 계산 실행 시간은175.72초이며 실제 브라우저 시간이 아니다. 최대 배출 간격3.90초로 정체는 없었다.
- 전체 단위 테스트188개, lint·Svelte 정적 검사·build·정적 결과 검사·화면 문서 연결 검사가 통과했다. 결승 밀집 검사에는 통로 밖으로 구슬 중심이 넘어가는지 확인하는 항목도 추가했다.
- Chromium 151·10코어 환경의1,000개 화면 성능은111.86fps·버튼 응답4.5ms였다.
- 고정 난수47의 Chromium1,000개 경기는374.37경기초·410.41실제초에 전원 완주했다.270실제초에는234.28경기초·736개 도착이었다. 최대 배출 간격2.52초, 정체0회, 경기 중 최저73.40fps였으며 전체 결과 복사도 통과했다. Node 직접 계산과 브라우저의 측정값은 각각 기록하며 서로의 실행 시간을 대신하지 않는다.
- 전체 Playwright90개가 통과했다. 음원 로딩 집합·첫 충돌·결승 충돌·카메라·4가지 당첨 방식·모바일·전체화면·중단/재시작·결과 복사를 포함한다. 기본90경기의 결승15초 초과는 이전과 동일한59경기이며 최대 체류52.56초로 유지됐다.
