# 구슬 반지름을16으로 키우고 결승 통로를 폭50으로 넓힌다

- 상태: 결정
- 근거: 2026-10-15 사용자 요청 “구슬 크기를 더 키우고 싶어. 잘 안보여.”와 “실제 크기 키우기” 선택
- 관련 요구사항: `REQ-MARBLE-002`, `REQ-MARBLE-004`
- 관련 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md#큰-구슬과-종료-후-출발-준비-복귀-2026-10-15)

## 배경

구슬 반지름13은 넓은 경기장 화면에서 작게 보였다. 그림만 키우면 구슬끼리 또는 블록과 겹쳐 보이므로 물리 반지름도 함께 키운다.

결승 통로는 폭40이었다. 지름26 구슬은 양쪽에 7씩 여유가 있었다. 반지름만16으로 바꾸면 여유가 4로 줄었다. 그 결과 다음 문제가 생겼다.

- 두 구슬이 입구에 나란히 끼어 회전바가 올 때까지 멈췄다.
- 왼쪽 진입의 반동·역전이 사라졌다.
- 결승 입구에 모인60개가60초 안에 다 나오지 못했다.

## 결정

- 구슬 반지름은16(지름32)이다.
- 출발 줄은 한 줄에 최대21개를 둔다. 줄 간격40은 유지한다.
- 결승 통로의 안쪽 폭을50으로 넓힌다. 통로 벽 중심은 x329·391이고 판정 범위는 x335~385다.
- 경사벽의 바깥 시작점과 높이는 유지한다. 끝점만 넓어진 통로에 맞추므로 실제 기울기는 약40.4°·30.4°다.
- 회전바 길이448·회전축·주기·탄성은 유지한다.

## 검토한 다른 방법

| 방법                     | 결과                                                                      |
| ------------------------ | ------------------------------------------------------------------------- |
| 통로 폭40 유지           | 60개 배출이62~72초로 늦어지고 왼쪽 반동이 사라졌다.                       |
| 반지름15·통로 폭40       | 60개 배출이 최대66초였다.                                                 |
| 통로 폭46                | 단독 구슬이 회전바1바퀴 안에 들어오지 못하는 경우가 2건 생겼다.           |
| 통로 폭48                | 60개 배출이55~58초로 폭50보다 늦고 왼쪽 반동 사례가 절반이었다.           |
| 폭50·기울기를 정확히 40° | 경사벽 끝이나 시작 높이를 옮기자 단독 구슬 실패 2건과 배출 62초가 생겼다. |

결승은 작은 위치 변화에도 구슬 경로가 크게 바뀐다. 통로 폭50과 기존 경사벽 시작점 조합이 다음 검사를 모두 통과했다.

- 단독 구슬3456조합이 회전바1바퀴(13.2경기초) 안에 완주한다.
- 결승 입구 밀집60개는 시작 각도4가지에서49~52초에 모두 나온다.
- 기본3개 맵의 2·30·60개 경기90개가120초 안에 모두 끝난다.
- 양쪽 진입 모두 반동과 역전 사례가 있다.

## 영향

결승 2개 대결 테스트는 앞뒤 간격 20·30·40·50을 함께 검사한다. 지름이 커지면서 간격30 하나로는 왼쪽 역전 사례가 나오지 않기 때문이다. 왼쪽 추월 고정 사례는 간격50을 사용한다.
