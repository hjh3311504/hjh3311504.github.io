# 아수라장 증강 공략의 챔피언 타일과 운명의 무기 카드 추가

- 날짜: 2026-11-02
- 상태: 채택
- 근거: 남은 챔피언 96명을 넣은 뒤 장갑 충격 어울리는 챔피언이 24명이 됐다. 사용자가 2026-11-02 장갑 충격·벌이다!!!의 어울리는 챔피언 내용이 너무 길다며, 제목을 `어울리는 챔피언 N명`으로 두고 아래에 허브처럼 챔피언 링크 타일만 두라고 정했다. 같은 날 운명의 무기 AP 챔피언 추천에 공허의 지팡이를, 암살자 챔피언 카드에 독사의 송곳니를 더하라고 정했다.
- 이전 결정: [아수라장 증강별 공략 페이지](2026-10-27-아수라장-증강별-공략-페이지.md), [아수라장 운명의 무기 1코어 추천](2026-10-28-아수라장-운명의-무기-1코어-추천.md)

## 결정

증강 공략의 어울리는 챔피언은 `어울리는 챔피언 N명` 제목과 챔피언 공략 링크 타일만 보여 준다. 챔피언별 조합 카드, 그 증강 빌드의 코어 아이템, 필수·선택 증강 범례는 두지 않는다. 조합과 증강 빌드는 각 챔피언 공략에서 본다. 타일은 허브와 같은 `ChampionTiles` 컴포넌트를 쓴다.

운명의 무기 1코어 추천은 카드 3개로 늘린다. 한 카드에 아이템을 여럿 둘 수 있게 원본 `roleItems`를 `items` 목록으로 바꾼다.

| 카드          | 추천 아이템           |
| ------------- | --------------------- |
| AD 챔피언     | 도미닉 경의 인사      |
| AP 챔피언     | 무덤꽃, 공허의 지팡이 |
| 암살자 챔피언 | 독사의 송곳니         |

검색 설명은 `증바람 운명의 무기(운무) 1코어 추천은 AD 챔피언 도미닉 경의 인사, AP 챔피언 무덤꽃·공허의 지팡이, 암살자 챔피언 독사의 송곳니입니다.`로 시작한다. 새로 더한 두 아이템은 사용자 지시라 근거 글 번호가 없다. 이 페이지는 계속 출처를 보여 주지 않는다.

## 검토한 대안

- 챔피언별 조합 카드 유지: 24명이면 페이지가 너무 길어 사용자가 줄이라고 정했다.
- 암살자 아이템을 AD 챔피언 카드에 함께 넣기: 사용자가 암살자 항목으로 따로 두라고 정했다.

## 영향과 검증

- 벌이다!!!처럼 챔피언마다 빌드가 다른 증강은 증강 공략에서 챔피언별 빌드를 보여 주지 않는다.
- 조합 카드가 빠지므로 [플레이 영상 결정](2026-10-28-아수라장-조합-플레이-영상은-YouTube로-넣기.md)의 증강 공략 영상(장갑 충격 말파이트)도 보이지 않는다. 영상은 챔피언 공략에만 있다.
- 단위 테스트가 운명의 무기 카드 3개의 아이템과 검색 설명을 확인한다.
- build 검증이 증강 공략에서 챔피언 타일 링크를 확인하고 조합 카드·범례가 없는지 확인한다.
- 브라우저 검사가 장갑 충격 타일 24개와 운명의 무기 카드 3개를 확인한다.
