# θ 로고의 좌측하단 잘림을 꼬리로 바꾼다

- 상태: 결정
- 근거: 2026-11-05 사용자 요청. Codex가 만든 꼬리 시안을 여러 번 고쳐 `길이 A` 시안을 골랐다.
- 관련 결정: [사이트 이름 Seta Lab과 θ 로고](2026-11-04-사이트-이름-Seta-Lab과-θ-로고.md)

## 결정

- θ의 좌측하단 사선 잘림을 왼쪽으로 짧게 뻗는 꼬리로 바꾼다. 우측상단 잘림, 가로획, 안쪽 구멍, 배경은 그대로다.
- 꼬리는 사선 면 전체에서 시작한다. 아랫선은 θ 바닥 높이에서 수평으로 이어지다 끝에서 55도로 올라가 둥근 끝이 된다. 96px favicon 기준으로 몸체 밖 돌출은 10px, 끝 높이는 약 6px다.
- `static/favicon.svg`가 원본이다. 같은 도형을 쓰는 `src/lib/local-preview.js`의 로컬 favicon과 `static/images/home/seta-lab-hero.svg`의 θ 타일도 함께 바꾼다. PNG·ICO favicon과 공유 이미지는 `npm run generate:assets`로 다시 만든다.

## 한계

16px favicon에서는 꼬리 끝의 들림이 거의 보이지 않는다. 큰 아이콘과 공유 이미지에서 모양 차이가 드러난다. 검색 결과와 공유 미리보기의 아이콘은 다시 수집돼야 바뀐다.
