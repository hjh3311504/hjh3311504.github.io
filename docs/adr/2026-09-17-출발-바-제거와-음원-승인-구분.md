# 출발 바 제거와 음원 승인 구분

- 상태: 사용자 후속 요청 반영
- 연결: REQ-MARBLE-002·003, SCR-WEB-004

## 결정

사용자는 슬라임 v3만 새로 승인했으며 나머지 교체 음원은 거절했다. 특히 키보드와 타자기의 잡음을 지적했다. 앞서 승인한 비누 v2와 슬라임 v3는 유지한다. 청축·타자기·샌드·왁뿌볼의 후보를 승인된 것으로 표시하거나 임의 확정하지 않는다.

첫 줄 무음이 계속되므로 출발 바 개방 구간 자체를 제거하라는 요청을 반영한다. 바의 충돌·그림·2초 대기·카운트다운·준비 중 카메라 고정을 제거했다. 첫 블록층을 y405에서 y300으로 당겼다. 기존 구슬의 여러 높이·겹치지 않는 배치와 난수 배정은 유지한다. 음원 준비가 끝나면 첫 물리 계산부터 중력으로 낙하한다.

이번 변경을 기존 무음의 원인 규명으로 기록하지 않는다. 문제가 발생하던 출발 방식을 사용자 요청에 따라 없앤 것이다. 첫 실제 블록 충돌부터 소리가 연결되는 검사는 유지한다.

## 검증

2/8/26/30/60명 모두 최초 계산에서 아래로 움직이며1.2초 안에 첫 줄 블록과 충돌한다. 시작 위치에서 구슬끼리 또는 첫 블록과 겹치지 않는지 검사한다. 모든 맵의90경기가 완주했고 좌·중·우 분산 목표도 유지됐다. 경기 최대 시간은60.90초이며 마지막 구간 체류 최대48.05초다. 기존60초·15초 시간 목표 테스트1개는 계속 실패한다. 기준을 완화하지 않는다.

전체 단위 테스트120개 중119개 통과, 기존 시간 목표1개 실패다. 승인된4개 WAV 파일과 재생 코드는 이번 작업에서 변경하지 않았다. 브라우저 검사에서는 카운트다운 없이 시작한 첫 줄 충돌의 시각·출력을 확인한다.

음향 브라우저 검사12개 중11개가 통과했다. WebKit 정적 미리보기의 키보드 맵 새 시작에서는 첫 충돌의 재생 명령과 출력 파형이 있었지만, 첫80ms의 평균 음량이0.00845로 기준0.01보다 작아 실패했다. 기준을 낮추지 않았으며, 출발 바 제거만으로 첫 소리의 충분한 크기가 보장됐다고 판단하지 않는다. 실제 귀로 들리는 만족도는 사용자 확인이 필요하다.

화면 Playwright 검사12개는 모두 통과했다. 모바일 탭·키보드 배속·일시정지·초기화·전체화면·음원 로딩 실패·이전 설정 연결·3개 당첨 방식을 확인했다. lint, Svelte 정적 검사, build, 정적 파일 검증, UI 요구사항 문서 연결과 `git diff --check`도 통과했다.
