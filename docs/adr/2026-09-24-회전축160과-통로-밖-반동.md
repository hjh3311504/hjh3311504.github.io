# 회전축 x160과 통로 밖 반동

- 상태: 적용
- 날짜: 2026-09-24
- 연결 요구사항: REQ-MARBLE-002, REQ-MARBLE-004
- 연결 화면: [SCR-WEB-004](../design/screens/SCR-WEB-004.md)

## 요청과 결정

사용자는 회전축을 오른쪽15 옮겨 x160으로 돌리고, 통로에 들어온 공을 완전히 밖으로 밀어낼 수 있는 배치를 요청했다. 동시에 마지막 공이 계속 튕겨 골인하지 못하는 상황을 막도록 요청했다.

회전축을 **x160·결승 시작점+480**에 둔다. 직전 x145·시작점+440에서 오른쪽15·아래40 이동이다. 길이440·두께16·회전 주기13.2경기초·반시계 방향·반발계수0.35·마찰0.05를 유지한다. 왼쪽40°·오른쪽30° 경사, 입구+400·폭40·판정선+710도 유지한다. 제품 코드는 회전축 좌표만 바꾼다. 마지막 구슬 수에 따른 바 축소, 추가 힘, 자동 골인을 사용하지 않는다.

이 결정은 [직전 결승 배치 ADR](2026-09-24-회전바-길이-유지와-결승-배치-조정.md)의 축 위치를 대체한다. 과거 ADR 본문은 보존한다.100개 블록 상한과 종료 뒤 설정 편집 시 준비 화면 복귀는 유지한다.

## 높이도 바꾼 이유

x160·높이+440만 적용하면 반복 반동이 재현된다. 마지막1개 표본 중 일부가60경기초에도 골인하지 못했고,60개 밀집 시험도120경기초까지59개만 도착했다. 구슬이 통로에서 올라와 왼쪽 경사로 돌아간 뒤 다시 같은 회전 위상에 걸렸다. 직전의1회전 이내 완주 검사와 접전 완주 검사가 실패했다. 이 실패를 검사 시간 상한 확대로 숨기지 않았다.

x160을 고정하고 입구 아래0/10/20/25/30/35/40/45/50/60/70/80 위치를 비교했다. 입구 아래70·80에서는336개 단일 표본과32개 접전 표본에 미완주가 없었다. 입구 아래80은70보다60개 밀집 전원 도착이 빨랐다. 입구 아래75·85·90의 중앙 진입64각도 검사도 미완주가 없었다. 한 지점에서 우연히 통과하는 후보를 피하고 입구 아래80을 선택했다.

통로 밖으로 밀어낸다는 기준은 구슬 중심만 입구를 넘는 것이 아니다. 구슬 위쪽까지 통로 안에 들어온 뒤, 회전바에 닿고, 구슬 아래쪽까지 입구 위로 올라와야 한다. 이때 기존 진입 기록이 지워지고 다시 중앙으로 들어와 판정선을 넘어야 골인한다. 벽을 옆으로 뚫고 나가는 동작은 허용하지 않는다.

## 관련 검사

- 1000개·스킬ON·회전각2가지·12경기초의 최대 실제 겹침은0.570464 미만, 표시 겹침은0.499946 미만이었다.60개 밀집의 최대 실제 겹침은0.621536 미만이다. 모두 기준1 이하다.
- 1000개·회전각4가지·35경기초의 벽 반대편 이탈 방지와 중앙 골인 검사가 통과했다. 번개 고정의 바 밀림·얼음 고정·0.25/1/2배속의 상태와 이벤트 재현성도 통과했다.
- 관련 단위 검사86개가 통과했다. 초기 실행에서는 옛 축 위치를 포함한 상태 해시3개와 통로 점유율 검사1개가 실패했다. 새 좌표가 의도한 변경인지 확인한 뒤 해시를 갱신했다. 실제 겹침·벽 통과·완주 검사를 별도로 유지했다.
- 직전 배치의 통로 점유율30% 미만 검사는 x145·높이+440을 명시해 보존했다. 현재 배치는 사용자의 통로 반동 확대 요청에 따라 점유 시간이 늘어나는지 검사한다. 영구 정체 방지는 실제 진입·완전 이탈·재진입·완주 검사와3,456조합 검사로 확인한다. 점유율 기준만 넓혀 통과시킨 결과가 아니다.
- 이전부터 실패하던 과거180/290/320길이 반동 비교2개는 이번에 다시 실행하지 않았다. 이 비교는 과거 배치를 명시하므로 현재 축 위치 변경의 영향을 받지 않는다. 전체 lint와 다른 도구의 전체 검사도 실행하지 않았다.
- 최종 build의 관련 Playwright7개가 통과했다. 마지막 당첨·팡파레1회·실제 골인, 데스크톱/모바일 반동·번개 밀림 표시, 화면 갱신이 느릴 때의 계산 유지와 일시정지·재개·초기화를 포함한다.
- Svelte 정적 검사 오류0개·경고0개, 변경 코드 ESLint·Prettier·REQ-MARBLE-002와 전체 화면 연결·정적 build 검사가 통과했다. 최종 build는1회 수행했다.
