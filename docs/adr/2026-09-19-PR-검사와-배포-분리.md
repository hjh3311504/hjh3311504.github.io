# PR 전체 검사와 배포 작업 분리

- 상태: 승인됨
- 날짜: 2026-09-19
- 관련 요구사항: REQ-PAGES-003
- 근거: 사용자가 로컬·PR·머지 뒤에 반복하는 검사를 줄이도록 요청했다.

## 결정

로컬은 변경한 기능에 필요한 검사만 실행한다. 전체 검사는 PR workflow에서 실행한다. AGENTS.md와 CLAUDE.md의 PR 전 로컬 전체 검사 요구를 함께 바꾼다.

PR에서는 lint·정적 검사·전체 단위 테스트·build·전체 브라우저 검사·정적 결과 검증을 수행한다. 기존 검사 결과 이름 build를 유지한다.

main push와 main 수동 실행에서는 build·정적 결과 검증·Pages 배포·공개 주소 확인만 수행한다. 전체 테스트를 통과한 PR을 거쳐 머지한다. main 직접 push에는 전체 검사 보장이 없으므로 일반 작업은 PR을 사용한다. 다른 branch의 수동 실행으로는 배포하지 않는다.

모든 실행 경로에서 build는1회만 수행한다. test:e2e:team-maker는 로컬의 build 포함 명령으로 유지한다. test:e2e:built는 이미 만든 최신 build를 검사하며 사전 build 명령이 없다. workflow는 명시적으로 build한 다음 후자를 호출한다.

PR의 결과물을 그대로 배포하지 않고 머지된 최종 코드로 배포 파일을 만든다. 따라서 최종 코드 build는 남지만 전체 테스트의 반복은 없어진다. build나 정적 결과 검증 실패 시 배포하지 않는 연결과 배포 뒤 공개4개 주소 확인을 유지한다.

## 검증

- actionlint1.7.12의 workflow 문법 검사 통과.
- PR·main push·main 수동 실행·다른 branch 수동 실행의4가지 조건, build 중복 방지와 배포 선행 작업 연결 확인 통과.
- build1회와 정적 결과 검증 통과.
- test:e2e:built로 페이지 이동 브라우저 검사1개 통과. 재build가 실행되지 않음을 확인했다.
- 변경 파일 포맷·문서 연결·diff 검사와 AGENTS.md/CLAUDE.md 일치 확인 통과.
- 제품 코드를 바꾸지 않았으므로 로컬 전체 경기 테스트는 반복하지 않았다.

GitHub에서 새 workflow를 실제 실행하기 전에는 실행 시간 단축이나 배포 성공을 확정하지 않는다.
