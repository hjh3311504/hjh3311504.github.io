# 결승에 반대 방향 회전판을 추가하고 겹친 이름표를 유지한다

## 결정과 승인

2026-09-19 사용자가 이름표·모바일 버튼·결승 기믹·공통 footer 수정 계획의 구현을 요청했다. 이름표는 구슬 아래에 항상 표시하고, 결승은 엇갈린 회전판을 선택했다.

기존 입구 판은180×16·반시계 방향·4.4경기초 주기를 유지한다. 윗 판을 x385·결승 시작점220아래에140×16·모서리 반경8로 추가한다. 윗 판은3.6경기초마다 시계 방향으로 회전하고 시작 각도는 입구 판보다90도 앞선다. 추가 난수를 소비하지 않는다. 탄성0.35·마찰0.05와 기존 표면 속도 충돌을 사용한다. 두 판은 벽 앞에 그리고 기존 팝잇 음원과 재생 제한을 공유한다.

기존 깔때기·골인 통로·슬로모션 시작점·0.25배속·도착 판정은 유지한다. 모든 기본 맵과 내 맵에 같은 기믹을 적용한다. 순위별 힘이나 순간이동은 추가하지 않는다.

이름표의 겹침 검사에 따른 생략을 제거한다. 구슬을 먼저 모두 그린 뒤 이름표를 그리고 추적 이름표는 마지막에 그린다. 이름끼리 겹치는 것은 허용한다. 모바일 상단 버튼 묶음은 너비 축소와 줄바꿈을 허용한다.

footer는 개인정보처리방침 버튼 다음에 `© 2026 Lake's develog`를 표시한다. 이미 같은 문구와 순서를 사용하는 홈은 유지한다.

## 검증 기준

기본3개 맵×2/30/60개×난수10개의120경기초 내 완주를 확인한다. 결승 밀집60개는 두 판의 시작 각도16조합에서60경기초 내 완주해야 한다. 출구 앞8.8경기초 배출 정체 기준을 유지한다.1,000개 장시간 완주 검사는 추가하지 않는다.

브라우저에서는 겹친 이름의 그리기 순서, 모바일 결승 확대, 전체 맵 보기, 너비320·360·390·768·1440px의 상단 버튼, 공개 페이지4개의 footer와 모달을 확인한다.

## 구현 후 확인

- 기본90경기는 모두120경기초 내 완주했다. 최대 완주 시간은93.17경기초다. 결승15초 목표 초과는60경기이며 최대 체류는57.31경기초다.
- 결승 진입 차이가1초 이내인80경기 중48경기에서 먼저 진입한 구슬과 우승 구슬이 달랐다. 이 수치는 변경 후 관측값이며 이전보다 역전이 늘었다는 비교 결과는 아니다.
- 결승 밀집60개·두 판의 시작 각도16조합은44.23~58.09경기초에 완주했다. 최대 배출 간격은4.18경기초이며8.8경기초 배출 정체는 없었다.
- 구슬 레이스 단위 테스트152개를 확인했다. 장치 수를61개로 가정한 기존 검사1개를 새 회전판을 포함한62개로 수정하고 해당 파일의6개 검사를 다시 통과했다.
- 브라우저17개 검사에서 이름표 그리기 순서·모바일과 전체화면 버튼·footer4곳·추적 전환·스킬·마지막 당첨·여러명 당첨을 확인했다.
- 같은 build의1,000개 구슬5초 화면 검사도 통과했다. Chromium 151·10코어 환경에서110.10fps·버튼 응답3.9ms를 기록했다. 브라우저 검사는 합계18개이며 build는1회 실행했다.
- Svelte 정적 검사·변경 코드 ESLint/Prettier·문서 연결·정적 build 결과·`git diff --check`를 통과했다. 전체 사이트 테스트와1,000개 장시간 완주 검사는 실행하지 않았다.
