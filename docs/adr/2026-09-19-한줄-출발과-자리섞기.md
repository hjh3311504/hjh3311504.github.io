# 한 줄 출발과 자리섞기

- 상태: 승인됨
- 날짜: 2026-09-19
- 관련 요구사항: REQ-MARBLE-002, REQ-MARBLE-003
- 근거: 사용자가 배속 옆 자리섞기와 가능한 한 줄 출발을 요청했다.

## 결정

경기장 폭720과 구슬 지름26·벽 여백12를 유지한다. 한 줄에 최대26개를 같은 높이에 놓고 초과 인원은40간격의 다음 줄로 이어 배치한다. 마지막 줄은 남은 인원에 맞춰 가로로 펼치며1개면 중앙에 놓는다. 출발 힘이나 받침판은 추가하지 않는다.

자리섞기는 배속 오른쪽에서 출발 준비 중에만 사용할 수 있다. 경기 중·일시정지·준비 중에는 비활성화한다. 명단과 설정을 유지하며 배치 난수를 다시 정한다. 같은 난수를 준비 화면과 실제 Worker에 전달해 보았던 자리에서 출발한다. 재시작과 새 경기에서는 새 난수를 사용하며 브라우저 저장 형식은 바꾸지 않는다.

부분 미리보기에서 전체 구슬 자리 배열을 만들지 않도록 아직 선택되지 않은 자리의 대응만 기록하며 순서대로 무작위 선택한다. 표시한 앞60개와 실제 전체 경기의 앞60개는 같은 자리를 받는다. 기존256개 단위 준비·취소 흐름을 유지하며 자리 생성과 섞기를 한 단계로 처리한다.

## 검증

인원2·10·26·27·30·60개의 최소 줄 수·겹침·벽 범위와 미리보기·실제 경기의 동일성을 확인한다. 기존 Worker 동일성·출발 충돌·90경기·결승 밀집 검사를 실행한다. 브라우저에서 버튼 위치·명단 보존·실제 출발 자리·경기 중 잠금과 모바일 화면을 확인한다.

- 관련 단위 검사63개 통과. 기본90경기는 모두120경기초 이내 완주했으며 최댓값은95.42초였다.
- 기존 결승15초 목표 초과는57/90경기, 최대 체류57.85초로 별도 기록한다. 결승 밀집4가지 시작 각도 검사도 통과했다.
- 실제 Worker 출발 위치·자리섞기 잠금과 마지막 조기 당첨 브라우저 검사2개 통과.
- 정적 검사·변경 파일 lint·포맷·build1회·정적 결과 검증·문서 연결 검사 통과.
- 기존 준비 분할 검사는 제거된 별도 섞기 단계의 총 호출 수 대신 한 단계의 처리량이256개 이내인지 확인하도록 바꿨다.
