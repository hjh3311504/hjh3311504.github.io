# 찰칵 키보드 B 음원 복구

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 이전 음원3개를 비교한 뒤 B를 선택했다.

찰칵 키보드는 보존된 Pixabay 음원 `clicky-v5-1.wav`와 `clicky-v5-2.wav`를 다시 사용한다. 비교용 반복 파일 대신 기존 두 타격 파일을 도감·경기·선행 로딩에 동일하게 연결한다. 파일 내용과 재생 속도·음정은 바꾸지 않는다.

재질당 동시3개·최소28ms와 전체 동시12개 제한을 유지한다. 옛날 타자기와 다른 블록의 음원·물리 값은 변경하지 않는다. 앞선 배속·타건음 결정에서 보류했던 키보드 음원 선택을 확정한다.
