# 아수라장 조합 플레이 영상은 YouTube로 넣기

- 날짜: 2026-10-28
- 상태: 채택
- 근거: 사용자가 2026-10-28 카이사(환영 무기 + 황혼과 새벽)와 말파이트(장갑 충격) 플레이 영상을 공략에 보여 달라고 요청했다. 처음에는 영상 파일을 저장소에 넣는 안을 검토했다. 사용자가 나중에 모든 챔피언에 영상을 1개씩 넣을 수 있는지 물었고, 저장소 용량을 비교한 뒤 YouTube에 올려 페이지에 넣기로 정했다.
- 이어지는 결정: [아수라장 챔피언별 주소와 검색 문구](2026-10-27-아수라장-챔피언별-주소와-검색-문구.md)

## 결정

조합 카드에 YouTube 플레이 영상을 넣는다. 영상은 사용자가 YouTube에 일부 공개로 올린다. 조사 원본 `champions.json`의 조합에 `playVideo`(`youtubeId`·`aspect`·`titleKo`)를 적는다. 출처 링크용 `videos`와는 따로 둔다.

| 챔피언   | 조합                    | 영상 ID       | 비율  |
| -------- | ----------------------- | ------------- | ----- |
| 카이사   | W만으로 패시브 터트리기 | `TXJnV9S1t8g` | 64/27 |
| 말파이트 | 방어력 기반 평타        | `Vx5VH92Zd2I` | 16/9  |

- 플레이어 주소는 `youtube-nocookie.com`이다. 처음에는 화면에 들어오면 소리 없이 자동 재생하도록 만들었다. 2026-10-31 사용자가 자동 재생을 빼고 소리가 나오게 하라고 정했다.
- 영상은 사용자가 누를 때만 소리와 함께 재생하고 반복한다. 플레이어는 브라우저의 `loading="lazy"`로 카드가 화면 가까이 올 때 불러온다.
- 같은 조합 카드가 나오는 증강 공략 페이지에도 영상이 보인다. 사용자가 허용했다.
- 리플레이 화면의 다른 플레이어 닉네임은 그대로 둔다. 사용자가 허용했다.
- 개인정보처리방침에 YouTube 플레이어가 Google에 접속 정보를 보낼 수 있다는 안내를 더한다.

## 검토한 대안

- 영상 파일을 저장소에 넣기: 소리를 뺀 1080p 원본은 2개에 약 17MB, 720p로 줄이면 WebM 약 6MB(예전 iPhone용 MP4 포함 약 16MB)다. 2개는 충분하지만 전체 챔피언(약 170명)에 넣으면 GitHub Pages 사이트 한도 1GB에 가까워지거나 넘는다. 영상을 바꿀 때마다 Git 이력도 커진다.
- Cloudflare R2 같은 외부 파일 저장소: 화면 코드는 `<video>` 그대로 쓸 수 있지만 계정과 업로드 관리가 늘어난다. 사용자가 YouTube를 골랐다.

## 영향과 검증

- YouTube 플레이어가 화면 위에 로고·제목을 보여 주고, 영상 카드가 화면 가까이 오면 외부 스크립트가 실행된다.
- 단위 테스트가 플레이어 주소의 옵션(자동 재생·소리 끔 없음)과 두 조합의 영상 정보를 확인한다.
- 브라우저 검사가 챔피언·증강 공략의 영상 주소, 자동 재생·소리 끔 없음, lazy 로딩을 확인한다. 실제 YouTube에는 접속하지 않는다.
