# ASMR 동시 재생 제한 완화

- 상태: 사용자 요청에 따라 적용
- 날짜: 2026-09-17

## 배경과 결정

사용자가 소리가 하나씩만 들린다고 피드백했다. 긴 질감 소리를 같은 재질에서1개만 허용하던 제한을2개로 늘린다. 질감4종의 합계 제한도2개에서4개로 늘린다.

최소 시작 간격은 키네틱 샌드·비누100ms→80ms, 슬라임140ms→110ms, 왁뿌볼180ms→140ms로 줄인다. 기존 소리를 끊지 않고 실제 오디오 시간으로 제한한다.

키보드·타자기·팝잇과 전체12개·28ms 제한은 유지한다. 장치는 합계1개·100ms를 유지한다. 승인 음원 파일과 전체 음량, 압축기 설정은 바꾸지 않는다.

## 검증

음원 단위 테스트18개가 통과했다. 같은 질감2개 겹침, 질감 합계4개 제한, 초과 재생 생략, 재생 중 소리 유지와 정지 후 초기화를 검사했다. 재질별 시작 간격과 장치1개 제한도 확인했다. 실제 청음에 따른 만족도는 자동 검사로 확정하지 않는다.
