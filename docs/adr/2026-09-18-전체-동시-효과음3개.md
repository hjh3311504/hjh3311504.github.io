# 전체 동시 효과음3개

- 상태: 적용됨
- 결정일: 2026-09-18
- 근거: 사용자가 전체 동시 재생 한도를3개로 줄이도록 요청했다.

일반 블록·특수 장치·미리듣기·팡파레가 공유하는 전체 한도를4개에서3개로 줄인다. 초과 충돌 생략, 팡파레의 기존 소리 교체, 음원·음량·28ms 간격은 유지한다. 이전 ADR은 보존한다.

단일·혼합 재질의 합계3개, 완료 후 자리 재사용, 재생 순서와 팡파레 교체를 검사한다.

오디오 단위 검사36개, 관련 Chromium 검사2개, lint·정적 검사·build·정적 페이지 검증·문서 연결 검사가 통과했다. 기존 미리듣기 검사는 빠른 연속 클릭 중4번째 소리가 새 한도에 의해 생략되어 실패했다. 음원별 확인에서는 실제 재생 종료를 기다리도록 변경했고, 전체 한도와 초과 생략은 별도 단위 검사로 유지했다.
