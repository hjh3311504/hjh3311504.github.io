## 원인과 결정

앞선 원격 검사에서 데스크톱은 물리 계산이 밀렸고 모바일은 화면 비용이 컸다. 로컬 CPU12배 감속으로 느린 화면을 재현한 Chromium trace에서도 일반 블록 처리·구슬 쌍 처리와 Canvas 복사·순위 구슬 그림 생성이 주요 비용이었다. 이 감속 조건은 실제 휴대폰이나 원격 CPU4배 감속과 같지 않다.

1. 회전각0인 일반 블록은 바깥 사각형에도 닿지 않는 구슬을 먼저 제외한다. 경계의 반올림 오차는 기존 정밀 판정에 넘긴다. 회전바·시소·호 모양은 기존 판정을 따른다.
2. 주변 블록 후보가 없는 구슬은 반복 접촉용 배열과 Set 준비를 건너뛴다. 경기장 벽과 결승 벽의 이동 제한은 그대로 적용한다.
3. 물리 단계의 이동과 진행 기록 루프를 각각 함수로 옮긴다. 단계 간격, 처리 순서와 수식은 유지한다.
4. 연속 화면의 구슬 그림은 번호·색·반지름·글꼴·화질로 재사용한다. 이름표의 측정 결과와 그림도 현재 글꼴·화질에서 재사용한다. 확대, 추적, 새 경기에서 필요한 캐시를 갱신한다.
5. 화면 밖 순위 영역에서는 구슬 아이콘을 그리지 않는다. 순위와 접근성 정보는 계속 갱신한다. 화면에 들어오면 최신 번호를 그리며 관찰자는 화면 종료 때 정리한다.
6. 경기 중 소리를 다시 켜며 오디오를 준비할 때 Worker에도 정지를 전달한다. 화면 상태만 정지하고 계산은 계속되는 시간을 없앤다.

필수0.25배속, 지형, 회전바, 반발계수, 스킬 규칙과 시간 보존 방식은 바꾸지 않는다. 화면 해상도와 이름·번호 표시도 유지한다. 성능 검사의30fps·실제1.9배 이상·잔여0.1초 이하 기준을 낮추지 않는다.

## 같은 입력의 계산 비교

Apple M5의 같은 프로세스에서 이전 코드와 새 코드를 번갈아 실행했다. 첫 실행의 최적화 준비 비용을 구분했다.

| 표본                                         | 이전                     | 변경            | 해석              |
| -------------------------------------------- | ------------------------ | --------------- | ----------------- |
| Chromium, 출발1000개·1200단계, 준비 뒤2회    | 904ms·870ms              | 752ms·754ms     | 약13%에서17% 감소 |
| Node, 실제105경기초 상태·600단계, 준비 뒤2회 | 단계 평균1.693ms·1.680ms | 1.597ms·1.612ms | 약4%에서6% 감소   |
| Canvas, CPU8배 감속, 일반 화면40회 평균      | 24.9ms                   | 22.3ms·22.65ms  | 약9%에서11% 감소  |

실제105경기초 자료는 `.context/slow-real-fixture.bin`이다. 지형을 지우거나 구슬을 고정하지 않았다.110경기초까지 구슬·블록·도착 순서의 전체 상태와600단계의 모든 이벤트 이력이 이전 코드와 정확히 일치했다. 최종 도착106개다. 같은 모듈의 캐시를 매 단계 비우는 비교도 출발·밀집·결승 각720단계에서 동일했다.

Canvas는 일반·전체 맵에서 픽셀 차이가0이었다. 같은 renderer를 재사용하며 확대, 추적, 이름·색·반지름, 새 경기, 화면 크기, 이동을 바꾼9개 표본도 픽셀 차이가0이었다. 첫 모듈 실행의 큰 초기 비용 차이는 개선율로 사용하지 않는다.

CPU12배 감속·390×844·1000개·난수47·2배속·소리OFF의 개발 화면 비교에서는 출발14.18fps에서18.85fps, 진행16.54fps에서20.50fps로 늘었다. 실제 진행은 변경 전후 약2배속이며 변경 뒤2.010배·2.007배였다. 이 진단은 fps 합격 검사가 아니다. 화면 그리기를 제거한 실험에서도 약29fps와31fps였으므로 Canvas 외 화면 작업도 남아 있다. 진단 코드가 출력한 `cpuSlowdown:4`는 복사한 표기 오류이며 실제 CDP 설정은12였다. 원본 로그를 덮어쓰지 않고 여기서 바로잡는다.
