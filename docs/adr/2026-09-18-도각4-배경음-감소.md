# 도각4 배경음 감소

- 상태: 적용됨
- 결정일: 2026-09-18
- 근거: 사용자가 도각4의 잡음이 많다고 지적했다.

## 결정

도각4를 `thock4-v5-1.wav`·`thock4-v5-2.wav`로 교체한다. P1의 기존 두 타건 구간과280ms·250ms 길이를 유지하면서 배경음을 줄인다. 두 파일의 교대 재생, 동시6개·전체12개·최소28ms 제한은 유지한다. 기존 파일과 ADR은 보존한다.

## 검증

이전 파일과 같은 타격·배경 구간을 비교한다. 게임 음량 보정 후에도 배경 구간은8dB 이상 낮아지고 타격 구간은1dB 이내로 유지되는지 검사한다. 파형 검사만으로 실제 청음 품질을 확정하지 않으며 수정 전후 청음 파일을 별도로 제공한다.

오디오 단위 테스트34개와 관련 Chromium 검사3개가 통과했다. lint·정적 검사·build·정적 페이지 검증·문서 연결 검사도 통과했다. 원래 파일과 비교한 배경 구간 감소량은 약11.8dB·15.8dB다. 게임 음량 보정 후의 타격 차이도1dB 이내로 확인했다.
