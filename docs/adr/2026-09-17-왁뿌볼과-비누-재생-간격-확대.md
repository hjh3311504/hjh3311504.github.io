# 왁뿌볼과 비누 재생 간격 확대

- 상태: 적용
- 사용자 요청: 왁뿌볼과 비누 소리가 나오는 간격을 더 늘린다.

왁뿌볼의 최소 시작 간격을100ms에서150ms로, 비누는60ms에서90ms로 늘린다. 두 재질 모두 기존보다50% 늘려 연속 충돌의 소리 밀도를 줄인다. 각 재질의 동시3개 제한과 음원·음량은 유지한다. 다른 재질과 물리는 변경하지 않는다.

간격은 기존처럼 실제 오디오 시간으로 계산한다. 제한 안에 들어온 새 충돌음만 생략하고 재생 중인 소리는 끝까지 유지한다. 기존 오디오 검사에서 두 재질의 간격 직전·직후 재생과 정지 후 재생 기록 초기화를 확인한다.
