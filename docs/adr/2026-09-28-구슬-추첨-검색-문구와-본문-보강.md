## 결정

화면 이름은 ASMR 구슬 레이스를 유지한다. 검색 제목은 `ASMR 구슬 레이스 | 마블룰렛 방식의 무료 구슬 추첨기`로 정한다. 2026-09-18 검색 제목 결정을 이 내용으로 갱신한다.

검색 설명·공유 정보·화면 소개·홈 카드·사용법·FAQ에 구슬을 굴려 이름을 추첨하는 용도를 설명한다. 이름 입력·맵과 당첨 방식 선택·시작과 결과 확인 순서로 안내한다. 앱 이름과 제작자는 유지하고 구조화 데이터의 설명을 화면에 표시하는 기능과 맞춘다. 일반 룰렛과의 차이, 무료 이용, 당첨 기준과 저장 범위도 기존 가이드에서 확인할 수 있다.

검색기와 AI 검색이 읽을 수 있도록 소개와 가이드를 정적 HTML에 포함한다. 공개 경로·검색 수집 허용·sitemap을 유지한다. 검색 순위나 AI 답변 인용 여부는 로컬 검사로 보장하지 않는다.

사용자가 승인한 문서 정리 범위는 현재 문서에 적용한다. 자체 기능 결정과 자체 측정 결과는 보존한다. 과거 Git commit은 수정하지 않는다.

## 검증 기준

- 정적 HTML에 검색 제목·설명·화면 소개·사용법·FAQ가 포함되어야 한다.
- 공유 정보와 WebPage·WebApplication의 설명이 검색 설명과 일치해야 한다.
- 앱 이름·제작자·대표 주소·공유 이미지와 무료 이용 정보가 유지되어야 한다.
- 홈에서 구슬 추첨 용도를 이해하고 도구로 이동할 수 있어야 한다.
- 모바일·데스크톱에서 긴 소개와 FAQ가 잘리지 않아야 한다.
