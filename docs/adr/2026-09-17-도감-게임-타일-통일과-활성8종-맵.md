# 도감·게임 타일 통일과 활성8종 맵 반영

- 상태: 적용
- 사용자 요청: 블록 소개 이미지를 게임 속 블록 이미지와 같게 바꾸고 새 블록들을 맵에도 반영한다.
- 승인 범위: 이전 맵 개편 보류는 이번 명시적 요청으로 해제한다. 기존 맵 ID와 저장 명단·설정은 유지한다.

## 같은 타일 이미지

renderer.js 안의 타일 그리기를 tile-painter.js의 createTilePainter로 분리한다. 경기의 정상 블록·파괴 효과와 도감이 같은 함수를 호출한다. 블록별 색·무늬·모서리 그림을 별도로 복제하지 않는다.

BlockThumbnail.svelte는 화면 밖 Canvas에32×32 타일을3배 해상도로 그려96×96 PNG로 표시한다. 로컬 글꼴이 준비되면 키캡 글자를 다시 그린다. 카드의 장식용 이모지·배경은 제거하며 버튼 이름·미리듣기·현재 맵 표시는 유지한다. 이미지에는 별도의 조작을 넣지 않는다. 작은 화면에서도 정사각형 비율을 유지한다.

## 맵

| 이름            | ID       | 위에서 아래로 배치            |
| --------------- | -------- | ----------------------------- |
| 도각도각 키보드 | keyboard | 도각 → 청축 → 타자기 → 팝잇   |
| 톡톡 나무공방   | crunch   | 나무 → 코르크 → 뽁뽁이 → 도각 |
| 뽁뽁 물놀이     | soft     | 물풍선 → 팝잇 → 뽁뽁이 → 도각 |

활성8종을 모두 사용한다. 맵마다 서로 다른4종·960개 블록을 유지한다. 비활성 질감4종은 다시 넣지 않는다. 분산 핀·회전 원통·3초 복구·반동·소리 정책·명단·당첨 방식은 변경하지 않는다. 맵의 types는 layers에서 계산하므로 새 재질의 음원도 선택 맵에서만 선행 로딩한다.

## 검증

전체 단위128개 중127개가 통과했다. 3개 맵·2/30/60명·난수10개의90경기는 모두 완주했다. 키보드는43.75~~60.30초, 나무공방은43.81~~59.93초, 물놀이는43.73~60.43초다. 기존 시간 목표 검사1개는 실패했다. 60/90경기가 전체60초 또는 마지막 체류15초를 넘었고 최대 마지막 체류는48.14초였다. 시간 기준을 완화하거나 충돌을 생략하지 않았다.

분산 출구 좌·중·우는32.0%·36.8%·31.2%, 다음 층 진입은31.4%·36.6%·31.9%로 기존 분포 기준을 통과했다. 가까이 진입한65경기 중58경기에서 마지막 구간 선두가 우승을 놓쳤다.

브라우저 관련12개 검사를 통과했다. 도감8개의 PNG 해상도와 이미지 구분, 모든 맵의4종 표시·선행 음원 목록, 미리듣기,320px·모바일 배속·전체화면·일시정지·초기화·저장 설정을 확인했다. 접근성 확인 후 도감 화면을 `output/playwright/block-library-game-tiles.png`로 저장해 키캡·풍선·코르크·나뭇결을 육안 확인했다. 당첨3개 방식의 장시간 브라우저 검사는 이번에 반복하지 않았으며 당첨 순서·중복 방지 단위 검사를 실행했다.

lint·Svelte Check(오류·경고0개)·build·정적 페이지·UI 문서 연결·git diff --check를 통과했다. 음원 파일과 원통 물리 로직은 변경하지 않았다.
