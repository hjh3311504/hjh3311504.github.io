# 물풍선 비활성화와 대체 후보

- 상태: 적용
- 날짜: 2026-09-17
- 근거: 사용자가 물풍선 비활성화와 나무공방·물놀이의 대체 블록 후보를 요청했다.

## 결정

물풍선을 도감과 모든 맵에서 제외한다. 내부 ID `asmr`, 그림·물리·음원 정의는 보존한다. 활성 블록은7종이다. 맵 ID와 저장 설정을 유지한다. 물놀이 첫 구역에는 기존 코르크를 임시 배치해4구역·960개와 재질 중복 금지를 유지한다. 다른 맵 구성은 유지한다.

새 후보는 짧은 단일 타격음을 기준으로 조립블록·흡착컵·당구공을 제안한다. Pixabay 후보 페이지의 소재와 설명을 확인했으며 청음 만족도는 미확인이다. 후보 파일을 다운로드하거나 편집하지 않았다. 사용자 선택 뒤 제작과 최종 맵 구성을 진행한다.

- [Lego Piece Pressed](https://pixabay.com/sound-effects/film-special-effects-lego-piece-pressed-105360/): 조립블록을 누르는 소리 후보.
- [Plunger Pop](https://pixabay.com/sound-effects/film-special-effects-plunger-pop-102094/): 원래 소재는 흡착식 뚫어뻥이다. 흡착컵 블록의 짧은 분리음 후보로 제안한다.
- [Billiard Sound 04](https://pixabay.com/sound-effects/film-special-effects-billiard-sound-04-288422/): 당구공 타격음 후보.

## 검증

- 오디오 단위 테스트25개와 활성 맵·보존 재질 관련 테스트2개 통과.
- Chromium 관련 Playwright3개 통과: 물풍선 제외,7종 도감 이미지·맵별 음원 로딩,320px 화면.
- lint, Svelte Check, build와 정적 build 검증 통과.
- UI 문서 연결 검사와 `git diff --check` 통과.
- 경기 전체 시간과 후보 음원의 실제 청감은 이번 변경에서 검증하지 않았다. 기존 경기 시간 목표 실패를 해결했다고 판단하지 않는다.
