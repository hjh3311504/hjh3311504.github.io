# 번개와 바람 스킬 추가

## 결정

사용자가2026-09-22 설계와 구현을 승인했다. 전체 발동 확률과 구슬별8초 대기는 유지하고 파동·번개·바람을 같은 확률로 선택한다. 파동만 발동하던 이전 결정을 확장한다.

번개는 가까운 상대를 우선하며 반경240 안에 상대가 없으면 경기 전체의 유효한 상대를 무작위로 고른다. 피격 구슬은2초간 고정하고 흰 전기 고리를 표시한다. 바람은 시전 위치에1초간 남으며 다른 구슬을 위로 날린다. 자세한 범위와 제외 조건은 요구사항과 화면 문서를 따른다.

기존 고정 상태와 스킬 효과 목록을 확장한다. 기존 바람 장치와 구분하기 위해 새 스킬 ID는 gust로 둔다. 상태와 물리 계산은 경기 시간을 사용하고 대상 선택은 스킬 전용 난수를 사용한다.

스킬3종의 음향은 동시1개·최소200ms를 공유하고 종류를 순환한다. 도감은 경기와 같은 그림과 파일을 사용한다. 전체 음향 한도와 화면 범위 정책은 유지한다.
