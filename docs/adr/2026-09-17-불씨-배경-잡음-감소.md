# 불씨 배경 잡음 감소

- 날짜: 2026-09-17
- 상태: 적용
- 근거: 사용자가 불씨의 배경 노이즈 제거를 요청했다.

## 변경

사용자가 선택한 Fire Sounds 원음과 기존 파일을 보존한다. 적용 파일과 원음 출처는 [음원 출처](../marble-audio-sources.md)를 따른다.

## 검증

조용한 구간(각 파일0.4~0.55초)의 RMS는 v2보다28.65/23.28dB 감소했다. 전체 RMS는−39.94/−39.89dB다. 이는 지속적인 소리가 줄어든 결과이며 첫 타격의 최대 파형은0.338/0.691로 남는다. 첫 유효 소리는5.75/0.96ms에 시작한다. 시작·끝은0이며 두 변형의 전체 RMS 차이는0.05dB 미만이다.

오디오 단위 테스트29개를 통과했다. 원래 꼬리 구간 전체의 최소 RMS를 요구하던 검사는 배경 잡음 유지까지 요구하게 되므로, 뒤에 실제 타닥거림이 남는지와 조용한 틈의 잡음 감소를 각각 확인하도록 바꿨다. 기존 WAV 전체의 해시가 그대로임을 확인했다.

lint·Svelte Check·build·정적 build 검증과 관련 Playwright2개를 통과했다. 도감 미리듣기와 각 맵의 새 파일 로딩을 확인했다. 물리와 맵 배치가 같으므로90경기 측정은 반복하지 않았다.
