# 결승 확대와 슬로모션 시작 지연

- 날짜: 2026-09-18
- 상태: 적용
- 근거: 사용자가 결승 포커스와 슬로모션이 너무 일찍 시작된다고 요청했다.

확대와0.25배속은 당첨 후보가 회전문 중심100위에 도착하면 함께 시작한다. 현재 배치에서는 결승 시작점300아래이며, 기존 구역 진입 기준보다300늦게 전환한다. 그 전에는 사용자가 선택한 배속과 일반 카메라 추적을 유지한다.

첫 번째·여러 명·마지막·n번째 모두 같은 위치 기준을 적용한다. 후보 선택과 선두 즉시 갱신, 부드러운 카메라 이동, 연출 시작 뒤 상승 반동에도 유지하는 규칙과 당첨 확정 시 해제 규칙은 유지한다. 회전문과 판정선·특수 구간의 위치는 변경하지 않는다.
