# 무작위 총력전: 아수라장 조사 메모

기준일은 **2026-10-24(KST)**, 기준 패치는 **26.21**이다. 한국 공식 명칭은 **무작위 총력전: 아수라장**, 영어 명칭은 **ARAM: Mayhem**이다. 현재 테마는 **스타덤을 향한 여정(Journey to Stardom)**이다. 26.21은 10월 21일 적용됐다. 한국 클라이언트를 직접 실행한 검증은 하지 않았다. 증강 목록은 26.21 클라이언트 데이터와 대조했다(`sources.md`의 3차 절). [한국 고객지원](https://support.riotgames.com/ko-kr/league-of-legends/events/league-of-legends-aram-mayhem-game-mode), [26.21 패치 노트](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-21-notes/)

이 자료는 웹페이지 제작 전 조사 초안이다. 증강의 기본 효과와 챔피언별 조합의 강함은 서로 다른 수준의 근거다. `champions.json`의 B·low 조합을 검증된 최상위 조합처럼 소개하면 안 된다. 실제 선택 화면의 스킬 배정과 툴팁을 우선한다.

증강은 경기 중 고르는 특별한 강화 효과다. 스킬 가속은 스킬을 다시 쓰기까지 기다리는 시간을 줄이는 능력치다. 적중 시 효과는 공격이 맞을 때 붙는 추가 효과이며 데이터에서는 `on-hit` 태그로 묶었다. 처치 관여는 직접 적을 잡거나 처치를 돕는 일이다. 브루저는 공격과 방어를 함께 챙겨 가까이서 싸우는 역할을 뜻한다. 실버·골드·프리즘은 증강의 등급이며 자기 챔피언에게 더 잘 맞는 순서와 항상 같지는 않다.

## 일반 칼바람과 다른 점

- 5대5 단일 공격로에서 상대 넥서스를 파괴하는 기본 목표에 증강 선택이 더해진다. 아레나의 2인 팀·라운드제를 가져온 모드가 아니다. [공식 개발 글](https://www.leagueoflegends.com/en-gb/news/dev/dev-bringing-mayhem-to-aram/)
- 룬 설정은 사용하지 않는다. 탈진도 선택할 수 없다. 다른 소환사 주문은 해당 선택 화면에서 확인한다. [한국 고객지원](https://support.riotgames.com/ko-kr/league-of-legends/events/league-of-legends-aram-mayhem-game-mode)
- 26.21에는 **칼바람 나락만** 사용한다. 도살자의 다리와 코신의 다리는 잠시 빠졌다. 과거 공략의 코신 다리 이동 장치 활용법을 그대로 적용하면 안 된다. [26.21 공식 패치 노트](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-21-notes/)
- 시작 골드는 **1,400골드**다. 26.21 클라이언트 지도 데이터에서 아수라장(`KIWI`) 모드 상수 `ai_StartingGold`가 1400이다. 최신 커뮤니티 글의 1,400골드 언급과도 같다. [클라이언트 지도 데이터](https://raw.communitydragon.org/latest/game/data/maps/shipping/map12/map12.bin.json), [황홀한 나비 글](https://gall.dcinside.com/mgallery/board/view/?id=howlingabyss&no=671401)

## 26.21의 헤드라이너

헤드라이너는 경기의 공통 규칙을 바꾸는 요소다. 다음 요약은 기본 증강 지급과 별개다. [26.21 공식 패치 노트](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-21-notes/)

| 헤드라이너    | 초보자에게 필요한 요점                                    |
| ------------- | --------------------------------------------------------- |
| K/DA          | 카드 수집으로 추가 증강 기회를 얻는다.                    |
| HEARTSTEEL    | 선택한 증강에 멤버별 추가 효과가 붙는다.                  |
| True Damage   | 처치 관여와 포탑 파괴로 능력치 모루를 얻는다.             |
| 펜타킬        | 시작과 18레벨에 스킬 강화 기회가 있다.                    |
| 디스코        | 춤을 통해 모든 플레이어에게 골드가 지급된다.              |
| 귀염둥이 카페 | 체력 유물이 강화된다.                                     |
| 꿀벌          | 꿀단지를 모으고 꿀벌을 피하는 규칙이 더해진다.            |
| 커맨드 라인   | 매 증강 선택에서 하나를 상위 등급으로 새로고침할 수 있다. |

진척도는 밴드별 트랙과 오디션 임무로 바뀌었다. 월드 챔피언십 트랙의 일부 콘텐츠는 26.22 예정이므로 26.21 일반 증강과 섞지 않는다. [공식 이벤트 고객지원](https://support.riotgames.com/en-us/league-of-legends/events/aram-mayhem-journey-to-stardom)

## 처음 알아야 할 5가지

1. **첫 증강이 잘 쓰는 스킬을 강화하는지 읽는다.** Q·W·E·R 중 지정된 스킬과 평타 적중 조건을 먼저 확인한다. 이름이 같아도 다른 챔피언의 영상과 똑같이 작동한다고 생각하지 않는다.
2. **두 번째 증강은 첫 증강의 조건을 돕는 것으로 고른다.** 평타가 필요하면 공격 속도·사거리, 회복이 필요하면 회복·보호막 능력치처럼 연결한다. 아직 나오지 않은 특정 프리즘만 기다리면 현재 선택을 낭비하기 쉽다.
3. **아이템도 선택한 증강에 맞춘다.** 장갑 충격은 방어력, 황홀한 나비는 회복·보호막 강화가 출발점이다. 다만 적 주문 피해가 강한데 방어력만 사는 식으로 한쪽 능력치만 고집하지 않는다.
4. **레벨 조건을 채운 뒤에는 구매·선택 시점을 함께 본다.** 증강을 받으려고 혼자 죽으러 가지 않는다. 아군이 밀고 있는지, 부활 뒤 무엇을 살 수 있는지 확인한다.
5. **아군이 함께 싸울 위치를 지킨다.** 눈덩이를 맞았다면 아군 밀집 지역으로 그대로 돌아가 적의 광역 진입을 배달하지 않는다. 측면 이동이나 보호 스킬로 피해를 줄일 수 있는지 판단한다.

3번은 [장갑 충격 경험담](https://gall.dcinside.com/mgallery/board/view/?id=howlingabyss&no=670147)과 [황홀한 나비 설명](https://gall.dcinside.com/mgallery/board/view/?id=howlingabyss&no=671401)을 바탕으로 한 요약이다. 5번은 [일반 칼바람 위치 선정 글](https://gall.dcinside.com/mgallery/board/view/?id=howlingabyss&no=590024)의 취지를 상황별 조언으로 바꿨다. 나머지는 확인한 규칙을 초보자용으로 풀어 쓴 작성자 권고다.
