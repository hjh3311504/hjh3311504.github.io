# 출처와 검증 상태

> 2차 조사 결과와 변경된 평가 기준은 문서 마지막의 「2차 보강 조사」를 따른다. 아래 1차 수량은 비교용 기록이다.

모든 확인 날짜는 **2026-10-24(KST)**다. 기준 패치는 **26.21**이다. 최신 패치를 표시한 웹페이지에도 이전 데이터, 출시 전 데이터, 삭제 증강이 섞여 있었다. 따라서 이름·등급·기본 효과의 확인과 챔피언별 강함의 검증을 구분했다.

## 출처 충돌과 미확인 항목

1. **전체 목록:** aramgg는226개지만 공식 신규35개 중 튕기는 꿀벌·마나 없음, 상관없음·간지럼 괴물·구원이 빠져 있다. 공식4개를 추가해230개를 만들었다. 이 숫자를 공식 활성 증강 총수라고 부르지 않는다.
2. **활성 상태:** 광대 대학·위력 추구·격려하기는 이전 공개 데이터의 삭제 표시와 최신 목록이 충돌한다. 빙글빙글은 최신 목록에 있지만 Mobalytics는 비활성이라고 쓴다. 이4개는 `availability: uncertain`으로 남기고 추천에서 제외했다.
3. **이전 목록에만 있는 항목:** 으악, 내 동전!·2연속 방어·무리한 진입은 현재226개 목록과 일치하지 않는다. 2연속 방어와 보강은 효과가 비슷하지만 개명 여부를 확정하지 않았다. 추가 활성 항목으로 중복 등록하지 않았다.
4. **등급:** 한 발에 두 놈은 Mobalytics의 골드 대신 두 한국 목록의 프리즘을 채택했다. 연쇄 반응은 공식26.16에 따라 골드다. 공포는 과거 프리즘과 현재 두 사이트의 골드가 충돌해 현재 표시를 쓰되 low로 남겼다. 위력 추구도 삭제·실버/골드 표시가 충돌한다.
5. **공식 문구:** 총4차례와 시작+3·7·11·15레벨 설명이 함께 존재한다. 출시 개발 글과 대조해 기본4회로 정리했으며, 시작과3레벨을 별도 두 번으로 세지 않았다.
6. **새로고침:** 슬롯별 기본1회는 공식26.9의 아레나→아수라장 방식 비교로 판단했다. 현재 아수라장 화면의 직접 검증, 추가 새로고침 누적 한도, 등급 상승 확률은 없다.
7. **시작 골드·부활:** 4차에서 클라이언트 지도 데이터로 확인했다. 아래 「4차 남은 한계 처리」 참고.
8. **효과 업데이트:** 자연의 회복은 수풀 안에 계속 서 있으면 재생하는 방식으로 쓰지 않았다. 공식26.16의 진입 발동을 반영했다. 다단 중첩·원기 회복·아이템 강화 상세의 깨진 변수나 숫자는 추측하지 않았다.
9. **현재 맵:** 세 지도 안내와 코신 다리 이동 장치 운영은26.21에서 그대로 적용되지 않는다. 공식의 일시 제외를 우선했다.
10. **아레나·출시 전 혼입:** 공식 패치 노트의 아레나 절과 아수라장 절을 구분했다. Mobalytics에 보이는 RISE·One Hit Wonder·비활성 퀘스트 등을 현재 일반 증강으로 임의 추가하지 않았다.
11. **조합:** 하나의 증강이 잘 맞는다는 자료가 두 증강의 동시 조합을 증명하지는 않는다. 과거 글의 4개 이상 묶음을2~3개로 줄인 경우도 같은 성능을 보증하지 않는다. 루시안의 보석 건틀릿+취약이 모든 피해에 중복 치명타를 낸다는 주장은 채택하지 않았다.
12. **아이템:** 한국어 이름은 공개 한국어 데이터와 최신 글을 대조했다. 가격·완성 순서·챔피언별 최적화·특수 모드 구매 제한을 한국 클라이언트에서 전수 확인하지 못해 아이템 묶음은 모두 low다. 변환 아이템은 기본 구매 이름으로 적었다.
13. **사이트 갱신 차이:** 한국 고객지원은 최초 응답에서 오래된 내용이 나타났으나 재확인 시10월21일 갱신본을 확인했다. ARAMMayhem의 목록·공개 JSON·개별 챔피언 경로도 기준 패치가 서로 달랐다. 페이지 날짜만 보고 같은 패치라고 합치지 않았다.

## 접근 방법

검색과 공식 페이지를 먼저 확인했다. DCInside는 일반 브라우저에서 고른 글을 차례로 열었다. 공개 재사용 데이터는 제공된 JSON 파일 몇 개만 읽었다. 링크를 무한히 따라가는 크롤러, 로그인·결제·접근 차단 우회, 댓글 수집은 사용하지 않았다. 이미지·아이콘 파일을 결과물로 내려받지 않았다.

[Mobalytics robots.txt](https://mobalytics.gg/robots.txt)의 한국어 경로 제한에 따라 영어 공개 페이지를 사용했다. [ARAMMayhem robots.txt](https://arammayhem.com/robots.txt)와 [DCInside robots.txt](https://gall.dcinside.com/robots.txt)를 확인했다. aramgg의 robots·약관은 검색 도구로 읽히지 않아 해당 경로의 세부 조건은 미확인이다. 공개 화면을 제한적으로 열람했으며 비공개 API를 호출하지 않았다. 리그 위키와 OP.GG는 조사 도구에서 읽히지 않아 접근을 반복하거나 출처로 사용하지 않았다.

## 검증

Node로 세 JSON 파일 파싱, 증강 ID 중복, 챔피언별 조합 수, 조합별 증강 수, 모든 조합·good·avoid·커뮤니티 증강 ID 참조를 검사했다. 증강230개·챔피언32명·조합64개·사용 글17개에서 중복0개와 없는 참조0개를 확인했다. 각 아이템 이름은 읽은 한국어 아이템 목록과 일치한다. 이 검사는 데이터 구조 검사이며 실제 게임 동작 검증은 아니다.

### 공개 통계 필드와 채택 기준

2026-10-24에 [공개 데이터 설명](https://arammayhem.com/data/)과 [combos.json](https://arammayhem.com/data/v1/latest/combos.json)을 먼저 다시 읽었다. 최신 배포 자료는 **26.20·2026-10-20**이다.

### 실제 사용한 통계와 해석

[HexMayhem 증강 목록](https://hexmayhem.com/augments)에서 공개 개별 페이지를 열었다. 브라우저 화면의 갱신일은 **2026-10-24**, 패치 표시는 **16.21**, 전체 집계는 **9,377,913경기**였다. 연도식 표기인 조사 기준26.21과 같은 회차로 대응시켜 patch를 기록하고 원문 표기를 sourcePatch에 보존했다. 검색 도구에 남은16.18~16.20 캐시와 전날 수치를 섞지 않았다. 전체 집계 수를 개별 조합 표본으로 쓰지 않았다.

| 범위                               | 공개 필드                                                        | 저장 방식                                                                                |
| ---------------------------------- | ---------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| 챔피언+증강 하나                   | Champion, With augment WR, Baseline WR, Lift, Pick rate, Matches | scope=single-augment, augmentId, winRate, baselineWinRate, liftPp, pickRate, games       |
| 챔피언+증강 하나+완성 아이템 세 개 | Champion, Augments, Core build, Win rate, Lift, Matches          | scope=augment+item, augmentId, items, winRate, games. 공개되지 않은 pickRate는 생략한다. |
| 증강2~3개 동시 조합                | 이번에 확보하지 못함                                             | scope=combo인 행을 만들지 않는다.                                                        |

개별 페이지는 기준 승률 대비 차이가 큰 챔피언20명을 보여준다. 여기서 안 보인다는 이유로 해당 챔피언에게 증강이 나오지 않거나 약하다고 판단하지 않았다. 원시 경기·승리 수, 서버 구성, 집계 기간의 시작 시점, 픽률의 제시 기회별 분모는 공개 화면에서 확인하지 못했다. winRate와 pickRate의 단위는 백분율이며 liftPp는 승률 차이(%p)다. 현재 픽률을 증강을 제시받을 확률로 해석하지 않는다.

Matches는 주로62.7K처럼 반올림된다. 이 경우 games=62700과 함께 gamesApproximate=true, gamesDisplay=62.7K를 저장했다. 이는 원시 경기 수가 아니라 화면 표시값의 환산이다. **화면에서는 반드시 약 또는 gamesDisplay를 함께 표시해야 한다.** 별도의 표본 수를 역산하지 않았다. 최소200경기는 출처의 순위 제외 기준과 같은 조사 기준이며 인과관계나 승률 보장은 아니다.

### confidence·rating 재적용

- **high:** 같은 챔피언의 증강3개 중2개 이상이 최소200경기이고 각각 기준 승률 대비 +3%p 이상이며, DC 글 또는 독립 가이드가 같은 활용 방향을 설명해야 한다. 모든 증강은26.21 조사 목록에 있고 availability=uncertain은 제외한다. 애니·야스오·헤카림·마스터 이의 각1개 조합이 해당한다. 오래된 DC 글의 수치까지 검증됐다는 뜻은 아니다.
- **medium:** 충분한 개별 통계 하나가 있거나, 상세한 DC 공략과 챔피언 스킬 원리가 맞는다. 일반 증강 공략을 특정 챔피언에 연결한 경우는 통계가 좋아도 이번에는 medium까지만 부여했다.
- **low:** 제목 중심 사례, 일반 효과에서의 추론, 현재 제시 조건·상호작용을 확인하지 못한 나머지 후보다.
- **S:** 4차에서 기준을 바꿨다. 아래 「4차 남은 한계 처리」 참고. 2차 당시에는 0개였다. **A:** 기준 승률 대비 +3%p 이상인 핵심 증강 또는 상세 공략이 있는 강한 후보다. **B:** 약한 양의 통계 또는 효과상 어울리는 후보다. 신뢰도와 강함은 다른 기준이므로 medium/B도 가능하다.
- evidenceLevel은 통계와 실제 연결한 DC 글의 유무로 stats+community, stats, community, inferred를 구분한다. 일반 운영 글만 연결된 챔피언을 combo의 community로 세지 않았다. 신규 필드 communityPostIds는 community-posts.json의 id와 연결한다.

32명·64개 조합을 유지했다. 3증강 조합은31개, 2증강 조합은33개다. 역할 구성은 기존32명을 유지하고 근거가 강한 챔피언을 앞에 배치했다. confidence는 high **0→4**, medium **3→43**, low **61→17**이다. evidenceLevel은 stats+community **16**, stats **28**, community **7**, inferred **13**이다. 아이템 confidence는 medium **11**, low **21**이며 공식 최적 빌드로 표시하지 않는다. 약한 통계를 근거로 임의로 승률을 높이지 않았다.

### 공식 사실 보강과 남은 한계

[공식26.17 아수라장 절](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-17-notes/)에서 한 발에 두 놈의 프리즘 변경, 궁극의 히드라 퀘스트, 죽음의 무도 업그레이드 효과를 확인해3개 증강에 출처와 확인 범위를 추가했다. 궁극의 히드라 설명에는 퀘스트 대상과 티아맷 지급을 보탰다. [공식26.21](https://www.leagueoflegends.com/ko-kr/news/game-updates/league-of-legends-patch-26-21-notes/)에 맞춰 붐 앤 베이스는 공격 속도가 아닌 이동 속도 증가임을 명확히 했다. 공식 사실을 보강한 증강은 총4개다.

현재 시작 골드, 부활 시간표, 한국 클라이언트 전체 증강 목록 일치 여부는 여전히 공식 확인하지 못했다. 신속 대전의 부활 시간을 아수라장에 옮기지 않았고 mode.md는 바꾸지 않았다. 26.21 공식 삭제13개와 availability=uncertain 4개는 추천 조합에서 배제했다. 통계의 지역·숙련도·선택 순서에 따른 편향과 실제 한국 클라이언트 동작 검증은 남아 있다. 개별 증강의 높은 승률 두 개를 더하거나 곱해 조합 승률을 만들지 않는다.

### 2차 검증 결과

Node로 JSON3개를 파싱했다. 증강230개·챔피언32명·조합64개·사용 글18개에서 중복 ID와 없는 참조는0개다. 모든 조합·good·avoid·커뮤니티·통계의 증강 ID를 확인했고 communityPostIds와 챔피언의 communityEvidenceIds도 실제 글 id에 연결된다. high4개는 최소200경기·기준 승률 대비 +3%p 이상인 개별 증강2개 이상을 갖춘다. 공개 화면 기록과 최종 통계81행의 승률·픽률·표본 표시도 대조했다. 이 중 증강+아이템 통계는7행이며 개별 증강 통계는74행이다. 등급은 S0·A37·B27이다.

포맷 검사는 `npx prettier --check docs/research/aram-mayhem/`, 공백 검사는 `git diff --check`를 사용했다. 조사 폴더는 전달받을 때부터 untracked였으므로 Git 검사는 이 폴더의 내용 자체를 비교하지 않는다. 이를 보완해 실제5개 파일의 끝 공백·마지막 줄바꿈도 Node로 검사했다. 탭을 모두 거부하는 보조 검사는 저장소의 탭 들여쓰기 설정과 맞지 않아 제외하고 Prettier 기준을 따랐다. 커뮤니티 집계 설명 추가 후 발생한 Prettier 경고1개는 포맷을 다시 적용해 해결했다.

## 4차 남은 한계 처리

**Riot API 수집은 하지 않는다.** 2026-10-24에 개발용 키로 KR·EUW·NA 실버·골드 플레이어 수백 명을 확인했다. 아수라장 queue `2400` 경기는 한 건도 나오지 않았다. 일반 칼바람 queue `450` 기록은 많았다. Riot Match-V5 API는 아수라장 경기를 제공하지 않는 것으로 판단했다. 그래서 증강 2~3개를 동시에 가진 경기의 조합 승률은 구할 수 없다.

**시작 골드·사망 대기 시간:** [26.21 클라이언트 지도 데이터](https://raw.communitydragon.org/latest/game/data/maps/shipping/map12/map12.bin.json)에서 확인했다.

- `Maps/Shipping/Map12/Modes/KIWI`(아수라장)는 모드 상수 `{64237f19}`를 쓴다. 이 상수의 `ai_StartingGold`는 1400이다. 칼바람 맵의 다른 모드도 모두 1400이다. 커뮤니티 글의 1,400골드와 같다.
- `KIWI`의 `mDeathTimes`는 일반 칼바람 `ARAM`과 같은 표다. 레벨별 9·10·11·13·15·17·19·21·22·24·26·28·30·32·34·36·38·40초다. 1,440초(24분)부터 60초마다 2.5%씩 늘어난다.
- 이 값은 기본값이다. 증강·아이템·헤드라이너가 바꾸는 실제 시간은 반영하지 않았다.

**S등급 기준:** 조합 전체 통계를 구할 수 없어 기준을 바꿨다. 증강 3개 중 2개 이상이 HexMayhem 개별 통계에서 최소 200경기이고 기준 승률 대비 +3%p 이상이어야 한다. 그리고 DC 글이나 독립 가이드가 같은 활용법을 설명해야 한다. 이 조건은 confidence high와 같다. 해당하는 애니·야스오·헤카림·마스터 이의 조합 4개를 S로 올렸다. 화면에는 "개별 증강 통계 + 커뮤니티 근거"로 설명한다. 조합 전체 승률처럼 표현하지 않는다.

## 화면 표시 원칙

2026-10-24 사용자 결정. 가이드 화면에는 승률·픽률·판수 같은 통계 숫자를 보여주지 않는다. "이 챔피언은 이 증강을 가면 좋다"는 추천과 이유, 아이템, 운영만 보여준다. 이 폴더의 통계와 출처는 어떤 조합을 추천할지 고르는 내부 근거로만 쓴다.
