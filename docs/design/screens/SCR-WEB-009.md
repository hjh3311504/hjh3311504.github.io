# 칼바람 아수라장 증강 가이드

| 항목 | 내용 |
|---|---|
| 화면 ID | `SCR-WEB-009` |
| 화면 이름 | 칼바람 아수라장 증강 가이드 |
| 연결 REQ | `REQ-UI-001`, `REQ-ARAM-001`, `REQ-WEB-020`, `REQ-WEB-021`, `REQ-WEB-022`, `REQ-WEB-027` |

## 목적

리그 오브 레전드 칼바람 나락 아수라장 모드를 처음 하는 사람이 챔피언을 고르고 바로 어떤 증강을 노리고 무엇을 살지 알 수 있게 한다. 통계 표 대신 조합 카드와 아이템 순서로 보여 준다.

2026-10-24 사용자가 가이드 제작을 요청했다. 2026-10-25~26에 독립 HTML 시안을 v1부터 v86까지 사용자 피드백으로 고쳤다. 2026-10-26 사용자가 마지막 시안을 실제 페이지로 구현하라고 요청했다. 시안 파일은 저장소에 보관하지 않는다.

## 화면 구성

공용 SiteShell·ToolPageHeader·Button·EmptyState·DisclosureSection·ToolPageFooter·FormField와 `.ui-field`를 사용한다. 위에서 아래로 다음 순서다.

1. 공통 내비게이션과 `칼바람 아수라장` 현재 위치 표시
2. ToolPageHeader: 제목 `칼바람 아수라장 증강 가이드`, 설명 `챔피언을 고르면 어떤 증강을 노리고, 무엇을 사고, 어떻게 싸우면 되는지 알려드려요.`
3. 패치 표시: `26.21 패치 기준 · 챔피언 31명`
4. 챔피언 고르기
   - 이름 검색 입력: FormField의 보이는 label `챔피언 이름 검색`과 예시 placeholder `예: 티모`
   - 역할 버튼: 전체와 가이드에 있는 역할. 고른 역할은 soft 버튼과 `aria-pressed`
   - 챔피언 아이콘 목록: 가나다순, 76px 이상 칸의 자동 줄바꿈 격자. 고른 챔피언은 파란 테두리
   - 검색 결과가 없으면 EmptyState `찾는 챔피언이 아직 가이드에 없어요.`
5. 챔피언 설명: 위쪽 구분선 아래에 둔다.
   - 머리: 64px 챔피언 아이콘, 이름(h2), 역할·난이도 태그
   - `아이템 추천`(h3): 빌드 카드와 신발 카드
   - `증강 추천`(h3)과 오른쪽 범례(필수 증강 실선·선택 증강 점선)
   - 조합 카드 목록
   - 두 칸 상자: `이것도 나오면 좋아요`(초록), `이 챔피언에게는 별로예요`(빨강)
6. 사용 안내: `가이드 보는 법`(기본 펼침, 3단계), `추천 기준과 자료`(기본 접힘)
7. Riot Games 고지: 영어 Legal Jibber Jabber 문장과 한국어 안내, 12px 흐린 글자
8. ToolPageFooter

### 빌드 카드

- 위쪽 버튼 줄: `기본 빌드 · 스타일` 버튼과 증강 빌드 버튼(증강 아이콘과 이름). 고른 버튼은 파란 테두리와 연한 파란 바탕
- 코어 아이템: 아이콘과 이름 타일을 `→`로 잇는다.
- 스킬 마스터 순서: 빌드에 순서가 있을 때만 코어 아래에 스킬 타일을 `→`로 잇는다.
- 추천 아이템: `3코어 이후 추천 아이템` 제목 아래에 `~할 때` 문장과 아이템 타일
- 증강 빌드의 바뀐 아이템은 파란 테두리와 `추가`·`변경` 표시를 붙인다.
- 운영 방법은 증강 빌드에 별도 설명이 있을 때만 단계 목록으로 보여 준다. 기본 빌드에는 두지 않는다.
- 신발 카드는 아이콘·이름·짧은 상황을 타일로 나열한다.

### 조합 카드

- `details` 카드. 제목 줄에 `강력 추천`(주황 바탕) 또는 `추천`(초록 글자) 표시와 조합 이름, 오른쪽 접기 화살표
- 강력 추천 카드는 연한 주황 바탕에서 흰 바탕으로 바뀌는 배경
- 증강 타일: 등급색(실버·골드·프리즘) 테두리 아이콘과 이름. 필수 증강은 주황 실선, 선택 증강은 점선
- 설명 문장과 단계 목록: 스킬(아이콘·키·이름), 증강, 아이템, 스킬 가속, 모루를 문장 안 타일로 보여 준다. `[E]`처럼 쓴 스킬은 키만 보여 준다.
- 힌트 한 줄은 14px 흐린 글자
- 출처: `디시 칼바람 갤러리(YYYY.MM.DD)` 또는 `유튜브 · 영상 제목`. 오른쪽 정렬, 12px, 새 탭
- 증강 효과 상자는 카드 맨 아래 연한 파란 바탕

### 반응형

- 1201px 이상은 공통 사이드바 오른쪽에 최대 1040px 본문을 둔다.
- 640px 이하에서는 빌드 버튼을 한 줄에 하나씩 두고 나오면 좋은 증강·피할 증강 상자를 한 열로 둔다. 카드 안쪽 여백은 16px이다.
- 챔피언 목록은 화면 폭에 맞춰 칸 수가 바뀐다. 360px에서도 가로로 넘치지 않는다.

## 동작과 예외

- 처음에는 정적 HTML의 첫 챔피언을 보여 준다. JavaScript가 켜지면 주소의 `#챔피언id`를 읽어 바꾼다. 모르는 값이면 첫 챔피언이다.
- 챔피언을 고르면 주소 끝을 `#챔피언id`로 바꾼다. 방문 기록은 늘리지 않는다. 설명이 화면 아래쪽에 있으면 설명 위치로 내려 준다. 움직임 줄이기 설정이면 바로 이동한다.
- 챔피언을 바꾸면 빌드 버튼은 첫 기본 빌드로, 열린 증강 효과는 닫힌 상태로 돌아간다. 접은 조합 카드는 챔피언별로 기억한다.
- 검색어는 앞뒤 공백을 무시하고 이름에 포함되는지로 거른다. 역할과 검색어를 함께 적용한다.
- 저장하는 데이터는 없다.
- JavaScript가 꺼져 있으면 첫 챔피언 설명과 안내를 읽을 수 있고 다른 챔피언을 보려면 JavaScript를 켜라는 문구를 보여 준다.

## 사용 안내

- `가이드 보는 법`: 챔피언 고르기, 아이템 순서 보기, 증강 고르기 3단계
- `추천 기준과 자료`: 패치·챔피언 수, 통계와 디시·유튜브 확인 방법, 강력 추천과 추천의 뜻, 여러 증강 동시 승률을 보장하지 않는다는 한계

## 접근성

- 챔피언·역할·빌드 버튼은 공통 Button에 `aria-pressed`를 붙인다. 버튼 묶음에는 `role="group"`과 이름을 붙인다.
- 증강 버튼은 `aria-expanded`로 효과 상자 열림을 알린다.
- 아이콘 이미지는 옆 글자와 같은 뜻이라 빈 대체 텍스트를 쓴다. 스킬 타일은 `title`로 키와 스킬 종류를 알려 준다.
- 조합 카드는 `details`·`summary`라 키보드로 열고 닫는다. summary 초점에 테두리를 보여 준다.
- 제목 구조는 h1 페이지 제목, h2 챔피언 이름과 안내 제목, h3 아이템 추천·증강 추천이다.
