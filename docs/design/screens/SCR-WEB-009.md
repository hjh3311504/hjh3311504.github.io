# 칼바람 아수라장 증강 가이드

| 항목 | 내용 |
|---|---|
| 화면 ID | `SCR-WEB-009` |
| 화면 이름 | 칼바람 아수라장 증강 가이드 |
| 연결 REQ | `REQ-UI-001`, `REQ-ARAM-001`, `REQ-WEB-020`, `REQ-WEB-021`, `REQ-WEB-022`, `REQ-WEB-027` |

## 목적

리그 오브 레전드 칼바람 나락 아수라장 모드를 처음 하는 사람이 챔피언을 고르고 바로 어떤 증강을 노리고 무엇을 살지 알 수 있게 한다. 통계 표 대신 조합 카드와 아이템 순서로 보여 준다.

2026-10-24 사용자가 가이드 제작을 요청했다. 2026-10-25~26에 독립 HTML 시안을 v1부터 v86까지 사용자 피드백으로 고쳤다. 2026-10-26 사용자가 마지막 시안을 실제 페이지로 구현하라고 요청했다. 2026-10-27 사용자가 검색 노출을 위해 허브와 챔피언 공략 페이지로 나누고, 챔피언 페이지의 선택 영역을 검색창(C안)으로 줄이도록 정했다. 시안 파일은 저장소에 보관하지 않는다.

## 화면 구성

공용 SiteShell·ToolPageHeader·Button·Dialog·EmptyState·DisclosureSection·ToolPageFooter·FormField와 `.ui-field`를 사용한다. 두 화면이 있다.

### 허브 `/aram-mayhem`

1. 공통 내비게이션과 `칼바람 아수라장` 현재 위치 표시
2. ToolPageHeader: 제목 `증바람 공략`, 설명 1줄 `통계 티어 대신 재밌다고 알려진 칼바람 아수라장 챔피언별 증강·템트리를 모았어요.`
3. 패치 표시: `26.21 패치 기준`
4. 챔피언 고르기
   - 검색 입력: FormField의 보이는 label `챔피언 이름 검색`, placeholder `예: 마이`. 도움말은 두지 않는다. 이름·별명·초성으로 찾는다.
   - 역할 버튼: 전체와 가이드에 있는 역할. 고른 역할은 soft 버튼과 `aria-pressed`
   - 챔피언 타일 목록: 가나다순, 76px 이상 칸의 자동 줄바꿈 격자. 타일은 챔피언 공략 페이지 링크다.
   - 검색 결과가 없으면 EmptyState `찾는 챔피언이 아직 가이드에 없어요.`
5. 사용 안내: `가이드 보는 법`(기본 펼침, 3단계), `추천 기준과 자료`(기본 접힘)
6. Riot Games 고지: 영어 Legal Jibber Jabber 문장과 한국어 안내, 12px 흐린 글자
7. ToolPageFooter

### 챔피언 공략 `/aram-mayhem/챔피언id`

1. 공통 내비게이션과 `칼바람 아수라장` 현재 위치 표시
2. ToolPageHeader: 제목 `증바람 {챔피언} 공략`. 설명 문장은 두지 않는다. 템트리 요약은 검색 설명(meta description)에만 넣는다.
3. 패치 표시: `26.21 패치 기준`
4. 챔피언 검색: 화면 오른쪽 아래(모바일 16px, PC 24px 여백)에 떠 있는 primary 버튼 `챔피언 검색`. 높이 44px의 둥근 버튼이며 마우스를 쓰는 기기에서는 `/` 키 표시를 붙인다. JavaScript가 연결된 뒤에만 보인다.
   - 버튼이나 `/` 키를 누르면 위쪽에 고정한 Dialog `챔피언 검색`(`placement="top"`)을 열고 입력창에 바로 초점을 둔다.
   - 입력창은 FormField의 `labelHidden`으로 label `다른 챔피언 찾기`를 화면에서 숨기고 같은 문구를 placeholder로 쓴다.
   - 입력할 때만 입력창 아래에 자동완성 목록(최대 8명, 28px 아이콘·이름·별명)을 보여 준다. 맞는 챔피언이 없으면 `찾는 챔피언이 아직 가이드에 없어요.`
   - 페이지 끝에 48px 빈 공간을 두어 떠 있는 버튼이 마지막 고지 글자를 가리지 않게 한다.
5. 챔피언 설명: 위쪽 구분선 없이 패치 표시 아래에 둔다.
   - 머리: 64px 챔피언 아이콘, 이름(h2), 역할·난이도 태그
   - `아이템 추천`(h3): 빌드 카드와 신발 카드
   - `증강 추천`(h3)과 오른쪽 범례(필수 증강 실선·선택 증강 점선)
   - 조합 카드 목록
   - 두 칸 상자: `이것도 나오면 좋아요`(초록), `이 챔피언에게는 별로예요`(빨강)
6. Riot Games 고지와 ToolPageFooter는 허브와 같다.

공략 질문과 사용 안내는 챔피언 페이지에 두지 않는다. 다른 챔피언으로 가는 링크 목록도 두지 않는다.

### 빌드 카드

- 위쪽 버튼 줄: `기본 빌드 · 스타일` 버튼과 증강 빌드 버튼(증강 아이콘과 이름). 고른 버튼은 파란 테두리와 연한 파란 바탕
- 코어 아이템: 아이콘과 이름 타일을 `→`로 잇는다.
- 스킬 마스터 순서: 빌드에 순서가 있을 때만 코어 아래에 스킬 타일을 `→`로 잇는다.
- 추천 아이템: `3코어 이후 추천 아이템` 제목 아래에 `~할 때` 문장과 아이템 타일
- 증강 빌드의 바뀐 아이템은 파란 테두리와 `추가`·`변경` 표시를 붙인다.
- 운영 방법은 증강 빌드에 별도 설명이 있을 때만 단계 목록으로 보여 준다. 기본 빌드에는 두지 않는다.
- 신발 카드는 아이콘·이름·짧은 상황을 타일로 나열한다.

### 조합 카드

- `details` 카드. 제목 줄에 `강력 추천`(주황 바탕) 또는 `추천`(초록 글자) 표시와 조합 이름, 오른쪽 접기 화살표
- 강력 추천 카드는 연한 주황 바탕에서 흰 바탕으로 바뀌는 배경
- 증강 타일: 등급색(실버·골드·프리즘) 테두리 아이콘과 이름. 필수 증강은 주황 실선, 선택 증강은 점선
- 설명 문장과 단계 목록: 스킬(아이콘·키·이름), 증강, 아이템, 스킬 가속, 모루를 문장 안 타일로 보여 준다. `[E]`처럼 쓴 스킬은 키만 보여 준다. 타일 세로 중심은 옆 글자의 중심에 맞춘다.
- 힌트 한 줄은 14px 흐린 글자
- 출처: `디시 칼바람 갤러리(YYYY.MM.DD)` 또는 `유튜브 · 영상 제목`. 오른쪽 정렬, 12px, 새 탭
- 증강 효과 상자는 카드 맨 아래 연한 파란 바탕

### 반응형

- 1201px 이상은 공통 사이드바 오른쪽에 최대 1040px 본문을 둔다.
- 640px 이하에서는 빌드 버튼을 한 줄에 하나씩 두고 나오면 좋은 증강·피할 증강 상자를 한 열로 둔다. 카드 안쪽 여백은 16px이다.
- 허브의 챔피언 목록은 화면 폭에 맞춰 칸 수가 바뀐다. 검색창 자동완성 목록은 검색창과 같은 너비다. 360px에서도 가로로 넘치지 않는다.

## 동작과 예외

- 허브의 챔피언 타일을 누르면 챔피언 공략 페이지로 이동한다. 예전 공유 주소 `/aram-mayhem#챔피언id`는 방문 기록을 늘리지 않고 챔피언 공략 페이지로 옮긴다. 모르는 값이면 허브에 머문다.
- 챔피언 검색 창의 목록은 입력할 때만 보인다. 방향키로 고르고 Enter나 마우스로 이동한다. Escape나 닫기 버튼으로 창을 닫는다. 어떻게 닫든 검색어를 비운다.
- `/` 키는 글자를 쓰는 칸(입력칸·여러 줄 입력칸·편집 영역)에 초점이 있거나, 한글 조합 중이거나, 다른 창이나 메뉴 서랍이 열려 있으면 동작하지 않는다. 체크박스·버튼에 초점이 있을 때는 동작한다.
- 검색은 띄어쓰기를 무시하고 이름·별명에 포함되는지 본다. 초성만 입력하면 초성으로 찾는다. 이름·별명이 검색어로 시작하는 챔피언을 먼저 보여 준다. 허브는 역할과 검색어를 함께 적용한다.
- 챔피언을 바꾸면 빌드 버튼은 첫 기본 빌드로, 열린 증강 효과는 닫힌 상태로 돌아간다. 접은 조합 카드는 챔피언별로 기억한다.
- 없는 챔피언 주소는 404다.
- 저장하는 데이터는 없다.
- JavaScript가 꺼져 있어도 허브의 챔피언 링크와 챔피언 공략 본문을 읽을 수 있다.

## 사용 안내

- `가이드 보는 법`: 챔피언 고르기, 아이템 순서 보기, 증강 고르기 3단계
- 사용 안내는 허브에만 둔다.
- `가이드 보는 법`의 챔피언 고르기는 챔피언 공략 페이지와 검색창의 별명 검색을 안내한다.
- `추천 기준과 자료`: 패치·챔피언 수, 승률 통계로 매긴 티어표가 아니라 재밌다고 알려진 도파민 빌드라는 기준, 출처 링크의 뜻, 강력 추천과 추천의 뜻, 이기는 빌드를 보장하지 않는다는 한계. 디시인사이드라는 이름은 적지 않는다.

## 접근성

- 역할·빌드 버튼은 공통 Button에 `aria-pressed`를 붙인다. 버튼 묶음에는 `role="group"`과 이름을 붙인다. 허브 챔피언 타일은 링크다.
- 떠 있는 버튼은 `aria-haspopup="dialog"`를 붙인다. 챔피언 검색 입력창은 `role="combobox"`, `aria-expanded`, `aria-controls`, `aria-activedescendant`를 쓴다. 목록은 `role="listbox"`, 항목은 `role="option"`과 `aria-selected`다.
- 증강 버튼은 `aria-expanded`로 효과 상자 열림을 알린다.
- 아이콘 이미지는 옆 글자와 같은 뜻이라 빈 대체 텍스트를 쓴다. 스킬 타일은 `title`로 키와 스킬 종류를 알려 준다.
- 조합 카드는 `details`·`summary`라 키보드로 열고 닫는다. summary 초점에 테두리를 보여 준다.
- 제목 구조는 h1 페이지 제목, h2 챔피언 이름과 안내 제목, h3 아이템 추천·증강 추천이다. 챔피언 페이지에는 안내 제목이 없다.
