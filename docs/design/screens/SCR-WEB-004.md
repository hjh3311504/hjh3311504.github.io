## 승인과 배치

2026-09-17 사용자가 특수 구간·결승 연출·커스텀 맵과 대규모 참가 지원 계획의 구현을 요청했다. 후속 선택으로 물풍선 장치는 제거하고 기존 소리를 젤리 연못에 옮겼다. 버터는 왁뿌볼 소리, 당첨은 승인된 팡파레를 사용한다. 별도 시안 승인을 받은 것으로 기록하지 않는다.

공용 SiteShell·ToolPageHeader·ToolPageFooter·Button·Surface·Dialog를 사용한다. 왼쪽은 설정, 오른쪽은 경기장·순위이며 모바일에서는 세로로 배치한다. 중앙 시작 패널은 설정 편집을 막지 않는다. 아래에는 일반11종 도감과 특수 장치 안내·미리듣기를 둔다. 본문16px·보조14px, 구슬 이름표14px·추적 후보18px를 기준으로 표시한다.

## 동작

- 기본 명단30개, 최소2개다. 고정 참가 상한 없이 `토끼*10`을 지원한다. 같은 이름도 고유 번호로 별도 당첨된다.
- 명단·맵·당첨 방식·인원/순번·볼륨·음소거를 변경마다200ms로 묶어 저장하고 페이지 종료 때 남은 변경을 저장한다. 결과와 배속은 저장하지 않는다.
- 첫 번째·마지막·여러 명·n번째 당첨을 지원한다. 실제 판정선 교차 시각으로 순서를 정한다.
- 기본3개 맵의 이름과 일반층 순서는 유지한다. 활성11종에서 중복을 허용해4구역을 고른 내 맵을10개까지 저장·수정·삭제·재정렬한다.
- 일반4층·960개와3초 복구, 교차 배치·둥근 모서리·재질별 물리는 유지한다.
- 층 사이 구간3곳은 기존960높이를 보존하고 핀 자리260을 덧붙여1220으로 늘린다. 순서는 `재질1 → 분산 통로·핀 → 재질2 → 버터·핀 → 재질3 → 젤리 연못·핀 → 재질4 → 핀 → 결승`이다. 기존 입구 유도벽과 특수 장치를 유지하고 각 뒤쪽에 원형 핀13개를 엇갈려 배치한다. 마지막 재질과 깔때기 사이에도320높이의 공간과 핀13개를 더해 총52개다.
- 버터의 파괴 횟수는 `max(1, round(5 × sqrt(구슬 수 / 30)))`이다.2/30/60/1000개 경기에서는 각각1/5/7/29회다. 독립 충돌마다 납작해지고3초 뒤 같은 내구도로 복구하며 겹침이 없어질 때까지 기다린다. 젤리 폭은540이며 한쪽에 폭244의 우회로를 둔다. 우회로의 좌우는 경기 난수로 정한다. 연못에 들어간 구슬만 저항과 진입음을 받는다.
- 결승은 직선 깔때기·청록색 회전 판1개·중앙 폭40통로다. 결승 전체 높이는740이다. 양쪽 벽은 결승 시작점400아래에서 같은 높이로 통로에 연결되고, 판정선은710아래에 둔다. 통로는 이전보다240길어진다. 회전축은 통로 중심보다70왼쪽의 입구 높이에 둔다. 판180×16의 끝이 출구를 열고 막으며, 구슬을 위로 걷어 올리는 반시계 방향으로4.4초마다 회전한다. 흰색 유도벽과 통로의 마찰은0으로 두어 벽을 따라 내려오도록 한다. 미니맵도 실제 벽과 판의 모양을 사용한다. 원통과 내부 진입 조건은 없다.
- 당첨 후보가 결승에 들어오면0.3배속과 최대2.4배 확대를 적용한다. 후보 변경은0.3초 유지 후 반영하며 카메라는 후보의 좌우·상하 위치를 부드럽게 따라간다. 당첨 수가 채워지면1배속으로 돌아간다. 첫 번째·여러 명은 선두, 마지막은 꼴등, n번째는 현재 n등 후보를 따른다.
- 우측 하단에 확정 당첨 목록을 표시하고 당첨마다 팡파레·입자를 실행한다. 움직임 줄이기에서는 확대와 입자를 줄인다.
- 경기장 중앙의 시작 패널과 기존 시작 버튼을 제공한다. 경기 설정 잠금 이유와 종료 후 편집 버튼을 항상 표시한다. 종료 확인을 취소하면 같은 경기를 이어간다. 준비 중 취소와 일시정지 중 안내도 제공한다.
- 좌측 미니맵의 흰 사각형은 현재 실제 화면 범위다. 모바일·전체화면·늘어난 출발 공간에도 같은 배치를 사용한다.
- 클릭·탭·Enter·Space와 배속 버튼은1/2배속을 전환한다. 결승 연출 중에는0.3배속 잠금을 설명한다. 모든 배속에서 음원·속도·음정은 같다.
- 버터는 기존 왁뿌볼 Crack-A, 젤리 연못은 기존 물풍선 음원을 쓴다. 장치·결승은 고무 범퍼, 당첨은 승인한 Tada Fanfare A다. 일반층 음향 범위는 최대800이며 다른 층의 재생음은 짧게 감쇠해 정리한다.
- 음원과 오디오 실행을 확인한 뒤 시작·재개한다. 로딩 실패 시 재시도·무음 시작을 제공한다. 음소거·볼륨은 모든 효과음에 적용한다.
- Web Worker가 계산을 담당한다. 주변 구슬만 검사하며 순서를 고정한다. 준비는 나눠 실행해 취소할 수 있다. 화면 밖 구슬 그림과 화면 밖 순위 행은 생략하지만 물리·전체 결과 복사는 유지한다.

## 예외와 검증

이름은20자·양의 정수 배수만 허용하며 안전한 정수 범위를 검사한다. 잘못된 입력은 해당 이름을 알려주고 시작을 막는다. 저장·음원 로딩·전체화면·복사 실패를 한국어로 알린다. 탭을 숨기면 일시정지한다. 화면을 떠나면 Worker·예약·오디오를 정리한다.

단위 테스트에서 버터 접촉·복구, 연못 진입·탈출, 충돌·교차 순서,0.3/1/2배속 Worker 동일성을 검사한다. 브라우저에서는 저장·중복 맵·취소·잠금 안내·모바일·전체화면·4개 당첨 방식·미니맵·대규모 버튼 응답을 검사한다. 분포만으로 사이드 우승 편향이 해결됐다고 판단하지 않는다. 측정과 남은 한계는 새 ADR에 기록한다.
