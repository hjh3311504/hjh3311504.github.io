## 승인과 배치

2026-09-17 사용자가 특수 구간·결승 연출·커스텀 맵과 대규모 참가 지원 계획의 구현을 요청했다. 후속 선택으로 물풍선 장치는 제거하고 기존 소리를 젤리 연못에 옮겼다. 크랙 왁스는 선택한 균열음2개, 당첨은 승인된 팡파레를 사용한다. 별도 시안 승인을 받은 것으로 기록하지 않는다.

공용 SiteShell·ToolPageHeader·ToolPageFooter·Button·Surface·Dialog를 사용한다. 왼쪽은 설정, 오른쪽은 경기장·순위이며 모바일에서는 세로로 배치한다. 중앙 시작 패널은 설정 편집을 막지 않는다. 아래 블록 도감은 공용 Section의 흰 배경 카드 안에 둔다. 기본 블록12종과 특수 블록3종을 각각 제목과 구분선으로 나눈다. 특수는 얼음 경사판·크랙 왁스·젤리 연못 순서다. 기본·특수 영역은 같은 열 너비를 사용하며 특수3종은3칸만 차지하고 남는 칸은 비워 둔다. 화면이 좁으면 열 수를 줄인다. 모든 카드에 같은 크기의 실제 경기 그림·이름·한 줄 설명·미리듣기 버튼을 사용한다. 블록 카드 배경은 선택되지 않은 맵 옵션과 같은 색을 사용한다. 선택한 맵의 기본 블록 이름 오른쪽에 파란 포함 라벨을 붙인다. 도감 상단에서 포함은 선택한 맵의 블록이라는 뜻임을 설명한다. 소리 설명과 중복 문단은 제거하며 크랙 왁스의 현재 충돌 횟수는 한 줄 설명에 포함한다. 좁은 화면에서 설명이 넘치면 말줄임하며 전체 문장은 title로 확인할 수 있다. 본문16px·보조14px, 구슬 이름표14px·추적 후보18px를 기준으로 표시한다.

## 동작

- 기본 명단30개, 최소2개다. 고정 참가 상한 없이 `토끼*10`을 지원한다. 같은 이름도 고유 번호로 별도 당첨된다.
- 명단·맵·당첨 방식·인원/순번·볼륨·음소거를 변경마다200ms로 묶어 저장하고 페이지 종료 때 남은 변경을 저장한다. 결과와 배속은 저장하지 않는다.
- 첫번째·마지막·여러명·n번째 당첨을 지원한다. 여러명은4~6처럼 도착 순위 범위를 입력하며 양 끝을 포함해4·5·6번째를 당첨시킨다. 실제 판정선 교차 시각으로 순서를 정한다. 마지막 방식은 미도착 구슬이1개만 남는 즉시 그 구슬을 당첨자로 확정하고 팡파레·축하 효과·당첨 목록을 한 번 갱신한다. 마지막 구슬의 골인을 기다리지 않으며 당첨 확정 시 슬로모션을 해제하고 선택한 배속으로 돌아간다. 남은 구슬의 물리 계산과 실제 도착 순위 기록은 계속하며 골인 때 다시 축하하지 않는다. 같은 계산 단계에서 전원 도착했다면 실제 교차 순서의 마지막 구슬을 당첨자로 정한다.
- 기본3개 맵을 제공한다. 도각도각 키보드는 도각1 → 도각2 → 도각3 → 도각4로 구성한다. 별도 도각 키보드 모음은 이 맵으로 통합하며 저장된 thock-collection 선택도 keyboard로 연결한다. 기존 도각 키보드의 표시 이름은 도각 키보드1이다. 활성12종에서 중복을 허용해4구역을 고른 내 맵을10개까지 저장·수정·삭제·재정렬한다.
- 일반4층·20열을 유지하고 구역당 줄 수는 `max(4, round(12 × √(전체 구슬 수 / 30)))`로 정한다.2/10/30/60개 경기의 전체 일반 블록은320/560/960/1360개다. 준비 화면도 전체 인원으로 높이를 계산하며200ms 입력 묶음을 사용한다.3초 복구·교차 배치·둥근 모서리·재질별 물리는 유지한다.
- 층 사이 구간3곳은 높이1220을 유지하며 유도 바 → 분산 핀 → 특수 블록 순서로 배치한다. 양쪽 구슬을 안쪽으로 모으는 바 아래에 원형 핀13개를 엇갈려 배치한다. 핀3줄의 세로 간격을50으로 줄여 바와 첫 핀 사이에 약130의 공간을 확보한다. 크랙 왁스·연못 위치는 유지한다. 바와 핀, 핀과 크랙 왁스·연못 사이에는 구슬 지름보다 넓은 틈을 둔다. 마지막 재질과 깔때기 사이에도320높이의 공간과 핀13개를 더해 총52개다.
- 첫 특수 구간에는 분산 핀 아래에160×28 크기의 얼음 경사판5개를 둔다. 모든 판은 좌우30도 대각선이며 닿은 구슬을 경기 시간1초 동안 표면에 고정한다. 해제 뒤에는 충돌을 유지한 채 중력으로 미끄러져 떨어지고, 같은 판에서 완전히 떨어지기 전에는 다시 얼지 않는다. 얼음판은 깨지지 않는다. 얼어붙은 구슬은 반투명 얼음 테두리로 표시한다.
- 크랙 왁스는 위치·크기를 유지한 채 좌측과 중앙은 오른쪽 아래30도, 우측은 왼쪽 아래30도로 기울인다. 그림·충돌·압축·복구 겹침 검사에 같은 각도를 사용한다. 파괴 횟수는 `max(1, round(5 × sqrt(구슬 수 / 30)))`이다.2/30/60/1000개 경기에서는 각각1/5/7/29회다. 독립 충돌마다 파괴 전부터 소리를 내며 납작해지고3초 뒤 같은 내구도로 복구하며 겹침이 없어질 때까지 기다린다. 젤리 연못은 같은 높이에 좌·중앙·우3개로 나눈다. 각 연못은 폭152·깊이140이며, 사이에 폭120의 우회로2개를 둔다. 연못에 들어간 구슬만 저항과 진입음을 받는다.
- 결승은 직선 깔때기·청록색 회전 판1개·중앙 폭40통로다. 결승 전체 높이는740이다. 양쪽 벽은 결승 시작점400아래에서 같은 높이로 통로에 연결되고, 판정선은710아래에 둔다. 통로는 이전보다240길어진다. 회전축은 통로 중심보다70왼쪽의 입구 높이에 둔다. 판180×16의 끝이 출구를 열고 막으며, 구슬을 위로 걷어 올리는 반시계 방향으로4.4초마다 회전한다. 흰색 유도벽과 통로의 마찰은0으로 두어 벽을 따라 내려오도록 한다. 미니맵도 실제 벽과 판의 모양을 사용한다. 원통과 내부 진입 조건은 없다.
- 당첨 후보가 회전문 중심100위(결승 시작점300아래)에 도착하면0.25배속과 최대2.4배 확대를 적용한다. 후보 변경은 대기 없이 반영하며 같은 화면 갱신에서 강조 표식·순위 목록을 새 후보로 즉시 옮긴다. 카메라는 이동을 바로 시작하며 실제 시간 약0.3초에 새 목표까지의 거리95%를 부드럽게 따라간다. 당첨 수가 채워지면 연출 전에 선택한1배속 또는2배속으로 돌아간다. 새 경기는1배속으로 시작한다. 첫번째는 선두, 여러명은 범위 안의 다음 당첨 순위 후보, 마지막은 꼴등, n번째는 현재 n등 후보를 따른다.
- 우측 하단에 확정 당첨 목록을 표시하고 당첨마다 팡파레·입자를 실행한다. 움직임 줄이기에서는 확대와 입자를 줄인다.
- 경기장 중앙의 시작 패널과 기존 시작 버튼을 제공한다. 경기 설정 잠금 이유와 종료 후 편집 버튼을 항상 표시한다. 일시정지와 종료 확인은 하나의 패널로 제공한다. 계속하기 또는 종료하고 설정 변경을 선택하며, 종료하면 경기를 이어갈 수 없고 참가자와 설정은 유지된다는 안내를 함께 표시한다. 별도 종료 확인창은 열지 않는다. 시작·일시정지·결과·오류 창은 공용 OverlayCard를 사용한다. 짙은 남색 배경·흰색 글자·가운데 정렬과 중앙 버튼을 통일하고 좁은 화면에서는 버튼을 줄바꿈한다. StageOverlay는 경기장 안의 배치만 담당하며 미니맵 조작을 막지 않는다. 시작·재개 시 준비 상태는 게임 상단에 표시하며 별도 로딩 창은 띄우지 않는다. 준비 취소는 설정 영역에서 제공하며 게임 하단에는 준비 취소 버튼을 띄우지 않는다. 시작·계속하기 버튼은 준비 중에도 같은 요소·문구·폭을 유지하고 중복 클릭만 막는다. 게임 하단에는 일시정지·계속하기만 표시하고 종료는 일시정지 창에서 선택한다.
- 좌측 미니맵의 흰 사각형은 현재 실제 화면 범위다. 모바일·전체화면·늘어난 출발 공간에도 같은 배치를 사용한다.
- 클릭·탭·Enter·Space와 배속 버튼은1/2배속을 전환한다. 결승 연출 중에는 배속 버튼에0.25배속을 표시하고 전환을 잠근다. 별도의 슬로모션 알림은 표시하지 않는다. 모든 배속에서 음원·속도·음정은 같다.
- 얼음 경사판은 선택한 동결음 `frost-freeze-v1.wav`를 얼어붙는 순간 한 번 재생한다. 미리듣기와 경기는 같은 파일을 사용하며 접촉 지속 중에는 반복하지 않는다.
- 크랙 왁스는 선택한 균열음2개를 충돌마다 번갈아 사용하며, 젤리 연못은 기존 물풍선 음원을 쓴다. 유도 바·분산 핀·결승 회전 바는 기존 팝잇 음원2개를 교대로 사용한다. 장치 합계3개·최소100ms와 충돌 세기에 따른 음량을 유지하며 골인 통로의 수직 벽은 무음이다. 당첨은 승인한 Tada Fanfare A다. 일반층 음향 범위는 최대800이며 다른 층의 재생음은 짧게 감쇠해 정리한다.
- 음원과 오디오 실행을 확인한 뒤 시작·재개한다. 로딩 실패 시 재시도·무음 시작을 제공한다. 음소거·볼륨은 모든 효과음에 적용한다.
- Web Worker가 계산을 담당한다. 준비 시 고정 정보를 한 번 보내고 진행 중에는 구슬 동적 상태와 변경된 블록 속성만 전송한다. 초기화 시 전송·복원 상태를 새로 만들고 이전 Worker 응답을 무시한다. 주변 구슬만 검사하며 순서를 고정한다. 준비는 나눠 실행해 취소할 수 있다. 화면 밖 구슬 그림과 화면 밖 순위 행은 생략하지만 물리·전체 결과 복사는 유지한다.

## 예외와 검증

이름은20자·양의 정수 배수만 허용하며 안전한 정수 범위를 검사한다. 잘못된 입력은 해당 이름을 알려주고 시작을 막는다. 저장·음원 로딩·전체화면·복사 실패를 한국어로 알린다. 결과 복사 성공·실패는 공용 Toast로 화면 아래에3초 표시한다. 본문 공간을 차지하거나 클릭을 막지 않으며 전체화면에서도 보인다. 재복사하면 표시 시간을 다시 시작하고 경기 초기화·새 시작·페이지 종료 시 정리한다. 탭을 숨기면 일시정지한다. 화면을 떠나면 Worker·예약·오디오를 정리한다.

단위 테스트에서 크랙 왁스 접촉·복구, 연못 진입·탈출, 충돌·교차 순서,0.25/1/2배속 Worker 동일성을 검사한다. 브라우저에서는 저장·중복 맵·취소·잠금 안내·모바일·전체화면·4개 당첨 방식·미니맵·대규모 버튼 응답을 검사한다. 분포만으로 사이드 우승 편향이 해결됐다고 판단하지 않는다. 측정과 남은 한계는 새 ADR에 기록한다.

결승 카메라는 도착 라인 아래에 화면 기준120px의 여백을 둔다. 높이가480px보다 작은 화면에서는 화면 높이의25%를 적용한다. 실제 결승 통로와 골인 판정 위치는 유지한다.

## 설정·맵·도감과 순위 카드 개선

2026-09-18 사용자가 화면·경기 길이·음향 개선 계획의 구현을 요청했다. 참가자 이름 label과 `race-names` 입력창 사이 여백은8px이다. `winner-names` 위 여백은16px이며 명단 도움말은 “토끼*10처럼 입력하면 같은 구슬을 여러 개 넣어요.”다. 예시 명단 버튼·설정 저장 안내·경기 중 미리듣기 제한 설명을 제거한다. 자동 저장과 미리듣기 잠금 동작은 유지한다.

## 여러명 도착 순위 범위

여러명을 고르면 시작 순위와 끝 순위를 숫자 입력창2개로 표시하고 가운데 ~는 고정한다. 기본값은 시작1·끝3이며 시작4·끝6이면4·5·6번째 도착한3개가 당첨된다. 모바일 숫자 키보드와 키보드 Tab 이동을 지원한다. 예시 도움말과 실제 당첨 구슬 수를 표시한다. 시작과 끝이 같으면1개만 당첨된다. 역순·0·소수·구슬 수 초과·안전하게 표현할 수 없는 정수·불완전한 입력은 오류를 알리고 시작을 막는다. 다른 당첨 방식에는 범위 오류를 적용하지 않는다.

범위 앞 순위가 도착해도 당첨 목록·축하·팡파레를 실행하지 않는다. 범위 시작 순위 후보부터 결승 연출을 적용하고 마지막 선택 순위가 도착하면 연출 전에 선택한 배속으로 돌아간다. 경기 중 입력을 잠그며 결과와 복사에는 경기 시작 시 선택한 범위를 표시한다. 전체 순위 복사는 유지한다. 범위 입력은 기존 localStorage 설정의 rangeText에 저장하고 이전 인원 설정은1~count로 복구한다.

여러명·n번째의 추가 입력은 같은 fieldset과 공통 스타일을 사용한다. 제목을 위에 두고14px 바깥 여백·8px 제목 간격,16px 글자와 같은 입력창 높이·안쪽 여백을 적용한다. 여러명은 숫자 입력2개와 고정 ~, n번째는 숫자 입력1개를 표시한다. 두 방식 모두 같은 위치와 스타일로 도움말·오류를 제공한다.
