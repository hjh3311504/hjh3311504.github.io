## 구성과 동작

공통 SiteShell·ToolPageLayout·ToolPageFooter 안에 제목과 요약을 표시한다. 글 영역에는 작성자·글 종류·게시일·선택적 수정일·적용일·버전, 선택적 대표 이미지, 목차, 본문과 관련 글을 둔다. 작성 정보 오른쪽에는 뒤로가기 링크를 배치한다. 상단의 별도 블로그 목록 링크와 프로그램 사용 버튼은 표시하지 않는다. 본문 카드 바깥의 하단에 primary 색상의 ‘프로그램명 체험하기’ 버튼과 뒤로가기 링크를 둔다. 이 영역과 footer 사이에 구분선을 표시한다. 작성 정보·버튼 영역·구분선·footer는 목차를 제외한 본문 카드 너비에 맞춘다. 프로그램이 연결되지 않은 글에는 체험 버튼을 표시하지 않는다. 뒤로가기는 이 글로 이동하기 전의 내부 페이지로 연결하며 목차 이동은 돌아갈 주소를 바꾸지 않는다. 직접 접속·새로고침·JavaScript 비활성 상태에서는 블로그 목록으로 연결한다.

본문 제목이3개 이상이면 목차를 제공한다. 화면 너비1280px 이상에서는 목차를 본문 오른쪽240px 영역에 배치하고 스크롤 중에도 화면 안에 유지한다. 좁은 화면에서는 본문 위에 표시한다. 긴 목차는 목차 영역 안에서 스크롤한다. 같은 제목도 서로 다른 위치로 이동한다. 본문 전체는 공통 Section 카드 안에 넣어 배경·테두리로 목차와 관련 글에서 구분한다. 카드 내부 여백은 공통 기준인 데스크톱24px·모바일16px를 따른다. 접근성 이름은 ‘글 본문’이다. 본문은 h2부터 작성하며 원시 HTML은 실행하지 않는다. 표와 코드에는 키보드로 접근할 수 있는 가로 스크롤 영역을 제공한다. 본문 스타일은 공통 UI 제목을 덮어쓰지 않는 .blog-prose 안에서만 적용한다. 문서 본문은 일반 UI 카드와 다른 문단·목록·표 구조라서 전용 CSS를 사용한다.

관련 글은 프로그램이 연결된 글은 같은 프로그램의 공개 글만 최대4개 표시하며 현재 글을 제외한다. 소개 글을 먼저 배치하고 나머지는 최신순이다. 예전 업데이트에서 현재 소개나 가이드로 이동할 수 있다. 연결할 글이 없으면 영역을 숨긴다. 일반 글은 프로그램 사용 버튼을 표시하지 않고 같은 종류의 일반 글로 연결한다. RSS 구독은 footer의 개인정보처리방침 옆에 두고 글자색·밑줄 색·굵기·위치를 같게 표시한다. 초안에는 로컬 미리보기 표시와 noindex를 제공한다. 배포된 초안·없는 주소는404다.

## 화면과 접근성

목차가 있는 글의 최대 너비는1200px, 없는 글은880px다. 본문 글자는 데스크톱18px·모바일16px, 줄 간격1.9를 사용한다. 영역 간격24px, 본문 제목 앞40px·뒤16px를 사용한다. 공통 헤더의 크기·여백은 덮어쓰지 않는다. 긴 주소·표·코드·이미지는 바깥 화면을 넓히지 않는다. 제목 위치 이동 시 상단 메뉴에 가리지 않게 한다. 기존 통계 동의·개인정보 모달을 유지하며 새 추적 항목은 추가하지 않는다.

## 검증

팀 메이커 소개 글에는 가상 명단을 사용한 참가자 입력·팀 배정 결과 화면과 대체 텍스트·캡션을 포함한다. 글은 단계 번호·행동형 제목, 짧은 안내, 이미지, 한 문장 캡션 순서로 구성한다. 이미지는 좁은 화면에서 필요한 부분을 촬영하고 최대400px 너비로 가운데 정렬한다. 주의사항은 글 마지막의 안내 영역에 모은다. 목차에는 제목의 단계 번호만 표시해 번호가 중복되지 않게 한다. 이미지와 캡션은 figure·figcaption으로 연결하며 캡션은14px·보조 글자색·위 간격8px로 표시한다.
