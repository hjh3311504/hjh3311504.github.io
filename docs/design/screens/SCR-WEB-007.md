| 연결 REQ | `REQ-WEB-020`, `REQ-WEB-021`, `REQ-WEB-022`, `REQ-WEB-027` |

사용자 설계·구현 승인: 2026-10-15 AdSense 3번째 거절(가치가 별로 없는 콘텐츠) 대응 계획 승인. 개인정보처리방침 모달을 `/privacy` route로 바꾸고 `/about`을 추가한다. 새 시안이나 handoff는 만들지 않는다.

## 구성과 동작

두 화면 모두 공통 SiteShell·ToolPageLayout·Section·ToolPageFooter를 사용한다. 본문은 블로그 글과 같은 `blog-prose` 스타일을 16px로 표시한다. 최대 너비는 880px이다.

- `/about` 소개와 문의: 사이트에서 다루는 것(블로그·도구3개), 글을 쓰는 방식(직접 만든 예제·측정값과 생성 코드 공개·공식 문서 근거·한계·수정일), 도구를 만드는 방식(브라우저 처리·공개 소스·출처 목록), 광고, 문의(이메일 `mailto` 링크와 GitHub 제보) 순서다. 공통 메뉴에서 ‘소개·문의’로 열고 현재 화면을 표시한다. AboutPage 구조화 데이터를 제공한다.
- `/privacy` 개인정보처리방침: 운영자·적용일, 브라우저 저장 정보, 저장 기간과 삭제, 사이트 접속과 외부 서비스, 방문 통계와 현재 수집 상태, 광고와 쿠키, 문의와 방침 변경 순서다. 공통 메뉴에는 넣지 않고 모든 공개 페이지 footer에서 연다.

## 화면과 접근성

제목은 각 화면에 `h1` 1개, 본문 항목은 `h2`다. 링크는 밑줄로 구분한다. 긴 이메일과 주소는 줄바꿈한다. 320px·390px·1440px와 밝은·어두운 테마에서 가로 넘침이 없어야 한다. 두 화면 모두 canonical과 공유 정보를 제공하고 sitemap에 포함한다.

## 검증

footer·메뉴에서 이동, 이메일 링크, 통계 상태 문구, 모바일 배치와 테마를 확인한다.
