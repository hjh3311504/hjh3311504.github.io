# 팀 메이커

| 항목 | 내용 |
|---|---|
| 화면 ID | `SCR-WEB-001` |
| 화면 이름 | 팀 메이커 |
| 연결 REQ | `REQ-WEB-001`, `REQ-WEB-002`, `REQ-WEB-003`, `REQ-WEB-005`, `REQ-WEB-006`, `REQ-WEB-007`, `REQ-WEB-009`, `REQ-WEB-011`, `REQ-WEB-012`, `REQ-WEB-013`, `REQ-WEB-014`, `REQ-WEB-015`, `REQ-WEB-016`, `REQ-WEB-017`, `REQ-WEB-018`, `REQ-WEB-020`, `REQ-WEB-021`, `REQ-WEB-022`, `REQ-WEB-023`, `REQ-WEB-024`, `REQ-WEB-025` |

## 목적

모임 진행자가 참가자와 배정 규칙을 관리하고 고르게 나눈 팀의 승패와 팀별 무작위 추첨을 기록한 뒤 별도 통계에서 확인한다.

## 화면 구성

위에서 아래로 다음 순서를 유지한다.

1. 공통 내비게이션: 데스크톱 고정 사이드바 또는 메뉴 버튼과 왼쪽 drawer
2. 제목 “팀 메이커”와 설명 “스포츠·게임·모임 참가자를 고르게 나누는 무료 팀짜기·조짜기 도구입니다.”
3. 브라우저 저장 실패 안내: 저장 실패 때만 표시
4. 참가자 입력 카드: 한 명 추가, 일괄 추가, 전체 선택·해제, 명단 저장·불러오기, 명단 삭제, 참가자 목록, 같은 팀·다른 팀 규칙
5. 나누는 방식 카드: 팀 수 또는 팀당 인원 선택, 값 조절, 계산 안내
6. 팀 만들기 버튼과 비활성화 이유
7. 결과 영역: 빈 결과 또는 오류, 팀 카드, 명단 복사, 다시 섞기, 순위 기록·취소, 팀별 추첨
8. 오늘의 기록 영역: 별도 `4. 오늘의 기록` 묶음 안의 경기 수, 초기화, 참가자 통계, 전체 기록, 개별 기록 삭제
9. 필요할 때 여는 dialog: 일괄 추가, 규칙 참가자 선택, 명단 저장·불러오기, 돌림판, 경기 기록·전체 통계 탭을 둔 전체 기록, 참가자 통계, 명단·기록·저장 명단·오늘 기록 초기화 확인

## 상태와 동작

| 상태·동작 | 조건 | 사용자에게 보이는 결과 |
|---|---|---|
| 처음 방문 | 저장된 값이 없음 | 참가자 0명, 팀 수 방식 2개, 팀당 인원 4명, 비활성화된 팀 만들기, 빈 결과 안내 |
| 저장값 복구 | 이 브라우저에 저장된 값이 있음 | 참가자·참가 여부·규칙·저장 명단·나누기 설정·승패 기록·효과음 설정을 복구하되 이전 팀 결과는 복구하지 않음 |
| 옛 기록 복구 | 순위를 기록하기 전 방식으로 저장된 기록이 있음 | 팀이 2개면 승·패를 그대로 되살리고, 3개 이상이면 1등만 되살린 뒤 나머지 팀을 `미정`으로 표시 |
| 한 명 추가 | 이름을 적고 추가 또는 Enter 실행 | 공백을 정리한 참가자를 선택 상태로 목록에 추가하고 입력을 비움 |
| 일괄 추가 | dialog에 줄바꿈이나 쉼표로 구분한 이름 입력 | 빈 이름과 공백을 버린 인원 수를 미리 알리고 한 번에 목록에 추가 |
| 중복 이름 | 같은 이름이 2개 이상 있음 | 각 이름을 별도 참가자로 유지하고 중복 이름도 각각 참가자로 처리된다고 안내 |
| 참가자 관리 | 이름 수정, 참가 여부 변경, 전체 선택·해제 또는 한 명 삭제 | 전체·참가 인원을 갱신하고 이전 팀 결과와 오류를 지움 |
| 명단 삭제 | 참가자가 있고 사용자가 확인함 | 현재 참가자·규칙·결과를 지우되 저장 명단과 승패 기록은 유지 |
| 명단 저장 | 참가자와 공백이 아닌 명단 이름이 있음 | 현재 참가자·참가 여부·목록 배치·규칙을 저장하고 같은 이름이면 덮어쓴다고 안내 |
| 명단 불러오기 | 저장 명단에서 불러오기 실행 | 현재 참가자와 규칙을 저장된 내용으로 바꾸고 이전 결과를 지움 |
| 저장 명단 삭제 | 삭제를 누르고 확인함 | 선택한 저장 명단만 지움 |
| 규칙 추가 | 선택된 참가자 2명 이상을 고름 | 같은 팀 또는 서로 다른 팀 규칙을 목록에 추가하고 이전 결과를 지움 |
| 규칙 삭제 | 규칙의 삭제 실행 | 해당 규칙을 지우고 이전 결과를 지움 |
| 나누기 방식 변경 | 팀 수 또는 팀당 인원 방식과 값을 변경 | 계산되는 팀 수 안내를 갱신하고 이전 결과를 지움 |
| 참가자 부족 | 선택된 참가자가 2명 미만 | 팀 만들기를 비활성화하고 두 명 이상 선택하라고 표시 |
| 설정값 오류 | 팀 수 또는 팀당 인원이 선택된 참가자 수보다 큼 | 팀 만들기를 비활성화하고 해당 이유를 표시 |
| 규칙 충돌·배정 불가 | 같은 팀과 다른 팀 규칙이 충돌하거나 정원 또는 조합 때문에 배정할 수 없음 | 이전 결과 대신 구체적인 실패 이유를 결과 영역에 표시 |
| 결과 생성 | 유효한 값으로 팀 만들기 실행 | `1팀`부터 시작하는 팀 카드, 참가자 목록과 인원을 표시하고 성공 문구를 알림 |
| 다시 섞기 | 결과가 있고 다시 섞기 실행 | 현재 참가자·설정·규칙을 유지해 새 결과를 만들고 승패와 추첨 결과를 초기화 |
| 승리 기록 | 팀이 2개인 결과에서 한 팀의 승리 실행 | `1팀승`·`2팀패`처럼 팀 이름과 결과를 붙인 문구로 표시하고 시각·순위·전체 팀 명단을 별도 `4. 오늘의 기록`에 추가 |
| 순위 기록 | 팀이 3개 이상인 결과에서 등수 버튼 실행 | 고른 팀 카드 칩에 `1등`처럼 다음 등수를 부여하고 남은 팀 버튼을 그다음 등수 버튼으로 바꾸며, 남은 팀이 하나면 자동으로 마지막 등수를 확정 |
| 순위 취소 | 순위를 기록한 결과에서 취소 실행 | 마지막으로 부여한 등수를 한 단계 되돌리고 그 팀의 당첨자를 지우며, 남은 순위가 없으면 기록 자체를 삭제 |
| 명단 복사 | 결과가 있을 때 명단 복사 실행 | 팀 이름과 참가자 이름만 줄바꿈으로 이어 붙인 글을 클립보드에 넣고 버튼 문구를 잠시 `복사함`으로 바꾼 뒤 되돌림 |
| 복사 실패 | 브라우저가 클립보드 쓰기를 막음 | 화면에 보이지 않는 입력칸으로 한 번 더 시도하고, 그래도 안 되면 결과를 직접 선택해 복사하라고 글로 안내 |
| 팀별 추첨 | 순위를 받은 팀의 뽑기 실행 | 아직 안 뽑힌 참가자로 돌림판을 다시 그려 열고, 모두 뽑으면 더 뽑을 수 없다고 알림 |
| 당첨자 목록 표시 | 이 팀의 당첨자가 한 명 이상 | 넓은 화면에서는 판 우측, 좁은 화면에서는 판 아래에 누적 당첨자 카드와 순번을 쌓고 방금 뽑힌 사람을 `최근 당첨자`로 표시함. 당첨자가 없으면 판만 보여 줌 |
| 회전 바로 끝내기 | 돌림판이 도는 중에 `바로 뽑기` 실행 | 처음 돌리기를 누른 시점에 정한 결과를 바꾸지 않고 남은 회전을 건너뛰어 바로 표시함 |
| 회전 중 닫기 | 돌림판이 도는 중에 닫기·Escape·배경 실행 | 닫기 버튼을 비활성화하고 dialog를 유지한 뒤 결과를 표시함 |
| 당첨자 취소 | 당첨자 한 명 취소 또는 당첨자 지우기 실행 | 해당 당첨자를 기록에서 빼고 돌림판 후보로 되돌림 |
| 오늘 기록 초기화 | 오늘 기록이 있고 사용자가 확인함 | 오늘 목록의 표시만 비우고 전체 기록과 통계 집계에는 그대로 남김 |
| 참가자 통계 보기 | `4. 오늘의 기록`의 참가자 통계 실행 | 화면에 보이는 오늘 기록만으로 1등 팀은 승, 나머지 팀은 패로 계산한 최다 승리·최다 당첨·최다 패배, 베스트 팀 조합과 참가자별 순위 표를 dialog에 표시 |
| 전체 기록 보기 | `4. 오늘의 기록`의 전체 기록 실행 | `경기 기록` 탭에는 날짜별 경기 수·시각·팀 결과·당시 명단을, `전체 통계` 탭에는 경기 수·기록한 날·참가자 수와 참가자 순위를 표시 |
| 전체 통계 정렬·검색 | 전체 통계 탭에서 정렬 기준이나 참가자 검색을 바꿈 | 기본은 1등 횟수가 많은 순이며 1등 확률·당첨 횟수·참가 경기 수로 다시 정렬하거나 이름으로 좁혀 봄 |
| 오늘 기록이 없는 참가자 통계 | 오늘 기록이 0건 | 순위와 표를 숨기고 `오늘의 기록이 없습니다.`만 보여 줌 |
| 기록이 없는 전체 기록 | 저장된 기록이 하나도 없음 | 탭과 전체 통계를 숨기고 빈 안내만 보여 줌 |
| 기록 삭제 | 기록 한 건의 삭제를 확인함 | 해당 기록만 목록에서 삭제 |
| 테마 변경 | 공통 내비게이션의 테마 조작을 실행함 | 자동, 밝게, 어둡게 순환 방식을 적용하고 선택을 브라우저에 저장 |
| 브라우저 저장 실패 | 저장 공간을 읽거나 쓸 수 없음 | 현재 작업은 계속 제공하고 창을 닫으면 입력이 사라질 수 있다는 alert 표시 |

## 화면 전용 제약

- 공통 내비게이션과 팀 메이커 본문은 같은 밝은·어두운 테마를 사용한다.
- 팀 메이커의 layout, 크기, 간격, 글꼴, 카드, 버튼, 입력, dialog, drawer, 그림자, 모서리, 상태색과 반응형 배치는 사용자가 전달한 Claude Design DSN-009 최종 작업물을 기준으로 한다. 명단 복사, 오늘 기록 초기화, 참가자 통계, 당첨자 영역, 누적 당첨자 카드, 전체 기록의 탭·정렬·검색과 참가자 순위 표현을 같은 시각 언어로 구현한다.
- 유일한 시각 변경은 primary 계열이다. 기존 보라색 primary와 그 hover·focus·soft·line 파생색만 Notion의 파란색 `#0075de`와 같은 파란색 계열로 바꾸고 나머지 색과 시각 속성은 바꾸지 않는다.
- 어두운 테마는 현재 구현의 따뜻한 검정 surface, 테두리와 상태색을 유지하되 primary·초점·현재 위치에는 Notion의 파란색 accent를 사용한다.
- `1201px` 이상에서는 왼쪽 사이드바를 기본 고정하고 팀 메이커 본문 너비를 남은 공간 안에서 유지한다.
- 데스크톱 고정 해제에서는 화면 위 메뉴 버튼으로, `1200px` 이하에서는 상단 bar의 햄버거 버튼으로 왼쪽 drawer를 연다.
- drawer가 열리면 초점을 첫 이동 항목으로 옮기고 Tab 이동을 내부에 두며 Escape나 배경 실행으로 닫은 뒤 초점을 햄버거 버튼으로 돌리고 본문 스크롤을 막는다.
- 현재 위치인 `팀 메이커`를 글과 모양으로 표시하고 `aria-current="page"`로 보조 기술에 알린다.
- 참가자와 기록의 소유자는 현재 브라우저 사용자이며 외부 서버로 보내지 않는다.
- 참가자와 설정은 `localStorage`에 저장하지만 생성된 팀 결과는 새로고침 뒤 복구하지 않는다.
- 참가자 수는 0명일 때 `(0명)`, 모두 참가할 때 `(8명)`, 일부만 참가할 때 `(8명 중 6명 참가)` 형식으로 적는다.
- 팀 수는 2~20개이며 기본값은 2개다.
- 팀당 인원은 1~20명이며 기본값은 4명이다.
- 같은 팀 규칙은 선택한 참가자를 한 묶음으로 배정한다.
- 다른 팀 규칙은 선택한 참가자를 서로 다른 팀에 배정한다.
- 같은 팀 규칙과 다른 팀 규칙이 충돌하거나 같은 팀 묶음이 한 팀 정원보다 크면 결과를 만들지 않는다.
- 규칙을 만족하는 배정은 제한된 횟수 안에서 찾고 찾지 못하면 규칙이나 설정을 고치라고 안내한다.
- 참가자를 삭제하면 해당 참가자를 포함한 규칙도 유효한 2명 이상만 남도록 정리한다.
- 저장 명단 이름은 앞뒤 공백을 제거하며 같은 이름은 새 항목이 아니라 덮어쓰기로 처리한다.
- 승패 기록은 기록 시각, 순위 배열, 당시 전체 팀 명단의 사본과 팀별 당첨자를 저장한다.
- 오늘 기록을 지운 시각도 함께 저장하고, 그보다 나중에 만든 기록만 오늘 목록에 보여 준다. 날짜가 바뀌면 저절로 다시 채워진다.
- 팀이 2개면 승리를 한 번 기록해 순위가 끝나고, 3팀 이상이면 1등부터 순차로 지정하며 남은 팀이 하나일 때 자동으로 마지막 등수가 된다.
- 통계에서는 팀 수와 관계없이 1등 팀만 승리로 세고 나머지 팀은 모두 패배로 센다. 3팀 이상에서 1등만 정해졌거나 이전 형식의 기록에 승리 팀만 남아 있어도 나머지 팀은 모두 패배다. 유효한 1등이 없으면 어느 팀도 승이나 패로 세지 않는다.
- 결과 화면에서는 마지막으로 부여한 순위만 한 단계씩 취소할 수 있다.
- 오늘 기록은 `3. 결과` 안에 넣지 않고 뒤에 이어지는 별도 `4. 오늘의 기록` 영역에 둔다.
- 오늘 기록이 비어도 `4. 오늘의 기록` 영역과 전체 기록 진입점은 계속 보여 준다. 저장된 기록이 하나도 없을 때만 영역을 숨긴다.
- 팀별 추첨은 순위를 받은 팀에만 제공하고, 이미 당첨된 사람을 뺀 나머지에서 뽑아 당첨자를 쌓으며 모두 뽑으면 멈춘다.
- 당첨자 목록은 팀 카드 안이 아니라 `3. 결과`의 팀 격자 아래 별도 영역에 팀별로 모아 둔다.
- 넓은 화면의 당첨자 영역은 항상 2열을 유지한다. 한 팀만 당첨자가 있어도 그 묶음은 절반 너비만 차지한다. 좁은 화면에서는 1열로 바꾼다.
- 돌림판이 도는 동안에는 효과음을 내지 않는다. 판이 멈춘 뒤에 당첨 팡파르만 울린다. 효과음 설정은 브라우저에 저장한다.
- 돌림판이 도는 동안에도 후보 이름을 계속 보여 준다. `돌리기`는 `바로 뽑기`로 바뀌고 닫기·Escape·배경 닫기는 막는다. `바로 뽑기`는 이미 정한 당첨자를 바꾸지 않고 남은 회전을 건너뛰며 판도 즉시 멈춘다.
- 돌림판 옆 당첨자 전체 지우기는 `명단 삭제` 글자 버튼으로 표시한다.
- 회전은 DSN-004 handoff 그대로 6500ms `cubic-bezier(0.1, 0.72, 0.06, 1)`이고, 멈춘 뒤 100ms에 팡파르가 온다.
- 명단 삭제, 저장 명단 삭제와 승패 기록 삭제는 실행 전에 대상과 영향, 되돌릴 수 없다는 점을 글로 확인한다.
- 오늘 기록 초기화도 같은 확인을 거치되 사라지는 것이 화면 표시뿐이고 전체 기록에는 그대로 남는다고 알린다. 되돌릴 수 없다고 적지 않는다.
- dialog는 제목과 설명을 보조 기술에 연결하고 닫기 버튼과 Escape를 제공하며 배경 스크롤을 막는다.
- 모든 입력과 버튼은 보이는 label 또는 같은 뜻의 접근성 이름과 키보드 초점 표시를 제공한다.
- 오류, 비활성화, 당첨 상태는 색상뿐 아니라 문구와 모양으로도 구분한다.
- 팀이 2개면 `1팀승`·`2팀패`처럼 팀 이름과 결과를 붙여 적는다.
- 기록 목록의 순위 라벨은 너비 `60px`로 맞춘다. 아직 순위가 없는 팀은 `순위 미정` 대신 `1팀`처럼 팀 이름만 적는다.
- 팀이 3개 이상이면 등수 숫자로 적는다. 팀 이름이 바로 옆에 보이는 결과 카드 칩에서는 `1등`처럼 등수만 적고, 팀 이름이 없는 기록 목록에서는 `1팀 1등`처럼 팀 이름과 함께 적는다. 마지막 팀도 등수 숫자로 적고 `꼴등` 같은 말은 쓰지 않는다.
- 순위 색은 1등 파랑, 마지막 등수 빨강, 중간 등수는 주황에서 빨강 쪽으로 단계를 준다. 색과 함께 등수 숫자를 글로 적어 색 없이도 구분한다.
- 참가자 통계는 화면에 보이는 오늘 기록만 세고 최다 승리·최다 당첨·최다 패배, 베스트 팀 조합과 참가자별 순위 표를 보여 준다.
- 전체 기록 dialog는 `경기 기록`과 `전체 통계` 탭을 둔다. 전체 통계는 저장된 기록 전체로 요약과 참가자 순위를 계산한다.
- 전체 통계의 기본 순서는 1등 횟수가 많은 순이다. 사용자는 1등 확률·당첨 횟수·참가 경기 수 순으로 다시 정렬하고 이름으로 검색할 수 있다.
- 막대와 백분율은 1등 확률이다. 1등 확률은 참가한 전체 경기 중 1등을 한 경기의 비율이며 소수점 첫째 자리까지 반올림해 표시한다.
- 모바일에서는 참가자 목록과 결과 카드를 한 열로 재배치하고 dialog와 돌림판이 화면 밖으로 넘치지 않게 한다.
