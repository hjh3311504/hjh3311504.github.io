# 루트 홈

| 항목 | 내용 |
|---|---|
| 화면 ID | `SCR-WEB-002` |
| 화면 이름 | 루트 홈 |
| 연결 REQ | `REQ-WEB-019`, `REQ-WEB-020`, `REQ-WEB-021`, `REQ-WEB-022` |

## 목적

방문자가 Lake의 개발 공간이라는 점을 이해하고 세로 목록에서 원하는 도구를 연다.

## 화면 구성

위에서 아래로 다음 순서를 유지한다.

1. 공통 내비게이션: 데스크톱 고정 사이드바 또는 메뉴 버튼과 왼쪽 drawer
2. 소개 영역: 이름과 개발하며 만든 도구·프로젝트에 관한 짧은 설명
3. 둘러보기 목록: 팀 메이커를 한 열에 배치하고 새 프로젝트도 같은 형식으로 아래에 추가
4. 기존 사이트 footer: 내용이 짧아도 첫 화면의 하단 영역보다 위로 올라오지 않고, 내용이 길면 문서 흐름에 따라 아래로 이동

### 간략한 화면 구성 예시

```text
데스크톱 · 사이드바 고정
┌ 내비게이션 ───────┐ ┌ 홈 ───────────────────────────────┐
│ Lake's develog    │ │ 소개                              │
│ 홈                │ │ Lake · 개발 기록                 │
│ 프로젝트          │ │                                   │
│  · 팀 메이커      │ │ 둘러보기                          │
│  ┆ 추가 시 아래로 │ │ ┌ 팀 메이커 · 도구 ────────────┐ │
│ [테마]            │ │ │ 설명                     [열기]│ │
│ [고정 해제]       │ │ └───────────────────────────────┘ │
└───────────────────┘ │                                   │
                      │ 새 항목은 한 열로 아래에 추가     │
                      │                                   │
                      │                            footer │
                      └───────────────────────────────────┘

모바일·태블릿 또는 데스크톱 고정 해제
┌ 화면 위 ──────────────────────────────┐
│ [☰ 메뉴]                             │
└───────────────────────────────────────┘
┌ drawer ─────────────┐
│ Lake's develog      │
│ 홈                  │
│ 프로젝트            │
│  · 팀 메이커        │
│  ┆ 추가 시 아래로   │
│ [테마]              │
└─────────────────────┘
```

이 예시는 요소의 순서와 묶음을 설명한다. 둘러보기 항목은 화면 너비와 관계없이 한 열을 유지한다. 색상, 간격, 글꼴, 장식과 정확한 문구는 Claude Design 결과를 기준으로 검토한다.

SvelteKit 템플릿 안내, 템플릿 기능 카드와 저장소 복제를 권하는 문구는 표시하지 않는다. 블로그 목록과 글도 제공하지 않는다.

## 상태와 동작

| 상태·동작 | 조건 | 사용자에게 보이는 결과 |
|---|---|---|
| 처음 방문 | 루트 주소를 엶 | 개발자 소개 뒤에 팀 메이커가 표시된 목록을 확인한다. |
| 팀 메이커 이동 | 공통 내비게이션 또는 팀 메이커 항목을 실행함 | `/team-maker`로 이동한다. |
| 새 프로젝트 공개 | 새 프로젝트가 사이트에 추가됨 | 기존 항목과 같은 구조의 새 항목이 둘러보기 목록 아래에 이어진다. |
| 짧은 홈 콘텐츠 | 소개와 둘러보기 목록의 높이가 첫 화면보다 짧음 | 남은 세로 공간을 본문이 채우고 footer가 첫 화면의 하단 영역에 놓인다. |
| 사이드바 고정 해제 | 데스크톱에서 고정 해제를 실행함 | 사이드바를 숨기고 화면 위에 drawer를 여는 메뉴 버튼을 표시한다. |
| drawer 열기 | 화면 위의 햄버거 버튼을 실행함 | 왼쪽에서 모든 이동 항목을 세로로 보여주는 drawer가 열린다. |
| 테마 변경 | 공통 내비게이션의 테마 조작을 실행함 | 기존 자동, 밝게, 어둡게 순환 방식을 유지하고 선택을 브라우저에 저장한다. |

## 화면 전용 제약

- 공통 내비게이션의 로고는 텍스트로 사이트 이름을 전달하고 루트로 이동한다.
- 현재 위치인 `홈`을 글과 모양으로 표시하고 `aria-current="page"`로 보조 기술에 알린다.
- 모든 링크와 테마 조작은 키보드로 실행할 수 있고 초점이 분명하게 보여야 한다.
- `1201px` 이상에서는 왼쪽 사이드바를 기본 고정하고 고정 해제 동작을 제공한다.
- 데스크톱 고정 해제와 `1200px` 이하에서는 화면 위에 떠 있는 햄버거 버튼으로 왼쪽 drawer를 연다.
- drawer가 열리면 초점을 첫 이동 항목으로 옮기고 Tab 이동을 내부에 두며 Escape나 배경 실행으로 닫은 뒤 초점을 햄버거 버튼으로 돌리고 본문 스크롤을 막는다.
- 둘러보기 항목은 데스크톱과 모바일 모두 한 열로 배치하고 이름, 종류, 설명과 이동 동작을 제공한다.
- footer를 화면에 고정하지 않는다. 본문이 짧으면 남은 공간을 채워 첫 화면 하단에 두고, 본문이 길면 마지막 항목 아래로 자연스럽게 밀리게 한다.
- 모바일에서는 메뉴 버튼, drawer와 본문에 가로 스크롤이 생기지 않아야 한다.
- 밝은 테마와 어두운 테마에서 본문, 링크, 초점 표시의 대비를 유지한다.
- 어두운 테마는 현재 구현의 따뜻한 검정 surface, 테두리와 위에서 아래로 옅어지는 배경을 유지하되 primary·초점·현재 위치에는 Notion의 파란색 accent를 사용한다.
