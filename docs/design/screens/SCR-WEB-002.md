## 목적

방문자가 Seta Lab이 모임·수업 도구와 가이드를 만드는 곳이라는 점을 이해하고 소개 바로 아래 도구 카드에서 원하는 도구를 열거나 블로그 최신 글을 읽는다.

## 화면 구성

위에서 아래로 다음 순서를 유지한다.

1. 공통 내비게이션: 데스크톱 고정 사이드바 또는 메뉴 버튼과 왼쪽 drawer
2. 소개 영역: 남색(`#0d2a47`) 바탕에 부제목 “필요한 도구를 한곳에”, 제목 Seta Lab, 한 문장 소개, 사이트를 만든 이유와 고쳐 나가는 방식을 담은 두 번째 문단, GitHub 링크를 두고 오른쪽에 θ 타일과 도구 화면 카드 3장을 겹친 그림(`static/images/home/seta-lab-hero.svg`)을 둔다. 그림은 장식이라 대체 텍스트를 비운다. 760px 이하에서는 그림이 글 아래로 내려간다.
3. 둘러보기 카드: 흰 카드 안에 팀 메이커, 대진표, 구슬 레이스, QR 코드, 칼바람 아수라장, 블로그 순서의 작은 카드 격자. 카드 최소 폭은280px이며 화면 폭에 따라3열·2열·1열이 된다. 각 카드는 왼쪽 아이콘, 이름·종류·설명, 오른쪽 아래 화살표로 구성하고 별도 열기 버튼은 두지 않는다. 카드 전체가 링크다.
4. 최신 블로그 글: 둘러보기 카드 밖에 둔다. 공개 글을 게시일 내림차순으로 최대9개 표시하고 전체 글 보기로 `/blog`에 연결. 첫 글은 전체 폭의 연한 파란 카드와 큰 제목·화살표로 강조하고 나머지는 2열 카드(760px 이하 1열)로 둔다. 제목은 줄 수 제한 없이 표시하고 요약은 최대2줄로 줄인다.
5. 도구 선택 안내: 팀 배정·당첨자 추첨·참여 주소 공유·토너먼트의 차이와 도구별 링크를 용도별 카드 4칸(아이콘·용도·설명, 760px 이하 1열)으로 보여 준다. 도구를 이어 쓰는 예시 상자는 2026-11-05에 뺐다. 문장은 접지 않는다.
6. 만든 사람과 문의: 왼쪽에 θ 로고와 제목, 오른쪽에 운영자 Seta·공개 소스·변경 기록·출처·라이선스 목록·소개와 문의 링크가 있는 두 문단을 둔 프로필 카드. 760px 이하에서는 로고와 제목이 한 줄, 문단이 아래로 내려간다.
7. 사이트 footer: 카드 밖에서 위쪽 구분선과 함께 소개·문의와 개인정보처리방침 링크 다음에 “© 2026 Seta Lab”을 표시하고 내용이 짧아도 첫 화면의 하단 영역보다 위로 올라오지 않고, 내용이 길면 문서 흐름에 따라 아래로 이동
8. 개인정보처리방침: 2026-10-15부터 모달 대신 `/privacy` 화면(`SCR-WEB-007`)으로 이동

소개 제목 `Seta Lab`(h1)은 2026-11-05부터 Gmarket Sans Bold의 영문만 남긴 `Seta Title` 글꼴로 표시한다. 섹션 제목·글 제목·카드 제목·본문은 기존 SUIT·SUITE를 유지한다.

QR 코드 아이콘의 배경과 그림자는 보라색(`#6d4bc3`)을 사용한다. 칼바람 아수라장 카드 제목은 ‘칼바람 아수라장’이고 아이콘 배경은 QR과 구분되는 장미색(`#db2777`)이다. 아이콘 선은 흰색을 유지한다.

## 화면 전용 제약

- 공통 내비게이션의 로고는 텍스트로 사이트 이름을 전달하고 루트로 이동한다.
- 현재 위치인 `홈`을 글과 모양으로 표시하고 `aria-current="page"`로 보조 기술에 알린다.
- 모든 링크와 테마 조작은 키보드로 실행할 수 있고 초점이 분명하게 보여야 한다.
- `1201px` 이상에서는 왼쪽 사이드바를 기본 고정하고 고정 해제 동작을 제공한다.
- 데스크톱 고정 해제와 `1200px` 이하에서는 화면 위에 떠 있는 햄버거 버튼으로 왼쪽 drawer를 연다. 아래로 스크롤하면 버튼을 숨기고, 위로 스크롤하거나 맨 위에 오거나 키보드 초점을 받으면 다시 보여 준다(2026-10-15 사용자 선택).
- drawer가 열리면 초점을 첫 이동 항목으로 옮기고 Tab 이동을 내부에 두며 Escape나 배경 실행으로 닫은 뒤 초점을 햄버거 버튼으로 돌리고 본문 스크롤을 막는다.
- 둘러보기 항목은 카드 격자(최소 폭280px, 3열·2열·1열)로 배치하고 이름, 종류, 설명과 이동 동작을 제공한다.
- footer를 화면에 고정하지 않는다. 본문이 짧으면 남은 공간을 채워 첫 화면 하단에 두고, 본문이 길면 마지막 항목 아래로 자연스럽게 밀리게 한다.
- 모바일에서는 메뉴 버튼, drawer와 본문에 가로 스크롤이 생기지 않아야 한다.
- 밝은 테마와 어두운 테마에서 본문, 링크, 초점 표시의 대비를 유지한다.
- 어두운 테마는 현재 구현의 따뜻한 검정 surface, 테두리와 위에서 아래로 옅어지는 배경을 유지하되 primary·초점·현재 위치에는 Notion의 파란색 accent를 사용한다.

사용자의 홈 수정 요청에 따라 둘러보기 맨 위에 블로그 진입점을 추가한다. 블로그 아이콘은 회색빛 파란색 배경과 흰 선으로 다른 도구와 구분한다. 최신 블로그 글은 한 열로 배치한다. 초기에는 도구 목록 뒤에 두었으며, 아래 2026-10-09 변경에 따라 소개 바로 아래로 옮긴다. 각 글은 종류·게시일·제목 링크·요약을 표시한다. 글끼리는 가로선 대신 옅은 배경의 둥근 카드와16px 간격으로 구분한다. 최신 블로그 글 제목과 목록 사이에는16px 여백을 두고, 각 글 카드의 안쪽 여백은12px로 한다. 섹션 사이의 가로선은 유지한다(2026-11-05 시안 A로 대체). 같은 게시일은 slug순으로 정렬하며 초안은 제외한다. 공개 글이 없으면 준비 안내와 전체 글 보기를 유지한다. 목록은 build할 때 정적 HTML에 포함한다.

## 블로그 목록 확대 (2026-10-09)

사용자 구현 승인: 루트 홈에서 더 많은 블로그 글을 보여주는 계획을 구현한다.

- 전체 글 보기와 글이 없을 때의 안내를 유지한다. 글 목록은 JavaScript 없이도 정적 HTML에서 접근할 수 있다.
