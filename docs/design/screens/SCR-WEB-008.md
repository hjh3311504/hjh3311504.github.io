# 팀 대진표

| 항목 | 내용 |
|---|---|
| 화면 ID | `SCR-WEB-008` |
| 화면 이름 | 팀 대진표 |
| 연결 REQ | `REQ-UI-001`, `REQ-BRACKET-001`, `REQ-BRACKET-002`, `REQ-WEB-020`, `REQ-WEB-021`, `REQ-WEB-022`, `REQ-WEB-027` |

## 목적

동호회·체육 수업·사내 행사 진행자가 팀을 나눈 직후 토너먼트 대진표를 만든다. 진행자 1명이 한 기기에서 승자를 기록하고 전체화면이나 인쇄물로 공유한다.

2026-10-16 사용자가 팀 대진표를 새 페이지로 선택했다. Team Maker 결과 버튼 연결과 `/bracket` 주소를 확정했다. 같은 날 사이트 스타일로 만든 데스크톱·모바일 정적 시안을 사용자가 승인했다. 시안 파일은 저장소에 보관하지 않는다.

## 화면 구성

공용 SiteShell·ToolPageHeader·Section·SectionHeader·Button·Dialog·DisclosureSection·ToolPageFooter를 사용한다. 위에서 아래로 다음 순서다.

1. 공통 내비게이션과 대진표 현재 위치 표시
2. ToolPageHeader: 제목 `대진표 만들기`, 설명 `팀을 넣고 토너먼트 대진표를 만들어 승자를 기록해요.`
3. 설정 영역: 961px 이상은 두 열, 960px 이하는 한 열
   - 1번 섹션 `팀`: 팀 수 표시(`(6/32팀)`), 팀 행 목록, `팀 추가`, `여러 팀 한 번에 추가` 버튼
   - 2번 섹션 `대진 설정`: 대진표 제목(선택, 20자), 배치 순서 라디오(입력 순서·무작위), 미리보기 문구, `대진표 만들기` 버튼
4. 3번 섹션 `대진표`: 전체 너비. 제목 오른쪽에 `전체화면`·`인쇄`·`새 대진표` 버튼
5. 사용 안내: 사용법 3단계, 6팀 부전승 예제, FAQ
6. ToolPageFooter. 도구 화면의 관련 블로그 글 영역은 2026-10 이전에 제거됐으므로 두지 않는다.

### 팀 섹션

- Team Maker 참가자 입력과 같은 구성이다. 제목 `팀 입력 (N/32팀)` 오른쪽에 `팀 목록 비우기` 휴지통 버튼을 둔다. 비우기는 확인 dialog를 거치며 만든 대진표와 결과는 남긴다.
- 제목 아래 입력칸·`추가`·`일괄 추가`를 한 줄에 둔다. 엔터나 `추가`로 넣고 쉼표로 여러 팀을 한 번에 넣는다. 추가 후 입력칸을 비우고 포커스를 유지한다. 빈 이름, 16자 초과, 이미 있는 이름, 32팀 초과는 추가하지 않고 입력칸 아래에 이유를 표시한다.
- 팀 행은 테두리가 있는 행이며 손잡이·번호·이름 입력·X 삭제 버튼 순서다. 번호는 입력 순서이며 입력 순서 배치에서 시드가 된다.
- 팀 목록은 최대 488px(팀원 없는 행 8개)까지 보이고 나머지는 목록 안에서 세로 스크롤한다. 엔터나 `추가`로 넣으면 목록을 맨 아래로 내려 방금 넣은 팀을 보여 준다.
- 손잡이를 끌어 순서를 바꾼다. 끄는 중 목록 위·아래 가장자리 40px 안으로 가면 목록이 저절로 스크롤된다. 키보드는 손잡이에서 위·아래 화살표로 1칸, Home·End로 처음·끝으로 옮긴다. 옮긴 뒤 포커스는 손잡이에 남고 바뀐 위치를 화면 낭독기에 알린다. 순서를 바꾸면 다른 팀 목록 변경과 같이 다시 만들기를 안내한다.
- Team Maker에서 가져온 팀은 이름 입력 아래에 팀원을 14px 한 줄로 표시하고 넘치면 말줄임한다. 전체 팀원은 title로 확인한다.
- 빈 이름·중복 이름은 해당 행 아래에 오류를 표시한다. 오류가 있으면 대진표 만들기를 막는다.
- 32개가 되면 입력칸과 `추가`를 비활성하고 이유를 표시한다.
- `일괄 추가` 버튼은 `여러 팀 한 번에 추가` dialog를 연다. 한 줄 또는 쉼표마다 한 팀을 받는 textarea다. 기존 목록에 덧붙이거나 바꾸기를 선택한다. 빈 칸은 무시하고 16자 초과·겹치는 이름·32개 초과는 추가 전에 알린다.
- 저장된 팀이 없으면 빈 목록과 안내 문구로 시작한다.

### 대진 설정 섹션

- 미리보기 문구는 `6팀 · 라운드 3개 · 부전승 1개 · 경기 5개`처럼 계산 결과를 알려 준다. 경기 수는 부전승을 뺀 실제 경기 수다.
- 팀이 2개 미만이거나 입력 오류가 있으면 버튼을 비활성하고 이유를 버튼 아래에 표시한다.
- 대진표가 이미 있고 설정이 바뀌면 버튼 문구를 `대진표 다시 만들기`로 바꾸고 `팀 목록이 바뀌었어요. 다시 만들면 대진표에 반영돼요.`를 표시한다.

### 대진표 섹션

- 대진표가 없으면 EmptyState로 `팀을 넣고 대진표를 만들어 보세요.`를 표시한다.
- 2026-10-16 사용자가 GPT 이미지 시안 A(정돈된 개선)를 선택했다. 시안 원본은 Git에 올리지 않는 `output/playwright/bracket-redesign/`에 두며 아래 규칙이 기준이다.
- 라운드는 열이다. 열 제목은 남은 팀 수로 `16강`·`8강`·`4강`·`결승`이며 카드 너비의 회색 둥근 막대에 표시한다. 마지막 열은 `우승`이다.
- 경기 카드 위쪽 줄에 `1경기`처럼 라운드 안의 경기 번호를 표시한다. 부전승 카드는 `부전승`, 결승 카드는 `결승`이다.
- 팀 칸은 카드 안의 둥근 회색 칸 2개다. 각 칸은 버튼이며 높이 44px 이상이다. 오른쪽에 빈 선택 원을 두고 승자는 파란 원 안의 체크로 바꾼다.
- 아직 정해지지 않은 자리는 `앞 경기 승자`와 기다리는 경기(`8강 3경기`)를 표시하고 누를 수 없다. 상대가 정해지지 않은 경기의 팀 칸에는 선택 원을 두지 않는다.
- 승자 칸은 체크·굵은 글씨·연한 파란 배경으로 표시한다. 진 팀은 흐린 글씨와 취소선으로 표시한다. 색상만으로 구분하지 않는다.
- 진행 상태가 가리키는 다음 경기 카드는 파란 테두리와 `다음 경기` 표시로 강조한다.
- 끝난 경기에서 다음 경기로 가는 연결선은 강조색, 나머지는 흐린 회색이다.
- 남은 팀 수가 홀수인 라운드에서만 1팀이 부전승을 받는다. 같은 팀은 두 라운드 연속 부전승을 받지 않는다. 6팀이면 8강은 경기 3개, 4강은 경기 1개와 부전승 1개다.
- 부전승 경기는 상대 자리에 `부전승`과 `결승 직행`처럼 올라가는 라운드를 표시하고 점선 테두리 카드로 구분한다. 누를 수 없다. 앞 경기 승자가 정해지기 전에는 `앞 경기 승자`로 표시한다.
- 경기 카드는 장식용 SVG 연결선으로 다음 경기와 잇는다. 연결선은 보조 기술에서 숨긴다. 같은 라운드 카드는 다음 라운드 카드의 세로 가운데에 맞춘다.
- 우승 카드는 경기 카드와 같은 높이다. 시안 B의 파란 선 트로피(손잡이가 있는 컵) 아이콘, 팀 이름 칸, 설명 순서로 표시한다. 결승 전에는 이름 칸을 `–`, 설명을 `결승 승자`로 둔다.
- 대진표 위에 연한 파란 진행 상태 띠를 둔다. 왼쪽은 `전체 진행` 제목 아래 `전체 경기(3/5) · 4강 진행 중`, 진행 막대, `60%`를 한 줄로 둔다. 세로줄로 나눈 오른쪽은 `다음 경기 · 4강 1경기(0/1)`과 `호랑이 vs 상어`, `경기로 이동 →` 버튼이다. 괄호 안 수는 그 라운드의 끝난 경기 수와 전체 경기 수이며 부전승은 넣지 않는다.
- 다음 경기는 양쪽 팀이 정해졌고 결과가 없는 경기 중 라운드·경기 순서가 가장 앞선 경기다. `경기로 이동`은 페이지를 스크롤하지 않고 그 카드의 첫 팀 버튼에 포커스를 옮긴다. 카드가 대진표 영역 밖에 있으면 영역 안에서만 가로로 넘겨 보이게 하고, 960px 이하는 그 라운드 탭으로 바꾼다. 마우스로 눌러도 보이도록 포커스가 카드 안에 있는 동안 카드 바깥에 3px 파란 테두리를 둔다.
- 모든 경기가 끝나면 왼쪽은 `전체 경기(5/5) · 모든 경기 끝남`과 `100%`, 오른쪽은 `우승` 제목 아래 트로피와 `호랑이`로 바꾼다.
- 넓은 화면에서 왼쪽 `전체 진행`과 오른쪽 `다음 경기`(또는 `우승`) 제목 줄은 같은 높이에 두고, 그 아래 두 번째 줄도 가운데 높이를 맞춘다.
- 띠의 전체 진행 글자는 보조 기술에서 숨긴다. 대신 화면에 보이지 않는 `경기 5개 중 3개 끝남 · 다음 경기: 4강 1경기`(우승 뒤 `우승: 호랑이`) 문장을 aria-live polite로 알린다.
- 760px 이하에서는 띠 오른쪽 영역을 가로줄 아래로 내리고 막대와 퍼센트를 다음 줄에 둔다. 팀 이름 칸이 좁으면 `경기로 이동`을 다음 줄로 내리고 긴 이름은 말줄임한다.
- 섹션 제목 `대진표` 오른쪽에 `6팀 · 입력 순서`(무작위면 `무작위 배치`)를 작은 회색 글씨로 둔다. 띠 아래 줄 왼쪽에 크기 조절(`−`·현재 배율·`+`·`화면 맞춤`), 오른쪽(760px 이하는 왼쪽)에 `이긴 팀을 눌러 승자를 기록하세요.` 안내를 둔다. 우승이 정해지면 안내를 숨긴다.
- `전체화면`·`인쇄`·`새 대진표` 버튼 앞에 16px 선 아이콘을 둔다.
- 대진표 제목이 있으면 진행 상태 위에 표시한다.

### 반응형

- 961px 이상: 대진표 전체를 펼친다. 넓으면 대진표 영역 안에서만 가로 스크롤한다. 페이지 전체는 가로로 넘치지 않는다.
- 페이지 최대 폭은 1550px다. 961px 이상에서는 대진표 섹션 전체가 창 높이 안에 들어오도록 대진표 그림을 비율 그대로 줄인다. 창 위아래에 16px 여백을 두고, 전체화면에서는 화면 높이에 맞춘다. 50%보다 작게 줄여야 하면 50%로 두고 대진표 영역 안에서 스크롤한다. 1920×1080 화면에서는 32팀까지 스크롤 없이 들어온다.
- 961px 이상에서는 크기 조절로 50%·67%·80%·100%·125%·150%·200% 중 지금 배율의 한 단계 위·아래로 바꾼다. 바꾼 배율은 `화면 맞춤`을 누르거나 첫 라운드 배치가 다른 대진표를 만들 때까지 유지하며, 창보다 커지면 대진표 영역 안에서 가로로 스크롤하고 섹션이 세로로 길어진다. `화면 맞춤`은 직접 배율을 골랐을 때만 누를 수 있다. 버튼으로 배율을 바꿀 때만 화면 낭독기에 새 배율을 알리고, 창 크기에 따른 배율 변화는 읽지 않는다. 960px 이하에는 크기 조절을 두지 않는다.
- 961px 이상에서 배율이 70% 미만이면 글자 위주 카드로 바꾼다. 카드 크기와 배치는 그대로 두고 `N경기` 제목줄(다음 경기 배지 포함)과 팀원·출처·부전승 설명 줄을 숨긴다. 정해지지 않은 자리는 `—`만 보이고 화면 낭독기에는 `앞 경기 승자 32강 1경기`를 읽어 준다. 팀 이름·라운드 제목·우승 팀 이름을 24px·22px·24px로 키워 50%에서도 약 12px로 보이게 하고, 승자 원은 28px로 키운다. 우승 칸 설명은 숨긴다. 팀원이 있으면 팀 이름 title로 팀원을 보여 준다. 다음 경기 카드의 파란 테두리는 유지한다. 인쇄는 항상 모든 정보를 담은 카드다.
- 961px 이상에서는 한 방향 배치와 좌우 대칭 배치 중 덜 줄여도 되는 배치를 고른다. 배율이 같거나 4팀 이하면 한 방향이다. 좌우 대칭 배치에서 결승의 두 앞 경기 중 위쪽 갈래는 왼쪽에서 오른쪽으로, 아래쪽 갈래는 오른쪽에서 왼쪽으로 진행해 가운데 결승에서 만난다. 열 제목도 `32강 … 4강 · 결승 · 4강 … 32강`으로 대칭이다. 우승 카드는 결승 위에 두고 세로선으로 잇는다. 1번 시드가 부전승을 먼저 받으므로 팀 수가 2의 거듭제곱이 아니면 양쪽 팀 수가 다를 수 있다. 이때 짧은 쪽을 통째로 내려 두 4강 카드를 결승과 같은 높이에 두고 가로선으로 잇는다.
- 960px 이하: 팀 수와 관계없이 한 방향 배치다. 대진표 위에 라운드 탭을 둔다. 대진표는 라운드 열 단위로 가로 스크롤하며 scroll-snap으로 열에 맞춘다. 탭을 누르면 그 열로 이동하고, 스크롤하면 보이는 열의 탭을 현재로 표시한다.
- 320px에서도 경기 카드 너비는 화면 너비에서 여백을 뺀 값을 넘지 않는다. 긴 팀 이름은 두 줄까지 표시하고 넘치면 말줄임한다.

## 동작과 예외

- 팀을 누르면 승자로 정하고 다음 경기 자리에 올린다. 상태 문구를 갱신한다.
- 이미 승자인 팀을 다시 누르면 승자를 취소한다. 다른 팀을 누르면 승자를 바꾼다.
- 취소·변경으로 이후 경기 결과가 사라지면 공용 Dialog로 `이후 경기 2개의 결과가 지워져요.`를 알리고 `바꾸기`·`취소`를 제공한다. 사라질 결과가 없으면 묻지 않는다.
- 다시 만들기·새 대진표는 결과가 1개 이상일 때만 확인한다. 새 대진표는 팀 목록을 유지하고 대진표와 결과만 지운다.
- 무작위 배치로 다시 만들면 새로 섞는다. 같은 무작위 대진표는 저장된 배치로만 복원한다.
- 페이지를 새로 열면 저장된 팀·설정·대진표·결과를 그대로 복원한다.
- Team Maker에서 이동해 온 경우 가져온 팀으로 대진표를 바로 만들고 대진표 섹션으로 스크롤한다. 기존 대진표에 결과가 있으면 먼저 `진행 중인 대진표가 있어요. 가져온 팀으로 바꿀까요?`를 묻는다. `기존 대진표 유지`를 고르면 가져온 팀을 버린다.
- 저장 실패는 대진표 섹션 위에 한 번 알리고 사용은 계속한다. 손상된 저장 정보는 무시하고 빈 목록으로 시작하며 그 사실을 알린다. 대진표만 손상됐으면 팀 목록은 그대로 두고 대진표만 지웠다고 알린다. 브라우저가 저장 공간 접근 자체를 막으면 저장 없이 사용할 수 있다고 알린다.

### 전체화면

- 대진표 섹션만 전체화면으로 연다. 제목·진행 상태·대진표·닫기 버튼만 보인다.
- 전체화면에서도 승자 기록과 확인 dialog를 사용할 수 있다. Escape나 닫기 버튼으로 나가고 초점을 전체화면 버튼으로 돌린다.
- 전체화면을 지원하지 않는 브라우저에서는 버튼을 숨긴다.

### 인쇄

- A4 가로 1장, 여백 10mm다. 제목·진행 상태·대진표만 출력하고 내비게이션·설정·안내·버튼·footer는 숨긴다.
- 화면의 넓은 대진표와 같은 카드·색·연결선·문구로 출력한다. 어두운 테마에서도 종이에는 밝은 테마 색을 쓴다.
- 32팀 대진표도 1장에 들어가도록 비율을 유지해 줄인다. 한 방향과 좌우 대칭 중 A4에 덜 줄여서 들어가는 배치로 출력한다. 승자는 화면과 같이 체크와 굵은 글씨로도 구분한다.
- 결과가 없는 대진표는 빈 칸으로 출력해 손으로 적을 수 있다.
- AdSense 코드는 다른 도구 페이지와 같이 넣는다. 대진표 섹션과 전체화면 안에는 광고 단위를 직접 두지 않고 인쇄물에는 광고를 출력하지 않는다.

## 사용 안내

DisclosureSection을 기본 펼침으로 사용한다.

- 사용법 3단계: 팀 입력 또는 Team Maker에서 가져오기 → 배치 순서 고르고 대진표 만들기 → 이긴 팀 누르기와 전체화면·인쇄
- 6팀 예제: 가상 팀 6개를 입력 순서로 배치한 결과를 정적 HTML로 보여 준다. 8강은 1-6, 2-5, 3-4 경기 3개다. 4강에서는 8강 1경기 승자가 부전승을 받고 나머지 두 승자가 경기한다.
- FAQ: 부전승은 누가 받나요, 결과는 어디에 저장되나요, 인쇄가 한 장에 안 들어가요, 17팀 이상도 되나요

## 접근성

- 경기 팀 버튼은 aria-pressed로 승자 여부를 알린다. 이름은 `8강 1경기, A팀을 승자로 정하기`처럼 라운드·경기·팀을 포함한다.
- 라운드 탭은 탭 패턴 대신 버튼 목록을 사용하고 현재 열에 aria-current를 둔다.
- 키보드만으로 팀 추가·삭제, 승자 선택, dialog, 전체화면을 사용할 수 있다.
- 밝은·어두운·시스템 테마에서 승자·패자·부전승 표시의 대비를 확인한다.

## 검증

- 팀 2~32개에서 라운드별 부전승 수, 연속 부전승 없음, 경기 수, 결승까지 진행을 확인한다.
- 승자 변경·취소 시 이후 결과 삭제 확인과 상태 문구를 확인한다.
- Team Maker에서 3팀·17팀 결과로 버튼 상태와 이동을 확인한다. 17팀은 넓은 화면에서 좌우 대칭 배치로 열린다. Team Maker 저장 데이터가 바뀌지 않는지 확인한다.
- 새로고침 복원, 저장 실패, 손상된 저장 정보 처리를 확인한다.
- 320px·390px·960px·1440px, 밝은·어두운 테마에서 가로 넘침과 긴 팀 이름을 확인한다.
- 16팀·32팀 대진표의 A4 가로 1장 인쇄를 확인한다.

## 미결 사항

- 공통 메뉴의 도구가 4개가 된다. 현재 세로 목록에 추가하며 묶음 재구성은 하지 않는다.
- PNG 저장은 경쟁 서비스가 모두 제공한다. 첫 버전 반응을 보고 추가를 결정한다.
