## 요청과 구현 범위

사용자 구현 승인: 2026-09-11 `https://www.teachercan.com/qr-code`처럼 QR 코드를 만드는 페이지 제작 요청. 참고 페이지의 입력·제목·북마크·복사·저장·인쇄·확대 흐름을 적용한다. 세부 색상과 component는 현재 사이트의 공통 디자인을 사용한다. 별도 시안 승인을 받은 것으로 기록하지 않는다.

## 화면 구성

- 미리보기 아래 qr-privacy-note는 표시하지 않는다. 작업 영역과 안내 사이 간격은 32px다.
- 사용법은 주소·제목 입력, 스캔 확인, 저장·복사·인쇄의 3단계로 짧게 설명한다. 제목 10자와 A4 1개·12개·30개 인쇄를 안내한다.
- FAQ는 유효기간·주소 변경, PNG·SVG 차이, 스캔 문제, 북마크 저장 위치의 4개로 구성한다. 각 답변은 2문장으로 정리한다.

- QR과 Team Maker의 번호가 있는 섹션 제목은 SectionHeader의 step 속성과 공통 ui-step-heading·ui-step-number 스타일을 사용한다.
- 미리보기 배경·캡션·빈 상태·생성 중 안내는 밝은·어두운·시스템 테마에 맞춘다. 스캔할 QR 사각형 자체는 흰 바탕과 검정 무늬를 유지한다. 크게 보기에도 같은 색상을 적용하며 출력 파일 색상은 유지한다.
- 북마크 항목 오른쪽에 8px 여백을 두어 X 버튼이 목록 끝에 붙지 않게 한다.

- 공통 내비게이션과 QR 코드 현재 위치 표시
- Team Maker와 같은 공용 ToolPageHeader로 제목과 용도 설명을 표시한다. 제목은 28px·800, 설명은 14px로 표시한다.
- 데스크톱: 왼쪽 입력·북마크, 오른쪽 미리보기·작업 버튼
- 760px 이하: 입력·북마크·미리보기 순서로 1열 배치
- 웹페이지 주소 한 줄 입력과 빨간색 필수 별표, 제목 10자·1줄과 선택 표시 생략
- 캡션 위쪽 마진은 없다. qr-input-error 요소와 고정 공간을 제거하며 입력 오류가 있을 때는 주소 도움말을 오류 문구로 바꾼다. 제목 안내는 ‘QR 이미지 아래에 한 줄로 표시됩니다(최대 10자).’로 표시한다.
- QR 미리보기 아래 버튼은 PNG·SVG 저장, 이미지 복사·크게 보기, 북마크에 저장·인쇄 순서로 2개씩 3줄에 배치한다. SVG 저장은 보라색으로 표시한다.
- 북마크 삭제는 Team Maker 참가자 삭제와 같은 X 아이콘·36px 버튼·호버 스타일을 사용한다.
- 기본 펼침 사용법과 FAQ, Team Maker와 같은 공용 ToolPageFooter의 운영자·개인정보처리방침

## 동작과 예외

- 한글 조합 중인 마지막 글자도 미리보기에 즉시 표시한다. 조합 중에는 입력창 값을 자르지 않으며 완료 시 보이는 글자 10자 제한을 적용한다. 미리보기와 저장 제목은 항상 최대 10자다.

- 주소를 수정한 뒤 200ms에 QR 무늬만 갱신한다. 생성 중에는 기존 무늬 위에 안내를 덮고 출력 버튼을 잠근다. 제목 변경과 파일 출력은 QR을 다시 계산하지 않는다.
- 미리보기 QR은 최대 280px이며 가운데 배치하고 좁은 화면에 맞춰 줄인다. 캡션은 일반 HTML 텍스트로 입력값을 즉시 표시하며 선택·복사할 수 있다. SUIT 700, 데스크톱 22px·모바일 20px를 기본으로 한 줄에 표시하며 좁은 화면에서만 글자를 줄인다. 제목을 가로·세로 가운데 맞춘다. 캡션 영역은 데스크톱 48px·모바일 44px이며 빈 제목에도 유지한다. 빈 상태는 QR 영역의 SVG 아이콘과 캡션 영역의 ‘QR 코드가 여기에 나타납니다’를 각각 가운데 표시한다. 주소 입력 요청 문구와 60자 측정용 문단은 제거한다.
- 데스크톱의 입력·북마크 열과 미리보기 카드는 위·아래가 일치한다. 입력 카드는 내용 높이를 유지하고 북마크 카드가 남은 공간을 채우며 목록 내부에서 스크롤한다. 모바일은 독립된 높이의 세로 배치를 유지한다.
- 입력 하단 안내·입력 지우기·상시 상태 문구·북마크 저장 위치 배지는 제거한다. qr-feedback과 고정 높이도 제거한다. 저장·복사 실패와 SVG 미지원·재시도는 필요한 경우에만 작업 버튼 아래에 표시하며 오류가 생기면 카드가 늘어날 수 있다. 처리 중 버튼은 크기를 유지하고 aria-busy와 중복 실행 방지를 적용한다.
- PNG·SVG 저장 시 클릭 당시 QR 경로와 제목으로 해당 형식만 생성한다. 출력 중 입력을 수정해도 파일 내용과 이름을 섞지 않는다. 복사·인쇄는 클릭 시 PNG를 생성하고 확대는 미리보기를 재사용한다.
- 주소는 웹페이지 주소용 한 줄 input으로 받으며 여러 줄 텍스트는 지원하지 않는다. 줄바꿈이 포함된 붙여넣기·드롭은 브라우저가 문자를 바꾸기 전에 거절하고 입력창의 기존 값을 유지한다. 오류를 알리고 QR 생성·저장·북마크 추가를 막는다. 주소를 수정하거나 한 줄 주소를 붙여넣거나 북마크를 불러오면 다시 검사한다. 줄바꿈이 포함된 북마크는 복원하지 않는다. 공백뿐인 입력에도 QR을 만들지 않는다.
- UTF-8 1,800바이트까지 받는다. input의 maxlength로 자르지 않고 입력 전체를 검사한다. 영문 약 1,800자, 한글 약 600자이며 초과하면 원문을 입력창에 유지한 채 QR 생성과 출력을 막고 이유를 표시한다.
- 흰 배경과 검정 QR, 최소 4칸 여백, 오류 복원 수준 M을 사용한다. QR 각 칸을 정수 픽셀로 그리고 가운데 배치한다. PNG·SVG·복사·인쇄는 너비 1,024px, QR 영역 768px, 위쪽 여백 32px를 사용한다. 제목은 QR 아래 32px를 띄우며 SUIT 700, 64px, 줄 간격 88px, 최대 너비 896px로 표시한다. 제목은 한 줄이며 실제 윤곽선 경계로 88px 영역의 가로·세로 가운데에 맞춘다. 제목이 있으면 높이는 952px, 빈 제목은 832px다.
- 제목은 이미지 아래에 표시하고 QR 내용에는 넣지 않는다. 제목을 파일 이름에도 사용한다.
- 복사를 지원하지 않거나 권한이 거절되면 PNG 저장을 안내한다.
- 북마크는 최대 30개다. 같은 내용·제목은 중복 저장하지 않는다. 저장 성공 후에만 목록에 반영한다.
- 북마크 삭제 뒤 마지막 삭제 1건을 취소할 수 있다. 페이지를 떠나면 취소 상태는 사라진다.
- 저장 실패나 손상된 저장 정보는 문구로 알리며 QR 생성은 계속 제공한다.
- 인쇄는 공용 Dialog에서 A4 세로 1장에 출력할 배열을 선택한다. 1열×1행(기본 1개), 3열×4행(12개), 5열×6행(30개)을 라디오 버튼으로 제공하고 선택은 페이지를 떠날 때까지 유지한다. 현재 QR과 제목을 동일하게 반복한다. 취소·닫기·Escape와 초점 복원을 지원한다.
- 설정을 열거나 배열을 바꿀 때 이미지를 생성하지 않는다. 인쇄하기를 누른 순간의 QR·제목·배열을 사용하고 PNG를 한 번 생성해 재사용한다. 모든 이미지가 준비되면 선택 창을 닫고 브라우저 인쇄 창을 연다. 실패는 선택 창에서 알리고 재시도할 수 있다. 준비 중 취소한 작업은 나중에 인쇄하지 않는다.
- 인쇄 여백 10mm, 칸 간격 4mm, 영역 190mm×276mm를 사용한다. 각 인쇄 칸 전체에 검정 실선 0.2mm와 내부 여백 2mm를 적용하며 테두리·여백을 칸 크기에 포함한다. 다운로드 파일에는 테두리를 넣지 않는다. 이미지를 비율대로 축소해 각 칸 가운데 배치하며 1개 출력은 최대 너비 140mm다. PDF는 A4·배율 100%·머리글/바닥글 없음으로 1장 출력과 QR 해독을 검사한다.
- 확대 dialog는 닫기와 Escape로 닫고 초점을 연 버튼으로 돌린다. 열린 동안 배경 스크롤을 막는다.
- 밝은·어두운 테마에서도 QR 이미지는 항상 흰 배경을 유지한다.
- 입력 내용은 외부 서버로 전송하지 않으며 북마크만 localStorage에 남긴다.

## 검증

한 줄 주소·한글·이모지의 QR 해독 결과, 제목 포함 다운로드, 빈 입력·초과 입력, 1,800자를 넘는 URL 붙여넣기의 원문 유지와 생성 차단, LF·CRLF 줄바꿈 붙여넣기의 거절과 오류 복구, 북마크 재방문·삭제 취소·저장 실패, 복사·인쇄·확대·Escape, 모바일 가로 넘침과 테마를 확인한다.

## 공용 UI와 SVG 제목 윤곽선

사용자 설계·구현 승인: 2026-09-11 공용 UI 정리와 제목 윤곽선을 포함한 SVG 저장 계획 구현 요청.

- 카드·제목·빈 상태·버튼은 기존 공용 component를 사용한다. 입력창은 기본 입력 요소를 유지한다.
- 두 안내는 공통 DisclosureSection의 카드·CSS 삼각형·초점 표시를 사용한다. 기본 마커를 숨기고 삼각형과 제목을 세로 가운데 정렬하며 간격은 12px다. Team Maker 하단 안내와 같은 표현이다.
- PNG·SVG 저장은 같은 줄의 별도 버튼이다. 아래에는 이미지 복사·인쇄·확대를 둔다.
- 미리보기·PNG·SVG 제목은 SUIT 700을 사용한다. PNG·SVG는 같은 경로와 배치를 사용하며 미리보기 캡션은 제목 문자열을 받는 일반 텍스트다. 제목 수정 시 제목의 지원 여부·윤곽선·한 줄 배치만 준비한다.
- SVG에는 흰 배경과 `qr-code`, `qr-title` 벡터 그룹을 넣는다. text·글꼴 참조·삽입 PNG는 사용하지 않는다.
- SUIT에 없는 제목 글자는 구체적으로 안내하고 SVG만 제한한다. 미리보기와 PNG는 SUIT 700을 기본으로 사용하며 SUIT에 없는 글자만 시스템 글꼴로 표시한다. QR에 담는 원문에는 영향을 주지 않는다.
- 글꼴을 읽거나 변환하지 못하면 제목 처리만 다시 시도한다. PNG 저장은 계속 사용할 수 있으며 재시도 중 누르면 제목 처리가 끝난 후 PNG를 생성한다.
- 제목이 없으면 글꼴 처리 코드를 불러오지 않는다. 글꼴은 성공한 결과를 재사용하며 실패한 로딩은 다시 시도할 수 있다.
- 제목은 공백을 포함해 보이는 글자 단위로 10자까지 허용한다. 이모지·결합 문자를 나누지 않고 한글 조합 중에는 입력을 자르지 않는다. 북마크 복원도 같은 10자·한 줄 기준을 적용한다. 기존 북마크가 없다는 사용자 확인에 따라 별도 변환은 없다. 한글 정규화는 NFC를 사용한다.

사용자 추가 구현 승인: 미리보기 높이 유지, 주소·제목 처리 분리, 버튼 클릭 시 이미지 생성과 SUIT 700 기본 사용. 제목 지원 검사는 제목 수정 시 실행하기로 선택했다.

사용자 추가 설계·구현 승인: 2026-09-11 QR 미리보기와 두 열의 배치 정리 계획. 캡션 일반 텍스트, QR·제목 크기, 출력 좌표, 안내 삭제와 북마크 내부 스크롤을 위 내용대로 반영한다. 320px·390px 모바일, 두 테마, 북마크 0개·1개·30개, 60자·이모지·오류 상태, 출력 해독과 글꼴 없는 SVG 렌더링을 검증한다.

사용자 추가 설계·구현 승인: 2026-09-11 QR 여백 축소와 인쇄 배열 선택 계획. 최대 제목 높이 유지와 인쇄 선택 창을 사용자가 선택했다. qr-feedback 제거, 너비별 한글 60자 높이 확보, A4 1개·12개·30개 인쇄를 위 내용대로 적용한다.

최신 사용자 설계·구현 승인: 2026-09-11 QR 제목 10자 제한과 정렬·인쇄 테두리 정리 계획. 제목은 10자·1줄이며 캡션 높이는 데스크톱 48px·모바일 44px다. 이전 60자 높이 측정은 이 결정으로 대체한다. 사용자가 인쇄 칸 전체 테두리를 선택했으며 기존 북마크가 없음을 확인했다. 빈 상태 분리와 공용 접기 화살표 정렬도 함께 적용한다.
