## 구성과 동작

공통 SiteShell·ToolPageLayout·ToolPageFooter를 조합한다. 제목은 ‘블로그’, 설명은 ‘경험과 생각, 일상의 이야기를 기록합니다.’다. 본문의 홈 링크를 제거하고 RSS 구독은 footer의 개인정보처리방침과 같은 글자색·밑줄 스타일로 그 옆에 둔다. 본문에는 한 열의 글 목록과 하단 페이지 이동을 두고 오른쪽에 카테고리를 배치한다. 프로그램 선택은 제공하지 않는다. 글 카드에는 선택적 프로그램·종류·게시일·제목 링크·요약을 표시한다. Section·SectionHeader·Button·EmptyState를 재사용한다.

카테고리는 전체 글과 공개 글이 있는 분류만 표시한다. 각 항목에 공개 글 수를 표시하며 목록 위의 별도 글 수 문구는 제공하지 않는다. 선택하면1페이지로 이동한다. 글은 페이지당6개이며 하단에 이전·최대5개의 페이지 번호·다음 버튼을 둔다. 페이지 숫자에는 font-feature-settings의 tnum을 적용해 숫자 폭을 맞춘다. 첫 페이지와 마지막 페이지에서는 해당 이동 버튼을 비활성화한다. 선택은 URL의 category·page에 남기며 새로고침·뒤로가기에 유지한다. 잘못된 카테고리는 전체 글로, 잘못된 페이지는1페이지로, 범위를 넘는 페이지는 마지막 페이지로 표시한다. 기본 HTML에는 모든 공개 글 링크를 포함한다. JavaScript 없이도 모든 글에 접근할 수 있다. 공개 글이 없으면 준비 안내를, 선택한 카테고리가 비어 있으면 전체 글 보기 버튼을 제공한다. 검색창은 없다.

개발 서버에서만 별도의 초안 목록을 제공한다. 초안과 공개 목록의 빈 상태를 구분한다. 초안은 공개 build에 포함하지 않는다.

## 화면과 접근성

공통 여백과 토큰을 사용한다. 최대 너비1200px, 카드 간격16px, 영역 간격24px다. 1280px 이상에서는 오른쪽240px 카테고리가 스크롤을 따라 고정된다. footer는 카테고리를 제외한 글 목록 너비에 맞춘다. 좁은 화면에서는 카테고리를 글 목록 위에 표시한다. 긴 제목·링크는 줄바꿈한다. 선택한 카테고리와 현재 페이지를 접근성 속성으로 전달한다. 페이지·카테고리 변경 후 글 목록 영역으로 초점을 옮긴다. 공통 내비게이션·테마·개인정보 모달·기존 통계 동의를 유지한다. 블로그에는 새 추적 항목을 추가하지 않는다.
