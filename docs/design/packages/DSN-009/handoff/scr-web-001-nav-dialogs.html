팀 메이커 · 내비게이션과 dialog

사이드바 고정 해제와 drawer, 그리고 참가자 입력·규칙·명단·참가자 통계 dialog를 담습니다. 초점 이동, Tab 제한, Escape 닫기와 복귀 초점을 프레임에 함께 적었습니다.

사이드바 고정 해제와 drawer

고정을 풀면 사이드바를 숨기고 화면 위에 떠 있는 44px 메뉴 버튼만 남깁니다. 버튼을 누르면 왼쪽 drawer가 열리고 초점은 첫 이동 항목인 “홈”으로 옮겨갑니다. 열려 있는 동안 본문 스크롤은 멈춥니다.

입력과 명단 dialog

dialog는 흰 surface에 12px 모서리, hairline 한 줄과 2단계 그림자를 쓰고 배경은 40% 검은색으로 덮습니다. 제목과 설명을 aria-labelledby·aria-describedby로 연결하고 닫기 버튼과 Escape를 함께 제공합니다.

참가자 통계 dialog

오늘 기록만으로 최다 승리·최다 당첨·최다 패배와 같은 팀 궁합, 참가자별 표를 보여 줍니다. 전체 기록 통계는 여기가 아니라 기록 보기 위쪽에 있습니다. 두 곳이 세는 범위가 달라서 각 화면에 그 범위를 글로 적습니다.
