# DSN-009 반복 markup 메모

정적 화면 문서라 같은 조각을 frame마다 다시 적는다. 아래는 손으로 맞추어 볼 때 쓰는 기준이다.
DSN-008에서 시각 체계는 바뀌지 않았고 화면 요소 7개가 늘었다.

## 사이드바 (팀 메이커가 현재 위치)

- 사이트 이름 `Lake's develog` → 루트로 이동
- 테마 버튼, 사이드바 고정 버튼
- `홈` → SCR-WEB-002
- 묶음 `프로젝트` → `팀 메이커` (`aria-current="page"` + `현재` 배지)

## 본문 순서 (SCR-WEB-001 승인 snapshot)

1. 공통 내비게이션
2. 제목 `팀 메이커` 와 설명 한 줄
3. 브라우저 저장 실패 안내 (실패했을 때만)
4. `1. 참가자 입력` 카드
5. `2. 나누는 방식` 카드
6. `팀 만들기` 버튼과 비활성화 이유
7. `3. 결과` — 빈 결과 또는 오류, 팀 카드, `결과 복사`, `다시 섞기`, 순위 기록·취소, 팀별 추첨,
   팀 격자 아래 `당첨자` 영역
8. `4. 통계` — 오늘 기록, 경기 수, `참가자 통계`, `기록 보기`, 오늘 기록 지우기, 개별 기록 삭제

## 결과 머리의 버튼 순서

왼쪽부터 `승리 취소`(3팀 이상은 `순위 취소`) · `결과 복사` · `다시 섞기`.
`다시 섞기`만 옅은 파란 채움(`.btn-soft`)이고 나머지는 흰 utility 버튼이다.

## 통계 머리의 버튼 순서

왼쪽부터 `참가자 통계` · `기록 보기` · 오늘 기록 지우기 휴지통(`.circle-btn.danger`, 36px).
휴지통만 아이콘 버튼인 까닭은 390px에서 글자 버튼 3개가 한 줄에 들어가지 않기 때문이다.

## 참가자 수 표기

`1. 참가자 입력` 머리의 `.count`는 괄호 안에 수만 적는다.

- 전원 참가: `(8명)`
- 체크를 해제한 사람이 있을 때: `(8명 중 6명 참가)`

## 예시 참가자

김지원, 이서준, 박하은, 최민수, 정예린, 강도윤, 윤서아, 임태호 (8명)

- 같은 팀: 김지원 · 박하은
- 다른 팀: 이서준 · 최민수
- 2팀 결과: 1팀 김지원·박하은·정예린·이서준 / 2팀 최민수·강도윤·윤서아·임태호
- 5팀 결과: 1팀 김지원·박하은 / 2팀 정예린·이서준 / 3팀 최민수·강도윤 / 4팀 윤서아 / 5팀 임태호

## 순위 배지

팀이 2개일 때와 3개 이상일 때 문구가 다르다. 어느 쪽이든 색에만 기대지 않는다.

- 2팀: 팀 이름과 승패를 붙여 한 덩어리로 적는다. `1팀승` · `2팀패`
- 3팀 이상: 등수 숫자로 적는다. `꼴등` 같은 말은 쓰지 않는다.
  - 팀 이름이 바로 옆에 보이는 결과 카드 chip: `1등` · `5등`
  - 팀 이름이 없는 기록 목록: `1팀 1등` · `5팀 5등`
- 아직 등수를 못 받은 팀: `순위 미정`, 점선 테두리

색은 `data-place` 로 정한다. `first` 파랑 · `middle` 주황 · `last` 빨강 · `none` 연한 회색.
중간 등수가 여럿이면 카드 인라인 `--rank-progress`(0~1)로 주황에서 빨강 쪽까지 단계를 준다.
5팀이면 2등은 `0`, 3등은 `0.5`, 4등은 `1`이다. 이웃한 등수끼리는 색 차이가 작으므로 등수
숫자를 늘 글로 함께 적는다.

## 당첨자

당첨자는 팀 카드 안이 아니라 `3. 결과`의 팀 격자 아래 `당첨자` 영역에 팀별로 모은다.
팀 카드 높이가 뽑을 때마다 흔들리지 않게 하려는 것이다.

- 묶음 하나가 팀 하나다. 팀 이름 색만 순위를 따라가고 나머지는 늘 초록이다.
- 각 줄은 순번 동그라미 + 이름 + 취소 버튼. 데스크톱 28px, 모바일 44px.
- 기록 목록에서는 그 팀 줄 끝에 `당첨 정예린, 김지원` 초록 알약으로 붙는다.

## 삭제 확인 세 줄

1. 제목 — 무엇을 지우는지 (`참가자 명단을 삭제할까요?`)
2. 설명 — 지워지는 것과 그대로 남는 것
3. 경고 — `되돌릴 수 없습니다.` (`.confirm-warn`, 빨간 굵은 글씨)

실행 버튼 `.btn-danger` 는 sticker 빨강으로 면을 채운다. 초점은 안전한 쪽인 취소가 먼저 받는다.

오늘 기록 지우기도 같은 모양을 쓰되 마지막 줄만 다르다. 화면 표시만 사라지고 기록 보기에는
그대로 남으므로 `기록 보기에는 그대로 남습니다.` 라고 적고 되돌릴 수 없다고 적지 않는다.

## 돌림판

현재 구현과 같다. **아직 안 뽑힌 사람 수만큼** 파스텔 조각을 두르고 이름표는 조각 위에 눕힌다.
뽑을 때마다 조각이 하나씩 줄고, 다 뽑으면 버튼이 `모두 뽑음` 으로 멈춘다.

- 크기: 데스크톱 360px, 당첨자가 있으면 320px, 모바일 298px
- 흰 테 6px 과 바깥 그림자
- 가운데는 지름 24px 원 하나로 조각이 만나는 점만 가린다
- 조각 색: `#f39a8f` `#f7bd76` `#ecd772` `#9ed48b` … 8색을 순서대로 돌려 쓴다
- 이름표 색: `#7a261e` `#6b3d0a` `#665b09` `#285d22` … 조각과 같은 순서
- 이름표 위치: `--label-angle` 은 조각 가운데 방향. 조각이 n개면 `360 / n / 2` 부터 `360 / n` 씩 더한다
- 판이 도는 동안에는 소리를 내지 않는다. 멈춘 뒤에 당첨 팡파르만 울린다

당첨자가 한 명이라도 있으면 dialog에 `has-picks` 를 붙인다. 640px 이상에서는 dialog가 620px로
넓어지고 판이 320px로 줄면서 우측에 당첨자 목록이 세로로 선다. 그보다 좁으면 판 아래에 가로로 눕는다.
