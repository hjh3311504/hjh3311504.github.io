# 팀짜기

| 항목 | 내용 |
|---|---|
| 화면 ID | `SCR-WEB-001` |
| 화면 이름 | 팀짜기 |
| 연결 REQ | `REQ-WEB-001`, `REQ-WEB-002`, `REQ-WEB-003`, `REQ-WEB-005`, `REQ-WEB-006`, `REQ-WEB-007`, `REQ-WEB-009`, `REQ-WEB-010`, `REQ-WEB-011`, `REQ-WEB-012` |

## 목적

모임 진행자가 참가자 이름과 팀 수를 입력해 인원 차이가 최대 1명인 무작위 팀을 만들고 결과를 복사한다.

## 화면 구성

위에서 아래로 다음 순서를 유지한다.

1. 제목 “팀 나누기”와 설명 “이름을 넣고 팀 수를 고르면 고르게 나눠 드려요.”
2. 설정 카드: 참가자 입력, 현재 참가자 수, 팀 수, 팀 만들기, 입력 안내
3. 결과 카드: 팀 이름, 참가자 목록, 다시 섞기, 결과 복사
4. 사용 방법
5. FAQ
6. 개인정보 안내
7. 루트 사이트로 돌아가기

홍보용 hero나 광고 영역은 주요 기능보다 앞에 두지 않는다.

## 상태와 동작

| 상태·동작 | 조건 | 사용자에게 보이는 결과 |
|---|---|---|
| 처음 방문 | 저장된 값이 없음 | 빈 참가자 입력, 기본 팀 수 2, 참가자 수 0명, 비활성화된 팀 만들기와 “참가자를 2명 이상 입력하세요” 안내 |
| 저장값 복구 | 저장된 참가자 입력과 팀 수가 있음 | 저장값을 채우고 정리된 참가자 수와 현재 검증 결과를 바로 표시 |
| 이름 정리 | 사용자가 여러 줄 이름을 입력 | 빈 줄과 앞뒤 공백을 제외한 수를 즉시 표시하며 같은 이름은 각각 1명으로 계산 |
| 참가자 부족 | 정리된 참가자가 2명 미만 | 팀 만들기를 비활성화하고 참가자가 2명 이상 필요하다고 표시 |
| 팀 수 오류 | 팀 수가 2 미만이거나 참가자 수보다 많음 | 팀 만들기를 비활성화하고 해당 이유를 표시 |
| 만들기 가능 | 참가자와 팀 수가 유효함 | 강조된 팀 만들기 버튼을 활성화하고 오류 안내를 숨김 |
| 결과 생성 | 사용자가 팀 만들기를 실행 | 결과 카드에 `팀 1`, `팀 2` 순서의 이름과 참가자 목록을 표시하고 결과 제목으로 초점을 이동 |
| 다시 섞기 | 결과가 있고 사용자가 다시 섞기를 실행 | 입력과 팀 수를 유지한 채 결과 목록만 새 배정으로 교체하고 변경 사실을 알림 |
| 결과 복사 | 결과가 있고 사용자가 복사를 실행 | 모든 팀 이름과 참가자 목록을 복사하고 성공 또는 실패를 글로 알림 |
| 결과 뒤 입력 변경 | 결과가 있는 상태에서 이름이나 팀 수를 변경 | 이전 결과를 숨겨 입력과 맞지 않는 결과를 복사하지 못하게 함 |
| 저장 내용 삭제 | 사용자가 삭제를 누르고 확인함 | 브라우저 저장값, 현재 입력, 결과를 지우고 팀 수를 2로 되돌린 뒤 삭제 완료를 알림 |
| 브라우저 저장 실패 | 브라우저가 저장을 허용하지 않음 | 팀 만들기는 계속 제공하고 새로고침 뒤 복구되지 않을 수 있음을 글로 알림 |

## 화면 전용 제약

- 참가자 데이터의 소유자는 현재 브라우저 사용자이며 외부 서버로 전송하지 않는다.
- 참가자 입력은 한 줄에 한 명이라는 label과 예시를 제공한다.
- 팀 수는 숫자 입력으로 제공하고 기본값은 2로 둔다.
- 복사 결과는 `팀 1` 제목, 각 참가자의 `- 이름` 목록, 팀 사이 빈 줄 순서의 일반 텍스트로 만든다.
- 입력 안내와 복사·삭제 결과는 보조 기술도 읽을 수 있는 상태 영역에 표시한다.
- 모바일과 PC 모두 1열 순서를 유지하며 작은 화면에서 버튼과 결과가 가로로 넘치지 않게 한다.
- 모든 입력과 버튼에는 보이는 label과 키보드 초점 표시를 제공한다.
- 오류, 비활성화, 성공 상태는 색상뿐 아니라 문구와 아이콘 또는 모양으로도 구분한다.
- 삭제는 되돌릴 수 없으므로 실행 전에 확인한다.
- 개인정보 안내에는 이름이 브라우저에만 저장되고 외부로 전송되지 않는다고 명시한다.
- 루트 링크는 같은 origin의 `/`로 이동한다.
- 사용 방법은 이름 입력, 팀 수 선택, 결과 활용의 3단계로 설명한다.
- FAQ는 중복 이름 처리, 인원 균등 배정, 브라우저 저장, 개인정보 전송 여부를 답한다.
