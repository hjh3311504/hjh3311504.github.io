# 정보 구조

## 범위

- surface: `web`
- route: `/team-maker/`
- 관련 REQ: `REQ-WEB-001`, `REQ-WEB-002`, `REQ-WEB-003`, `REQ-WEB-005`, `REQ-WEB-006`, `REQ-WEB-007`, `REQ-WEB-009`, `REQ-WEB-010`, `REQ-WEB-011`, `REQ-WEB-012`

## 화면과 이동

| 화면 ID | 목적 | 주요 이동 |
|---|---|---|
| `SCR-WEB-001` | 참가자와 팀 수를 입력해 고르게 나눈 결과를 만들고 복사한다. | 직접 방문 → `SCR-WEB-001` → 루트 사이트 `/` |

입력, 오류, 결과, 다시 섞기, 복사는 별도 화면으로 나누지 않고 한 페이지의 상태 변화로 처리한다.
