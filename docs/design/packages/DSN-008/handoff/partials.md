# DSN-008 반복 markup 메모

정적 화면 문서라 같은 조각을 frame마다 다시 적는다. 아래는 손으로 맞추어 볼 때 쓰는 기준이다.

## 사이드바 (팀 메이커가 현재 위치)

- 사이트 이름 `Lake's develog` → 루트로 이동
- 테마 버튼, 사이드바 고정 버튼
- `홈` → SCR-WEB-002
- 묶음 `프로젝트` → `팀 메이커` (`aria-current="page"` + `현재` 배지)

## 본문 순서 (SCR-WEB-001 승인 snapshot)

1. 공통 내비게이션
2. 제목 `팀 메이커` 와 설명 한 줄
3. 브라우저 저장 실패 안내 (실패했을 때만)
4. `1. 참가자 입력` 카드
5. `2. 나누는 방식` 카드
6. `팀 만들기` 버튼과 비활성화 이유
7. `3. 결과` — 빈 결과 또는 오류, 팀 카드, 다시 섞기, 승리 기록·취소, 팀별 추첨
8. `4. 통계` — 오늘 기록, 경기 수, 기록 보기와 개별 기록 삭제

## 참가자 수 표기

`1. 참가자 입력` 머리의 `.count`는 괄호 안에 수만 적는다.

- 전원 참가: `(8명)`
- 체크를 해제한 사람이 있을 때: `(8명 중 6명 참가)`

## 예시 참가자

김지원, 이서준, 박하은, 최민수, 정예린, 강도윤, 윤서아, 임태호 (8명)

- 같은 팀: 김지원 · 박하은
- 다른 팀: 이서준 · 최민수
- 결과: 1팀 김지원·박하은·정예린·이서준 / 2팀 최민수·강도윤·윤서아·임태호

## 프레임 번호

팀 메이커는 문서 6개로 나눠 담았다. 문서마다 위 차례로 서로 오간다.

| 파일 | 프레임 | 내용 |
|---|---|---|
| `scr-web-001-team-maker.html` | T1–T2 | 기본 흐름 · 밝은 테마 |
| `scr-web-001-results.html` | T3–T5 | 결과와 승리 기록, 어두운 테마 |
| `scr-web-001-errors.html` | T6–T8 | 안내와 오류 |
| `scr-web-001-nav-dialogs.html` | T9–T13 | 고정 해제·drawer와 입력·명단 dialog |
| `scr-web-001-draw-confirm.html` | T14–T18 | 팀별 추첨과 삭제 확인 |
| `scr-web-001-mobile.html` | T19–T23 | 모바일 상태 |

`scr-web-002-home.html` 은 H1–H7 을 담는다.

## 승패 배지

승패는 팀 이름과 붙여 한 덩어리로 적는다. 이긴 팀은 `1팀승`, 진 팀은 `2팀패` 형태다.
`1등`·`2등` 같은 등수 표기는 쓰지 않는다.

## 삭제 확인 세 줄

1. 제목 — 무엇을 지우는지 (`참가자 명단을 삭제할까요?`)
2. 설명 — 지워지는 것과 그대로 남는 것
3. 경고 — `되돌릴 수 없습니다.` (`.confirm-warn`, 빨간 굵은 글씨)

실행 버튼 `.btn-danger` 는 sticker 빨강으로 면을 채운다. 초점은 안전한 쪽인 취소가 먼저 받는다.

## 돌림판

현재 구현과 같다. 참가자 수만큼 파스텔 조각을 두르고 이름표는 조각 위에 눕힌다.

- 크기: 데스크톱 360px, 모바일 298px
- 흰 테 6px 과 바깥 그림자
- 가운데는 지름 24px 원 하나로 조각이 만나는 점만 가린다
- 조각 색: `#f39a8f` `#f7bd76` `#ecd772` `#9ed48b` … 8색을 순서대로 돌려 쓴다
- 이름표 색: `#7a261e` `#6b3d0a` `#665b09` `#285d22` … 조각과 같은 순서
