쓴 디자인 시스템

이 project에 직접 연결된 Draft 디자인 시스템인 Notion을 그대로 썼습니다. 조직 기본값은 쓰지 않았습니다. 모든 화면 CSS는 _ds/notion-e5ec3c58-0bba-4770-8bb2-3cee184c0cb2/styles.css를 불러와 토큰을 그대로 씁니다.

역할 값 쓰는 곳
따뜻한 canvas --canvas #f6f5f4 페이지 바탕. 임의의 흰색 바탕을 쓰지 않는다.
흰 surface --surface #ffffff 카드, 입력 칸, 사이드바, drawer, dialog
hairline --hairline #e6e6e6 면을 나누는 1px 선. 가로 구분선 대신 쓴다.
구조적 accent --primary #0075de 기본 버튼, 링크, 현재 메뉴, 초점 테두리, 승리 chip. 이 밖에는 쓰지 않는다.
장식 sticker 팀 카드 위 띠, 루트 홈 아이콘 타일. 버튼과 구조에는 쓰지 않는다.
돌림판 조각 돌림판 조각과 이름표에만 쓴다. 현재 구현의 8색을 그대로 옮겼다.
경고 --accent-orange-deep #793400 저장 실패, 배정 실패, 삭제 확인의 글자와 테두리
글꼴 SUITE 제목 · SUIT 본문 제목은 700, 본문은 400을 넘지 않는다.
모서리 4px 입력 · 8px 버튼 · 12px 카드와 dialog 입력 칸은 알약 모양으로 만들지 않는다.
어두운 테마 #1a1918 #262523 #403d3a Notion에 없으므로 현재 구현의 검증된 값을 그대로 쓴다. 구조적 accent는 밝은 테마와 같은 Notion --primary #0075de를 유지하고 새 색 체계를 만들지 않았다.

색을 못 보아도 읽힐 수 있게

상태를 색으로만 알리지 않습니다. 모든 상태에 글자를 넣었고, 승패를 뺀 나머지에는 모양도 함께 넣었습니다. 승패는 “1팀승”·“2팀패”처럼 팀 이름과 결과를 붙여 적어 글자로 구분합니다.

상태 글자 모양 색
승리 “1팀승” 살짝 떠오른 카드 파란 채움과 흰 글자
패배 “2팀패” 알약 붉은 글자와 옅은 붉은 채움
당첨 “당첨자 · 이름” 체크 표시 기본 글자색
비활성화 버튼 아래 멈춘 이유 한 줄 점선 테두리 + 자물쇠 연한 바탕
오류 무엇이 안 됐는지 + 무엇을 고칠지 왼쪽 굵은 선 + 경고 모양 주황색 계열
같은 팀 · 다른 팀 “같은 팀” · “다른 팀” 안으로 모이는 화살표 + 실선 / 밖으로 벌어지는 화살표 + 점선 같은 글자색
현재 메뉴 “현재” 배지 + aria-current="page" 왼쪽 막대 + 굵은 글씨 파란 바탕

만들지 않은 것

  • 보류 화면인 프로젝트 상세 화면은 만들지 않았습니다.
  • 블로그 목록, 글 본문, RSS, SvelteKit 템플릿 안내는 넣지 않았습니다.
  • 능력치 모드, 주장 지정, 결과 복사, 사용 방법, FAQ, 개인정보 안내 문구는 없습니다.
  • 다국어, 후원, 공유 링크, 실제 광고, 로그인, server 저장, 기기 간 동기화는 넣지 않았습니다.
  • 문서에 없는 로딩·권한 상태를 지어내지 않았습니다.
  • REQ-SEO-001은 화면에 드러나는 요구사항이 아니므로 시각 결과와 연결하지 않았습니다.
  • 참가자 정보를 밖으로 보내거나 server에 저장하는 표현은 넣지 않았습니다. 명단 dialog에도 “이 브라우저에만 보관하며 밖으로 보내지 않습니다”라고 적었습니다.
