팀별 추첨과 승패 기록

돌림판은 현재 구현을 그대로 씁니다. 참가자 수만큼 파스텔 조각을 두르고, 이름은 자기 조각 위에 눕혀 흰 그림자로 띄웁니다. 가운데는 지름 24px 원 하나로 조각이 만나는 점만 가립니다. 당첨자는 색이 아니라 “당첨자”라는 글과 체크 모양으로 알립니다.

되돌릴 수 없는 삭제 확인

참가자 명단 삭제, 저장 명단 삭제, 기록 삭제 세 가지 모두 같은 틀을 씁니다. 제목에 무엇을 지우는지 적고, 설명에 지워지는 것과 그대로 남는 것을 적고, 마지막 줄에 되돌릴 수 없습니다.를 빨간 굵은 글씨로 따로 둡니다. 실행 버튼은 sticker 빨강으로 면을 채워 취소 버튼과 무게를 다르게 하고, 초점은 안전한 쪽인 취소가 먼저 받습니다.
