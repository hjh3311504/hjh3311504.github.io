## 화면과 이동

| 화면 ID | 목적 | 주요 이동 |
|---|---|---|
| `SCR-WEB-002` | 방문자가 개발자와 현재 공개된 도구·콘텐츠를 이해하고 세로 목록에서 원하는 항목을 연다. | 직접 방문 → 세로 목록에서 Team Maker 또는 Blog 선택 |
| `SCR-WEB-001` | 참가자를 관리하고 조건에 맞춰 팀을 나눈 뒤 승패와 팀별 추첨을 기록한다. | 공통 헤더 또는 직접 방문 → 참가자 입력 → 나누는 방식 → 결과 |

루트, Team Maker와 Blog는 같은 공통 내비게이션을 사용한다. `1201px` 이상에서는 왼쪽 사이드바를 기본 고정하고 본문을 그 오른쪽에 배치한다. 사용자가 고정을 풀면 사이드바를 숨기고 상단 bar의 메뉴 버튼으로 여는 왼쪽 drawer로 전환한다. `1200px` 이하에서는 처음부터 상단 bar와 같은 drawer를 사용한다.

내비게이션에는 로고, 홈, 프로젝트 묶음, Blog, 테마 조작과 고정 전환을 둔다. 프로젝트 묶음에는 Team Maker와 이후 공개할 프로젝트를 세로로 추가한다. 현재 화면은 글과 모양으로 표시한다. Team Maker에서는 본문의 밝은 시각 체계를 유지하며 테마 조작을 숨긴다.

현재 공개된 블로그 글 3개는 내용을 유지한다. `/blog/`에서 전체 목록을 보여주고 각 글은 `/blog/<slug>/`에서 연다. `/sitemap.xml` route는 유지하며 sitemap 안의 글 주소만 새 경로를 사용한다.

루트의 `둘러보기` 목록은 한 열로 쌓는다. 현재는 Team Maker와 Blog를 각각 독립된 항목으로 보여주며, 새 프로젝트가 공개되면 같은 형식의 항목을 아래에 추가한다. 항목 수가 늘어나도 공통 헤더에 모든 프로젝트 링크를 나열하지 않는다.

참가자 일괄 추가, 규칙 선택, 명단 저장·불러오기, 승패 기록, 팀별 추첨과 삭제 확인은 새 route가 아닌 Team Maker 화면의 dialog로 처리한다.
