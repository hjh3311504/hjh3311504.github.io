팀별 추첨과 전체 기록

돌림판은 현재 구현을 그대로 씁니다. 아직 안 뽑힌 사람 수만큼 파스텔 조각을 두르고, 이름은 자기 조각 위에 눕혀 흰 그림자로 띄웁니다. 뽑을 때마다 조각이 하나씩 줄고, 다 뽑으면 버튼이 멈춥니다. 지금까지의 당첨자는 넓은 화면에서 판 우측에, 좁은 화면에서는 판 아래에 순번과 함께 쌓입니다.

되돌릴 수 없는 삭제 확인

참가자 명단 삭제, 저장 명단 삭제, 기록 삭제 세 가지 모두 같은 틀을 씁니다. 제목에 무엇을 지우는지 적고, 설명에 지워지는 것과 그대로 남는 것을 적고, 마지막 줄에 되돌릴 수 없습니다.를 빨간 굵은 글씨로 따로 둡니다. 실행 버튼은 sticker 빨강으로 면을 채워 취소 버튼과 무게를 다르게 하고, 초점은 안전한 쪽인 취소가 먼저 받습니다.

빈 기록과 오늘 기록 초기화

기록이 하나도 없을 때의 전체 기록과, 오늘 기록을 화면에서만 지우는 확인을 담습니다. 오늘 기록 지우기는 삭제가 아니라 표시 감추기라 확인 문구의 마지막 줄이 삭제 확인과 다릅니다.
