## 화면과 이동

| 화면 ID | 목적 | 주요 이동 |
|---|---|---|
| `SCR-WEB-002` | 방문자가 개발자와 현재 공개된 도구를 이해하고 세로 목록에서 원하는 항목을 연다. | 직접 방문 → 세로 목록에서 팀 메이커 선택 |
| `SCR-WEB-001` | 참가자를 관리하고 조건에 맞춰 팀을 나눈 뒤 승패와 팀별 추첨을 기록하고 통계를 확인하며 사용법과 개인정보 처리 방식을 이해한다. | 공통 헤더 또는 직접 방문 → 참가자 입력 → 나누는 방식 → 결과 → 통계 → 사용 안내·FAQ |

루트와 팀 메이커는 같은 공통 내비게이션을 사용한다. `1201px` 이상에서는 왼쪽 사이드바를 기본 고정하고 본문을 그 오른쪽에 배치한다. 사용자가 고정을 풀면 사이드바를 숨기고 화면 위 메뉴 버튼으로 여는 왼쪽 drawer로 전환한다. `1200px` 이하에서도 같은 drawer를 사용한다. 팀 메이커는 상단 bar에 메뉴 버튼을 두고, 루트 홈은 화면 위에 떠 있는 메뉴 버튼을 둔다.

내비게이션에는 사이트 이름, 홈, 프로젝트 묶음, 테마 조작과 고정 전환을 둔다. 프로젝트 묶음에는 팀 메이커와 이후 공개할 프로젝트를 세로로 추가한다. 현재 화면은 글과 모양으로 표시한다. 루트 홈과 팀 메이커는 같은 밝은·어두운 테마를 사용한다.

블로그 목록, 모든 글과 RSS route는 제공하지 않는다. `/sitemap.xml` route는 유지하며 루트, 팀 메이커와 QR 코드 주소를 포함한다.

루트의 `둘러보기` 목록은 한 열로 쌓는다. 현재는 팀 메이커와 QR 코드를 독립된 항목으로 보여주며, 새 프로젝트가 공개되면 같은 형식의 항목을 아래에 추가한다. 현재 공개된 도구 2개의 링크를 공통 내비게이션에 표시한다. 항목이 더 늘면 메뉴 구성을 다시 검토한다.

참가자 일괄 추가, 규칙 선택, 명단 저장·불러오기, 승패 기록, 참가자 통계, 팀별 추첨과 삭제 확인은 새 route가 아닌 팀 메이커 화면의 dialog로 처리한다.

팀 메이커의 3단계 사용법, 활용 상황, 주요 기능과 FAQ는 같은 `/team-maker` 화면에서 도구 뒤에 이어진다. 각 안내 섹션은 처음에는 펼치고 제목을 눌러 따로 접거나 다시 펼칠 수 있다. 별도 검색용 route를 만들지 않으며 검색 사용자와 기존 사용자에게 같은 내용을 제공한다.

개인정보처리방침은 홈·QR 코드 footer와 Team Maker 안내 마지막에서 여는 모달로 제공한다. 새 route를 추가하지 않는다.

정적 404와 동적 오류 화면은 공통 내비게이션과 한국어 오류 안내를 사용한다. 홈 이동 버튼을 제공하고 검색 색인에서는 제외한다. 상품 화면이나 sitemap 항목을 새로 추가하지 않는다. 사이트 글꼴은 로컬 파일로 제공하며 favicon과 공유 이미지는 현재 Lake 사이트 디자인을 사용한다.

- `SCR-WEB-003`: `/qr-code`에서 주소·텍스트 입력 → QR 미리보기 → 저장·복사·인쇄·확대. 연결 REQ는 `REQ-QR-001`, `REQ-WEB-020`, `REQ-WEB-021`, `REQ-WEB-022`, `REQ-WEB-027`이다.
