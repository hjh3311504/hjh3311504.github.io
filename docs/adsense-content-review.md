# AdSense 재심사 준비: 콘텐츠와 출처 점검

점검일: 2026년 9월 19일. 사용자가 기존 페이지 보강 계획의 설계·구현을 승인했다.

## 심사 결과와 점검 범위

첨부된 거절 안내는 ‘복제된 콘텐츠’와 ‘가치가 별로 없는 콘텐츠’를 지적한다. 문제 URL이나 복제 원문은 제시하지 않았다. 사용자는 최근 수정 후 신청한 결과라고 확인했다. 정확한 거절 원인은 확정하지 않는다.

기준은 Google의 [복제 콘텐츠 정책](https://support.google.com/publisherpolicies/answer/11190248?hl=ko)과 [사이트 품질 안내](https://support.google.com/adsense/answer/7299563?hl=ko)다. 외부 자료에 새로운 가치를 더하는지와 방문자에게 유용한 내용을 제공하는지를 확인한다. 라이선스 준수와 광고 승인은 별개의 판단이다.

현재 홈·팀 메이커·QR 코드·구슬 레이스의 공개 HTML과 소스를 확인했다. 공개 페이지는 HTTP 200으로 응답했고, 도구 사용 안내는 JavaScript 실행 전 HTML에 들어 있었다. 개인정보처리방침과 문의 경로도 있었다. 이 범위에서 외부 콘텐츠를 그대로 삽입하는 iframe이나 광고 실행 script는 확인하지 못했다. 인터넷 전체의 문구·이미지 유사성을 조사한 결과는 아니다.

## 남은 확인 항목

- `static/images/team-maker/`의 `laurel-1.png`·`laurel-2.png`·`laurel-3.png`, `confetti.png`, `stat-days.png`·`stat-win.png`·`stat-lose.png`·`stat-pick.png`·`stat-games.png`·`stat-people.png`, `favicon.svg`: 기존 문서는 묶음 전체를 자체 MIT에서 제외한다. 파일별 제작 경위와 사용 조건을 확인할 근거가 더 필요하다. 임의로 라이선스를 부여하거나 삭제하지 않았다. 2026-10-25에 PNG 10개는 직접 작성한 SVG로 교체해 해결했고, 단순 도형인 `favicon.svg`는 유지했다.
- `wrap-pop-ai-v1.wav`: 현재 뽁뽁이 효과음이다. 기존 문서·선택 JSON에서 이 파일명과 원음 또는 제작 기록의 명시적 연결을 찾지 못했다.
- `asmr-lava-ai-v1.wav`: 현재 젤리 연못과 연결된 효과음이다. 같은 이유로 원음 또는 제작 기록 확인이 필요하다.
- `typewriter-8-ai-v1.wav`: 코드에 등록돼 있으나 현재 타자기 선택은 도각2로 연결된다. 보존 파일의 출처 연결을 확인해야 한다.

파일명에 `ai`가 있다는 이유만으로 생성 도구나 이용 조건을 추정하지 않는다. 이 항목들이 실제 거절 원인이라는 뜻도 아니다. 현재 기록으로 확정할 수 없는 출처를 구분한 결과다.

## 구현 후 검증 결과

- `npm run check`: 오류·경고 0개.
- 변경 소스·검증 script·기존 테스트의 ESLint와 포맷 검사, README·이 점검 문서의 포맷 검사, `git diff --check`: 통과. 기존 포맷 제외 대상인 REQ·화면 문서는 형식을 유지하고 문서 연결 검사로 확인했다.
- `npm run build`: 1회 통과. `npm run verify:team-maker`: 새 안내가 4개 페이지의 정적 본문에 포함된 것을 포함해 통과.
- `python3 scripts/verify_ui_design.py docs/requirements docs/design --all`: UI REQ 31개·화면 4개 통과. 변경한 REQ-WEB-019·REQ-WEB-026·REQ-QR-001·REQ-MARBLE-005의 개별 연결 검사도 통과.
- 재build 없는 관련 Playwright 검사 6개: 최종 모두 통과. 공통 메뉴, PC·모바일 안내, 배정 규칙, 명단 저장·불러오기, 구슬 당첨 순위 범위, 스킬 설정을 확인했다. 최초 공통 메뉴 검사는 홈에 추가된 문의 링크와 기존 메뉴 링크를 동시에 찾아 실패했다. 검사 대상을 메뉴 내부로 좁힌 뒤 해당 1개만 재실행해 통과했다.
- Playwright CLI: 접근성 snapshot으로 안내 제목·본문을 먼저 확인했다. 홈·QR·구슬 레이스의 320px·390px·1440px 가로 넘침, QR 안내 2개·구슬 안내 4개의 독립적인 접기·펼치기, 홈과 구슬 안내의 도구 이동을 확인했다. QR 예제로 주소·제목을 입력하고 12개 인쇄 칸 생성과 인쇄 호출을 확인했다. 인쇄 호출은 실제 출력 대신 가로채 검사했으며 종이 출력·실물 스캔은 수행하지 않았다.
- 전체 단위 테스트·전체 브라우저 경기 검사는 실행하지 않았다. 변경 범위는 안내·스타일·문서와 관련 검증이며 배정·QR 생성·경기 로직은 바꾸지 않았다.

## 3번째 거절과 보강 (2026-10-15)

2026-10-15에 다시 ‘가치가 별로 없는 콘텐츠’로 거절됐다. 소유 확인은 ads.txt로 했다. 문제 URL은 제시되지 않았다.

Google 안내는 고유하고 유용한 내용, 쉬운 탐색, 약속한 정보 제공을 기준으로 든다. 글 수나 방문자 수의 공식 최소 기준은 없다. 참고: [사이트 준비](https://support.google.com/adsense/answer/12176698?hl=ko), [가치 있는 콘텐츠](https://support.google.com/adsense/answer/10015918?hl=ko), [필수 콘텐츠](https://support.google.com/adsense/answer/1348695?hl=ko).

| 사이트 설명이 포트폴리오처럼 보임           | 사이트·블로그 설명을 파일·이미지·데이터 가이드 중심으로 변경       |

| 프로그램 소개 글 3개가 약 1,100자           | 활용 상황·한계·FAQ·관련 글을 더해 각 약 2,950자로 보강             |

가이드 11개가 10월 5~15일에 공개됐고 예약 글 6개가 10월 21일까지 공개된다. 심사 시점에는 공개 글과 색인이 더 적었을 수 있다. 이번 보강도 승인을 보장하지 않는다.

재심사 전 확인:

1. AdSense 계정의 게시자 ID가 `pub-3102141816876720`인지 확인한다.
2. AdSense에서 Google CMP를 켠다.
3. 배포 뒤 Search Console에 sitemap을 다시 제출하고 새 페이지·보강 글의 색인을 요청한다.
4. 예약 글이 모두 공개되고 색인된 뒤, 약 2주 후에 재심사를 요청한다.

## 4번째 거절과 보강 (2026-10-25)

다시 ‘복제된 콘텐츠’와 ‘가치가 별로 없는 콘텐츠’로 거절됐다. 문제 URL은 제시되지 않았다. 공개 사이트의 canonical·sitemap·소개·방침·광고 코드는 정상이었다. 기술 설정보다 사이트가 보이는 방식에 원인이 있다고 추정한다. 결정은 [다른 서비스명과 블로그 주제 분류 ADR](adr/2026-10-25-AdSense-재심사-다른-서비스명과-블로그-주제-분류.md)에 남겼다.

코드로 해결하지 못한 위험도 있다. 가이드 글이 10월 5일부터 거의 매일 같은 구조로 공개됐다. 운영 기간도 짧다.

재심사 전 확인:

1. 매일 예약 공개를 멈추고 주 2~3개로 줄인다. 글마다 구성을 바꾸고 운영자의 실제 경험과 판단을 넣는다.
2. 겹치거나 짧은 글(CSV 3개, QR 2개)을 합치거나 보강할지 검토한다.
3. 배포 뒤 Search Console에 sitemap을 다시 제출하고 색인된 페이지 수를 확인한다.
4. 배포 뒤 최소 3~4주 운영 기록을 쌓고 재심사를 요청한다.
