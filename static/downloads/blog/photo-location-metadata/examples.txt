재현 기록

2026-10-15, macOS 26.6.2, ExifTool 13.55
개인 사진 대신 80x60px 단색 테스트 JPEG를 만들었습니다.
GPS 좌표는 명령으로 넣은 예시값이며 실제 촬영 위치가 아닙니다.

다운로드한 두 파일이 있는 폴더에서 실행합니다.

1. 원본의 GPS 정보 읽기
$ exiftool -a -G1 -s '-gps*' sample-with-gps.jpg
[GPS]           GPSVersionID                    : 2.3.0.0
[GPS]           GPSLatitudeRef                  : North
[GPS]           GPSLatitude                     : 37 deg 33' 59.40"
[GPS]           GPSLongitudeRef                 : East
[GPS]           GPSLongitude                    : 126 deg 58' 40.80"
[Composite]     GPSLatitude                     : 37 deg 33' 59.40" N
[Composite]     GPSLongitude                    : 126 deg 58' 40.80" E
[Composite]     GPSPosition                     : 37 deg 33' 59.40" N, 126 deg 58' 40.80" E

2. 원본을 보존하고 GPS 이름의 정보를 지운 복사본 만들기
$ exiftool '-gps*=' -o sample-without-gps.jpg sample-with-gps.jpg
    1 image files created

3. 복사본 확인하기
$ exiftool -a -G1 -s '-gps*' sample-without-gps.jpg
(출력 없음: 찾은 GPS 항목 없음)

4. 같은 출력 이름이 이미 있을 때 다시 실행
$ exiftool '-gps*=' -o sample-without-gps.jpg sample-with-gps.jpg
    0 image files updated
    1 files weren't updated due to errors
Error: 'sample-without-gps.jpg' already exists - sample-with-gps.jpg
종료 코드: 1

확인 결과
- 원본에서 GPSLatitude, GPSLongitude 등 GPS 항목이 나왔습니다.
- 복사본에서는 GPS 항목이 나오지 않았습니다.
- 두 파일의 픽셀 크기는 80x60px입니다.
- 원본 파일은 복사본 생성 뒤에도 그대로 남았습니다.
- 같은 출력 이름이 있을 때 실행이 실패하는 것을 위 명령으로 확인했습니다.
