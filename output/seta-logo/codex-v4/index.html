05 사선으로 자른 끝 ↗

좋아한 원본의 길이·몸체·굵기 대비를 유지했습니다. 가로획 끝만 사선으로 정리해 절삭 모서리와 어울리게 했습니다. 원본의 개성을 지키며 완성도를 높이는 방향입니다.

favicon64 ↓favicon16 ↓투명 심볼 ↓남색용 흰 심볼 ↓밝은 가로형 ↓어두운 가로형 ↓

final/ 적용 세트
favicon은 64×64 viewBox

작은 크기 · 16px 표시는 별도 전용 SVG를 사용합니다. 가는 부분을 보강하고 돌출 획을 단순하게 정리했습니다. 32px는 기본 SVG입니다.
다운로드 · 심볼·타일·가로형 SVG는 페이지 안에서 만들어 내려받습니다. 이 HTML 하나만 옮겨도 비교 그림이 표시됩니다. 글꼴만 요청한 SUIT CDN을 사용합니다.
색 적용 · 남색 모형의 큰 로고는 흰색, ③은 밝은 파랑 #9bd8ff입니다. 사이드바는 로고24px와 글자를 조합했습니다. 타일은 파랑 #0075de입니다.
검토 범위 · 선택한 v3-10의 획과 공간만 발전시켰습니다. 현재 시안은 실제 사이트에 적용하지 않았습니다.
