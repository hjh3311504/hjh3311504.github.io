# Seta Lab 홈 소개 문구 후보

제목은 모든 세트에서 **Seta Lab**을 유지한다. GitHub 버튼도 그대로 둔다. 대표 버튼은 아래 도구 목록으로 이동한다. 글자 수는 공백과 문장부호를 포함한다.

## 세트 1 — 도구와 가이드를 함께 소개

1. 위쪽 작은 글씨: **쓰는 도구, 읽는 가이드**
2. 한 문장 소개: **무료 웹 도구와 직접 확인한 내용을 담은 가이드를 만듭니다.**
3. 대표 버튼: **도구 살펴보기**
4. 특징 띠:

| 제목 | 설명 |
| --- | --- |
| 가입 없이 이용 | 설치나 회원가입 없이 도구를 사용해요. |
| 직접 확인한 글 | 실험한 내용과 확인 순서를 글로 전해요. |
| 손안에서도 이용 | 휴대폰 브라우저에서도 도구를 사용해요. |

- 장점: 도구와 글을 함께 소개해 사이트의 목적을 분명히 보여 준다.
- 걸리는 점: 특정 사용 상황이 없어 도구의 쓰임은 아래 목록에서 확인해야 한다.

## 세트 2 — 필요한 순간에 바로 사용

1. 위쪽 작은 글씨: **필요할 때 꺼내 쓰세요**
2. 한 문장 소개: **모임과 일상에서 쓸 무료 도구를 브라우저로 제공합니다.**
3. 대표 버튼: **쓸 도구 찾기**
4. 특징 띠:

| 제목 | 설명 |
| --- | --- |
| 준비 없이 시작 | 설치나 가입 절차 없이 바로 사용해요. |
| 비용 없이 사용 | 필요한 도구를 무료로 이용해요. |
| 모임 중에도 사용 | 모인 자리에서 휴대폰으로 도구를 사용해요. |

- 장점: 방문자가 도구를 언제 쓸 수 있는지 쉽게 떠올릴 수 있다.
- 걸리는 점: 도구 사용에 집중해 가이드와 블로그의 존재가 드러나지 않는다.

## 세트 3 — 만든 사람이 보이는 공간

1. 위쪽 작은 글씨: **세타가 만들고 기록해요**
2. 한 문장 소개: **세타가 혼자 만드는 무료 웹 도구와 직접 실험한 글을 소개해요.**
3. 대표 버튼: **만든 도구 보기**
4. 특징 띠:

| 제목 | 설명 |
| --- | --- |
| 직접 만들고 관리 | 세타가 도구와 글을 만들고 관리해요. |
| 이 브라우저에 저장 | 저장한 명단과 설정은 이 브라우저에 남아요. |
| 가입 절차 없이 | 회원가입이나 설치 없이 도구를 사용해요. |

- 장점: 운영자가 누구인지 드러내고 도구와 실험 글을 자연스럽게 연결한다.
- 걸리는 점: 제작자 소개가 앞서며, 저장 설명만으로는 기기 간 공유 여부까지 알기 어렵다.

## 세트 4 — 써 보고 읽어 보는 공간

1. 위쪽 작은 글씨: **써 보고, 읽어 보세요**
2. 한 문장 소개: **바로 쓸 무료 웹 도구부터 게임 가이드와 실험 글까지 모았어요.**
3. 대표 버튼: **도구 고르기**
4. 특징 띠:

| 제목 | 설명 |
| --- | --- |
| 필요한 도구 사용 | 설치나 가입 없이 브라우저에서 사용해요. |
| 게임 선택에 참고 | 챔피언별 증강과 아이템 정보를 확인해요. |
| 문제를 확인할 때 | 직접 실험하며 정리한 확인 순서를 참고해요. |

- 장점: 도구, 게임 가이드, 실험 글의 쓰임을 각각 구체적으로 알려 준다.
- 걸리는 점: 특징 띠가 콘텐츠 안내에 가까워 모바일 지원과 저장 방식은 전달하지 못한다.

## 세트 5 — 휴대폰에서도 쓰는 도구

1. 위쪽 작은 글씨: **손안에서 여는 도구함**
2. 한 문장 소개: **컴퓨터와 휴대폰에서 바로 쓸 수 있는 무료 웹 도구를 만듭니다.**
3. 대표 버튼: **도구 목록 보기**
4. 특징 띠:

| 제목 | 설명 |
| --- | --- |
| 앱 설치 없이 | 웹페이지를 열어 도구를 사용해요. |
| 휴대폰 화면에 맞게 | 휴대폰에 맞는 화면으로 도구를 사용해요. |
| 계정 만들지 않고 | 회원가입 없이 무료로 이용해요. |

- 장점: 휴대폰에서도 별도 앱 없이 쓸 수 있다는 점이 바로 드러난다.
- 걸리는 점: 작은 글씨와 소개, 특징 띠에 모바일 메시지가 반복되고 글 콘텐츠는 드러나지 않는다.

## 추천 — 세트 1

무료 웹 도구와 가이드를 함께 소개해 첫 화면만으로도 사이트의 목적을 알 수 있다.
가입 없는 이용, 직접 확인한 글, 휴대폰 지원을 나눠 설명해 내용이 겹치지 않는다.
특정 도구 이름이나 개수에 기대지 않아 도구가 늘어나도 그대로 쓸 수 있다.
